農場最核心的一圈很單純：買種子、播種、照顧、收成。這一頁帶你走過田地裡會遇到的事，以及每件事背後的小邏輯，讓你知道菜為什麼長得慢、為什麼枯了、為什麼這次收得特別少。

> 📱 App

## 為什麼這樣設計

- **照顧要有感，但不能太累。** 作物要澆水、會長雜草、可能生蟲，但水壺每天補滿，下雨還會自動幫你澆水，所以每天花一點時間就夠。
- **天氣會影響結果，而且你有辦法應對。** 好天氣長得順，壞天氣可以靠道具保護，收成不再是單純的「種了就有」。
- **收成帶一點運氣。** 每次收成的數量是隨機的，讓每塊田都有點期待感。

## 怎麼操作

### 📱 播種

1. 點**空田**，旁邊會彈出氣泡，按「播種」。
2. 在清單裡挑要種的種子。種子是從[商店](./growth-shop.md)買的，放在庫存裡，不占倉庫的格子。
3. 清單上變灰的種子會告訴你原因：不是這個季節可以種的，或是等級還沒解鎖。
4. 如果這株作物預計**來不及在換季前長好**，會先問你一聲「這株作物可能來不及在換季前成熟，仍要播種嗎？」，你可以選擇照種，只是它很可能會在換季時枯掉，見[季節、天氣與日夜](./season-weather.md)。

### 📱 照顧

點生長中的作物，氣泡會顯示作物名稱、**成長條**和**水分條**，並提供這幾個動作：

| 動作 | 做什麼 |
|---|---|
| 澆水 | 補水分，會用掉水壺的次數 |
| 除草 | 拔掉雜草，不用水壺 |
| 除蟲 | 清掉蟲害，不用水壺 |
| 使用道具 | 對這塊田用天氣、肥料、驅蟲等道具，見[季節、天氣與日夜](./season-weather.md) |

![生長中作物的氣泡：成長條、水分條，以及澆水、除草、除蟲、使用道具](/img/farm/gameplay-4.png)
*圖中：點生長中的作物，氣泡裡有成長與水分的進度條，下面是各種照顧動作*

#### 水分

- 作物每天都在消耗水分。**下雨會自動澆水**，不用你動手。
- 水分太低時，作物會**停止生長**；如果一直缺水沒人理，最後會**枯萎**。
- 每種作物耗水的快慢不同，晴天又熱的時候水分掉得更快。
- 沒有水壺次數時，「澆水」按鈕會變灰。這時可以等隔天補水，或等下雨。

#### 雜草與蟲害

- **雜草**會隨機長出來，田裡會看到草叢，作物會長得比較慢，直到你把它拔掉。
- **蟲害**在連續高溫又潮濕的日子裡特別容易出現，會讓這次收成的結果變差，要趕快除蟲。
- 也可以靠道具預防：驅蟲劑能清掉蟲害，並在一段時間內擋住新的蟲害。

田地上會直接用小圖示標出缺水、雜草、蟲害，不用點進去才知道。

![田地上的缺水、雜草與蟲害標記](/img/farm/gameplay-5.png)
*圖中：農場畫面上，需要照顧的田會顯示水壺、雜草或蟲害的小標記*

#### 日照與作物脾氣

不同作物對陽光和水的喜好不一樣：有的喜歡大太陽、有的喜歡陰天，有的不挑；有的很耗水，有的比較耐旱。這會影響它們在不同天氣、白天夜晚的生長速度。商店裡每種作物的卡片會用比較條，讓你看出它大概要長得久還是快。

有些作物收成後會重新結果，不用再播種，可以**多次採收**（例如番茄和莓果）。

### 📱 收成

作物長到成熟，田上會出現收成的標記。點作物，按「收成」。

- **收成的數量是隨機的。** 一般情況下，中間的數量比較常見；如果成長期間遇到沒有防護的壞天氣（強風、豪雨、寒流、晴熱缺水）或蟲害，結果會變得更不穩定，平均也比較差。**數量在作物成熟的那一刻就決定了**，之後再怎麼照顧也不會改變。
- 收成會給你經驗，累積起來就是升級，見[等級、商店與佈置](./growth-shop.md)。
- 收成的作物會先放進**倉庫**；倉庫滿了才會放進板條箱。如果倉庫和板條箱都滿了，這次收成會失敗、作物繼續留在田裡，所以收成前記得留出空間，見[賣出、倉庫與大頭菜](./market.md)。
- 成熟後如果一直沒收，作物不會消失，但它還是佔著田，**遇到換季或長期缺水一樣會枯萎**，別放太久。

![成熟的作物氣泡，有「收成」按鈕](/img/farm/gameplay-6.png)
*圖中：作物成熟後，點它會出現「收成」按鈕*

### 📱 枯萎與清除

作物枯萎之後會變成枯草，氣泡會顯示「已枯萎」，並提供「清除枯草」。清除前會再確認，清完這塊田才能重新播種。

![枯萎的作物氣泡，顯示「已枯萎」與「清除枯草」](/img/farm/gameplay-7.png)
*圖中：枯萎的作物只能清除枯草，清掉後才能再播種*

### 你不在的時候

作物在你關掉 App 的時候**照樣生長**。下次打開農場，會依經過的時間和那段時間的天氣集中補算，所以你不用為了顧田一直守著。單機農場是手機打開時補算，雲端農場則由伺服器照時間推進。

### 被偷之後

雲端農場裡，成熟的作物可能被農友偷走。被偷走當期收成的田會**休耕一陣子**，這段時間不能播種，多次採收的作物會暫停生長；點那塊田會顯示休耕中，詳見[社交](./social.md)。

## 注意事項／小提醒

:::tip
- **新手先種長得快的。** 剛開始解鎖的作物種類不多，挑成長期比較短的，可以更快看到收成、拿到經驗。
- **看一下天氣再決定要不要澆水。** 如果今天會下雨，就把水壺留著。
- **水壺不是萬能的。** 想要整片放著不管，可以考慮灑水器之類的道具。
:::

:::note
- 除草、除蟲、收成都不需要水壺，只有澆水需要。
- 道具只能用在**已經播種**的田，空田或已枯萎的田不能用。
:::
