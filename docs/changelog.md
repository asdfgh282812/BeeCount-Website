這裡整理每個版本使用者看得到的重點，由新到舊排列。App 內「我的」→「新功能！」可以選版本回頭看；App 與 Web 的更新依版本合併整理。

## 4.3.0

- **農場道具強化與搭配**：肥料加速更明顯，生長燈在夜間也會額外加速，雨雲罐與灑水器更容易入手。道具可搭配成滋養、夜耕、反季栽培或安心農區，依種植需求安排用途。見[道具搭配](./farm/season-weather.md#item-combinations)。
- **四季種子與農場物件用途**：商店能切換季節瀏覽種子，未解鎖作物會變灰；設備可先放空田，收成重種也保留未到期效果。水井可提供井水延長灑水器、木桶能收集雨水，告示牌可替農區命名。見[等級、商店與佈置](./farm/growth-shop.md)。

- **排行榜顯示農友佩戴徽章與新版獎勵分級**：主徽章帶名稱，其他佩戴只顯示圖示，最多三枚；匿名列不顯示徽章。記帳與豐收榜增加獎勵級距，神偷與守護榜前三名可獲名次獎勵，已公布週次不重算。見[排行榜徽章](./farm/social.md#leaderboard-badges)與[獎勵級距](./farm/social.md#leaderboard-rewards)。
- **共享帳本多人分帳與訪客連結**：可記錄單人或多人付款，以均分、金額、百分比或份數分攤，查看群組／個人統計、誰要付給誰，並記錄部分或全額還款。沒有帳號的朋友可用專屬連結在網頁參加；連結可設密碼，訪客也能換成自己的密碼。入口：App「帳本設定 → 成員管理 → 分帳與訪客」，Web 帳本卡片「成員/邀請」。分帳交易不帶帳戶，可另外記到自己的帳本。見[多人分帳與訪客連結](./sync/split-ledger.md)。
- **大頭菜本週價格走勢表**：大頭菜頁會用曲線與價目表，記下本週週一到週六每個時段已公布的收購價，並對照本週買入價；還沒到的時段留白，不會預告未來價格。入口：農場 → 市場 → 右上角大頭菜，見[大頭菜](./farm/market.md#turnips)。
- **單格隱藏小看門狗**：可以替雲端農場的一格當期作物佈置短時間保護，拜訪者看不到；每次佈置會抽出固定的抓到率加成。和全農場看門狗重疊時，小看門狗優先，只判定一次；抓到後仍須賠償、扣良心，但不加小偷標記。確認前會顯示費用與保護時間。入口：App 首頁 → 雲端農場 → 點有活作物的田地 → 佈置小看門狗。見[小看門狗](./farm/social.md#little-guard-dog)。
- **農場每日帳務挑戰**：每天第一次進入農場，隨機回答一道自己的帳務選擇題或是非題；題目明寫日期，顯示後有完整 15 秒，答對自動獲得 10 好幣。每天只有一次機會，答錯、逾時或離開即結束，結果以紅色與綠色搭配文字標示。入口：App 首頁 → 農場；Web 頭像選單 → 農場排行榜。見[每日帳務挑戰](./farm/daily-quiz.md)。
- **股票智慧加減碼**：台股上市、上櫃與美股可依前一交易日收盤價相對 60 個交易日均價，設定逢低／逢高的當期投入金額。定期定額表單可更新試算，買進紀錄保留當期判斷。入口：資產 → 投資理財帳戶 → 持股 → 定期定額。見[智慧加減碼](./invest/smart-dca.md)。
- **行事曆活動與花費**：App 可讀取手機行事曆，把新交易或已記的消費綁到聚餐、旅行等活動，並搜尋、看收支及活動報表。已建立的活動跟著帳本同步至 Web；手機原始行事曆不會整份上傳。入口：我的 → 提醒 → 行事曆整合，或首頁行程。見[行事曆活動](./record/activities.md)。

## 4.2.2

- **編輯交易保留原帳戶與轉帳日期**：修正編輯或複製支出、收入時未帶入原帳戶的問題，AI 記帳建立的交易也適用。編輯轉帳時也會保留原本的日期與時間，不再重設為現在。入口：交易詳情 → 編輯或複製。

## 4.2.1

- 回收桶的完整刪除、還原、重新下載步驟與示範圖，見[帳本回收桶](./prepare/ledger.md#recycle-bin)；股票及股利的試算／實際金額操作，見[跨幣別交割](./invest/overview.md#settlement-rate)。
- **股票交割金額可選擇是否採用線上匯率**：美股等外幣證券用幣別不同的帳戶（例如台幣）交割時，新增「採用線上匯率」開關：開啟時依線上匯率試算交割金額；關閉後可照銀行對帳單輸入實際扣款或入帳的金額，避免試算值和銀行實際金額不一致。新增交易預設開啟，編輯舊交易會保留原本金額。確認待領股利的實收金額，以及網頁版的買賣與股利表單也有同樣的開關。入口：資產 → 投資理財帳戶 → 新增股票交易 → 選擇幣別不同的交割帳戶。
- **刪除帳本會先進回收桶**：刪除帳本前會顯示交易數與附件數，帳本有交易時還要輸入帳本名稱才能確認。刪除的帳本會在回收桶保留 30 天，可以還原或永久刪除，App 與網頁版都能操作。還原後請在雲端帳本中點選該帳本重新下載。入口：帳本管理 → 右上角「回收桶」。

## 4.2.0

- **農場許願**：App 從商店發起、市場查看與供應，Web 從農場排行榜進入。發布預扣貨款，有效 24 小時，未成交部分到期退款；單人單次提供原始整張需求可獲系統補貼。見[農場許願](./farm/wishes.md)。
- **一般方案額度與永久加購名額**：帳本 3 本（可共享 1 本）、專案未封存 8 個／共 20 個、報表 4 張（含內建）、兩類存錢桶各未封存 2 個／共 8 個、交易範本 10 個。不夠用可到好好幣商店永久加購，支持者有效期間免除此數量限制；既有超額用量與方案到期的處理見[方案額度與購買名額](./sync/limits.md)。
- **好好幣商店與雲端容量**：畜牧取得的好好幣可換共享 AI 點數、永久名額及圖片空間，一般方案也能換 AI 點數。雲端圖片基本 5GB，可永久擴充；支持者期間暫免容量限制，到期超額會暫停新增上傳，原圖保留。見[好好幣商店](./farm/hh-shop.md)與[雲端圖片容量](./record/attachment.md#cloud-storage)。
- **共享帳本的邀請中標示與管理**：帳本卡片會標出進行中的邀請，App 新增「邀請碼管理」，可集中複製、分享或撤銷。未使用、未過期的邀請也會讓帳本占用共享額度，見[邀請碼管理](./sync/shared-ledger.md#invite-management)。
- **我的稱號與徽章**：記帳資歷、筆數、連續天數、功能探索、支持者與雲端農場共 33 枚徽章，可佩戴最多三枚並設定主稱號，App 與 Web 同步。App 入口在「我的」名字下方，Web 在頭像選單「我的稱號」。我的頁首改為左側頭像、右側問候語與徽章，下方保留記帳天數、筆數及帳本結餘。見[我的稱號與徽章](./more/badges.md)。
- **支持者每月農場禮包**：雲端農場的支持者可按月領取農場好幣、道具、種子與佈置券；年訂也逐月產生，待領禮包不會過期。入口：App 農場上方好幣膠囊 → 週結算；Web「農場排行榜 → 農場錢包」。見[支持者農場禮包](./farm/bookkeeping.md#supporter-gift)。
- **農友互助與採收入庫回饋**：拜訪時可用自己倉庫的作物幫忙放飼料，也能替被偷後休耕的田提供活力；植物照顧與放飼料共用每日額度，活力另有冷卻限制。採收成功後，作物會飛向倉庫或板條箱並顯示實際入庫數量。見[農友互助](./farm/social.md#help)與[採收入庫](./farm/gameplay.md#-收成)。
- **交易長備註**：商家列左右各半，右側新增獨立備註，最多 400 字，可換行並顯示字數。App 點擊後由下方彈出統一玻璃視窗，Web 在交易視窗內展開多行編輯；名稱與備註都能透過關鍵字搜尋。入口：新增／編輯交易 → 商家右側「備註…」。見[記帳欄位](./record/fields.md#名稱商家與備註)與[搜尋與批次處理](./record/search-batch.md)。

- **存錢桶**：為旅行、換手機、預備金設定目標金額與期限，隨意存，或切成每天、每週、每月的格子一格一格存（也有逐格遞增的 52 週挑戰）。可以指定存放帳戶，用收入、支出或轉帳搭配帳單標記存取，也可以只做純記錄；定期存可設到期提醒，達標時會先放花朵慶祝動畫再問你要不要封存。入口：App「規劃 → 未來的錢 → 存錢桶」，Web 頭像選單「記帳工具 → 存錢桶」。見[存錢桶](./record/savings.md)。
- **日期與時間選擇器**：選日期時點上方的「年月」可以直接選年份與月份，月曆高度固定不再忽高忽低；提醒時間改用與記帳相同的時間選擇器。
- **支持者方案附帶共享 AI 點數**：支持者方案每月附帶 50 點，AI 小助手與文字、圖片、語音記帳會用營運者分享的 AI，不用自己準備 API Key；第一次使用或好好幣兌換點數時開始算一個月，依用量（token）扣點，自己設定了服務商就用自己的、不扣點。在「我的 → 智慧記帳」最上方查看餘額。見[方案與購買](/pricing#共享-ai-點數)與[AI 記帳](./record/ai.md#共享-ai-點數)。
- **App 與 Web 都能直接購買授權**：在「授權」頁選擇一般或支持者方案、月訂或年訂，用信用卡付款後授權自動啟用，也會寄信給你。已有金鑰的話，按「已有金鑰？」展開輸入框。見[方案與購買](/pricing)與[授權金鑰](./sync/license.md)。
- **定期定額自動續扣**：月訂與年訂都可以選定期定額，比單次購買便宜，每期自動扣款並延長授權，隨時可以在授權頁取消，已付款的期間照常可用。見[取消自動續扣](./sync/license.md#取消自動續扣)。

## 4.1.4

- **分期付款可以編輯了**：設錯首次日期不用再刪掉重來。分期交易的編輯可選「修改此記錄」或「修改此記錄與之後各期」，開的是跟記帳一樣的編輯表單；改金額會問後面各期怎麼調整，改日期會讓之後每期都落在那一天；分期付款頁的計畫卡也能「編輯」整個計畫。入口：App「規劃 → 未來的錢 → 分期付款」，Web 頭像選單「記帳工具 → 分期付款」。見[分期付款](./record/installment.md#修改這一期與之後各期)。
- **修正分期付款的畫面排版**：分期交易的編輯選單在小螢幕或大字級下底部不再被截斷，分期計畫卡的「刪除」也不再單獨掉到最下面一行。

## 4.1.3

- **修正農場臭蟲**：修正種菜時誤判時間倒退的問題，並移除農場操作時的「正在同步…」提示。

## 4.1.2

- **手續費輸入更順手**：新增交易的手續費與折扣金額更好點選，小算盤可輸入與計算到小數點後 6 位，並提供可取消或修改的 1.5% 手續費建議。 手續費與折扣可收起並保留，主金額下方會顯示簡短摘要。
- **農友的天氣與小動物**：拜訪農友時，場景會呈現對方農場的雨、雪與夜景，也能看到養的小動物走動。清醒時進入農場，小動物已散落各處；睡覺時間則待在農舍裡。
- **農場操作更流暢**：從首頁進入農場，種植與照顧作物會立即回饋，並在背景同步。一塊田地等待確認時，可接著照顧其他田地。

## 4.1.1

- **月報表**：到「報表 → 月度帳單」選擇本月或上月，查看收支摘要，也能隱藏收入、存到相簿或分享。報表字體放大、配色更清楚，閱讀更輕鬆。見[月報表](./analysis/statistics.md#monthly-report)。
- **修復其它小臭蟲**：修正 Android 底部導覽列遮住操作元件的問題，並改善訂閱編輯時開啟選擇器的操作。

## 4.1.0

- **訂閱管理**：在「規劃 → 週期記帳 → 訂閱」管理訂閱、免費試用與續訂提醒，查看付款行事曆及支出分析，App 與 Web 都能使用。見[訂閱管理](./record/subscriptions.md)。
- **AI 助手更好用**：支援拆帳、手續費、折扣、借還款與週期排程，也能查手冊回答使用問題，並保存最近 20 個對話，登入帳好嗎 Cloud 後可在 App 與 Web 接續查看。見[AI 記帳](./record/ai.md)與[AI 聊天與查帳](./record/ai-chat.md)。
- **不連網也能 AI 記帳**：支援的手機可在「我的 → 智慧記帳 → AI 服務管理 → 執行策略」選擇本機優先或僅本機，使用內建模型處理基本記帳與查帳，不需 API Key；進階功能仍需雲端，Web 可管理策略。見[裝置內建 AI](./record/ai.md#on-device)。
- **農場可以養動物、擴地了**：雲端農場新增畜牧、副產品販售、加買攤位與橫向擴地，作物長得更快，配樂也會隨季節、日夜與雨天切換。見[畜牧](./farm/livestock.md)、[商店與成長](./farm/growth-shop.md)與[農場設定](./farm/settings.md)。
- **農場錢包可查交易紀錄，大頭菜改為專屬入口**：農場 → 好幣 → 週結算 → 交易紀錄，可查近 7 天好幣收支，Web 的農場排行榜也能唯讀查看；大頭菜不再能上架市場，只能在大頭菜頁（週一到週六）或到農友農場賣，並換上專屬圖示。見[好幣交易紀錄](./farm/bookkeeping.md#wallet-history)與[大頭菜](./farm/market.md#turnips)。
- **日常操作更方便**：新增附件集中清理、台灣銀行與支付圖示、帳戶分類與搜尋、每筆交易後餘額及新手圖示預覽，並統一一般帳戶交易清單。見[附件](./record/attachment.md#all-attachments)、[帳戶](./prepare/account.md)與[資產總覽](./prepare/account-overview.md)。
- **資料與報表入口更集中**：Web 將分類、標籤與專案集中在「資料」，「報表」可切換統計與比較報表，並與 App 共用報表清單與儲存條件。見[Web 版](./sync/web.md#data)、[統計報表](./analysis/statistics.md#web)與[比較報表](./analysis/comparison.md)。
- **修復其它臭蟲**：修復無故登出、信用卡繳款後仍提醒等問題，減少閒置耗電，並改善頁首與 AI 等待提示。

## 4.0.1

- **過夜後不會再被登出**：App 放在背景過夜再打開，不會再無故跳出「尚未登入雲端同步」要你重新登入。手機在背景收通知時和 App 同時更新登入狀態，以前偶爾會讓其中一份失效，現在已經修好。如果這次更新前已經被登出，重新登入一次即可。
- **農場連線與餘額調整更穩定**：改善農場斷線後的恢復，連線失敗時可重新嘗試；修正調整帳戶餘額時的彈窗錯誤，並改善啟動、分頁切換與圖表日期切換。
- **銀行利息自動記帳**：資產 → 銀行卡帳戶 → 帳戶資訊 → 存款利息：設定分級利率、優惠期間與每月或每半年付息，自動記錄後仍可調整實付金額。

## 4.0.0

4.0 是一次大改版：改名、換新面貌、功能入口重新整理，還多了農場。從 3.x 直接更新就好，資料、登入與授權金鑰都會保留。

- **改名「帳好嗎 TallyCheck」，換上新 logo 與新芽綠**：App、**帳好嗎 Cloud** 與網頁版都改名，換新 logo、吉祥物「好好」與新芽綠的色調，標語是「你的帳，還好嗎？」。你原本的資料、登入狀態與桌面小工具都不受影響，見[常見問題](./faq.md#改名了我的資料和登入還在嗎)。
- **東西搬家了**：這一版重新整理各功能的位置，最常用的幾個新位置是：
  - 底部「專案」分頁改叫「規劃」，應收應付、分期付款、週期記帳、訂金尾款、交易範本都搬進來；「明細」分頁改叫「首頁」，頁首的「明細」改叫「全部交易」。
  - 帳本管理在「我的 → 資料管理」；帳本的名稱、幣種、每月起始日、成員、清空、刪除集中在「帳本設定」（長按帳本 → 設定，或首頁帳本清單裡目前帳本旁的設定按鈕）。
  - 原本很長的「個性化設定」拆成「我的 → 外觀、一般、記帳偏好、隱私與安全」，桌面小工具也在同一組。
  - 年度帳單搬到「報表」頁最上面；「我的 → 雲端帳號與同步」把雲服務、同步與已登入裝置整合成一個管理首頁；「我的 → 智慧記帳」集中拍照、相簿、語音與常用偏好，服務商與模型在「AI 服務管理」。
  - 總預算拿掉了，要控制花費請用規劃裡專案的預算。長按帳戶或報表現在會開選單（編輯、複製、刪除…），要調整順序請選「編輯排序」。

  找不到功能時，看[常見問題](./faq.md#以前的功能搬到哪裡了)的對照表，或到「我的 → 功能說明」重看導覽。
- **記帳頁新排版與快速記帳**：分頁精簡成「支出、收入、轉帳、借貸」（借貸頂部切換應收或應付）；原本的「建議」分頁變成頂部一排「建議分類」；週期、分期、訂金尾款改成表單底部直接切換的「一般／週期／分期／訂金」；金額字變大，太長時會縮小而不是被截掉，支出、轉帳、借貸共用同一個確認鍵。在任何分頁長按底部中間的鍵，都能選拍照、相簿、語音或「範本」，選範本就直接帶入記帳。入口：首頁中間的「記帳」鍵。見[記第一筆帳](./record/first-record.md)、[交易範本](./record/template.md)。
- **首頁、交易詳情與待處理中心更清楚**：首頁日曆預設只顯示一週，今天的交易一進來就看得到，需要時再展開整個月；交易詳情以金額為主，有附圖時分類金額卡會用照片當背景。首頁右上角的鈴鐺變成常駐的「待處理中心」，待補的訂金尾款、待確認的股利、還沒補選帳戶或專案的交易與雲端通知都集中在這裡；旁邊的眼睛可以一鍵隱藏金額，資產頁頁首也有。開啟首頁的 AI 對話泡泡，輸入框上方會依帳本與對話顯示建議，點「換一組」看其他問題。見[通知與提醒](./more/notifications.md)。
- **全新介面質感**：導覽列、篩選選項、分段切換與確認按鈕換上玻璃材質，到「我的 → 外觀 → Liquid Glass」選擇清透、平衡或厚霧；分段選項也能按住左右拖曳，放開後切換。全 App 的操作圖示統一成圓潤風格，底部分頁選取後變成主題色實心。各頁列表與卡片外觀統一，大字體下長金額會縮小而不是被擠出畫面，載入失敗也能直接重試。見[外觀](./more/appearance.md)。
- **信用卡回饋即時出現，每張卡有自己的提醒**：消費勾選回饋規則後，回饋交易會立刻出現在入帳日，金額隨消費即時更新；金額可以直接改，差額會像拆帳一樣多一條「手動調整」，之後重算也會保留。選「僅手動入帳」的規則，在回饋明細頁按「手動入帳」記一筆。各卡的繳費提醒可以沿用全域預設，或個別設定提醒時間、提前與連續提醒。入口：資產 → 信用卡 → 帳戶資訊 → 紅利回饋、提醒；或我的 → 提醒 → 信用卡繳費提醒。見[紅利回饋](./credit-card/rewards.md)。
- **雲端同步更穩、更清楚**：伺服器暫時連不上（例如更新中）時，App 會跳出提示，「我的 → 雲端帳號與同步」也會顯示「伺服器連不上」；你仍維持登入，記錄先存在這台裝置，恢復後自動同步。雲端的帳戶、分類或標籤比手機多、而且手機沒有待上傳的變更時，下拉重新整理會自動完整重新拉一次。登入過期或這支手機被遠端登出時，可以按「繼續離線使用」繼續記帳，重新登入同一個帳號後接續同步；自己按「登出」才會清除本機資料。共享帳本的邀請連結改用你自己的伺服器網址，在網頁開啟會先登入並直接加入帳本，網頁上的「用 App 開啟」會跳到「加入共享帳本」並自動填好邀請碼。見[雲同步與離線](./sync/overview.md)。
- **首次登入個人化引導**：全新帳號第一次登入後，可以依序設定外觀與 AI，再輸入名稱、選擇幣種建立第一本帳本（必要），接著建立第一個帳戶或略過。App 與網頁版都有。見[安裝與登入](./preface/install-login.md#首次登入個人化引導)。
- **網頁版同步改版**：網頁版也換上新名稱、色調與玻璃質感，右下角多了浮動的 AI 助手，頭像選單改成分組、一次展開一組，新增農場排行榜（只能看排名，不能玩）；啟用「可愛類別圖示」後，編輯分類時可以用搜尋框找彩色圖示。見[Web 版](./sync/web.md)。
- **帳好嗎農場開張**：首頁多了一座全畫面的像素農場：用好幣買種子、佈置田地與建築、照顧作物、看天氣收成；每天記帳、每週依記帳習慣領好幣。登入後農場跟著帳號走，換手機也能繼續，還可以拜訪農友、看每週排行榜。好幣是遊戲幣，不能用真錢買，也不影響你的記帳資料。入口：首頁的農場入口。見[農場](./farm/overview.md)。

## 3.9.1

- **股票買賣可設定交割日（T+2）**：買進或賣出股票時，多了「交割日」：成交當天股數就會變動，但帳戶的錢要到交割日才會真的扣款（買進）或入帳（賣出）。沒特別選的話預設是成交後第 2 個營業日，遇週末與休市日會自動順延；券商實際的扣款日不同時可以自己改。例如 10/12 買 0050，轉帳會當下就建好、日期記在 10/14，10/14 上午才會從帳戶扣掉。舊的交易不受影響，定期定額維持原本的扣款方式。網頁版的買賣表單也有同樣的交割日欄位。入口：資產 → 投資理財帳戶 → 新增股票交易 → 交割日。

## 3.9.0

- **交易範本上線 App，還會記住你常用的**：把固定的記帳（一杯拿鐵、加油、每月轉帳）存成範本，下次點「名稱」欄就整組帶入。範本會記住類別、金額、帳戶、商家、標籤、專案、幣別、手續費／折扣、不計入收支／預算與信用卡回饋；金額每次不同的可以留 0，套用時再填。用得越多的範本排越前面，也能切回手動排序。範本會跟**帳好嗎 Cloud** 同步，Web 的範本表單也補齊了同樣的欄位，並加上搜尋與排序。入口：記帳頁「名稱」欄最右邊的 ☆ 存成範本、點「名稱」欄套用，管理在「我的 → 交易範本」。見[交易範本](./record/template.md)。
- **訂金尾款追蹤**：先付訂金、之後才付尾款（訂飯店、訂餐廳、訂做家具）時，記訂金時打開「訂金尾款追蹤」，填尾款金額與日期（都可以先留空）。尾款補上之前不計入統計與帳戶餘額，到期當天提醒你，並在首頁當天列表出現一列「待完成交易」；補上後成為一般記錄，沿用訂金的類別、專案和商家。Web 也有「待完成交易」頁。見[訂金尾款追蹤](./record/deposit.md)。
- **通知中心加上分類，待完成交易直接列出**：新增「全部、待完成、欠還款、信用卡、週期、系統」分頁，各有未讀數；待補的尾款直接列在「待完成」分頁，點一筆就能補上。見[通知與提醒](./more/notifications.md)。
- **信用卡結帳日遇假日自動順延，還能單期調整**：①結帳日遇到週末或所選地區的假日，自動延後或提前；②繳款期限可選「每月固定日」或「結帳日後第 N 天」；③銀行某一期的結帳日臨時不同時，可以只調那一期，或每一期都改，並可一鍵還原預設。Web 的帳戶編輯也有前兩項。見[信用卡設定](./credit-card/setup.md#結帳日遇假日與繳款期限-)。
- **搜尋篩選與批次修改變多了**：搜尋可依類型、帳戶、標籤、專案、商家與特殊狀態（不計入收支／預算、拆帳、退款、週期產生）篩選；批次操作除了備註與分類，也能一次修改帳戶、日期、標籤、專案、商家與不計入設定，動作列可左右滑動。同時修正了批次改備註或分類時，會把交易原有商家與信用卡回饋勾選一併清掉的問題。見[搜尋與批次處理](./record/search-batch.md)。
- **換匯轉帳會顯示換到的金額**：不同幣別帳戶之間轉帳，交易資訊卡會在金額下標出「→ JPY 30,000」這類換到的外幣金額，不再出現看不懂的「≈」數字。見[轉帳](./record/transfer.md#換匯轉帳會顯示換到的金額)。
- **對帳模式的拆帳交易不再只顯示「-」**：拆成多個分類的交易在對帳模式與信用卡回饋明細顯示「多類別」，在對帳模式點一下還能展開每個類別各是多少錢。見[對帳模式](./reconciliation/mode.md#拆帳交易顯示多類別)。
- **建議分頁標出支出／收入**：記帳頁「建議」分頁的圖標右下角多了「支」「收」小圓圈；共享帳本（編輯者）裡不再推薦你本機自己的分類，改成只推薦帳本主人的分類。見[記第一筆帳](./record/first-record.md)。
- **資產頁圖表分開顯示收入與支出**：走勢圖下方原本只有收支相抵後的金額，現在分別顯示選取日期的支出與收入；放得下就顯示完整數字，放不下才縮寫成 k／w。見[資產總覽與淨值](./prepare/account-overview.md)。
- **帳戶餘額趨勢標出金額、可滑動查看**：帳戶頁的餘額趨勢圖右側有金額刻度，標題列顯示選取那天的餘額；手指在圖上點一下或左右滑動，就能看到任一天的餘額與金額泡泡。見[資產總覽與淨值](./prepare/account-overview.md)。

## 3.8.3

- **使用說明換成新的說明書**：我的 → 使用說明 改成開啟新的**帳好嗎**說明書網站，各項功能都有一步一步的操作說明。
- **分類顏色可自訂、可一鍵平均分配**：編輯分類時可以用自訂調色盤挑任何顏色；也可以點一下調色盤圖示，把所有分類的顏色平均分配在整個色盤上。入口：我的 → 資料管理 → 分類管理（右上角調色盤圖示）；自訂顏色在編輯分類的顏色列最後面。

- **股票定期定額改用成交日開盤價，並避開休市日**：股票定期定額現在以「成交日當天的開盤價」成交，開盤前會等待，不再拿前一天的價格去買。遇到週末或休市日：每月、每年、每 N 週的規則順延到下一個交易日，每日與每週指定星期幾的規則略過該天。休市日表跟節日資料一起自動更新，不用等 App 改版。入口：資產 → 投資理財帳戶 → 定期定額（下次執行日會顯示實際成交日）。
- **Cloud 通知在 App 沒開時也能跳出來**：**帳好嗎 Cloud** 的通知（信用卡帳單、繳款日、提醒等）現在會在背景定期拉取，即使沒有開著 App 也會跳出系統通知。喚醒時機由系統決定，可能延遲數分鐘到數小時，而且從多工畫面把 App 滑掉後就不會再喚醒。入口：不用設定，登入**帳好嗎 Cloud** 後自動生效；通知列表在首頁右上角的鈴鐺。
- **信用卡通知不開 App 也會準時跳**：登入**帳好嗎 Cloud** 時，信用卡提醒（帳單已結算、到期前 7 天、今天到期、已逾期）現在會直接排程在手機上，不用開著 App 也會準時跳出來。時機與文案跟你原本在通知列表看到的 Cloud 通知一致，提醒時間沿用 我的 → 自動化 → 信用卡繳費提醒 裡設定的時間。金額是你上次使用 App 時的快照，每次開啟或離開 App 時會更新。入口：不用設定，登入**帳好嗎 Cloud** 後自動生效。
- **通知可以看完整內容**：點通知現在會彈出詳情面板，顯示完整標題、全文與確切時間，太長的公告不會再被截斷。如果通知有對應的項目（信用卡、欠款等），面板上有「前往查看」按鈕可以直接跳過去。入口：首頁右上角鈴鐺 → 點任一則通知。

- **股票漲跌顏色可單獨設定**（預設紅漲綠跌），並與 Web 同步。見[外觀](./more/appearance.md)。
- **零股手續費與券商一致**，並修正報價有時停在前一個交易日的問題。見[股票持股](./invest/overview.md)。

- **通知設定跟著帳號走**：記帳提醒與信用卡提醒換裝置會自動套用。見[通知與提醒](./more/notifications.md)。
