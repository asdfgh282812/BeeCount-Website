歡迎。這本手冊寫給「想把每一筆錢記清楚」的你：刷卡、分期買手機、跟朋友分攤旅費、每月定期定額買 0050，都可以在蜜蜂記帳裡處理。你不需要懂程式，也不需要先看完整本，照著需要的章節翻就好。

## 這是什麼

蜜蜂記帳是一款記帳 App，這個客製化版本在原本的記帳功能之外，加強了信用卡（結帳日、繳款日、回饋）、股票投資、分期、借還款、對帳等台灣使用者常用的功能。

這個版本有幾個和一般 App 不太一樣的地方，先知道比較不會卡關：

- **不在 App Store 或 Google Play 上架。** Android 是直接安裝 APK 檔（App 內可以自己檢查更新），iOS 是透過 SideStore 側載。細節見[安裝與登入](./preface/install-login.md)。
- **一定要登入 BeeCount Cloud。** 你的帳本存在雲端伺服器上，手機、平板、網頁共用同一份資料。第一次打開 App 會依序要你輸入伺服器位址、登入、輸入授權金鑰。
- **帳號由管理員提供。** 這個版本不開放自己註冊，授權金鑰也是管理員發給你的。

## 手冊怎麼讀

每一頁都用同樣的順序寫：

1. 先說這個功能解決什麼生活問題。
2. `為什麼這樣設計`：用一兩句話交代設計的想法，例如信用卡帳單週期為什麼這樣算。
3. `怎麼操作`：一步一步的操作，按鈕名稱用「」標出來，和畫面上的字一致。
4. `注意事項`：預設值、限制、容易誤會的地方。
5. `相關頁面`：接下來可以看哪裡。

第一次使用的話，建議照這個順序看：

1. [安裝與登入](./preface/install-login.md)，把 App 裝好、登入。
2. [教學指引](./preface/guideline.md)，了解手冊裡的符號與先後順序。
3. 「準備」章節，建好帳本、帳戶、分類。
4. 「記帳」章節，記下第一筆帳。

## 符號說明

| 符號 | 意思 |
|---|---|
| 📱 App | 這個功能在手機 App 上操作 |
| 💻 Web | 這個功能在網頁版上操作 |
| 🔖 | 進階功能。新手可以先跳過，等日常記帳熟了再回來看 |
| 💡 | 小技巧 |
| ⚠️ | 容易出錯或不可復原的地方 |

頁面開頭的 `📱 App　💻 Web` 表示兩個平台都有這個功能；只標一個，就代表只有那個平台能用。

## App 與 Web 怎麼分工

App 和 Web 看到的是同一份資料，在一邊記帳，另一邊幾秒內就會更新。兩邊大致這樣分：

| | 📱 App | 💻 Web |
|---|---|---|
| 適合 | 隨手記一筆、拍照記帳、語音記帳 | 一次整理很多資料、看大張報表 |
| 只有這裡有 | 自動記帳（iOS 捷徑、Android 截圖）、桌面小工具、App 鎖 | 交易範本、比較報表、批次處理交易、⌘K 命令面板 |
| 其他 | 記帳、帳戶、信用卡、投資、報表等大部分功能 | 同左，介面不同但資料互通 |

Web 版怎麼登入與使用，見[Web 版](./sync/web.md)。
