# 交易範本

> ⚠️ **僅 Cloud 版可用**：本頁功能是 BeeCount Cloud（自建服務端）獨有的進階功能，純 App 本機記帳沒有這個入口。

每天都要記的星巴克咖啡、公車錢這類固定消費，存成範本後一鍵套用就能產生一筆交易，不用每次都重新選分類、選帳戶。

## 開啟入口

右上角**頭像** → 「工具」分組 → **交易範本**。

## 建立範本

| 欄位 | 說明 |
|---|---|
| 名稱 | 範本的名字，例如「星巴克咖啡」 |
| 類型 | 支出 / 收入 / 轉帳 |
| 金額、分類、帳戶、備註 | 存好之後套用時預設帶入這些值 |
| 標籤 | 選填 |

![交易範本列表](https://photo.pnsgzomf.synology.me/i/2026/08/11/6a79f90c109f3.png)

## 套用範本

列表上點「套用」，只需要確認（或修改）發生時間，金額/備註也可以當次覆寫，其餘欄位（分類、帳戶）直接沿用範本設定，一鍵就產生一筆真實交易——不是先開表單再手動填。

## 跟週期性收支的差別

[週期性收支](./recurring.md)是「設一次、系統自動按時間產生」，交易範本是「你自己手動按一下才產生一筆」——固定會發生、不想每次手動點的用週期性收支；不固定什麼時候發生、但常常要記的用交易範本。
