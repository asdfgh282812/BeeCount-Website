一起旅行時，小晴先付住宿、小宇付餐費，最後到底誰要補給誰？開啟「分帳模式」後，每筆交易都能記下付款人與分攤的人，帳本會整理出「誰需要支付誰多少」。沒裝 App、沒有帳號的朋友，也能用自己的訪客連結參加。

> 📱 App　💻 Web　4.3.0 新增。擁有者與帳號成員需要登入**帳好嗎 Cloud**並具有效授權；訪客使用瀏覽器，不需要註冊帳號或安裝 App。

:::note 圖片使用示範資料
以下以「週末旅行」、小晴、小宇與小安示範操作。名稱、帳號、連結、密碼與金額均為虛構資料。
:::

## 先選適合的記法

| 想解決的事 | 使用功能 |
|---|---|
| 幾個人共同花費，最後計算誰要付給誰 | 本頁的「分帳模式」 |
| 一張發票分到食材、日用品等多個分類 | [拆帳與退款](../record/split-refund.md) |
| 自己代墊一筆，想在個人帳本追蹤對方何時還錢 | [借還款](../record/debt.md)，或拆帳裡的應收明細 |
| 只想讓家人共同記帳，不需要計算分攤 | [共享帳本](./shared-ledger.md)，不用開啟分帳模式 |

**分帳交易不帶帳戶，不會直接扣你的現金或信用卡餘額。** 這本帳用來整理共同花費；想讓自己的帳戶也留下付款紀錄，可使用下方的[記到我的帳本](#personal-ledger)。

## 開啟分帳模式 {#enable}

只有帳本擁有者能開關分帳模式與邀請訪客。建議替這次旅行或共同生活建立一本專用帳本，方便查看整段期間的花費。

### 📱 App

1. 到「我的 → 資料管理 → 帳本管理」，在要使用的帳本點 ⋯ →「設定」，進入「帳本設定」。也可以從首頁帳本清單，點目前帳本旁的齒輪。
2. 點「成員管理」。
3. 找到下方的「分帳與訪客」，開啟「分帳模式」。
4. 要邀請有帳號的朋友，使用原本的「邀請新成員」；要邀請沒有帳號的朋友，再開啟「邀請訪客」，依[訪客連結](#guest-links)的步驟操作。

切換到分帳帳本後，底部分頁會變成「首頁」「統計」「我的」，記帳使用右側獨立的「+」按鈕。切回一般帳本，就會恢復原本的分頁。

![App 成員管理列出小晴、小宇與訪客小安，下方已開啟分帳模式及邀請訪客](/img/sync/split-app-members.png)
*圖中：帳號成員與訪客在同一份清單，下方「分帳與訪客」集中管理兩個開關。*

### 💻 Web

1. 從頭像選單進入「帳本」，找到要使用的帳本。
2. 點卡片的「成員/邀請」，在「成員與邀請」視窗往下找到「分帳與訪客」。
3. 開啟「分帳模式」；需要免帳號參加時，再開啟「邀請訪客」。

![Web 週末旅行的成員與邀請視窗，顯示成員、分帳開關與訪客連結](/img/sync/split-web-members.png)
*圖中：Web 的「成員與邀請」視窗，下方可開啟分帳、邀請訪客與管理連結密碼。*

:::note 原本的交易會怎樣？
開啟分帳模式不會自動替舊交易補上付款人與分攤。分帳統計與債務關係只計算有分攤資料的交易，舊交易仍保留在帳本裡。
:::

## 成員與訪客有什麼不同？ {#people}

| 身分 | 如何加入 | 主要權限 |
|---|---|---|
| 擁有者 | 建立帳本 | 管理帳本、帳號成員、分帳設定與訪客連結，也能記帳與結算 |
| 帳號成員 | 登入後接受 6 碼邀請 | 在 App／Web 共同記帳、查看分帳統計與債務關係、記錄還款；不能管理訪客連結與帳本設定 |
| 訪客 | 開啟自己的專屬連結，首次填暱稱 | 在網頁記帳、查看分攤明細與統計、記錄涉及自己的還款；只能修改或刪除自己建立的交易 |

- 帳號成員最多 **5 人，含擁有者**。
- 分帳參與者（帳號成員加訪客）最多 **20 人**；有效訪客連結最多 **20 條**。訪客不占前述 5 人的帳號成員名額。
- 訪客不能查看帳戶、成員的電子郵件，或沒有分攤資料的舊交易，也不能管理帳本。

分帳模式開啟後，成員與已取暱稱的訪客會列在同一份「成員管理」清單，訪客旁會標示「訪客」。

### 改帳本內的名稱與頭像

在「成員管理」點自己的那一列或編輯按鈕，可修改這本帳本使用的名稱與動物 emoji 頭像。擁有者可以替任何參與者修改；一般成員只能改自己。訪客則可在訪客頁點自己的名稱與頭像修改。

這些變更只影響這一本分帳帳本，付款人、債務關係與統計會使用新名稱；帳號本身的暱稱與大頭貼不變。

## 記一筆共同花費 {#add-entry}

📱 在 App 切到分帳帳本，點右側「+」。💻 在 Web 切到該帳本，按「建立交易」。訪客使用網頁的「記帳」分頁。

1. 選支出或收入，輸入這一筆的**總金額**與幣別。
2. 視需要選分類、填備註與日期時間；分類可以留空。
3. 在「誰付的錢」選付款人。兩個人以上一起付款，使用「多位付款人」。
4. 在「怎麼分」選擇分攤方式。
5. 在「分給誰」選真正要負擔這筆費用的人，核對每人的金額，再儲存。

**付款人與分攤的人可以不同。** 例如小晴先付兩人的晚餐 900 元，付款人選小晴，分攤選小晴與小宇並均分；兩人各負擔 450 元，債務關係會顯示小宇需要付給小晴 450 元。

![App 新增分攤支出表單，總額 1200 元由小晴付款，小晴、小宇與小安各分攤 400 元](/img/sync/split-app-entry.png)
*圖中：另一個三人聚餐範例，總額 1,200 元，付款人與「分給誰」分開選；三人均分各 400 元。*

### 四種分攤方式

以下以 900 元、三人一起分攤為例：

| 「怎麼分」選項 | 填法 | 結果 |
|---|---|---|
| 均分 | 選三人 | 每人 300 元 |
| 金額 | 直接填每人金額，例如 200、300、400 | 三人的金額合計必須等於 900 |
| 百分比 | 例如 20%、30%、50% | 分別為 180、270、450 元；百分比合計必須是 100% |
| 份數 | 例如 1、1、2 份 | 分別為 225、225、450 元 |

至少要選一位分攤的人。無法整除時，系統會依幣別的小數位處理零頭，儲存後可在詳情核對每人的實際分攤金額。

### 多位付款人

在「誰付的錢」點「多位付款人」，填入每人實際出的錢。例如總額 1,200 元，小晴付 800、小宇付 400，再由三人均分：每人負擔 400 元，小宇已付足自己的份額，第三人仍需補給小晴 400 元。

- 至少要有兩位付款人，各自的付款金額都須大於 0，合計須等於交易總額。
- 可用「填入剩餘金額」補足尚未分配的付款額；App 以「+」操作。
- 修改交易總額後，也要重新核對付款與分攤金額。
- 要改回單人付款，在付款人區重新選一位即可。

![App 多位付款人頁，小晴填 800 元、小宇填 400 元，已分配合計等於 1200 元](/img/sync/split-app-payers.png)
*圖中：改成小晴付 800、小宇付 400，右上角按「完成」回到分帳表單。小安填 0，表示沒有先付款。*

### 外幣與匯率

旅費可用消費當時的幣別記錄，付款與分攤都先以**交易原幣**計算，債務關係與分帳統計再換算為**帳本幣別**。

- 📱 App：點金額旁的幣別切換；選外幣後，點下方「≈」換算金額可調整匯率。關閉「採用線上匯率」，就能填自己的換算金額或匯率。
- 💻 Web／訪客：選外幣後按「編輯匯率」，關閉「使用線上匯率」後填自訂資料。
- 自訂匯率須大於 0。線上匯率暫時取不到時，可填有效的自訂匯率，或改回帳本幣別。
- 編輯既有外幣交易、幣別未變時，會沿用該筆原本的換算匯率；需要改匯率時再自行調整。

### 查看、修改或刪除

點一筆分帳交易，可看到金額、日期、分類、備註、每位付款人出了多少、分帳方式與每人分攤金額，以及由誰建立。

![App 分帳交易詳情，總額 1200 元，小晴付 800、小宇付 400，三人各分攤 400 元](/img/sync/split-app-detail.png)
*圖中：詳情同時列出「付款人」與「分帳方式」，能核對先付的錢與各自負擔的金額。*

修改或刪除後，統計與債務關係會重新計算。App 需等交易同步至 Cloud，雲端結算才會更新；離線或尚未同步時，首頁卡片可能暫時顯示上次的結果。訪客只能改刪自己記的交易，其他人的交易可查看詳情。

多人分攤支援支出與收入，不能與分類拆帳或週期性收支合用；分帳交易不提供轉帳與一般退款操作。

## 查看誰要付給誰，並記錄還款 {#settle}

### 開啟「債務關係」

- 📱 App：點分帳帳本首頁、日曆上方的債務卡片，或到「帳本設定 → 債務關係」。首頁最多先列兩筆，其他可按「查看全部」。
- 💻 Web：點分帳帳本卡片的「債務關係」。
- 訪客：開啟網頁的「結算」分頁。

每一列會顯示誰「需要支付」誰多少；都結清時顯示「大家都結清了」。金額會綜合這本帳的分攤交易與已記錄的還款。

![App 債務關係頁，顯示小安需要支付小晴 400 元，債務優化目前關閉](/img/sync/split-app-debts.png)
*圖中：延續三人聚餐的多位付款人範例，小宇已付足自己的 400 元，剩下小安要補給小晴 400 元。*

### 「債務優化」怎麼用？

關閉時，畫面保留直接欠款的關係；開啟後，會把付款路徑重新整理，盡量減少付款次數。例如小晴欠小宇 300 元、小宇欠小安 300 元，優化後可以由小晴直接付小安 300 元。

**這只是每個人自己的顯示偏好。** 不會替你付款，也不會修改原始交易；其他人可以選不同的顯示方式。實際付款前，先和對方確認收款人與金額。

### 錢已經付了，再「記錄還款」

1. 點要結清的那列，開啟「記錄還款」。
2. 核對付款方、收款方與金額。只還一部分，就把金額改成這次實際還的數字。
3. 可填備註，再按「記錄還款」。
4. 下方「還款紀錄」會留下這次紀錄，尚未付清的餘額繼續列在債務關係裡。

![App 記錄還款對話框，小安付給小晴的金額改為 200 元，備註先還一半](/img/sync/split-app-settle.png)
*圖中：應付 400 元，這次只還 200 元，就填這次實際還的金額。確認前請核對付款與收款的人。*

這個操作**只記錄你們已發生的還款，不會執行銀行轉帳**。訪客只能記錄自己付出或收到的還款。

若記錯，可刪除有權限刪除的還款紀錄，原本由這筆還款抵掉的債務會重新出現；訪客只能刪自己建立的還款紀錄。

## 記到我的帳本 {#personal-ledger}

分帳帳本不動帳戶餘額。有帳號的成員若想在自己的日常帳本留下實際付款，可使用「記到我的帳本」：

- **新增共同花費後**：自己是付款人時，會詢問「也要記到自己的帳本嗎？」單人付款帶入整筆，多位付款人只帶入自己付的金額，並非自己分攤的金額。
- **記錄還款後**：若自己是付款方，可另記一筆支出；自己是收款方，可另記一筆收入。對方替你記錄還款後，你也會收到可記到自己帳本的提示。

選擇另一本非分帳帳本、分類與帳戶，再按「記到我的帳本」。還款提示可選「稍後再說」，之後從債務關係頁的待處理清單按「記一筆」，或選「略過」。訪客沒有自己的帳本，因此沒有這項操作。

:::note 一次性複製
這會另外建立一般交易。之後編輯或刪除共同花費、還款紀錄，不會連動修改個人帳本裡那筆；需要時請兩邊分別調整。複製的是實際付款額，自己的消費負擔請看下方「個人」分帳統計。
:::

## 看群組或個人的花費 {#statistics}

📱 App 使用底部「統計」分頁；💻 Web 點帳本卡片上、債務關係旁的「分帳統計」圖示；訪客使用網頁的「統計」分頁。

1. 切換「群組」或「個人」；個人模式可選要看的參與者。
2. 選「每年」「每月」「每週」「每天」「過去一年」或「自訂期間」。固定區間可以切到上一期或下一期。
3. 查看收入、支出、結餘、筆數，以及類別比例與明細。群組模式另列出每個人的「付出」與「分攤」。

**個人統計看的是他分攤到的金額，不是他先付多少。** 小晴先付 900 元、與小宇均分，群組支出是 900，小晴與小宇的個人支出各是 450；「付出」則能看出小晴先出了 900。

![App 分帳統計群組模式，顯示 2026 年 11 月支出 1200 元及飲食類別比例](/img/sync/split-app-stats.png)
*圖中：三人聚餐的群組總支出是 1,200 元；切到「個人」後，可選人查看各自分攤到的金額。*

這裡只計算有分攤資料的交易。原本的「成員收支」按記帳的帳號成員統計，和每人實際分攤的口徑不同；要對共同花費，請看分帳統計。

## 邀請沒有帳號的朋友 {#guest-links}

### 擁有者建立連結

1. 進入「成員管理」（Web 為「成員/邀請」視窗），找到「分帳與訪客」。
2. 確認已開啟「分帳模式」與「邀請訪客」。
3. 在「訪客連結」按「新增訪客連結」。
4. 需要密碼時填「密碼（選填）」，不設可留空，再按「建立連結」。密碼規則見[連結密碼](#guest-password)。
5. 按「複製連結」傳給這位朋友；App 也可用「分享連結」。有設密碼時，記得另行告知。
6. 每位朋友各建立一條連結，不要讓幾個人共用同一條。

尚未有人使用時，清單會顯示「尚未使用」及「等待輸入暱稱」。朋友第一次填完暱稱後，才會出現在分帳的人員名單，之後可在付款人與分攤名單選到他。

![App 訪客連結清單，小安的連結顯示使用中、訪客已自訂密碼，以及複製、分享、重設密碼與回收操作](/img/sync/split-app-links.png)
*圖中：小安已使用連結並換成自己的密碼，擁有者仍能複製連結、重設密碼或回收。示範網址無法用來加入帳本。*

![Web 新增訪客連結對話框，密碼欄填入虛構的 Trip2026](/img/sync/split-web-password.png)
*圖中：建立連結時可選填臨時密碼；此處的 `Trip2026` 僅供說明，請自行設定密碼。*

### 訪客第一次使用

1. 在手機或電腦的瀏覽器開啟收到的連結。
2. 若出現「這條連結需要密碼」，輸入邀請人給的密碼，按「繼續」。
3. 在「歡迎！先取個暱稱」輸入自己的名字；也可在「設定自己的密碼（選填）」設定專用密碼。
4. 按「開始記帳」。頁面有「記帳」「明細」「統計」「結算」四個分頁。

![訪客網頁的連結密碼頁，輸入密碼後按繼續](/img/sync/split-guest-unlock.png)
*圖中：有設密碼的連結會先要求解鎖，解鎖前不顯示帳本內容。*

![訪客首次使用的暱稱頁，暱稱填小安，並填寫自己的密碼](/img/sync/split-guest-nickname.png)
*圖中：第一次輸入暱稱，也可設定自己的密碼；填寫後會取代邀請人原先給的密碼。*

之後繼續使用同一條連結，不需要每次再取暱稱。明細可查看大家有分攤的交易；自己的交易才會提供修改與刪除。頁面可按「重新整理」取得最新資料。

![訪客明細頁顯示旅行聚餐 1200 元、三人分攤，底部有記帳、明細、統計與結算分頁](/img/sync/split-guest-list.png)
*圖中：訪客用瀏覽器就能查看分帳明細，右上角鑰匙可進入「連結密碼」。*

:::tip 每人保管自己的連結
訪客連結代表這位朋友在帳本裡的身分。沒有設密碼時，拿到連結的人就能以這個身分使用；設有密碼時，需要連結與密碼。請只傳給本人，不要貼到公開群組。
:::

## 訪客連結密碼 {#guest-password}

密碼屬於**單一訪客連結**，不是帳號登入密碼。長度為 **4～64 個字元**；擁有者建立或重新發連結時都可以選填。

### 訪客改成自己的密碼

- 第一次填暱稱時，填寫「設定自己的密碼（選填）」。儲存後會**取代擁有者給的密碼**，之後使用自己的新密碼進入。
- 之後要更改，點訪客頁右上角的鑰匙「連結密碼」。已有密碼時，要先填目前的密碼，再填新密碼。
- 改密碼後，其他裝置原本的解鎖狀態會失效，需要輸入新密碼。同一瀏覽器可能會保留解鎖狀態，因此正常使用時不一定每次都詢問。

![訪客變更密碼對話框，包含目前的密碼、新密碼與儲存按鈕](/img/sync/split-guest-password.png)
*圖中：已設密碼時，變更前需輸入目前的密碼；新密碼至少 4 個字元。*

### 擁有者設定、重設或移除

回到「成員管理 → 訪客連結」，在對應連結旁操作：

| 操作或狀態 | 意義 |
|---|---|
| 設定密碼 | 替原本沒有密碼的連結加上密碼 |
| 重設密碼 | 用新密碼取代目前密碼，訪客需要重新解鎖；忘記密碼時用這個 |
| 移除密碼 | 回到拿到連結即可進入，原本的資料不會刪除 |
| 密碼由你設定 | 目前使用擁有者設定的密碼 |
| 訪客已自訂密碼 | 訪客已換成自己的密碼；擁有者不能查看該密碼 |

Web 的「移除密碼」位於「重設密碼」開啟的對話框裡。

密碼儲存後不能再顯示或複製原文，忘記時請重設。訪客沒有自行找回密碼的流程，請聯絡帳本擁有者。連續輸錯 **5 次**會暫時鎖定 **15 分鐘**，請等候後再試。

## 回收連結、移除訪客與停止分帳 {#manage-guests}

- **回收單一連結**：在「訪客連結」按「回收」並確認，該連結立即失效，已記的帳與還款仍保留。
- **重新發連結**：已回收或過期的連結可按「重新發連結」，另選密碼後把新連結傳給本人。已使用過的連結會沿用原本的參與者，無須重取暱稱；舊連結不能繼續使用。
- **移除訪客**：在成員清單移除前，要先結清他的餘額。移除後歷史交易保留，連結失效。要移除帳號成員，使用原本的成員移除操作。
- **暫停所有訪客**：關閉「邀請訪客」，所有訪客暫時無法進入，既有連結與資料保留；重新開啟後，仍有效且未回收的連結可再使用。
- **關閉分帳模式**：也會一併關閉「邀請訪客」。要恢復訪客使用，需重新確認兩個開關都已開啟；原本交易不會因此刪除。

「這條連結已失效」可能是連結已回收、過期，或帳本停止訪客使用；先請擁有者確認設定，再決定是否重新發連結。

## 共享名額怎麼算？ {#limits}

一般方案預設可開啟 **1 本共享帳本**。有其他帳號成員、有效未使用的成員邀請碼，或已開啟「邀請訪客」且仍有有效訪客連結，都會讓這本帳本算共享中。同一本帳本的多位成員或多條連結，只算一本共享名額。

訪客不必購買帳號授權，但邀請訪客仍受帳本擁有者的共享額度限制。若要釋出名額，需同時確認這本帳本已沒有其他成員、有效成員邀請，以及啟用中的有效訪客連結。完整額度與加購方式見[方案額度與購買名額](./limits.md)。
