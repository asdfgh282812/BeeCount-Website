# 拆帳與退款

> ⚠️ **僅 Cloud 版可用**：本頁功能是 BeeCount Cloud（自建服務端）獨有的進階功能，純 App 本機記帳沒有這個入口。

## 拆帳

一筆消費裡其實混了好幾種用途（例如一次購物同時買了食物跟日用品），可以拆成多筆分類明細，但金額還是算同一筆交易。

在交易表單裡開啟「拆帳」開關，新增多筆「分類 + 金額」的組合：

- 至少要拆 2 筆
- 每筆拆分金額加總**必須剛好等於**交易總金額
- 拆帳只能用在支出或收入，跟週期性收支不能同時使用
- 拆帳交易本身不再有單一分類（因為分類已經拆到每一筆明細裡了）

![拆帳交易明細](https://photo.pnsgzomf.synology.me/i/2026/08/11/6a79f90b4f46a.png)

> 目前拆帳是「按分類拆」，不是「按人拆」——如果是要跟朋友均攤某筆消費、記錄誰欠你多少，請用[欠還款](./debt.md)功能。

## 退款

訂錯東西、消費後拿到退款，可以記一筆退款交易，跟原始那筆消費關聯起來，方便回頭查對。

操作方式：在交易明細裡點「退款」按鈕，系統會自動開一個新交易表單、預先帶入退款金額跟關聯資訊，你確認存檔即可。

![退款交易關聯原交易](https://photo.pnsgzomf.synology.me/i/2026/08/11/6a79f90a77074.png)

退款交易的明細頁會顯示「退款」標籤，點一下可以直接跳回原始那筆交易。

**限制**：一筆交易只能被退款一次；退款交易本身不能再被二次退款。

## 跟信用卡回饋沖銷退款的差別

信用卡消費滿額回饋被沖銷（例如退貨導致回饋跟著扣回）走的是系統內部自動記帳，跟這裡「使用者自己手動記一筆退款」是兩回事，兩者不會互相干擾。詳見[信用卡紅利回饋規則](./card-rewards.md)。
