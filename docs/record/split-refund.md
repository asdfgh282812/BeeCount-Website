去賣場結帳 1,500 元，其中 900 是食材、600 是衛生紙洗衣精。記成一筆「購物」，餐飲分類就少了 900；分成兩筆，又要拆兩張發票。**拆帳**讓你把一筆交易分到多個分類，總額還是一筆。

後來有一件商品退貨，退回 300 元，這時**退款**能讓報表上那個分類的支出正確減少，而不是多出一筆收入。

> 📱 App　💻 Web

:::tip 想算朋友之間誰要付給誰？
本頁說明一筆交易拆到多個分類，以及退款。若是旅行、聚餐等多人共同花費，要指定付款人與每人的分攤，請看[多人分帳與訪客連結](../sync/split-ledger.md)。多人分攤不能與本頁的分類拆帳同時使用。
:::

## 為什麼這樣設計

拆帳把同一筆交易分成多個分類，也能把幫別人代付的份額記成應收款項。總額必須等於各明細加總，自己的收支與代墊款項分開計算。

退款記成「另一筆反向交易」，原交易不會被改動。這樣帳戶餘額與你的銀行帳單對得上，退款與原消費之間也有連結，報表可以把退款從原本的分類扣回去。

## 用 AI 拆帳

在 App 的 AI 對話、語音或圖片入口，或 Web 的 AI 記帳草稿，可以說「晚餐付了 900，我自己 300，小明欠我 600，用現金」。系統保存一筆付款：帳戶扣 900、自己的支出算 300，另建立小明的應收款 600；不必再記一筆借出。

只拆分類也可以說「賣場結帳 1,500，食材 900、日用品 600」。至少兩筆明細、至少一筆一般分類，合計必須等於實付。含欠款的拆帳須使用帳本主要幣別帳戶，不能再搭配週期；其他限制與核對方式見 [AI 記帳](./ai.md#拆帳費用借還款與週期)。

## 拆帳

### 📱 在 App 上

1. 新增交易頁，選「支出」或「收入」，先選好一個分類。
2. 點分類那一行右邊的分岔圖示（提示「拆分到多個分類」）。
3. 剛才選的分類變成第一筆明細，下方直接攤開同一個分類格。點另一個分類，就多一筆明細。
4. 分類區現在變成一排圓形圖示：最前面是「多類別」總圖示（右上角徽章是明細筆數，下面是總額），接著是每一筆明細的分類圖示與金額，最後是「+」。

   ![App 拆帳模式：一排圓形圖示，最前面是多類別總圖示，接著是各筆明細與「＋」](/img/record/split-refund-1.png)
   *圖中：多類別總圖示與兩筆明細（食材、日用品），最後是新增明細的「＋」，下方是分類格*

5. 點某一筆明細，它就被選中（圖示外圍出現框線），這時輸入金額，數字會填到這一筆。依序把每筆金額輸入好。
6. 想再加一筆，點「+」攤開或收起分類格選分類。同一個分類可以重複選成多筆。
7. 每筆明細可以寫自己的備註：名稱欄會變成「這筆明細的備註…」，備註屬於目前選中的那一筆，圖示下面也會顯示它（沒寫備註才顯示分類名稱）。整筆交易的備註是各明細備註去重後用「、」串起來。
8. 更換某一筆的分類：點已選中的那筆，或長按它，選「更換分類」。有 2 筆以上時，每筆圖示右上角有「×」，點了直接移除。
9. 想放棄拆帳，長按「多類別」總圖示選「還原成單一分類」，再選一個分類。
10. 送出前至少要 2 筆、每筆金額都大於 0，否則提示「請完成拆帳明細（至少 2 筆，且金額需大於 0）」。

#### 每筆明細各自的手續費與折扣

選中一筆明細後，點金額列的「+」展開手續費／折扣。這兩個欄位只屬於目前選中的那一筆；切換明細時，會帶出那一筆自己的名稱與金額。主金額填原始金額，分類圖示上的金額則即時顯示調整後的淨額，「多類別」顯示各筆淨額加總。

例如火車原始金額 600、手續費 9，火車圖示顯示 **609**；另一筆汽車 120 沒有費用，仍顯示 120，整筆總額為 **729**。費用只計入填寫的那筆明細。

- 支出明細：淨額 = 原始金額 + 手續費 − 折扣。
- 收入明細：淨額 = 原始金額 − 手續費 + 折扣。
- 每筆調整後的淨額都必須大於 0，手續費與折扣不能為負數。
- 進入拆帳前已填好的手續費／折扣會歸第一筆明細；還原成單一分類時，各筆費用會合併，整筆總額維持不變。
- 編輯交易時，金額欄帶回原始金額與這筆自己的費用；交易詳情的分類明細也會列出原始金額、手續費與折扣，方便核對。

**拆帳裡記代付：** 展開拆帳的分類格時，格子上方有一排切換：支出拆帳是「支出」「應收」，收入拆帳是「收入」「應付」。切到「應收」選一個應收分類（例如「代付」），會先跳出面板請你填對象與到期日，這一筆就成為一筆應收款項，金額不計入支出統計，但帳戶照整筆扣款。例如晚餐刷卡 1,000 元，自己吃 600、幫朋友代付 400，就把 400 那筆切到「應收」。收入拆帳切到「應付」則是向對方借入。至少要有一筆一般分類的明細，全部都是欠款的話，請直接用借貸分頁。款項的後續收還款見[借還款](./debt.md)。

![App 拆帳分類格上方的「支出」「應收」切換，切到應收後列出代付等應收分類](/img/record/split-refund-2.png)
*圖中：分類格上方的「支出」「應收」切換，切到「應收」後格子裡是借出、代付、報帳等應收分類*

拆帳後，交易詳情會顯示「拆帳」徽章，並在下方「分類明細」列出每一筆的圖示、分類、備註與金額；交易列表上顯示「多類別」圖示。在分類的明細頁，落在那個分類的拆帳明細會當成一般交易列出，點開可看完整拆帳。

### 💻 在 Web 上

1. 「建立交易」視窗，類型選「支出」或「收入」，在「分類」標題右邊點「拆分到多個分類」。
2. 每一列選一個「分類名稱」並填「金額」。「新增分類」多加一列，「刪除」移除一列，下方提示「已分配 … / 總額 …」。
3. 每一列下方可點「+ 手續費／折扣（這筆明細）」，各自填費用名稱與金額。該列的「金額」填原始金額，展開區會顯示套用後的「總額」；需要清除時按「移除」。
4. 主表單的交易金額填各筆淨額的合計，「已分配」也以淨額計算。至少 2 列、每列淨額都大於 0，且合計須等於交易金額，否則會提示「拆分金額加總必須等於交易金額」等訊息。
5. 想取消點「取消拆分」。各筆手續費／折扣會合併回整筆交易，總額維持不變。

Web 的拆帳也能掛欠款：點某一列的分類，選擇器上方可切到「應收」（支出交易）或「應付」（收入交易），再選欠款分類並填對象與到期日。

列表上拆帳交易會顯示「拆分」徽章，詳情視窗有「分類明細」。

![Web 拆分到多個分類：兩列分類與金額，下方顯示已分配與總額](/img/record/split-refund-web-1.png)

:::note 不能同時使用
拆帳不能用在轉帳、週期性收支、分期付款或新增退款時。AI 拆帳則以實付／實收金額核對明細合計，見 [AI 記帳](./ai.md)。統計與預算會把拆帳明細各自算進自己的分類，多幣別交易會依匯率比例折算。
:::

## 退款

### 📱 在 App 上

1. 在首頁（或全部交易、搜尋）點要退款的那筆交易，打開交易詳情。
2. 點操作列上的「退款」圖示。
3. 新增交易頁自動打開：類型對調（支出變收入），金額、備註、帳戶、幣別都帶入，**分類留空，請自己選**（通常選回原本的分類）。
4. 實際退多少就改金額。退一部分就是部分退款。
5. 送出。這筆會標成「退款單」並與原交易連結，原交易的詳情會列出「已退款」清單。

### 💻 在 Web 上

點交易列開啟「交易詳情」，按「退款」。會開啟建立交易視窗，類型自動對調並帶入原交易資料。分類可以留空，系統會自動歸到「退款」分類。已退過款的交易按鈕會停用並提示「這筆交易已經退過款，不能重複退款」。詳情裡的「已退款金額」會顯示累計退款。

### 退款的限制

- 一筆交易只能退一次，退款單本身不能再退款。
- 轉帳與餘額調整不能退款，圖示會變灰。
- 分期交易的退款走分期專用流程，見[分期付款](./installment.md)。

## 退款怎麼影響報表

退款從原本的分類扣回，而不是讓收入與支出各多一筆。例如本月餐飲支出 5,000，退款 300，報表顯示餐飲 4,700：

- 扣回「原交易的分類」；原交易是拆帳的，按各明細金額比例分攤。
- 算在「退款單自己的日期」，不會回頭改過去那一期，所以某期某分類的淨額可能是負的。
- 原交易標了「不計入收支」，退款也不計入。
- 報表的排行與筆數不算退款單。
- 預算用量不變，仍按原始消費計算。
- 專案頁的「退款」分類以淨額顯示。

信用卡紅利回饋也會跟著退款減少：全額退款回饋歸零，部分退款依淨額等比例重算。4.0 起回饋是即時產生的回饋交易，退款存檔後會跟著重算。詳見[紅利回饋](../credit-card/rewards.md)與[統計報表](../analysis/statistics.md)。

## 注意事項／小提醒

:::tip 退貨前先確認帳戶
退款單帶入的帳戶是原消費的帳戶。如果錢退到別張卡或現金，記得在送出前改帳戶。
:::

:::note 離線多裝置
「已經退過款」的檢查只在介面上擋。多台裝置離線各退一次，理論上可能出現兩筆退款，這種邊界情況請自行確認。
:::
