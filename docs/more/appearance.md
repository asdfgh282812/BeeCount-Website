每個人看帳的習慣不太一樣：有人喜歡預設的新芽綠、有人想換成別的主題色，晚上只想看深色；有人習慣收入紅色、支出綠色，有人剛好相反；看股票時，台灣人又習慣「紅漲綠跌」。這一頁把所有「看起來怎麼樣」的設定集中在一起。

> 📱 App　💻 Web（Web 只有其中一部分，下面會註明）

## 為什麼這樣設計

收支顏色和股票漲跌顏色是兩個獨立的開關，因為台灣記帳與看盤的習慣不一定一致。外觀設定大多會跟著帳號走，換手機或打開 Web 時，看到的是同一套樣子。

4.0 之前，這些設定全部擠在「我的」→「個性化設定」一頁裡；4.0 起拆成「外觀」「一般」「記帳偏好」「隱私與安全」「桌面小工具」五個入口，依用途找比較快。

## 怎麼操作

### 📱 在 App 上

點底部的「我的」，往下找到同一張卡片裡的五列，就是五個設定入口：

| 入口 | 放了什麼 |
|---|---|
| 外觀 | 外觀模式、主題色、Liquid Glass、造型、節日、動畫、可愛類別圖示、顯示縮放 |
| 一般 | 顯示幣種與匯率、每月起始日捷徑、語言、每週起始日、行事曆預設顯示、餘額顯示格式、收支與股票顏色 |
| 記帳偏好 | 新增交易的建議分類、顯示交易時間、備註顯示方式、歷史備註 |
| 隱私與安全 | 隱藏金額、App 鎖定 |
| 桌面小工具 | 在主畫面快速查看收支情況 |

*圖中：「我的」頁有外觀、一般、記帳偏好、隱私與安全、桌面小工具五個設定入口，取代 4.0 之前的「個性化設定」*

### 外觀

「我的」→「外觀」：

| 設定 | 說明 |
|---|---|
| 外觀模式 | 選「跟隨系統」「亮色模式」或「暗黑模式」。 |
| 主題色 | 進入後有一整排顏色卡（預設是「新芽綠」，還有蜂蜜黃、火焰橙、晴空藍、薰衣草…），最後一張「自訂」可以用色相、飽和度、亮度自己調色。「蜂蜜黃」是 4.0 之前的預設色，想換回去可以在這裡選。 |
| Liquid Glass | 底部分頁列、選單與面板的玻璃質感，有「清透」（預設，更通透）、「平衡」（柔和模糊）、「厚霧」（底色更厚，閱讀更輕鬆）三種，選完立即套用。系統開啟「減少透明度」時會自動改成實色。 |
| 造型 | 頁首的背景圖案（4.0 之前叫「皮膚」），可用「全部／動態／靜態」篩選。標示「內建配色」的造型會連主題色一起換掉。 |
| 節日 | 日曆的節日標記與節日主題，見下方〈節日〉。 |
| 面板動畫 | 關掉後，動態造型會停在靜止畫面，比較省電。 |
| 減少動畫 | 開啟後全站動畫精簡，省電，也比較不容易眼花。 |
| 可愛類別圖示 | 分類圖示換成彩色的 flat 風格圖示，分類顏色改用圖示下方的底線表示；開啟後選分類圖示時還有可搜尋的圖庫，見 [分類](../prepare/category.md)。 |
| 顯示縮放 | 調整文字和介面大小，詳見下方〈顯示縮放〉。 |

### 顯示縮放

點「顯示縮放」，可以用「快速檔位」（從「極小」到「極大」）一鍵切換，或拉「自訂調整」的滑桿，範圍是 0.7 倍到 1.5 倍。頁面上方有即時預覽，覺得太大太小，按「重設到1.0x」就回到標準。

### 節日

點「節日」可以設定：

![App「外觀 → 節日」頁：選擇要顯示哪些國家／地區的節日與主要國家](/img/more/appearance-holiday-1.png)
*圖中：「節日」頁最上面是顯示節日開關，往下勾選要顯示哪些國家或地區的節日，並選定「主要國家」（節日台詞與節日主題以它為準）*

![同一頁往下：節日主題開關（節日當天才換色）與節日資料來源](/img/more/appearance-holiday-2.png)
*圖中：同一頁往下是節日主題開關（節日當天換上節日主題，例如春節、國慶的紅色）、應景台詞（需開啟 AI）與節日資料來源*

1. 「顯示節日」：在日曆標出節日，點到那天會出現應景台詞。
2. 「國家／地區」：複選要顯示哪些地方的節日（台灣、中國、香港、日本、韓國、美國）。
3. 「主要國家」：多個國家同一天都有節日時，只顯示主要國家的。
4. 「節日主題」：節日當天，主題色和頁首會自動換成應景樣式，隔天換回來。預設開啟。
5. 「應景台詞」：沒設定 AI 時用內建台詞；開啟 AI 後，每月最後 3 天會請 AI 寫下個月的台詞，只會送出節日名稱與日期，不含任何帳目。

節日主題只是「暫時換裝」，不會改掉你自己選的主題色和造型。節日當天進到「主題色」或「造型」頁，最上面會有提示條，可以直接跳到「節日設定」。

### 一般

「我的」→「一般」：

| 設定 | 說明 |
|---|---|
| 顯示幣種 | 整個 App 共用的顯示幣種（4.0 之前叫「主幣種」），資產折算的目標。見 [多幣種與匯率](../prepare/currency.md)。 |
| 匯率管理 | 查看與手動修正匯率，這裡是匯率管理的正式入口。 |
| 每月起始日 | 只是捷徑，會開啟目前帳本的設定；每月起始日是帳本自己的設定，見 [帳本](../prepare/ledger.md)。 |
| 農場設定 | 農場遊戲的設定，見 [農場](../farm/overview.md)。 |
| 語言 | 切換 App 介面語言，預設跟隨系統。 |
| 每週起始日 | 「星期一」或「星期日」，日曆與週統計都會照這個排。預設星期一。與 Web 同步。 |
| 行事曆預設顯示 | 選「一週」或「一個月」，未設定時是「一週」。只影響 App 首頁日曆；頁面上臨時展開／收合不改寫此偏好。首次個人化也可選擇，詳見[日曆與明細](../analysis/calendar.md#一週與整個月)。 |
| 餘額顯示格式 | 「完整金額」顯示 123,456.78；「簡潔顯示」把大金額縮成 12.3萬。只影響帳戶餘額。 |
| 收支顏色方案 | 二選一：「紅色收入 · 綠色支出」或「紅色支出 · 綠色收入」。預設是前者。 |
| 股票漲跌顏色 | 「紅漲 · 綠跌」（台灣習慣，預設）或「綠漲 · 紅跌」（國際習慣）。 |

![App「一般」頁：顯示幣種與匯率、語言、每週起始日、行事曆預設顯示、餘額顯示格式、收支與股票顏色](/img/prepare/currency-4.png)
*圖中：「一般」頁第一組是顯示幣種與匯率管理，第二組是語言、每週起始日、行事曆預設顯示、餘額顯示格式、收支顏色方案與股票漲跌顏色*

**餘額顯示格式：完整金額或簡潔顯示**

帳戶餘額數字很大時，一長串數字不好讀。到「我的」→「一般」→「餘額顯示格式」，選「簡潔顯示」，大金額就縮寫成「萬」為單位，例如 12.3萬。繁體中文介面會用繁體的「萬」，不會出現簡體的「万」。

![App「餘額顯示格式」視窗：完整金額與簡潔顯示兩個選項](/img/more/appearance-amount.png)
*圖中：「餘額顯示格式」視窗，目前選用的格式有打勾；「簡潔顯示」會把大金額縮寫，例如 12.3萬（只對帳戶餘額生效）*

![App 資產頁選簡潔顯示後，淨資產與各帳戶餘額以「萬」為單位](/img/more/appearance-wan.png)
*圖中：選「簡潔顯示」後，資產頁的淨資產、總資產與總負債都以「萬」顯示；走勢圖座標軸是另一套縮寫（w 代表萬、k 代表千），不是同一個設定*

這個設定只影響「帳戶餘額」的顯示（資產頁、帳戶列表、帳本卡片等），不會改到交易金額；想看精確到小數的數字，把它改回「完整金額」即可。

### 記帳偏好

「我的」→「記帳偏好」：

| 設定 | 說明 |
|---|---|
| 新增交易的建議分類 | 新增交易頁最上方顯示一排「建議分類」，依你的習慣排出可能要記的支出與收入分類。關掉後這一排就消失。預設開啟。 |
| 顯示交易時間 | 帳單列表多顯示「時：分」，編輯時也能選時間。預設關閉。 |
| 備註顯示方式 | 「分類優先」：顯示分類名，備註用括號附在後面。「備註優先」：有備註就顯示備註，沒有才顯示分類名。 |
| 歷史備註 | 設定輸入備註時的建議清單：顯示範圍（全部分類／目前分類）、排序方式（使用次數／最近使用）、顯示數量（1 到 100 筆）。 |

![App「記帳偏好」頁：新增交易的建議分類、顯示交易時間、備註顯示方式與歷史備註](/img/more/appearance-6.png)
*圖中：「記帳偏好」頁有建議分類與顯示交易時間兩個開關，以及備註顯示方式、歷史備註兩個選項*

### 隱私與安全

「我的」→「隱私與安全」有兩項：

- 「隱藏金額」：打開後，首頁、資產頁等畫面上的金額都以星號顯示。這個開關在首頁與資產頁的頁首也各有一顆眼睛按鈕可以快速切換，三個地方是同一個設定。4.0 之前它在「我的」頁首。
- 「App 鎖定」：用 PIN 碼或生物辨識保護隱私，說明見 [裝置與安全](../sync/devices.md)。

![App「隱私與安全」頁：隱藏金額開關與 App 鎖定](/img/more/appearance-7.png)
*圖中：「隱私與安全」頁有「隱藏金額」開關與「App 鎖定」入口*

### 桌面小工具

「我的」→「桌面小工具」會顯示可放到主畫面的小工具預覽與說明，加到主畫面的做法見 [快速記帳](../record/quick.md)。

### 帳戶滑動動作

資產頁帳戶左右滑動露出的快捷動作，4.0 起搬到「資產」頁右上角的齒輪 →「帳戶滑動動作」，說明見 [帳戶](../prepare/account.md)。

### 💻 在 Web 上

Web 的外觀設定比較精簡：

1. 點右上角頭像，展開「設定」群組，選「個人資料」。
2. 點「主題色」膠囊，選整站的主色（按鈕、邊框、高亮都會跟著換，預設同樣是新芽綠）。
3. 在「同步偏好」卡片可以調整：Liquid Glass、收支配色、股票漲跌顏色、皮膚（對應 App 的「造型」）、餘額顯示格式、每週起始日、行事曆預設顯示、備註顯示方式、顯示交易時間、可愛類別圖示。這些設定與 App 同一份，改完會同步過去；其中「行事曆預設顯示」會標示「此設定僅於 App 生效。」，不影響 Web 日曆的預設檢視。同一頁下方還有「顯示幣種」與匯率管理，見 [多幣種與匯率](../prepare/currency.md)。
4. 深色模式不在設定頁：點頭像，在「偏好」區的「切換主題」選「跟隨系統」「淺色」或「深色」三個按鈕之一（滑鼠停在按鈕上會顯示名稱）。
5. 節日主題由 App 的設定決定：App 開著節日主題，Web 在節日當天也會自動換色。

![Web 個人資料頁的同步偏好卡片](/img/more/appearance-web-1.png)
*圖中：Web「個人資料」頁的同步偏好卡片，包含 Liquid Glass、收支與股票顏色、皮膚、餘額顯示格式、行事曆預設顯示、每週起始日、備註顯示方式等選項；行事曆選項下標示「此設定僅於 App 生效。」*

## 注意事項／小提醒

:::note 主題色在 Web 和 App 的差別
App 改主題色會自動傳到 Web；但你在 Web 上自己改過主題色後，主題色只存在那個瀏覽器，不會回傳到 App，之後 App 的變更也不會蓋掉它。
:::

:::tip 造型會鎖住主題色
選了標示「內建配色」的造型，「主題色」頁會暫時不能改，並出現「換造型」按鈕。換回其它造型，就會恢復你原本選的顏色。
:::

- 「新增交易的建議分類」只存在這支手機，不會同步到其他裝置。
- Web 日曆的週起始日跟著「每週起始日」同步；改了之後兩邊都會照新的設定排。
- 「行事曆預設顯示」只套用到 App；Web 日曆固定從月檢視開始，也可在日曆頁臨時切成一週。
- 桌面小工具不跟節日主題換色，只在 App 更新它時才會重畫。
