想開始記帳之前，要先把 App 裝好，再登入你的 BeeCount Cloud 帳號。這個版本不是從 App Store 或 Google Play 下載的，安裝方式和一般 App 稍微不同，不過只要做一次。

> 📱 App

## 為什麼這樣設計

你的帳本存放在 BeeCount Cloud 伺服器上，手機、平板和網頁共用同一份資料，所以 App 一定要先登入才能使用。授權金鑰則用來確認你是被允許使用的人，由管理員發給你。換手機或重灌時，登入之後資料就會自動回來，不用另外備份還原。

## 先準備好三樣東西

向提供蜜蜂記帳給你的管理員索取：

1. **安裝檔的取得方式**：Android 是 APK 下載連結，iOS 是 SideStore 的軟體源（Source）網址。
2. **伺服器位址**：像 `example.com` 這樣的網址，登入時要輸入。
3. **授權金鑰**：格式像 `BC-XXXXX-XXXXX-XXXXX-XXXXX`。管理員帳號不需要金鑰。

## 怎麼操作

### 📱 Android：安裝 APK

1. 用手機瀏覽器開啟管理員給你的下載連結，下載 APK 檔。
2. 下載完成後，點開這個檔案。
3. 如果系統跳出「不允許安裝來自這個來源的應用程式」之類的提示，依畫面指示到設定允許，再回來繼續安裝。實際文字會因手機廠牌而不同。
4. 安裝完成後，點「開啟」。

:::tip 下載頁有好幾個檔案怎麼選
有些版本會同時提供 arm64 與 universal 兩種。近幾年的手機選 arm64 即可，不確定就選 universal。裝好之後，App 之後會自己挑對的版本更新。
:::

### 📱 iOS：用 SideStore 安裝

1. 先在 iPhone 上準備好 SideStore。SideStore 是第三方側載工具，設定方式請參考它自己的說明。
2. 在 SideStore 的「Sources」加入管理員給你的軟體源網址。
3. 在這個軟體源裡找到「蜜蜂記帳」，點「Install」。
4. 安裝完成後，從主畫面開啟蜜蜂記帳。

### 📱 第一次開啟：歡迎流程

第一次開啟 App 會進入歡迎畫面，依序完成下面幾步。畫面下方有「上一步」「下一步」可以往回修改。

1. **選語言。** 清單有「跟隨系統」「中文」「繁體中文」「English」「한국어」，預設跟隨系統。台灣使用者請選「繁體中文」，之後可以到「我的」改。按「下一步」。

2. **輸入伺服器位址。** 在「伺服器位址」輸入管理員給你的網址，按「連接」。連得上才會進下一步；如果出現「請輸入有效的伺服器位址」或「無法連接該伺服器，或伺服器未啟用 SSO」，請檢查網址有沒有打錯、手機有沒有連上網路。

3. **登入。** 按「使用 SSO 登入」，App 會開啟手機瀏覽器，請在瀏覽器裡完成登入。登入成功後會自動跳回 App。你不需要在 App 裡輸入帳號密碼。

4. **輸入授權金鑰。** 如果你的帳號還沒有有效授權，會多出「需要授權金鑰」這一頁。輸入金鑰後按「啟用」，成功會顯示「授權已啟用，有效至 …」。已經有授權或是管理員帳號就不會看到這一頁。金鑰的詳細規則見[授權金鑰](../sync/license.md)。

5. **選幣種。** 如果雲端上還沒有任何帳本（通常是第一次使用），會出現幣種選擇，預設是 TWD（新台幣），選好按「下一步」。App 會幫你建立一本「預設帳本」。之後想改可以在帳本設定調整，見[帳本](../prepare/ledger.md)。

6. **選分類模式。** 如果建好帳本後雲端還沒有分類，會出現「選擇分類模式」，有三種：

   | 模式 | 適合誰 |
   |---|---|
   | 扁平分類 | 想簡單快速，一層分類就夠（預設） |
   | 階層分類 | 想分得細，例如「餐飲」底下再分「早餐」「午餐」 |
   | 不建立分類 | 想完全自己建 |

   選好後按「完成」。分類之後都可以再新增或調整，見[分類](../prepare/category.md)。

完成之後就會進到主畫面。如果你在網頁版已經建過帳本，登入後會直接進主畫面，上面第 5、6 步會自動略過。

:::note 歡迎頁的「老用戶？匯入配置」
語言頁底下有一個「老用戶？匯入配置」，是給用舊版匯出設定檔（YAML）的人還原設定用的。一般新使用者不需要點它。匯入後仍然要登入並啟用授權。
:::

### 登入之後第一次：圖片下載模式

第一次登入後，App 會問你「雲端圖片下載」要用哪一種：

- **即時下載**：所有雲端記錄的圖片自動下載到手機，花流量也佔空間，圖片少於 1,000 張時適合。
- **動態下載**：打開有圖片的記錄時才下載，省空間。

不確定就選動態下載，之後可以到「我的 → 同步」裡的「雲端圖片下載」改。附件的用法見[附件](../record/attachment.md)。

## 更新 App

### 📱 Android

- **自動提示**：開啟或回到 App 時，如果有新版本，會跳出「發現新版本 x.y.z」，按「立即更新」就會下載並開啟系統安裝畫面。按「稍後」的話，同一個版本 24 小時內不會再自動提示。
- **手動檢查**：「我的 → 關於 → 檢查更新」，會顯示目前版本，已是最新會告訴你「當前已是最新版本」。

### 📱 iOS

iOS 不能由 App 自己安裝更新。有新版本時會跳出「有新版本可用」，提醒你回到取得安裝檔的管道（SideStore）更新。你可以按「知道了」，或「不再提示此版本」。

:::warning 版本太舊會被擋住
管理員可以設定「最低可同步版本」。如果你的 App 版本低於這個版本，App 會顯示「請更新 App」，更新前不能使用。更新完成後按「我已更新，重新檢查」即可。
:::

## 注意事項／小提醒

:::warning 換帳號會清掉這支手機上的資料
如果在同一支手機上登出，改用另一個帳號登入，App 會先清空這支手機上原本的帳本資料，再同步新帳號的資料。上一個帳號還沒同步到雲端的修改會一併消失，所以換帳號前請確認已經同步完成。
:::

:::note 沒有網路也能記帳嗎
可以。離線時記的帳會先存在手機，連上網路後自動補傳。不過授權至少每 7 天要連網確認一次，詳見[授權金鑰](../sync/license.md)。
:::

- 沒有登入或授權失效時，App 會顯示全螢幕的登入或授權畫面，在處理完之前無法進入任何功能。
- 登入用的是瀏覽器完成的 SSO，App 本身沒有「註冊」按鈕。需要新帳號請洽管理員。
