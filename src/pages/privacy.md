**最後更新日期：2026/10/09**

這份文件說明「蜜蜂記帳客製化版本」（以下簡稱本服務，包含 App 與 Web）如何處理你的資料。我們盡量寫得直白：哪些資料會離開你的手機、會去哪裡、你能怎麼控制。

## 重點摘要

- 使用本服務必須登入 BeeCount Cloud。你的帳務資料會同步並儲存在這個 BeeCount Cloud 伺服器上，而不是只留在手機裡。
- BeeCount Cloud 是由本服務的營運者自行架設與管理的伺服器，不是第三方的雲端記帳平台。
- AI 功能預設關閉，需要你自己設定 AI 服務商並同意後才會使用；啟用後，相關內容會傳送給你設定的服務商。
- 我們在程式碼中檢查過，App 與 Web 沒有內建廣告、行為分析或當機回報（例如 Firebase、Sentry 等）的 SDK，也沒有販售資料。

## 1. 本服務會儲存哪些資料

**帳號資料**：登入用的電子郵件、顯示名稱、頭像、密碼（以雜湊方式儲存，不存明文）。若啟用兩步驟驗證，會另外儲存驗證所需的資訊與復原碼（復原碼以雜湊儲存）。登入方式若使用營運者設定的單一登入（SSO）服務，則會取得該服務提供的使用者識別與電子郵件。

**授權金鑰**：本服務需要有效的授權金鑰才能使用。伺服器會記錄金鑰綁定的帳號、啟用日期與到期日。

**帳務資料**：你記的帳本、帳戶、分類、標籤、專案、預算、交易、借還款、分期、週期性收支、股票持股與定期定額、信用卡設定與回饋規則、附件圖片等。這些資料會同步到 BeeCount Cloud，並在你的各個裝置與 Web 之間共用。若你使用共享帳本，被你邀請的成員也看得到該帳本的內容。

**偏好設定**：外觀、提醒、通知、功能導覽進度等設定會存在你的帳號裡，換裝置時自動套用。若你設定了 AI 服務商，這份設定（包含你填入的 API Key）也會隨帳號儲存在伺服器上，讓 Web 和其他裝置可以沿用。

**裝置與版本資訊**：每次登入或回報版本時，伺服器會記錄該裝置的名稱、平台、裝置型號、作業系統版本、App 版本、最近一次連線的 IP 位址與時間。用途是讓你在「裝置」頁看到有哪些裝置登入、讓你可以移除不認得的裝置，並讓營運者知道有哪些 App 版本還在使用（例如判斷是否需要要求更新）。

**操作紀錄**：伺服器為了維運與除錯，會保留一般的系統紀錄。若你建立了個人 API Key（MCP），伺服器會記錄每把 Key 最近使用的時間與來源 IP，以及 MCP 呼叫紀錄（保留 30 天），你可以在 Web「設定 → 開發者」查看。

**資料可被營運者存取**：因為資料存放在營運者管理的伺服器上，營運者在技術上能夠存取伺服器內的資料。請只在你信任該營運者的前提下使用本服務。

## 2. 資料在你的裝置上

App 本身也會在手機上保存一份資料庫、附件與設定，以支援離線使用。授權確認後，離線最多可使用 7 天。你解除安裝 App 時，手機上的這份資料會一併刪除；伺服器上的資料不受影響。

## 3. 會把資料傳到哪裡

### 3.1 BeeCount Cloud（必要）

同步、登入、授權、通知、App 版本與更新檢查，都是連到你登入的 BeeCount Cloud 伺服器。Android 版的自動更新會另外連到營運者指定的公開檔案位置，下載版本資訊與安裝檔，這類請求會讓該檔案服務看到你的 IP 位址。

### 3.2 AI 功能（選用，預設關閉）

AI 記帳、AI 聊天與其他 AI 功能，需要你自己設定 AI 服務商與 API Key。在你把 AI 從關閉切換到開啟時，App 會跳出提示並徵求你同意。

啟用後，為了完成你發起的辨識或對話，下列內容會傳送給你設定的 AI 服務商：帳單圖片、語音錄音、你輸入的文字，以及完成辨識所需的分類名稱、帳戶名稱與相關交易紀錄。節日台詞功能只會送出節日名稱與日期，不含任何帳目。

服務商由你自己選擇（App 內預設範本為智譜 GLM，你也可以填其他相容的服務商），這些資料依該服務商自己的隱私權政策處理，我們無法控制。從 Web 使用 AI 功能時，請求是由 BeeCount Cloud 伺服器使用你儲存的設定轉送給你設定的服務商。

### 3.3 股票報價（使用股票功能時）

股票持股的報價由 BeeCount Cloud 伺服器向公開資料來源取得，包括 Yahoo Finance、臺灣證券交易所與櫃買中心的公開資料；營運者若另外設定了付費報價來源，也可能使用。查詢送出的是股票代號或你輸入的搜尋關鍵字，由伺服器發出，不含你的帳務資料。

### 3.4 匯率

App 在需要最新匯率時，會連線到公開的匯率資料來源（透過 jsDelivr 等 CDN 發布的公開匯率資料，以及 Frankfurter），BeeCount Cloud 伺服器也可能自行取得匯率。請求內容只有幣別代碼，但這些服務會看到發出請求的 IP 位址。

### 3.5 其他網路連線

- 使用說明與本隱私權政策頁面，會從手冊網站載入。
- Web 版的圖示字型從 Google Fonts 載入，因此 Google 會看到你的瀏覽器 IP 位址與基本請求資訊。
- 若 App 內有分享、開啟外部連結等動作，會開啟你選擇的對象或網站，之後適用對方的政策。

## 4. 沒有廣告與追蹤

依我們對 App 與 Web 原始碼的檢查，本服務沒有：

- 廣告 SDK；
- 第三方行為分析或追蹤 SDK；
- 第三方當機回報服務。

我們不會出售或出租你的資料，也不會把帳務資料提供給廣告商。

## 5. 裝置權限

權限只在你使用對應功能時才會用到：

| 權限 | 用途 |
|---|---|
| 相機 | 拍攝帳單或收據，用於 AI 圖片記帳或附件。 |
| 麥克風 | 語音記帳。 |
| 相簿／檔案 | 選取帳單圖片、匯入匯出 CSV、附件與設定檔。 |
| 通知 | 記帳提醒、通知中心的系統通知、下載更新進度。 |
| 生物辨識（指紋／Face ID） | App 鎖。驗證由手機系統完成，App 不會取得你的生物特徵資料。 |
| 網路 | 登入、同步與上述的各項連線。 |
| 安裝應用程式（Android） | 在 App 內更新時安裝新版安裝檔。 |

## 6. 資料保存與你的選擇

- **匯出**：你可以隨時在 App「我的 → 資料管理」匯出帳單（CSV）、附件與設定，或在 Web 匯出 CSV。
- **修改與刪除**：你可以自己修改或刪除帳務資料與裝置；刪除後，同步到伺服器的對應資料會一併更新。
- **帳號與整體資料刪除**：若想停用帳號，或要求刪除伺服器上與你有關的全部資料，請聯絡提供你帳號的服務營運者。
- **關閉功能**：AI 功能、提醒與通知都可以隨時在設定中關閉；個人 API Key 可在 Web 隨時撤銷。
- **兩步驟驗證與 App 鎖**：可以在設定中開啟，加強帳號與手機上資料的保護。

## 7. 安全

登入使用加密連線與存取權杖；密碼與復原碼以雜湊儲存。我們盡力保護資料，但沒有任何系統能保證絕對安全。請妥善保管你的密碼、授權金鑰與個人 API Key，匯出的檔案也請避免隨意傳給他人，因為設定檔可能包含 AI 服務商的 API Key。

## 8. 兒童

本服務不是為未成年人設計。如果你是未成年人，請在監護人同意下使用。

## 9. 政策更新

本政策有重大調整時，會更新上方的「最後更新日期」。繼續使用本服務，代表你接受更新後的內容。

## 10. 聯絡方式

對本政策或你的資料有任何疑問，請聯絡提供你 BeeCount Cloud 帳號的服務營運者。
