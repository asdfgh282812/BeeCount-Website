# 管理员功能

头像菜单「管理」分组下的功能仅**管理员账号**（`is_admin = true`）可见，普通用户看不到这些入口。自部署时首次启动自动创建的账号就是管理员，其他账号需要管理员手动设置。

## 使用者管理

头像菜单 → **使用者管理**，管理整个 BeeCount Cloud 平台的账号。

![使用者管理](/img/web/admin-users.jpg)

- 查看所有用户的信箱、用户 ID、角色、状态、创建时间
- **新增使用者** — 填信箱 + 临时密码，账号建好后发给对方，让 ta 在 App 或 Web 登录
- 编辑用户信息、重置密码、停用 / 删除账号

![新增使用者](/img/web/admin-users-add.jpg)

:::tip 平台账号 vs 共享账本成员
这里管理的是**整个服务器**的登录账号（一人一个邮箱密码）。如果只是想让家人 / 朋友一起记同一本账，不需要在这里建账号，直接用[共享账本](../app/shared-ledger.md)的邀请码就够了——共享账本的 Owner / Editor 是账本维度的角色，跟这里的平台账号管理是两回事。
:::

BeeCount Cloud **不支持自助注册**（避免公网暴露被滥用），新账号只能由管理员在这里创建。

## 健康检查

头像菜单 → **健康**，一眼看服务器是否正常。

![健康检查](/img/web/health.jpg)

- **健康检查**：数据库连接状态、在线用户数、服务器时间
- **使用概览**（仅管理员可见）：全服务器统计——用户数、账本数、交易数、账户数、分类数、标签数

适合定期检查服务器是否正常运行，或者在用户反馈"同步不了"时先看这里排查是不是服务端本身出了问题。

## 线上装置

头像菜单 → **装置**，列出整个平台当前登录中的设备（管理员可按用户筛选；普通用户在[个人资料页](../app/security/app-lock.md#设备管理)里只能看到自己的设备）。

![线上装置](/img/web/devices.jpg)

每条记录显示：平台（web / iOS / Android）、客户端版本、系统、最近活跃时间、首次登录时间、IP 地址。管理员可以在这里发现异常登录（比如陌生 IP），必要时协助用户撤销对应设备的登录态。

## 如何把某个账号设为管理员

首次启动自动创建的账号自带 `is_admin = true`。给其他账号开管理员权限目前需要直接操作数据库（`user_profiles.is_admin` 字段），详见 [BeeCount Cloud 部署文档](../app/cloud-sync/beecount-cloud.md)和[数据清理](../app/maintenance/data-cleanup.md)里的相关说明。
