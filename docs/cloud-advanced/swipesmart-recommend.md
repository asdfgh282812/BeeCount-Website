# SwipeSmart 刷卡建議

> ⚠️ **僅 Cloud 版可用**：本頁功能是 BeeCount Cloud（自建服務端）獨有的進階功能，純 App 本機記帳沒有這個入口。

> 這是**兩個獨立系統的整合**：SwipeSmart 是另一套獨立部署的信用卡回饋推薦引擎，維護「銀行卡片 × 消費分類 → 回饋規則」的資料庫。BeeCount 本身不內建卡片規則庫，而是即時呼叫你自己部署的 SwipeSmart 服務取得建議。使用前你需要已經有一個在跑的 SwipeSmart 服務（網址由你自己的部署決定）。

記帳表單輸入金額跟商家後，會即時顯示「這筆消費刷哪張卡回饋最高」的提示——有綁定對應帳戶的建議可以直接點擊代入帳戶欄位，沒綁定的降級成純文字說明，兩種都會顯示。

> 這跟 [信用卡紅利回饋規則](./card-rewards) 是**兩個不同、互補共存的功能**，不會互相取代：紅利回饋規則是你自己在 BeeCount 維護規則、**消費後**自動結算入帳；SwipeSmart 刷卡建議是**消費前**問「該刷哪張卡」，資料來源是 SwipeSmart 自己持續維護的銀行卡片規則庫。

## 步驟 1：在 SwipeSmart 建立個人 API Key

登入你的 SwipeSmart 網站，右上角「API 金鑰」→ 輸入名稱（例如「BeeCount」）→ 建立。完整金鑰只會在建立當下顯示一次，請立刻複製，關閉後就再也看不到完整內容了。

這把金鑰**綁定你在 SwipeSmart 裡的個人身分**，等同你本人操作（能讀寫你自己的常用卡片/使用額度，也能呼叫推薦引擎），但**絕對**拿不到任何管理端點的權限，即使這把金鑰的擁有者是 SwipeSmart 的管理員也一樣。金鑰弄丟或外洩時，回到同一個分頁隨時可以撤銷，撤銷立即生效。

## 步驟 2：把金鑰貼到 BeeCount

登入 Web 端後，右上角**頭像** → 「設定」分組 → **個人資料**，往下捲到「SwipeSmart 刷卡建議」區塊，貼上金鑰並儲存。

![SwipeSmart 個人 API Key 設定](https://photo.pnsgzomf.synology.me/i/2026/08/11/6a7a10be4cae0.png)

金鑰在 BeeCount 這邊是加密儲存的機敏資料，畫面上只會顯示遮罩（例如 `ssm_219a••••`），不會同步到其他裝置。存好之後如果你名下已經有信用卡帳戶名稱跟 SwipeSmart 卡片目錄剛好對得上，系統會順便自動幫你配對好幾張。

## 步驟 3：卡片對照

儲存金鑰後會多出「卡片對照」設定，點「設定對照」打開視窗：左邊是你的信用卡帳戶，右邊選擇要對應的 SwipeSmart 卡片。

![卡片對照設定視窗](https://photo.pnsgzomf.synology.me/i/2026/08/11/6a7a10bf266c5.png)

- **名稱相近或相同的卡片會自動幫你對應好**（例如 BeeCount 帳戶叫「cube卡」，SwipeSmart 目錄裡有「國泰世華銀行 CUBE卡」，就會自動配上），其餘的手動選一下。
- 沒有對照的信用卡帳戶不會擋住功能，只是這張卡的建議會降級成純文字說明，不能直接點擊代入帳戶（見下方）。
- 已隱藏的帳戶就算對照過，建議上也不會被選中——避免一個你已經不想看到的帳戶被靜默代入。

## 記帳時看到的建議

卡片對照完成後，新增交易時只要金額跟商店都填了，就會自動查詢建議：

![記帳表單建議刷卡](https://photo.pnsgzomf.synology.me/i/2026/08/11/6a7a10bfcc85d.png)

- **已綁定帳戶**的建議是一顆可點擊的按鈕，顯示銀行/卡名跟預估回饋，點一下就把帳戶欄位換成那張卡，你可以再自己調整。
- **沒綁定帳戶**的建議是純文字，例如「這筆消費刷「永豐銀行 DAWHO現金回饋卡」回饋較高（未綁定此卡，無法直接帶入）」，方便你知道有更划算的選擇，但不會幫你亂選帳戶。
- 完全沒有建議可顯示的情況只有兩種：還沒貼 SwipeSmart 個人 API Key，或者 SwipeSmart 服務暫時連不上——這時整個建議區塊就不會出現，不影響正常記帳。

## 常見問題

**沒有信用卡帳戶或還沒對照，會不會擋住記帳？**
不會。SwipeSmart 服務不可用、沒設定金鑰、卡片沒對照，都只是不顯示/不能點擊建議，記帳本身完全不受影響。

**建議是怎麼判斷「刷哪張卡」的？**
完全是 SwipeSmart 那邊依照商家名稱模糊比對消費分類、再套用你自己維護的回饋規則庫算出來的，BeeCount 這邊沒有另外做一份判斷邏輯，也不會擋掉或改寫 SwipeSmart 算出的結果。

**這個功能會不會自動幫我選卡、自動送出？**
不會。建議永遠只是「提示」，帳戶欄位要你自己點擊才會換，交易也要你自己按「儲存」才會真的記上去。

**多台裝置需要各自貼一次金鑰嗎？**
金鑰是加密存在 BeeCount 帳號底下的機敏設定，同一個帳號登入不同裝置會看到同一把（遮罩顯示），不用重貼；但如果換了新的 SwipeSmart 帳號或金鑰過期/撤銷了，要記得回這裡「更換」。
