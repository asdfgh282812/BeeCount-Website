皮夾裡實際有 3,200 元，蜜蜂記帳卻顯示 3,350 元，可能是某幾筆小額現金花費忘了記。與其回頭一筆一筆找，也不想自己算差額再手動記一筆，可以直接告訴蜜蜂記帳「現在應該是多少」，它會算出差額，補上一筆調整交易。

> 📱 App　💻 Web

## 為什麼這樣設計

- 你知道的是「實際餘額是多少」，不是「差了多少」。讓你輸入結果，差額交給系統算，不會算錯。
- 調整會留下一筆獨立的「餘額調整」交易，之後查得到什麼時候、從多少調成多少。

## 怎麼操作

### 📱 在 App 上

1. 「資產」點進要調整的帳戶。
2. 在頁面上方標題列右側，點「調整餘額」圖示（在編輯鉛筆旁邊）。
3. 彈出「調整總額」視窗，上面顯示「目前餘額」。
4. 在「輸入調整後的餘額」填實際的金額，預設已填入目前餘額。
5. 想備註原因的話，填「備註（選填）」。
6. 按「確定」。

系統用「調整後餘額 − 目前餘額」算出差額，補上一筆交易。備註留空時，會自動寫成「餘額調整（核對後由 3,350.00 調整為 3,200.00）」。

也可以在資產頁直接操作：把帳戶向右滑，露出「調整餘額」，點下去開同一個視窗。這是預設設定，要改左右滑各是什麼動作，到「我的」→「個性化設定」→「滑動快捷操作」。

### 💻 在 Web 上

1. 左側選單點「帳戶」，點開要調整的帳戶。
2. 在視窗上方的那一列，按右邊的「調整餘額」。
3. 在「調整餘額」視窗看「目前餘額」，在「目標餘額」填正確的金額。
4. 需要的話填「備註(選填)」。
5. 按「確認調整」，出現「餘額調整已儲存」。

## 注意事項／小提醒

:::note 調整後的交易
- 產生的交易類型是「餘額調整」，不是收入或支出。日期是你按下確定的當下，沒有日期欄位可選。
- 調整交易不能編輯，也不能退款。弄錯的話，刪除那一筆再重新調整。
- 調整交易不計入信用卡帳單週期的消費，也不影響紅利回饋資格，不會出現在對帳清單裡。
:::

- 合併帳單主帳戶（群組）沒有自己的餘額，不提供調整，請到底下的子帳戶調整。
- 投資理財帳戶的餘額是持股成本的帳面數，不提供調整。要改請新增買進、賣出或期初持股。
- 輸入的就是畫面上顯示的那個數字，沒有正負號翻轉。信用卡欠款在餘額裡是負數，例如目前餘額顯示 -5,000 代表欠 5,000。
- 差額為 0 也可以送出，適合只想留一筆「已核對」備註的時候。
- 「餘額調整」是整個帳戶的校正，和[對帳模式](./mode.md)不同：對帳模式是拿信用卡帳單逐筆核對消費，只有信用卡才有。如果是想修正信用卡某一期帳單，優先用對帳模式找出漏記的交易。
