記帳最怕麻煩：要先解鎖、找到 App、點進去、再找「新增」。快速入口把這些步驟縮短，長按一下就能直接拍照記帳，桌面小工具更是連 App 都不用開就能看到今天花了多少。

> 📱 App

## 為什麼這樣設計

不同情境需要不同的起手式：在櫃檯前想拍收據，在路上想用講的，在家想對一下本月預算。所以入口分成三層：App 裡面的長按選單、App 圖示的長按快捷、桌面小工具，由近到遠，挑順手的用就好。

## 長按底部中間的「+」

在首頁，長按底部中間的「+」按鈕，會往上展開三個圓形選項：

| 選項 | 做什麼 |
|---|---|
| 拍照 | 開啟相機，拍下帳單後由 AI 辨識記帳 |
| 相簿 | 從相簿選一張圖（剪貼簿裡有圖片時，會讓你選從剪貼簿貼上） |
| 語音 | 對著手機說出要記的帳 |

手指不放，滑到想要的選項上再放開就會執行。一般點一下「+」則是正常的新增帳單，見 [記第一筆帳](./first-record.md)。

這三個都需要先開啟 AI 並設定好服務商，細節見 [AI 記帳](./ai.md)。沒設定時會提示你先去設定。

## 長按 App 圖示

不用打開 App，直接在主畫面長按蜜蜂記帳的圖示，會跳出四個快捷項目：

- 「圖片記帳」：從相簿選圖辨識。
- 「拍照記帳」：拍照辨識。
- 「語音記帳」：說話記帳。
- 「AI 小助手」：直接開啟 AI 聊天，見 [AI 聊天與查帳](./ai-chat.md)。

iPhone 與 Android 都支援。部分 Android 桌面（啟動器）可能不顯示這個選單，可以改用系統內建的桌面試試。

## 快捷指令連結

「快捷指令」頁整理了一組可以點開 App 特定功能的連結，適合放進 iPhone 的「捷徑」App、Android 的捷徑工具，或其他自動化工具，做出自己的主畫面按鈕。

![App「快捷指令」頁：列出語音、圖片、拍照、快速記支出／收入／轉帳等連結，可複製](/img/record/quick-1.png)
*圖中：① 用途說明　② 一條快捷連結（例如語音記帳）　③ 複製這條連結*

1. 在「我的」點「智慧記帳」，再點「快捷指令」。
2. 在「可用快捷指令」清單點你要的項目，連結會複製到剪貼簿，並提示「連結已複製到剪貼簿」。

可用的項目：

| 項目 | 連結 | 做什麼 |
|---|---|---|
| 語音記帳 | `beecount://voice` | 透過語音快速記錄帳單 |
| 圖片記帳 | `beecount://image` | 從相簿選擇圖片識別帳單 |
| 拍照記帳 | `beecount://camera` | 拍照識別帳單 |
| 快捷記支出 | `beecount://new?type=expense` | 直接打開支出記帳頁面 |
| 快捷記收入 | `beecount://new?type=income` | 直接打開收入記帳頁面 |
| 快捷記轉帳 | `beecount://new?type=transfer` | 直接打開轉帳記帳頁面 |

頁面下方也列出「如何新增快捷指令」的步驟：

- **iPhone**：開啟「捷徑」App，點右上角「+」新建捷徑，加入「開啟 URL」動作，貼上剛複製的連結，儲存後可加入主畫面。
- **Android**：下載支援建立捷徑的工具程式（例如 Shortcut Maker），選「URL 捷徑」，貼上連結，設定圖示和名稱後加到桌面。

### 進階：用連結直接建立帳單

「自動記帳介面」讓你用連結帶參數，直接建立一筆帳單，適合搭配自動化工具。範例：

```
beecount://add?amount=100&type=expense&category=餐飲&note=午餐
```

支援的參數：

| 參數 | 說明 |
|---|---|
| `amount` | 金額（必填） |
| `type` | `expense`（支出）、`income`（收入）、`transfer`（轉帳） |
| `category` | 分類名稱，需與 App 中已有的分類相符 |
| `account` | 帳戶名稱，需與 App 中已有的帳戶相符 |
| `note` | 備註 |
| `tags` | 標籤，多個用逗號分隔 |
| `date` | 日期，ISO 格式，例如 `2026-10-09` |

:::note
語音、拍照、圖片這幾個連結背後是 AI 記帳，需要先開啟 AI 並設好服務商與金鑰。分類、帳戶名稱對不到時，該欄位會空著。
:::

## 桌面小工具

> 📱 iPhone 與 Android 皆有，App 內的名稱叫「桌面小組件」

把帳本「釘」在主畫面上：不開 App，就能看到今天花多少、淨資產走勢、預算還剩多少；想記一筆，點小工具就直接跳到新增頁。

### 有哪些款式

| 款式 | 尺寸 | 顯示內容 |
|---|---|---|
| 收支速覽 | 小、中 | 今日與本月收支 |
| 淨資產 | 小、中、大 | 淨資產與走勢，大尺寸含總資產、總負債 |
| 快速記帳 | 小、中 | 常用分類按鈕與「記一筆」 |
| 預算進度 | 小、中 | 本月預算已用與剩餘 |
| 最近交易 | 中、大 | 最近幾筆收支 |
| 綜合儀表盤 | 大 | 本月概覽、走勢、最近交易與快速記帳 |

### 先預覽再加入

1. 在「我的」點「個性化設定」。
2. 點「桌面小組件」。
3. 在「組件庫」裡逐款看樣子。畫面上是示範資料，加到桌面後才會顯示你帳本的真實內容，主題色跟隨 App 設定。
4. 頁面下方的「如何添加小組件」也有步驟說明。

### 加到主畫面

- **iPhone**：長按主畫面空白處進入編輯模式，點左上角「+」，搜尋「蜜蜂記帳」，選款式與尺寸後加到主畫面。
- **Android**：長按桌面空白處，選「小工具」或「Widgets」，找到「蜜蜂記帳」，長按想要的款式拖到桌面。

### 點下去會去哪裡

- 收支速覽：小尺寸點一下記支出；中尺寸左半邊記支出、右半邊記收入。
- 快速記帳：點某個分類，會帶著該分類開啟新增支出。
- 淨資產、預算進度、最近交易：分別開啟資產頁、預算頁、明細頁。
- 綜合儀表盤：各區塊對應各自的頁面。

### 資料來源與更新

- 內容取自你「目前選的帳本」，跟著帳本的設定走。
- 預設每 30 分鐘自動更新一次，打開 App 時會立刻更新；記帳、切換帳本、改主題後也會跟著更新。
- 深色模式與主題色跟著系統和 App 設定。

## 注意事項

:::tip
想要「付完款自動記」而不是「自己點」，看 [自動記帳](./auto.md)。
:::

- 小工具要先在 App 裡登入並有帳本資料才有內容；剛安裝、還沒有資料時會顯示「暫無交易」「暫無帳戶」之類的空狀態。
- 有些 Android 桌面對第三方小工具的尺寸支援不一，某個尺寸顯示異常時，換相鄰的尺寸試試。
- iPhone 小工具的款式名稱在添加畫面中，可能與 App 內的用字略有不同（例如簡體字），內容相同。
