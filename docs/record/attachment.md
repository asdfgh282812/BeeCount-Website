買家電留下的保固單、報帳要用的收據、水電費繳費單……這些紙本很容易遺失。記帳時順手拍一張附在交易上，之後翻帳目就能看到當時的憑證。

> 📱 App（可新增、預覽、刪除）　💻 Web（可檢視與預覽）　圖片同步與下載模式需要**帳好嗎 Cloud**。

## 為什麼這樣設計

照片會越累積越多，每次同步都全部抓到手機，流量和儲存空間很快就被吃光。所以雲端圖片提供兩種下載模式，讓你依自己的手機空間決定要不要先抓全部。

## 怎麼操作

### 📱 在 App 上新增附件

1. 在新增或編輯交易頁，標籤列（標籤、禮物、圖片、旗子那一排）找到圖片圖示。
2. 還沒有附件時點它，選「拍照」或「從相簿選擇」。相簿一次可選多張。
3. 附件加好後，圖示變成實心，旁邊顯示張數，例如「2」。
4. 照常送出交易。新增交易時附件會在儲存時一起存下；編輯既有交易時，加進來的附件會立刻存下。

![App 記帳頁點圖片圖示：選擇拍照或從相簿選擇](/img/record/attachment-1.png)
*圖中：點標籤列的圖片圖示後，跳出「拍照」與「從相簿選擇」兩個選項*

### 📱 預覽、再新增或刪除

1. 已經有附件時，再點圖片圖示會進入預覽頁，上面顯示共幾張圖片。
2. 左右滑動切換，雙指可縮放。
3. 預覽頁上有新增（圖片加號）與刪除（垃圾桶）圖示，新增同樣是「拍照」或「從相簿選擇」，刪除前會問「確定刪除此附件？」。

在首頁或全部交易點交易，交易詳情裡第一張附件會鋪在分類與金額那一塊當背景（4.0 起），沒有附件就只顯示分類圖示。

### 📱 集中查看所有附件 {#all-attachments}

想找一張收據，不必逐筆打開交易。到「我的 → 資料管理」，在「匯出附件」「匯入附件」下方點「查看所有附件」。

1. 頁面集中列出這台裝置資料中的所有交易附件，跨帳本顯示，不只目前選取的帳本。
2. 圖片依**交易發生時間**由新到舊、按月份分組，每張縮圖下方都有交易日期與時間。這不是拍照或上傳時間。
3. 點縮圖開啟預覽，左右滑動看其他圖片，雙指可縮放。這個入口的預覽不提供直接刪除，要刪除請返回清單選取。
4. 若附件對應的交易已不存在，圖片會排在最後的「交易已刪除」區，仍可查看與清理。

目前沒有依帳本或交易篩選的功能。這裡只列交易附件；分類、帳戶或訂閱的自訂圖示不會混進來，「匯出附件」旁的預覽則也包含自訂圖示。

**多選刪除**

1. 點右上角的「選取」，勾選要移除的圖片；底部可「全選」或「取消全選」。
2. 點「刪除（N）」，核對張數後確認。
3. 不想刪除時，點右上角「取消」離開選取模式。

:::warning 刪除會影響雲端與其他裝置
確認後會刪除本機附件及交易上的附件關聯，**交易本身、金額與備註仍保留**。下次同步成功後，雲端與其他裝置也會移除這些附件，不是只清手機快取；離線時雲端不會立即刪除。這項操作無法復原，需要保留的圖片請先[匯出備份](../more/data.md)。
:::

使用「動態下載」時，尚未在本機的雲端圖片仍需要網路才能載入。Web 目前沒有這個跨交易的附件總覽與多選刪除入口。

### 💻 在 Web 上

Web 的交易列表有「附件」欄，顯示張數，點開可預覽、用「上一張」「下一張」切換。「交易詳情」視窗也會列出「N 個附件」。

Web 目前沒有在記帳視窗新增附件的欄位，要新增附件請在 App 操作。只有已上傳到雲端的圖片才能預覽，還沒上傳完的會提示「僅中繼資料」；不是圖片的檔案提示「該附件不是圖片，暫不支援預覽」。

## 限制與壓縮

- 一筆交易最多 9 張，超過會提示「已達到最大附件數量」。
- 圖片會自動壓縮：長邊最多 1920 像素，品質約 80%，另外產生縮圖，所以不用擔心手機原圖太大。
- AI 拍照或圖片記帳時，可以讓系統自動把原圖加為附件，開關在「智慧記帳」設定的「自動新增附件」，見 [AI 記帳](./ai.md)。

## 雲端圖片容量與擴充 {#cloud-storage}

使用**帳好嗎 Cloud** 時，圖片用量依帳號／上傳者計算，跨帳本合計，包含交易附件、帳戶與分類圖片、訂閱圖示及個人頭像；同一份檔案重用不會重複計算。

1. App 到「我的 → 雲端帳號與同步」，查看雲端圖片總用量、基本與擴充額度、剩餘空間及各類圖片的大小；可按「更新用量」或下拉重新整理。Web 在「雲端帳號與同步」查看。
2. 一般方案目前基本 **5GB**；需要更多空間時，按「用好好幣擴充容量」進商店。預設 5 好好幣永久增加 100MB，每個帳號最多擴充 2GB，實際以商店顯示為準。
3. 支持者有效期間暫免容量限制，但仍顯示實際用量；期滿後既有圖片全部恢復計入「基本容量＋永久擴充」。

空間不足時，App 會在加入新圖片前提示；**不會自動刪除舊圖**，既有圖片仍可查看、下載及刪除。可以整理不需要的附件、購買永久容量，或查看支持者方案。

這是 Cloud 雲端圖片空間；手機照片與快取、其他同步服務的容量各自計算。兌換說明見[好好幣商店](../farm/hh-shop.md#storage)，整理交易圖片可用本頁的[附件總覽](#all-attachments)。

## 雲端圖片下載模式 📱

登入**帳好嗎 Cloud** 後，附件會自動備份到雲端（「附件同步」）。這些雲端圖片要怎麼下載到手機，由你選：

| 模式 | 做法 | 適合 |
|---|---|---|
| 即時下載 | 同步時把所有雲端附件一次載到手機 | 圖片少於約 1,000 張，想隨時離線也能看 |
| 動態下載 | 同步只更新資料，檢視含圖片的交易時才下載那一張 | 圖片很多，想省手機儲存空間與流量 |

1. 「我的」→「雲端帳號與同步」→ 進入**帳好嗎 Cloud** 同步頁，找到「雲端圖片下載」（登入後才會出現）。
2. 點開選「即時下載」或「動態下載」。

登入**帳好嗎 Cloud** 後的第一次（舊版升級上來的也一樣），會跳出選擇視窗，預設選「即時下載」，不能取消也不能點視窗外關閉，一定要選一個。還沒選之前，視同動態下載。

:::note 這個設定只存在這台裝置
手機與平板可以各選不同模式，不會跟著帳號同步，因為儲存空間是裝置自己的事。
:::

:::tip 切換的影響
切到「即時下載」會在背景補齊所有帳本的圖片（提示「正在背景下載雲端圖片…」）。切到「動態下載」不會刪掉已經下載的圖片。動態下載時如果沒有網路，尚未下載的圖片會顯示破圖，連上網路再看就好。上傳不受這個設定影響。
:::

## 注意事項／小提醒

:::note 備份還原要先匯入附件
換手機或還原資料時，請先匯入附件包，再匯入帳本資料，附件才會正確對應到交易。附件匯出與匯入見[匯入與匯出](../more/data.md)。
:::
