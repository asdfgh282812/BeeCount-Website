# 命令面板与快捷键

Web 端右上角搜索框可以用 **⌘K（macOS）/ Ctrl+K（Windows / Linux）**随时呼出，是桌面端最高效的操作入口——不用点鼠标翻页，打字或按方向键就能完成大部分操作。

![命令面板](/img/web/command-palette.jpg)

## 呼出方式

- 快捷键 `⌘K` / `Ctrl+K`（任意页面都能按）
- 点击右上角搜索框

按 `Esc` 关闭，方向键 `↑↓` 切换选项，`Enter` 执行。

## 快捷操作

面板顶部「快捷操作」区，随时可以执行：

| 操作 | 说明 |
|---|---|
| 新建交易 | 快捷键 `N`，直接呼出记账窗口 |
| 年度报告 | 打开年度记账回顾（12 屏沉浸式） |
| 匯出本月 / 本年 CSV | 直接下载当前账本的交易数据 |
| 匯入账本资料 | 打开[导入数据](../app/record/import-export.md#web-端导入)对话框 |
| 切换到浅色 / 深色主题 | 跟头像菜单的主题切换等价 |
| 加入共享账本 | 输入邀请码加入他人的[共享账本](../app/shared-ledger.md) |
| 登出 | 退出当前账号 |

## 页面导览

直接跳转到任意主要页面：首页、交易、日历、账户、分类、标签等，不用点顶部导航。

## 搜索交易

在搜索框直接输入关键词（备注、分类名、金额），命令面板会实时列出匹配的交易，回车可直接打开该笔交易详情——比进交易列表页再筛选更快。

## 使用技巧

- 记账时按 `N` 比点鼠标去顶部导航更快，尤其是键盘操作熟练的用户
- 月底导出对账，直接 `⌘K` → 输入「匯出」→ 回车，不用进设置页找入口
- ⌘K 面板里也能直接问 AI 记账问题，详见 [AI 对话](../app/ai/chat.md#web-端-k-也能问-ai-文档)
