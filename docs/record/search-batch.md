「去年那台吸塵器花了多少？」「這個月 500 元以上的支出有哪些？」「把一堆沒寫備註的交易補上同一句話」。記得越多，越需要快速找到某幾筆、一次處理好。

> 📱 App　💻 Web（兩邊支援的操作不同，下面分開寫）

## 為什麼這樣設計

搜尋與篩選是「先縮小範圍」，批次處理是「對縮小後的結果一次動手」。所以批次操作入口放在搜尋結果裡：先搜出要處理的那群交易，再勾選，避免在一整本帳裡一筆筆找。

## 📱 在 App 上

### 搜尋

1. 在「明細」分頁頭部點右上角的放大鏡。在「明細」列表頁（收據圖示）裡也有搜尋入口。
2. 在搜尋框輸入關鍵字（提示「搜尋備註、商家、分類或金額...」）。系統會在目前帳本的所有交易中，找備註、商家、分類名稱或金額含有該關鍵字的交易。
3. 結果顯示「共 N 條結果」，旁邊有這批結果的「支出」與「收入」合計。
4. 點結果中的一筆，開啟[交易資訊卡](./fields.md)。

沒有輸入任何條件時會提示「輸入關鍵詞開始搜尋」，找不到時顯示「未找到符合的結果」。

### 篩選

點搜尋框右邊的篩選圖示，開啟「篩選」：

![App 搜尋頁的篩選視窗：分類、金額範圍與起訖日期](/img/record/search-batch-1.png)

| 條件 | 說明 |
|---|---|
| 分類篩選 | 選一個分類；選一級分類時，它底下子分類的交易也會一起出現 |
| 金額篩選 | 填「最小金額」「最大金額」，可只填其中一個 |
| 時間篩選 | 「開始日期」「結束日期」，可只填其中一個 |

套用後，搜尋框下方會出現已選條件的標籤，可個別移除。「清空篩選」一次清掉全部。不輸入關鍵字、只用篩選條件也能搜。

### 看最近的交易

不想搜尋，只想翻列表：「明細」分頁頭部的收據圖示進入「明細」列表頁，上方可切「今日」（預設）、「七天內」、「一個月內」、「全部」。「七天內」「一個月內」只限定起點，未來日期的交易仍會出現；「今日」只看今天。若找不到手滑設成未來日期的交易，選「全部」。

### 批次處理

1. 搜尋有結果時，點結果上方的「批次操作」。
2. 每一筆前面出現勾選框，頂部顯示「已選擇 N 項」。點「全選」選取全部結果，已全選時它會變成「取消全選」。
3. 選好之後，下方有三個動作（未選取時為灰色）：
   - **設定備註**：為選中的交易設定同一句備註。輸入框留空會清空備註。
   - **調整分類**：把選中的交易改到同一個分類。選中的交易包含轉帳會提示「選中的交易包含轉帳，無法修改分類」；收入與支出混在一起會提示「選中的交易類型不一致，請選擇全部為收入或全部為支出的交易」。
   - **刪除**：確認視窗寫「確定要刪除選中的 N 筆記帳嗎？此操作無法復原。」
4. 做完點「退出批次操作」回到一般搜尋。

:::warning 批次刪除無法復原
刪除後無法還原，建議先用篩選縮小範圍，再確認勾選的筆數與金額。
:::

:::note 分期交易會被略過
屬於分期計畫的交易不會被批次刪除，結果提示會寫明略過幾筆。要刪請到[分期付款](./installment.md)處理。
:::

## 💻 在 Web 上

### 搜尋與篩選

1. 進入「交易」頁，最上面是關鍵字輸入框，輸入後列表會跟著縮小。
2. 搜尋框右邊的篩選圖示開啟「交易篩選」，可設定：交易搜尋（關鍵字）、交易類型篩選（全部／支出／收入／轉帳）、帳戶篩選、起始日期、結束日期、金額下限、金額上限、分類、標籤。「套用」生效，「重設」清掉。篩選圖示上有圓點時表示目前有條件在作用。
3. 搜尋框下一排是快速日期：「今日」「七天內」「一個月內」「全部」，頁面預設停在「今日」。

![Web 交易頁：關鍵字框、篩選圖示、快速日期與批量選擇](/img/record/search-batch-web-1.png)

![Web「交易篩選」視窗](/img/record/search-batch-web-2.png)

:::note 只設一端的日期
只填起始日期、不填結束日期，會顯示該日（含）之後的所有交易，包含未來日期；只填結束日期則顯示該日（含）之前的所有交易。
:::

### 批量選擇

1. 點右上角的「批量選擇」圖示（桌面寬度才有，手機寬度不顯示）。
2. 每一列前面出現勾選框，上方出現工具列：「已選 N 項」「共 N 項」、「全選當前頁」（再按變「取消當前頁」）。
3. 工具列可做的事：
   - 「匯出 CSV」：只匯出勾選的交易。
   - 「刪除」：跳出「批量刪除交易」確認，顯示筆數與合計金額，並提醒「該操作不可撤銷」，按「確認刪除 N 項」才執行。屬於分期計畫的交易會被略過，結果提示會說明，要刪請到分期付款頁。
4. 點「取消」離開批量選擇。

Web 的批量選擇只有匯出與刪除，沒有批次改備註或批次調整分類。

### 匯出目前篩選結果

「交易」頁右上角的「匯出 CSV」會依目前的篩選條件，匯出目前帳本的交易，看到什麼就匯出什麼。更完整的匯出說明見[匯入與匯出](../more/data.md)。

## 注意事項／小提醒

:::tip 用篩選找「忘記是哪天」的交易
只記得大概金額時，用金額範圍加上時間範圍縮小，比單獨用關鍵字更快。
:::

:::note 搜尋範圍是目前帳本
App 與 Web 的搜尋都在目前選到的帳本內進行，要搜其他帳本請先切換帳本，見[帳本](../prepare/ledger.md)。
:::
