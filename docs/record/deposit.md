朋友聚餐先訂位付了 500 元訂金，餐費 2,000 元要當天才結。訂金當然要記，但「還沒付的 1,500」不該出現在這個月的支出裡，又怕到時候忘記補。用「訂金尾款追蹤」，記訂金時一併登記尾款的金額與日期，**帳好嗎**會到期提醒你，補上之後兩筆才一起算進帳。

> 📱 App　💻 Web（待完成交易頁）

## 為什麼這樣設計

尾款在補上之前**不是一筆交易**：它單獨存放，所以不會出現在統計、帳戶餘額、預算與對帳裡，也就沒有「少算一筆」或「多扣一筆」的風險。補上的那一刻才產生一筆真正的交易，並沿用訂金的類別、專案與商家。

因為尾款不在交易列表上，為了不讓你忘記，到期日當天會在首頁當天的列表插入一列淡色的「待完成交易」提醒，待處理中心（首頁鈴鐺）也有專門的「待處理」分頁，規劃分頁的「未來的錢」裡還有「待完成交易」一列可以隨時查看。

## 怎麼操作

### 📱 在 App 上：記下訂金與尾款

1. 到「記帳」，選「支出」分頁，照平常填訂金的分類、金額、帳戶。
2. 看表單最下面的「一般／週期／分期／訂金」分段選擇，選「訂金」。4.0 之前這個要點「單次」列開「進階設定」視窗，再打開「訂金尾款追蹤」開關；現在直接選「訂金」這一格就等於打開，不用再開視窗。

![App 記帳頁底部的分段選擇選了「訂金」，展開尾款設定](/img/record/deposit-1.png)
*圖中：底部「一般／週期／分期／訂金」停在「訂金」，下方展開「訂金尾款追蹤」的說明與尾款欄位*

3. 選了「訂金」會出現「尾款金額」與「尾款日期」，兩個都可以先不填（顯示「未定」）：

![App 選了訂金後出現尾款金額與尾款日期，目前都是未定](/img/record/deposit-2.png)
*圖中：尾款金額、尾款日期預設都是「未定」*

4. 填入尾款金額，點「尾款日期」選日期：

![App 填好尾款金額 1500 與尾款日期](/img/record/deposit-3.png)
*圖中：尾款金額填了 1500，尾款日期選好日期，日期欄右邊的 ✕ 可以清回「未定」*

5. 確認後儲存這筆訂金。金額 500 是訂金，尾款另外追蹤。

**轉帳**也可以追蹤尾款（例如先轉一筆訂金給別人），開關在轉帳表單上獨立的一列，不在底部的分段選擇裡。

:::note 哪些情況不能用
- **收入**沒有「訂金」這一格，只有支出與轉帳有。
- **週期、分期**是互斥的格：選了「訂金」就不能同時是「週期」或「分期」。由週期或分期產生的既有交易，點「訂金」只會跳出「週期或分期記錄無法使用」的提示。
- 已經**拆帳**的交易不能開（拆帳時整排分段選擇都不提供），因為補尾款要沿用訂金的類別，而拆帳交易沒有單一類別。
- **跨幣別轉帳**（有轉入金額的換匯）目前不支援。
:::

### 儲存之後會發生什麼

訂金照一般支出入帳，列表上帶「訂金」標籤。尾款則只是一筆待補記錄：

- 不計入收支統計、不影響帳戶餘額、預算與對帳。
- 尾款日期當天，首頁那一天的列表最前面會多一列淡色的「待完成交易」，標題寫「尾款」、帶訂金備註與金額：

![App 首頁當天列表：淡色的「待完成交易」尾款列，與下方帶「訂金」標籤的一般記錄](/img/record/deposit-5.png)
*圖中：最上面淡色一列是尚未補上的尾款（標示「待完成交易」，金額 −1,500），下一列是已入帳的訂金 −500，帶「訂金」標籤*

- 這一列只是顯示用的提醒，不是資料庫裡的交易：日期還是「未定」的不會顯示；逾期（日期已過）的不會被搬到今天，只留在待處理中心的「待處理」分頁。它也不會進統計、餘額、搜尋或匯出。點它會直接進到補尾款頁。

### 📱 補上尾款

到了該付尾款的時候，從以下任一處進到「補尾款」頁：

- 首頁當天列表的「待完成交易」列。
- 底部「規劃」分頁 →「未來的錢」→「待完成交易」，點該筆的「補尾款」。
- 待處理中心（首頁右上角鈴鐺）的「待處理」分頁，點該筆的「補尾款」。見[通知與提醒](../more/notifications.md)。
- 訂金的交易詳情上點「點選補尾款」。

![App 補尾款頁：訂金資訊、實際金額、帳戶、入帳日期、延後入帳與備註](/img/record/deposit-6.png)
*圖中：補尾款頁，上方灰字是訂金與預計付款日，「實際金額」預設帶入登記的尾款金額，右上角是「完成入帳」*

1. 「實際金額」填實際付的尾款。登記時若留了「未定」，這裡一定要填，才能入帳。
2. 「帳戶」預設沿用訂金的帳戶，要換可以點選（轉帳則是換轉出帳戶）。
3. 「入帳日期」預設是今天。若尾款是刷信用卡、實際入帳在下一期，可以打開「延後入帳」，見[信用卡對帳模式](../reconciliation/mode.md#延後入帳)。
4. 需要的話寫備註，按右上角「完成入帳」。

補上後，這筆就成為一般記錄，帶「尾款」標籤，類別、專案、商家與收支旗標沿用訂金；訂金與尾款兩筆互相關聯，從任何一筆的交易詳情都看得到尾款金額與「交易總計」，點「點選查看」可以在兩筆之間跳轉：

![App 訂金的交易詳情：下方灰色區塊寫「尾款 NT$1,500.00 · 交易總計 NT$2,000.00」](/img/record/deposit-7.png)
*圖中：訂金交易詳情最下方的關聯區塊；尾款補上前這裡顯示「點選補尾款」*

### 修改或取消

- **修改尾款金額／日期**：在待完成的那一筆點編輯圖示（待處理中心「待處理」分頁，或規劃分頁的「待完成交易」），或編輯訂金交易，表單底部的分段選擇只剩「一般／訂金」，停在「訂金」，用來改尾款，或改選「一般」關掉訂金尾款追蹤。已補上的尾款只能看，不能改。
- **關掉追蹤**：等於刪掉還沒補上的尾款，訂金保留為一般支出。

### 刪除的連動

| 你做的事 | 結果 |
|---|---|
| 刪除訂金交易 | 連同尾款記錄（不論補上了沒有）一起刪除，視為取消訂位、訂金退回 |
| 刪除還沒補上的尾款 | 訂金保留為一般支出，視為訂金被沒收 |
| 刪除已補上的尾款交易 | 該筆尾款追蹤一併刪除，訂金保留 |
| 刪除整個帳本 | 該帳本的尾款追蹤一併清除 |

## 提醒

- **App 本機推播**：尾款日期已定、當天提醒時間還沒到時，到期當天跳出手機通知，即使 App 沒開也會跳。提醒時間沿用「我的 → 提醒 → 信用卡繳費提醒」裡設定的「提醒時間」。日期還沒定的不會提醒；過了提醒時間才新增的，不會補發。
- **待處理中心**：登入**帳好嗎 Cloud** 後，尾款到期前 3 天與逾期時，Cloud 也會寫一則通知進待處理中心（同一筆只提醒一次）。它和本機推播的時間點不同，不是重複通知。
- 「待處理」分頁與規劃分頁的「待完成交易」裡永遠列得出所有還沒補上的尾款，不依賴 Cloud。

## 💻 在 Web 上

**記下訂金**：在「交易」頁按「建立交易」，填好分類、金額、帳戶之後，往下找到「訂金尾款追蹤」開關打開，填「尾款金額」「尾款日期」（皆可留空），再按「建立交易」。

![Web 建立交易視窗：打開訂金尾款追蹤，填尾款金額與尾款日期](/img/record/deposit-web-1.png)
*圖中：「訂金尾款追蹤」開關打開後，出現「尾款金額」「尾款日期」，下方一行說明未定可以留空，尾款補上之前不會計入任何統計*

**看待補的尾款**：右上角頭像選單 →「記帳工具」→「待完成交易」。

![Web 待完成交易頁：待補尾款清單，每筆有訂金、尾款、已逾期標示與補尾款等按鈕](/img/record/deposit-web-2.png)
*圖中：「待補尾款」列出訂金與尾款金額，日期已過會標示「已逾期」；右邊是「補尾款」「編輯」「查看訂金交易」「刪除」；下方「已補上」可展開*

- 「補尾款」開啟視窗，填「尾款金額」「付款時間」（帳戶沿用訂金的帳戶），按「補上尾款」。
- 「編輯」改尾款金額與日期，「刪除」只移除這筆待補的尾款，訂金交易會保留。
- 「已補上」區塊可以展開，看已經補完的，並用「查看訂金交易」「查看尾款交易」跳轉。

Web 建立訂金交易時，交易與尾款追蹤是分兩次儲存的：如果尾款那一步失敗，訂金已經存好，會提示「交易已儲存，但尾款追蹤設定失敗」，到交易列表編輯那筆訂金補登即可。

## 注意事項／小提醒

- 尾款補上前不算支出，所以月底報表、預算看起來會比「實際要花的」少；到「待處理」分頁或規劃分頁的「待完成交易」隨時看還有哪些尾款沒補。
- App 與 Web 的待完成資料會跟著**帳好嗎 Cloud** 同步；舊版 App 看不懂這種資料，但不會因此卡住同步。
- 這個版本還不支援：應收款「代付」的尾款、補尾款時拆帳。
