農場的設定不多，都集中在同一頁：選城市、選計分帳本、調音樂、決定要收哪些通知，不想玩的話也可以在這裡整個關掉。這一頁把每個選項講清楚，最後附上常見問題和一些小技巧。

> 📱 App

## 為什麼這樣設計

- **農場是輔助，不該打擾你。** 所以它可以整個關閉；通知可以按種類開關，會讓人覺得吵的提醒（作物可以收成）預設是關的。
- **你的隱私你決定。** 暱稱、匿名都能自己選，排行榜上不會出現真實金額或信箱。

## 怎麼操作

### 📱 進入農場設定

有兩個入口，進去的是同一頁：

- 在農場畫面右上角點**設定**（滑桿圖示）。
- 「我的 → 一般 → 農場設定」。就算首頁的農場小卡被你隱藏了，也可以從這裡找回來。

### 📱 設定項目一覽

| 項目 | 做什麼 | 單機也有？ |
|---|---|---|
| 單機農場 / 雲端農場 | 顯示你現在用哪一種存檔；雲端時點它可以重新整理同步 | ✅ |
| 農場暱稱 | 拜訪、互動紀錄與排行榜都用這個名字，有字數限制 | 雲端 |
| 排行榜匿名 | 公開排行榜上隱藏暱稱與大頭貼，顯示成匿名農友 | 雲端 |
| 農場通知 | 決定哪些農場事件出現在通知中心 | 雲端 |
| 排行榜裝飾獎勵 | 榜首獲得的免費樹木額度，有的時候才會出現，點進去可去佈置農場 | 雲端 |
| 良心值、新手保護、小偷標記 | 只是讓你看目前的狀態，點開有說明 | 雲端 |
| 看門狗 | 花好幣買保護作物的看門狗 | 雲端 |
| 農場社交 | 進入社交頁 | 雲端 |
| 啟用農場 | 整個開關農場 | ✅ |
| 背景音樂、音量 | 農場配樂的開關與音量 | ✅ |
| 點按音效 | 點作物、建築、擺設、物品卡的輕巧木質聲，可單獨開關 | ✅ |
| 天氣城市 | 農場的天氣與日夜跟著這個城市 | ✅ |
| 計分帳本 | 週結算依這本帳本的記帳情況計分 | ✅ |

單機農場的設定頁最上面的那一列會寫「農場儲存在這台裝置，包含於快照備份；登入帳好嗎 Cloud 後使用帳號的雲端農場。」，單機農場沒有的項目就不會顯示。

### 📱 暱稱與匿名

- 第一次建立雲端農場時會要你取一個暱稱；之前沒取過的人，下次連線進入農場時會提示補填。
- 暱稱有字數限制，不能是空白，也不能包含換行或控制字元，不用唯一。之後可以在「農場 → 設定 → 農場暱稱」，或社交頁右上角的名牌圖示修改。
- 開啟「排行榜匿名」之後，公開榜單上只會顯示成「匿名農友」，隱藏暱稱與大頭貼。

### 📱 農場通知（雲端農場）

「農場 → 設定 → 農場通知」可以按種類決定要不要收：

| 通知 | 什麼時候來 | 預設 |
|---|---|---|
| 每週結算 | 週結算完成可以領取；計分帳本被共享或刪除時，也會提醒你重新選 | 開 |
| 排行榜獎勵 | 每週排行榜公布 | 開 |
| 作物被偷 | 有人偷了你的菜（短時間內多次會合併成一則）| 開 |
| 看門狗抓到偷菜 | 你的看門狗抓到小偷 | 開 |
| 作物可收成 | 有作物成熟 | **關** |
| 季節更換 | 換季前的提醒（有作物在田裡才會提醒）與換季當下 | 開 |

收到的農場通知會集中在「待處理中心」的「**農場**」分頁（首頁頂部的鈴鐺，或「我的 → 待處理中心」進去），不會混進「系統」分頁。點通知的「前往查看」可以直接跳到農場、週結算、排行榜或社交頁。通知不是即時推播，而是 App 定期去讀取，時機由手機系統決定，所以可能晚一點才看到，更多說明見[通知與提醒](../more/notifications.md)。

![農場通知的選單：每週結算、排行榜獎勵、作物被偷等各種通知可以個別開關](/img/farm/settings-4.png)
*圖中：農場通知的開關，作物可收成預設是關的*

![待處理中心的「農場」分頁：週結算、被偷等農場通知](/img/farm/settings-5.png)
*圖中：待處理中心有獨立的「農場」分頁，農場通知都收在這裡*

單機農場沒有通知，請自己打開農場看，特別是換季前記得留意。

### 📱 音樂與音效

- **背景音樂**：依天氣和日夜換曲，進農場自動播放，逛商店、倉庫、設定時也持續播放；離開農場就停止，App 進到背景會暫停，回來接續。預設開啟，可以用滑桿調音量，也可以整個關掉。
- **點按音效**：獨立於背景音樂，可以單獨關閉。
- iOS 上音樂會尊重手機的靜音開關。
- 音樂不受「減少動畫」影響；想要安靜，請用上面的開關。「減少動畫」影響的是畫面上的雨雪風動畫、飄出的表情與開寶箱動畫，見[季節、天氣與日夜](./season-weather.md)。

### 📱 關閉農場

不想玩了，可以在「農場設定」把**啟用農場**關掉（會先跳出確認）：

- 首頁的農場小卡會消失，週結算停止，也不會再發農場通知。
- **存檔會保留**，田地、庫存與好幣都還在；作物仍然依真實時間生長（所以沒收的作物可能枯萎）。
- 雲端農場關閉後，你不會再出現在農友列表，也不會被偷。
- 想再玩，到「我的 → 一般 → 農場設定」重新開啟就好。

![關閉農場前的確認對話框](/img/farm/settings-6.png)
*圖中：關閉農場時的確認，說明存檔會保留、可以從我的 → 一般 → 農場設定重新開啟*

## 注意事項／小提醒

### 常見問題

**首頁看不到農場小卡？**
可能是農場被關閉了。到「我的 → 一般 → 農場設定」重新打開。

**為什麼沒領到週獎勵？**
週結算要自己**點進去領取**，好幣才會入帳。另外也要確認：那週有記帳、計分帳本是非共享帳本、農場在那週有開著。

**水壺用完了怎麼辦？**
隔天會補滿，當天有記帳還能多補一些；下雨的日子作物會自動澆水，不用水壺。

**我的菜怎麼枯掉了？**
常見原因是：換季時還在田裡、一直缺水沒澆、成熟後放著不收超過換季。見[田地玩法](./gameplay.md)與[季節、天氣與日夜](./season-weather.md)。

**為什麼收成失敗？**
倉庫和板條箱都滿了。先賣掉一些、擴充倉庫，或多擺幾個板條箱，見[賣出、倉庫與大頭菜](./market.md)。

**為什麼偷不了菜？**
主人還在農場遊戲裡、有新手保護、這座農場剛偷過在冷卻、今天或這週的次數用完、你的良心值太低，或你的倉庫放不下，都會偷不了，見[社交](./social.md)。

**找不到社交的按鈕？**
社交只有雲端農場才有。沒登入帳好嗎 Cloud 的單機農場，畫面上不會出現。

**換手機之後農場還在嗎？**
雲端農場：登入同一個帳號就會自動載入。單機農場：農場資料包含在快照備份裡，從備份還原才會回來，細節見[其他備份方式](../sync/other-backup.md)。

**離線能玩嗎？**
單機農場可以。雲端農場離線時只能看最後同步的畫面，操作要連線。

**手機時間改過，農場不能操作？**
單機農場偵測到手機時間往回調，會暫停操作；等時間恢復正常就好。

**好幣可以換成真錢嗎？**
不行，好幣只存在遊戲裡，跟你的真實帳戶完全無關。

### 小技巧

:::tip
- 記完帳順手進農場，今天的水壺是補得最足的時候。
- 看一眼天氣再決定要不要澆水，下雨天可以省下水壺。
- 換季前幾天，先把能收的收完。
- 道具存著待用很方便，但快到壞天氣之前才用才划算，效果有時間限制。
- 收成前先看倉庫還有沒有空位。
- 好幣不夠買想要的東西，先去賣作物、領週結算，別急著買大頭菜。
:::
