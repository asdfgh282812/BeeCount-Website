# 管理員功能

頭像選單「管理」分組下的功能僅**管理員帳號**（`is_admin = true`）可見，普通用戶看不到這些入口。自部署時首次啟動自動建立的帳號就是管理員，其他帳號需要管理員手動設定。

## 使用者管理

頭像選單 → **使用者管理**，管理整個 BeeCount Cloud 平台的帳號。

![使用者管理](/img/web/admin-users.jpg)

- 查看所有使用者的信箱、使用者 ID、角色、狀態、建立時間
- **新增使用者** — 填信箱 + 臨時密碼，帳號建好後發給對方，讓 ta 在 App 或 Web 登入
- 編輯使用者資訊、重設密碼、停用 / 刪除帳號

![新增使用者](/img/web/admin-users-add.jpg)

:::tip 平台帳號 vs 共用帳本成員
這裡管理的是**整個伺服器**的登入帳號（一人一個信箱密碼）。如果只是想讓家人 / 朋友一起記同一本賬，不需要在這裡建帳號，直接用[共享賬本](../app/shared-ledger.md)的邀請碼就夠了——共享賬本的 Owner / Editor 是賬本維度的角色，跟這裡的平台帳號管理是兩回事。
:::

BeeCount Cloud **不支援自助註冊**（避免公網曝光被濫用），新帳號只能由管理員在這裡建立。

## 健康檢查

頭像選單 → **健康**，一眼看伺服器是否正常。

![健康檢查](/img/web/health.jpg)

- **健康檢查**：資料庫連線狀態、線上用戶數、伺服器時間
- **使用概覽**（僅限管理員可見）：全伺服器統計資料－使用者數、帳本數、交易數、帳戶數、分類數、標籤數

適合定期檢查伺服器是否正常運行，或者在用戶反饋"同步不了"時先看這裡排查是不是服務端本身出了問題。

## 線上裝置

個人資料選單 → **裝置**，列出整個平台目前登入中的裝置（管理員可依使用者篩選；一般使用者在[個人資料頁](../app/security/app-lock.md#裝置管理)裡只能看到自己的裝置）。

![線上裝置](/img/web/devices.jpg)

每筆記錄顯示：平台（web / iOS / Android）、客戶端版本、系統、最近活躍時間、首次登入時間、IP 位址。管理員可以在這裡發現異常登入（例如陌生 IP），必要時協助使用者撤銷對應設備的登入態。

## 如何把某個帳號設為管理員

首次啟動自動建立的帳號自備 `is_admin = true`。給予其他帳號開管理員權限目前需要直接操作資料庫（`user_profiles.is_admin` 欄位），詳見 [BeeCount Cloud 部署文件](../app/cloud-sync/beecount-cloud.md)和[資料清理](../app/maintenance/data-cleanup.md)裡的相關說明。
