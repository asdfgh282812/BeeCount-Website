「這家店刷哪張卡最划算？」錢包裡卡太多，每次結帳前都要想一下。連接 SwipeSmart 之後，你在記帳時輸入金額和商家，蜜蜂記帳就會列出回饋最高的卡，點一下就把那張卡帶進帳戶欄位。

> 📱 App　💻 Web　　需要 BeeCount Cloud 並登入，以及你自己的 SwipeSmart 帳號

## 為什麼這樣設計

- 回饋規則資料庫由 SwipeSmart 維護並比對，蜜蜂記帳只負責把查詢結果放在記帳流程裡，不用另外開 SwipeSmart 查。
- 建議只是提示：帳戶要你自己點才會換，交易也要你自己按儲存才會記上去。查詢失敗、沒連線、沒設定，都只是不顯示建議，不會影響記帳。

## 怎麼操作

### 1. 連接 SwipeSmart

先到 SwipeSmart 網站建立一把 Personal API Key，完整金鑰只會在建立當下顯示一次，請馬上複製。

![App「SwipeSmart 信用卡推薦」頁：尚未連接時，貼上 Personal API Key 後按連接](/img/credit-card/swipesmart-1.png)
*圖中：① 貼上 Personal API Key　② 按「連接」*

**📱 在 App 上**

1. 點「我的」→「雲服務」，進入 BeeCount Cloud 的同步頁（要先登入）。
2. 點「SwipeSmart 信用卡推薦」。
3. 在「貼上你的 SwipeSmart Personal API Key」欄位貼上金鑰，按「連接」。
4. 成功後會顯示「已連接：xxxx」（只露出金鑰前幾碼）與「已自動對應 N 張信用卡帳戶」。要停用就按「中斷連接」並確認。

![App SwipeSmart 頁連接成功後：已連接的金鑰、「連接」「中斷連接」兩個按鈕與「卡片對照」入口](/img/credit-card/swipesmart-2.png)
*圖中：① 連接成功：只顯示金鑰前幾碼，其餘遮起來　② 換金鑰時按「連接」　③ 「中斷連接」　④ 「卡片對照」：把蜜蜂記帳裡的卡對應到 SwipeSmart 的卡*

**💻 在 Web 上**

1. 左側選單點「設定」→「個人資料」，往下捲到「SwipeSmart 刷卡建議」。
2. 在「SwipeSmart 個人 API Key」按「新增」，貼上金鑰儲存。要換新的就按「更換」，金鑰預設以遮罩顯示，可按「顯示」暫時看明文。
3. 儲存後會提示「SwipeSmart Key 已儲存，並自動配對了 N 張信用卡」。

金鑰在雲端是加密儲存的，同一個帳號登入不同裝置不用重貼。

### 2. 卡片對照

名稱相近的卡會自動配好，沒配到的要自己對一下，這樣建議才能直接點選代入你的帳戶。

- 📱 App：同一頁點「卡片對照」，每張信用卡一個下拉選單，選對應的 SwipeSmart 卡片；沒配到的顯示「未對照」，也可以清空。

![App 卡片對照頁：每張信用卡右邊一個下拉選單，尚未對照的顯示「未對照」](/img/credit-card/swipesmart-3.png)
*圖中：① 蜜蜂記帳裡的每張信用卡　② 右邊的下拉選單選它對應 SwipeSmart 的哪張卡；名稱相近的會自動對好，其餘預設「未對照」*
- 💻 Web：在 SwipeSmart 區塊按「設定對照」，左邊是你的信用卡帳戶，右邊選要對應的 SwipeSmart 卡片。

### 3. 記帳時看刷卡建議

**📱 在 App 上**

1. 新增一筆「支出」，輸入金額（大於 0）。
2. 在「商家…」欄位輸入商家名稱，例如「保費」。
3. 停止輸入約半秒後，商家欄下方會出現一排可左右滑動的建議卡片，顯示「銀行 卡名」與預估回饋（例如 +120 (10.0%)），依回饋由高到低排列。

   ![App 新增支出：輸入金額與商家「保費」後，商家欄下方列出兩張建議卡與預估回饋](/img/credit-card/swipesmart-5.png)
   *圖中：① 商家欄（輸入後約半秒開始查詢）　② 回饋最高的建議卡：銀行、卡名與預估回饋　③ 第二張建議卡，可左右滑動看更多*
4. 點一張建議卡，會把那張信用卡帶入帳戶欄，同時出現這張卡的「選擇紅利回饋」入口。如果這張卡在這個分類以前手動選過回饋規則，會幫你自動勾上。

**💻 在 Web 上**

新增支出，輸入金額和商家後，帳戶欄下方出現「建議刷卡」區塊，最多列出 3 張已對照的卡，每張顯示銀行、卡名和預估回饋（例如預估回饋 45（1.5%））。點一張就代入帳戶，區塊會收起來，變成可再展開的一行摘要。沒有對照到你帳戶的卡，只會用文字說明「這筆消費刷『某銀行 某卡』回饋較高（未綁定此卡，無法直接帶入）」。

### 4. 沒有建議時：排除項提示

保費、稅費等許多消費，卡片的一般回饋本來就不計算。如果 SwipeSmart 查完是空的，App 的商家欄位下方會出現一行小字：「此項可能為排除項，建議進網頁端查詢」。要看詳細原因，請到 SwipeSmart 網頁查詢。

只有 SwipeSmart 本身回傳空結果才會顯示這行；有建議但沒對照到你帳戶的卡，則不會顯示。

### 5. 問 AI 助手

連接並對照好之後，直接在 AI 助手對話裡問：「YouTube 訂閱刷哪張卡？」AI 會推測真正的商家、查回饋，優先列出你自己的卡並標示估計回饋。接著說「幫我記 199」或「就用第一張記帳」，就會用那張卡記帳。

沒登入 BeeCount Cloud 或沒連接 SwipeSmart 時，AI 會提示並附上前往登入或前往連接的按鈕。沒講金額的話，會用 1,000 試算，但不會拿試算金額去記帳。詳見[AI 聊天與查帳](../record/ai-chat.md)。

### 6. 從 SwipeSmart 一鍵記帳

在手機上用 SwipeSmart 網頁查完刷卡建議，不用回頭重打：

1. 在 SwipeSmart 的推薦結果點「一鍵記帳」。
2. 手機有裝蜜蜂記帳的話，會直接開啟 App 的「新增交易」表單，已預填商家、金額、分類（對得到時）和信用卡帳戶（已完成卡片對照時）。
3. 檢查內容，自己按儲存。不會自動寫入交易。
4. 沒裝 App，或 App 沒反應時，會改開 BeeCount 網頁版。網頁版沒登入的話，先登入，登入後會回到這筆待記的交易。

卡片沒對照到帳戶時，帳戶欄位留空，改把「SwipeSmart 建議刷：銀行 卡名（…）」寫進備註，提醒你回頭補對照。分類只在名稱剛好對到一個你的支出分類時才帶入，對不到就留空。

## 注意事項／小提醒

:::note 查詢條件
App 要「支出、已連接金鑰、金額大於 0、商家不是空的」才會查詢；同一組金額與商家不會重複查。收入和轉帳不會出現建議。
:::

- 未對照的卡在 App 的建議列不會出現，避免點了沒反應；Web 則用文字提示。
- 已隱藏的帳戶就算對照過，也不會被代入。
- 日期沿用表單預設值（現在），事後補記要自己改日期。
- AI 對話的建議無法分辨「商家認不得」與「排除項目」，兩者都會是空結果。
- 這個功能和紅利回饋是兩回事：刷卡建議是消費前問「刷哪張」，[紅利回饋](./rewards.md)是消費後算回饋入帳。
