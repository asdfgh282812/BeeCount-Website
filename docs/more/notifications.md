信用卡繳款日、朋友欠你的錢、除息後該確認的股利，這些日子很容易忘。**帳好嗎**會在對的時候提醒你，提醒集中在「待處理中心」（4.0 之前叫「通知中心」），你也可以另外設定每天固定時間的記帳提醒。

> 📱 App　💻 Web（雲端通知需要登入**帳好嗎 Cloud**，兩邊看到的是同一份通知）

:::important 手機 App 沒跳通知，可以另外用瀏覽器接收
目前 App 的 Cloud 新通知主要靠 App 開啟時檢查，以及手機系統允許的背景更新，**不是保證即時送達的手機推播**。App 放在背景、被手動關閉或受到省電限制時，可能沒有跳出提醒，但通知已經留在待處理中心。

想增加接收管道，可以在電腦或**手機瀏覽器**啟用[瀏覽器背景通知](#browser-push)。iPhone／iPad 要先加入主畫面，再從主畫面開啟並允許通知。瀏覽器通知與 App 的權限分開，啟用其中一邊不會自動開啟另一邊。
:::

## 為什麼這樣設計

雲端通知是由伺服器依你的資料（帳單週期、欠款到期日、持股除息日…）統一產生的，App 和 Web 共用通知內容與已讀狀態。在手機上標為已讀後，Web 的清單也會顯示已讀；至於手機或電腦會不會跳出通知橫幅，還要看接收方式、通知權限與系統設定。

4.0 起，App 把散在各處的「待確認」事項（待補尾款、待確認股利、待確認帳戶、待確認專案）也收進同一個頁面，所以改叫「待處理中心」；這些事項是手機本機的資料，不需要登入**帳好嗎 Cloud** 就看得到。

## 通知清單與系統通知有什麼不同

| 你看到的地方 | 代表什麼 | 沒開 App 時會怎樣 |
|---|---|---|
| App 的待處理中心、Web 的通知鈴清單 | 通知已記錄在帳號裡，可以查看內容與標為已讀 | **清單有新通知，不代表手機或瀏覽器已跳出橫幅** |
| App 的 Cloud 通知橫幅 | App 讀到新的雲端未讀通知後，請手機系統顯示 | 背景檢查受系統限制，可能延遲或等到下次開啟 App 才讀到 |
| App 的本機排程提醒 | 記帳、信用卡、訂閱等提醒已由 App 預先交給手機系統安排 | 已成功排好的提醒可在 App 沒開時顯示，仍需允許通知；其他裝置改了條件，要等這台 App 同步後更新排程 |
| 瀏覽器背景通知 | 已啟用的瀏覽器接收 Cloud 推播，再請系統顯示 | 不必等待手機 App 背景拉取；關閉網頁後仍可接收，但受網路、權限與系統背景設定影響 |

**實際看到系統通知橫幅，或在裝置的通知中心找到該則通知，才算確認這台裝置收到。** 只看到網站清單新增一筆，或看到「推播服務已接受」，都不能當作裝置已顯示的證明。

## 怎麼操作

📱 App 的提醒相關入口在「我的」頁，同一張卡片裡的兩列：

- 「待處理中心」：集中所有通知與待處理事項，右邊會顯示待處理的件數。
- 「提醒」：進入「提醒設定」，裡面有「記帳提醒」與「信用卡繳費提醒」兩項。

![App「我的 → 提醒」頁：記帳提醒與信用卡繳費提醒兩個通知設定](/img/more/notifications-1.png)
*圖中：「提醒設定」頁有「記帳提醒」與「信用卡繳費提醒」兩項（週期記帳已搬到「規劃」分頁）*

### 待處理中心（通知與鈴鐺）

**📱 在 App 上**

![App 待處理中心：欠款未結清、股利待確認、信用卡回饋入帳等通知，紅點代表還沒讀](/img/more/notifications-3.png)
*圖中：待處理中心的「全部」分頁，每則通知可點開看完整內容，紅點代表還沒讀，頂端是分類分頁*

1. 首頁頁首有一個鈴鐺圖示，**永遠都會顯示**（4.0 之前沒登入 Cloud 又沒有待補尾款時會消失）。右上角的紅色數字是雲端未讀通知加上待處理事項的件數（超過 99 顯示 99+）。也可以從「我的」→「待處理中心」進入。
2. 點鈴鐺進入「待處理中心」。沒有通知時會顯示「目前沒有通知」。
3. 點一則通知，會標為已讀，並從下方彈出「詳情面板」，顯示完整標題、確切時間（你所在時區的時間）與完整內文，內文可以長按複製。過長時面板內可以捲動。
4. 如果這則通知有對應的項目（信用卡、欠款、週期性收支、股利），面板上會有「前往查看」按鈕，按下才會跳到相關頁面：信用卡通知到帳戶詳情、週期性收支通知到週期帳單清單、欠款到期通知到還款頁、股利通知到待確認股利頁。沒有對應項目的通知（例如系統公告）只有「關閉」。

![App 通知詳情面板：完整標題、時間與內文，下方是「關閉」與「前往查看」](/img/more/notifications-detail.png)
*圖中：通知詳情面板顯示完整標題、確切時間與完整內文（可以長按複製），下方是「關閉」與「前往查看」（有對應信用卡、欠款等項目的通知才有）*

設計理由：通知列表為了排版整齊，每則最多只顯示 3 行，太長的公告以前根本看不到全文；而且跳轉之前系統要先查本機資料，有時還要切換帳本，只是想讀全文的人不該被直接帶走。所以改成先看詳情，要跳再按「前往查看」。
5. 右上角「全部標為已讀」可一次清掉未讀。
6. 通知頁可以下拉重新整理；載入失敗時按「重試」。

**通知分類分頁**

待處理中心頂部有一排可左右滑動的分類分頁：

![App 待處理中心頂部的分類分頁：全部、待處理、欠還款、信用卡、週期、農場、系統，各有未讀數](/img/more/notif-tabs-1.png)
*圖中：頂端一排分頁，每個分頁右上角的紅色數字是該類的未讀數（「待處理」是待處理事項的件數）*

| 分頁 | 內容 |
|---|---|
| 全部 | 所有通知（待處理事項不會混進來） |
| 待處理 | 還沒完成的事項：最上面是「待確認股利」「待確認帳戶」「待確認專案」三張分組卡（沒有的就不出現，點進去逐筆處理），下面逐筆列出還沒補上的訂金尾款，見[訂金尾款追蹤](../record/deposit.md) |
| 欠還款 | 欠款到期、未結清款項 |
| 信用卡 | 帳單、繳款提醒與紅利回饋入帳 |
| 週期 | 週期性收支續期、轉帳被跳過 |
| 農場 | 農場的收成、週結算、訪客、排行榜、被偷等通知，見[農場](../farm/overview.md) |
| 系統 | 預算警示、股利待確認、系統公告與其他 |

- 「待處理」分頁的數字是待處理事項的總件數（待補尾款、待確認股利、帳戶、專案），其他分頁是該類的未讀數，「全部」是全部未讀。
- 「待處理」分頁裡每一筆尾款都有「補尾款」，也能直接編輯或刪除，不用再進到另一個畫面；它讀的是本機資料，沒有登入**帳好嗎 Cloud** 也看得到。資產頁的「待確認帳戶」卡片與規劃頁的「待確認專案」卡片，點下去也是直接開這個分頁。

![App 待處理中心的「待處理」分頁：待確認分組卡與尾款金額、「補尾款」按鈕](/img/more/notif-tabs-2.png)
*圖中：「待處理」分頁上方是待確認股利、帳戶、專案的分組卡，下方列出訂金尾款，右下角是「補尾款」，旁邊有編輯與刪除*

- 「全部標為已讀」是全域的，不分分頁；分頁選擇不會記住，每次進來都從「全部」開始。
- 尾款與訂金的金額會跟著「隱藏金額」一起遮住。

**💻 在 Web 上**

點右上角的鈴鐺，會展開通知清單，可以「全部已讀」。點選一則通知會先開啟完整內容；有對應項目時，再按「查看詳情」前往帳戶、欠款或週期性收支。Web 的通知清單沒有分類分頁。

#### 被偷通知也能看植物與數量 {#stolen-crops-web}

農場的被偷通知在 App 與 Web 都會列出植物名稱、數量，例如「蘿蔔 × 5、南瓜 × 3 被偷走了」。兩小時內多次被偷會合併，同種植物的數量加總；清單中的內文較長時會截短，點通知就能閱讀全文。

![Web 被偷通知的完整內容，列出蘿蔔五個與南瓜三個及回禮期限](/img/farm/stolen-web-detail.png)
*圖中：Web 可以閱讀完整的被偷通知；想拜訪或回禮，請回 App 操作*

App 可從「待處理中心 → 農場」點通知，再按「前往查看」進入農場社交；Web 沒有農場拜訪或回禮畫面，所以這類通知不會顯示「查看詳情」跳轉按鈕。通知開關與 App 操作見[農場通知](../farm/settings.md#stolen-crops)。

### 瀏覽器背景通知 {#browser-push}

這是 App 的 Cloud 通知之外的另一條接收管道，**電腦與手機都可以使用**。如果管理員已更新並啟用瀏覽器推播，登入 Web 後，右上角通知鈴底部會有「**瀏覽器通知**」設定。

#### 啟用與測試

1. 用想接收通知的瀏覽器登入 Web，點右上角通知鈴。
2. 按「啟用瀏覽器通知」，在瀏覽器詢問時選擇允許。每個瀏覽器、每台裝置都要分別啟用。
3. 等狀態變成「**這個瀏覽器已啟用**」。如果只顯示「已允許，尚未完成訂閱」，代表通知權限已開，但還沒完成接收設定，請繼續按「啟用瀏覽器通知」。

![瀏覽器已允許通知，但尚未完成訂閱，通知鈴底部仍有啟用按鈕](/img/more/notifications-web-permission.png)
*圖中：「已允許，尚未完成訂閱」與「這個瀏覽器已啟用」是不同狀態；瀏覽器允許通知後，仍要完成網站的訂閱設定。*

4. 啟用後，按旁邊的「**傳送測試通知**」。這會透過 Cloud 實際發送，請查看系統通知橫幅或通知中心，不只看網站裡有沒有新增一筆。

![瀏覽器通知啟用完成，顯示停用與傳送測試通知按鈕](/img/more/notifications-web-enabled.png)
*圖中：啟用成功後，狀態顯示「這個瀏覽器已啟用」，旁邊會出現「傳送測試通知」。*

5. 之後 Cloud 產生的新通知會透過瀏覽器接收。點系統通知會開啟 Web 的完整內容，再按「查看詳情」前往相關項目。不想接收時，可回到這裡按「停用」。

#### 手機怎麼啟用

- **iPhone／iPad**：需 iOS／iPadOS 16.4 以上。先從瀏覽器分享選單選「加入主畫面」，再由主畫面的帳好嗎圖示開啟、登入，依上面的步驟允許並啟用通知。只在一般瀏覽器分頁開網站，還不算完成這個步驟。
- **Android**：用支援背景推播的瀏覽器登入並啟用，另外確認 Android 系統允許這個瀏覽器顯示通知；網站通知也要允許。不同廠牌的背景與省電設定可能影響接收。

![手機瀏覽器顯示 iPhone 與 iPad 需要先加入主畫面的提示](/img/more/notifications-web-ios.png)
*圖中：以手機寬度呈現的 iPhone／iPad 操作提示；要從加入主畫面的圖示開啟，再啟用通知。*

#### 測試後只多一筆清單，沒有跳出通知？ {#browser-push-troubleshooting}

**正常應該是瀏覽器／作業系統顯示通知，而不是只有網站清單多一筆。** 測試通知會先建立網站內的紀錄，接著才嘗試推播，因此請先看測試按鈕下方的結果：

| 畫面結果 | 代表什麼 | 接下來怎麼做 |
|---|---|---|
| 測試通知已排入佇列 | 已安排發送，尚未確認推播服務接受 | 稍等後再看結果；一直停在這裡時，請回報管理員檢查發送狀態 |
| 推播服務已接受測試通知 | Cloud 已把通知交給推播服務，**不代表裝置已顯示** | 查看裝置通知中心，並檢查下方的瀏覽器與系統通知設定 |
| 測試未能送出、伺服器驗證未通過等錯誤 | 發送尚未成功 | 依畫面提示重新啟用或回報管理員；不要把網站清單裡的測試紀錄當成成功 |
| 要求更新通知服務 | 目前仍是舊版的通知服務 | 按「更新通知服務」，重新整理後再啟用；更新前先儲存未完成的內容 |

![測試通知顯示推播服務已接受，並提醒檢查裝置通知中心](/img/more/notifications-web-test.png)
*圖中：推播服務已接受測試，但仍要親自確認裝置是否出現通知；清單中的測試紀錄不等於系統橫幅。*

如果顯示已接受，卻沒有橫幅，依序檢查：

1. **先看裝置通知中心**：可能已有通知，只是沒有跳橫幅或發出聲音。
2. **瀏覽器的網站權限**：在網址列旁的網站設定中確認「通知」為允許；也可以從瀏覽器設定搜尋「網站通知」。
3. **作業系統的通知權限與顯示方式**：Mac 到「系統設定 → 通知」檢查使用中的瀏覽器或已安裝的網站 App，允許通知並開啟橫幅；Windows 到「設定 → 系統 → 通知」檢查瀏覽器。手機則到系統的「通知」設定檢查接收用的瀏覽器或主畫面網站 App。**只允許帳好嗎手機 App，不等於已允許瀏覽器。**
4. **專注／勿擾模式與通知摘要**：這些設定可能讓通知安靜顯示、延後出現，或不跳橫幅。
5. **網路與背景限制**：確認裝置有網路，瀏覽器沒有被強制停止，系統也沒有禁止它在背景接收。

- 顯示「伺服器尚未啟用」時，需要管理員完成推播設定；瀏覽器不支援或已封鎖通知時，也會顯示對應說明。
- 只會發送啟用後的新通知，不會一次補發所有歷史未讀。登出會解除這個瀏覽器的綁定，重新登入後需再次啟用。
- 瀏覽器通知仍需要 Cloud 正常產生並發送，也不是送達保證。每日記帳、存錢桶、訂閱等由 App 本機排程的提醒，仍依各功能原本的方式發送，不會因為啟用瀏覽器通知就自動改成雲端推播。

### 通知清單裡會出現的通知

| 通知 | 什麼時候出現 |
|---|---|
| 信用卡帳單 | 結帳日隔天（帳單已結算）、繳款日前 7 天、繳款日當天、繳款日已過仍未繳清（天數可在「信用卡繳費提醒」調整，見下方）。已繳清的帳單不會提醒。 |
| 欠款到期 | 借還款的到期日快到或已逾期，且還沒還清。 |
| 未結清款項 | 某個對象還有未結清的借還款時，會有一則摘要（例如「小明有未結清款項」），結清前一直維持未讀。 |
| 週期性收支 | 週期規則自動續期，或轉帳因餘額不足被跳過。 |
| 紅利回饋 | 信用卡紅利回饋派發。 |
| 訂金尾款 | 登記的尾款快到期（前 3 天）或已逾期，由**帳好嗎 Cloud** 寫進通知；另外 App 在尾款到期當天還會有本機推播，見[訂金尾款追蹤](../record/deposit.md#提醒)。 |
| 股利待確認 | 持有的股票除息後，有股利等你確認入帳。 |

欠款通知會固定排在最上面，其次是信用卡帳單。

### 手機 App 沒跳出 Cloud 通知時 {#app-no-banner}

農場、股利、信用卡回饋、公告等 Cloud 通知，可能已經出現在待處理中心，手機卻沒有跳出提醒。**目前 App 的雲端通知接收靠定期檢查，不保證像即時通訊 App 一樣立即彈出。**

- **App 開啟或回到前景時**：會檢查新通知，平常清單約每分鐘更新一次。讀到新的未讀通知後才請系統顯示；手機仍需允許通知，且顯示方式可能受專注模式影響。
- **App 留在背景時**：3.8.3 起會請系統定期喚醒、拉取新通知。這是盡力執行的背景更新，可能延遲數分鐘到數小時，不能保證固定時間執行。
- **iPhone／iPad 從 App 切換器把 App 往上滑掉**：App 的背景檢查可能停止，要重新開啟 App。低耗電模式或關閉「背景 App 重新整理」也會限制背景接收。
- **Android**：背景工作週期最短約 15 分鐘，仍可能受省電、電池最佳化或背景執行限制影響；系統通知頻道沒有允許橫幅時，也可能只有清單、沒有彈出提醒。

可以依序這樣處理：

1. 開啟 App，進入首頁鈴鐺的待處理中心重新整理，先確認 Cloud 是否已有這則通知。
2. 到手機系統的「通知」設定，確認帳好嗎已允許通知，以及橫幅、鎖定畫面或通知中心的顯示方式。
3. iPhone／iPad 確認「設定 → 一般 → 背景 App 重新整理」已開啟，並重新開啟曾被手動關閉的 App；Android 則檢查背景執行與省電限制。
4. 若希望多一條接收管道，在同一支手機上依[瀏覽器背景通知](#browser-push)啟用 Web 推播，完成後按「傳送測試通知」確認。**App 與瀏覽器各有自己的權限，兩邊要分別檢查。**

:::note 這不代表手機 App 所有提醒都不能用
每日記帳、信用卡繳費、訂閱等**已由 App 預先排進手機系統**的本機提醒，可以在 App 沒開時顯示；上面的背景更新限制主要影響「App 去讀取剛產生的 Cloud 新通知」。若本機提醒也沒出現，請檢查通知權限、提醒開關、排程時間及同步是否完成。
:::

### 每日記帳提醒

1. 「我的」→「提醒」→「記帳提醒」。
2. 打開「每日記帳提醒」。
3. 點「提醒時間」設定幾點提醒，預設是晚上 9:00。預設是關閉的。
4. 想確認通知能不能正常跳出，按「傳送測試通知」。

![App 記帳提醒頁：每日提醒開關、提醒時間與發送測試通知按鈕](/img/more/notifications-2.png)
*圖中：「記帳提醒」頁有每日記帳提醒開關、提醒時間、傳送測試通知按鈕，下方是 iOS 通知權限與使用提醒*

Android 如果收不到通知，頁面下方有「檢查電池最佳化狀態」與「檢查通知頻道設定」可以排查，請確認通知頻道與背景設定沒有封鎖提醒。iOS 已排好的本機提醒由系統負責顯示，不需要一直開著 App；如果是 Cloud 新通知沒有跳出，請改看[App 背景接收的限制](#app-no-banner)。

### 信用卡繳費提醒

4.0 起，繳費提醒可以**每張卡各自設定**。

1. 📱 App：「我的」→「提醒」→「信用卡繳費提醒」；或到「資產」，點進一張信用卡，在「帳戶資訊」分頁點「信用卡繳費提醒」，直接開啟這張卡的設定。💻 Web：點頭像，在「設定」群組選「信用卡繳費提醒」；帳戶詳情裡也有捷徑。
2. 總覽頁上半部是**全域預設**，會套用到所有「沿用全域預設」的卡片：
   - 「提醒時間」：三種提醒共用的時間，預設 10:00；
   - 「還款提醒」：在繳款日前提前 1、3、5 或 7 天提醒；
   - 「帳單結算提醒」：結帳日的隔天提醒；
   - 「到期連續提醒」：從繳款日起每天提醒到繳清為止，最長 1、2、3、5、7 或 10 天。
3. 總覽頁下半部的「各卡提醒」列出獨立的信用卡與合併帳單主帳戶，右邊標示「沿用全域預設」或「個別覆寫」，點一張進入這張卡的設定頁。
4. 單卡設定頁最上面是「沿用全域預設」開關：打開時這張卡跟著全域預設走；關閉後可以單獨調整提醒時間與三種提醒，之後全域預設再改，也不會影響這張卡。再把開關打開，這張卡就回到全域預設。
5. 合併帳單底下的子卡共用主帳戶的提醒，所以只會有一組設定，不會同一張帳單提醒好幾次。

![App 信用卡繳費提醒總覽：全域預設的提醒時間與三種提醒，下方是各卡提醒清單](/img/credit-card/billing-3.png)
*圖中：「信用卡繳費提醒」上半部是全域預設的提醒時間、還款提醒、帳單結算提醒與到期連續提醒，下半部「各卡提醒」列出每張卡目前是沿用預設還是個別覆寫*

![App 單張信用卡的提醒設定：沿用全域預設開關與三種提醒](/img/more/notifications-5.png)
*圖中：點進單張卡之後，最上面是「沿用全域預設」開關，關閉後才能單獨調整這張卡的提醒時間與三種提醒*

信用卡要先設好結帳日與繳款日才會有提醒（沒填時單卡設定頁會提示「請先在帳戶設定填寫結帳日與繳款期限，才能排程提醒。」），設定方式見[設定信用卡](../credit-card/setup.md)。這些設定存在你的帳號裡，Web 與 App 看到的是同一份；通知權限則要在每台手機各自允許。

:::note 升級前就有登入**帳好嗎 Cloud** 的人
如果你還沒動過這些設定，會保留 4.0 之前的行為（結算、繳款日前 7 天、繳款日當天，加上逾期提醒），設定頁會顯示目前實際生效的值，並註明這是舊版 Cloud 提醒。你一調整任何選項，之後就改依這裡的設定排程。
:::

:::note 登入**帳好嗎 Cloud** 時：信用卡通知不開 App 也會準時跳（3.8.3 起）
信用卡的帳單日與還款日，App 本機本來就有，時間是可以預測的，不需要等伺服器通知你。所以登入**帳好嗎 Cloud** 後，App 會把下面四種提醒直接排進手機系統，到時間手機自己跳出來，不用開著 App（下表是還沒調整過設定時的預設；調整過「信用卡繳費提醒」的話，跳出的就是你開啟的那幾種，天數也照你選的）：

| 提醒 | 什麼時候跳 |
|---|---|
| 帳單已結算 | 結帳日隔天 |
| 還款快到了 | 繳款日前 7 天 |
| 今天到期 | 繳款日當天 |
| 已逾期 | 繳款日隔天（同一期只提醒一次） |

- 跳出的時間沿用「信用卡繳費提醒」裡設定的「提醒時間」（預設 10:00），每張卡可以各自設定，內容與待處理中心的信用卡通知一致。
- 這四種信用卡通知在待處理中心裡仍然看得到，但背景拉取不會再重複跳出系統通知，所以不會收到兩次。
- **金額是上一次使用 App 時的快照：** 每次開啟或離開 App 時會重新計算排程。如果你在別的裝置繳了款，又一直沒開這台的 App，通知可能還是跳舊金額。
- 已經繳清的那一期不會排；沒有欠款的卡不會預排本期的提醒。「帳單已結算」的文案不帶金額（結算當下的金額到那天才算得出來）。
- 自動扣繳的結果（扣款成功、餘額不足略過）要等 Cloud 排程跑完才知道，本機算不出來，仍由待處理中心與背景拉取負責。
:::

### 訂閱續訂與試用到期提醒 {#subscription-reminders}

在 App「規劃 → 週期記帳 → 訂閱」新增或編輯服務，打開「續訂提醒」，選當天或提前 1、2、3、5、7 天提醒；免費試用到期也使用同一個設定。Web 可在「頭像選單 → 記帳工具 → 週期性收支 → 訂閱」設定，再同步到手機。

- 通知由手機 App 本機排程，Web 不會另外發送系統通知，也不是待處理中心的雲端通知。請允許手機的通知權限。
- 提醒時間沿用「我的 → 提醒 → 信用卡繳費提醒」的**全域提醒時間**，預設上午 10:00，不採用單張卡的個別覆寫時間。
- 每個訂閱只預排下一次扣款的提醒；App 啟動、同步或修改訂閱後會重新安排，已排好的通知不用開著 App 也會跳。已過的提醒時間不會補發。
- 在其他裝置取消或改期後，手機完成同步才會更新本機提醒。

建立、試用設定與取消的完整步驟，見[訂閱管理](../record/subscriptions.md#reminders)。

### App 更新提醒

- **Android**：有新版本時，開啟 App 會跳出「發現新版本」，按「立即更新」會下載並安裝；按「稍後」則 24 小時內不再提醒。想主動檢查，到「我的」→「關於」→「檢查更新」。
- **iOS**：有新版本時會跳出「有新版本可用」，告訴你目前版本與新版本，請到你原本取得安裝檔的管道更新。可以按「知道了」，或「不再提示此版本」（下一個版本發布後會再提醒）。

如果 App 版本過舊、低於伺服器要求的最低可同步版本，會直接停在更新頁，必須先更新才能繼續同步。

## 注意事項／小提醒

:::tip 提醒設定跟著帳號走
記帳提醒與信用卡提醒（含每張卡各自的設定）存在你的帳號裡，換新手機或重新安裝後會自動套用。但系統的「通知權限」要在每台裝置上各自允許。
:::

- 鈴鐺與「待處理中心」永遠都在；沒登入**帳好嗎 Cloud** 時只看得到「待處理」分頁的本機事項，雲端通知要登入後才會出現。
- 想少收一點通知：到手機的系統設定裡針對「**帳好嗎**」調整，或關掉個別提醒開關。
