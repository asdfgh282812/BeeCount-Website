你在手機上記了一筆午餐，回到家打開電腦的網頁版，這筆帳已經在那裡了。換新手機時，登入之後所有帳本和歷史紀錄就回來了。這就是帳好嗎 Cloud 的雲同步在做的事。

> 📱 App　💻 Web

## 為什麼這樣設計

這個版本把資料集中放在你的帳好嗎 Cloud 伺服器上，而不是讓每台裝置各存一份、再手動上傳下載。這樣做有三個好處：

- 手機、平板、網頁看到的是同一份資料，不會有「哪一台才是最新」的問題。
- 換機、重灌都不怕資料遺失。
- 家人或朋友可以一起用同一本帳，見[共享帳本](./shared-ledger.md)。

為了確保只有被允許的人使用，App 會在背景確認登入狀態與授權金鑰，見[授權金鑰](./license.md)。

## 同步是怎麼運作的

1. 你在任何一台裝置記帳、修改或刪除，這個變更會先存在那台裝置上。
2. 有網路時，變更自動傳到伺服器，不需要手動按「上傳」。
3. 伺服器通知你的其他裝置，其他裝置把變更拉下來。通常幾秒內就看得到。
4. 如果同一筆資料在兩邊同時被改，以最後修改的那一次為準。

:::tip
一般使用時你不用做任何事，記帳就是同步。只有懷疑資料沒同步時，才需要看下面的檢查方法。
:::

## 離線時會怎麼樣

- **可以繼續記帳。** 沒有網路時記的帳先存在手機裡，連上網路後會自動補傳。
- **看不到其他裝置的新資料。** 要等重新連上網路才會同步進來。
- **授權每 7 天需要連網確認一次，但不會擋住你記帳。** 每次 App 連上伺服器確認授權有效後，可以離線使用 7 天。4.0 起，超過 7 天都沒連網、或是這支手機被登出，本機的帳照常可看、可記，連上網路後 App 會自動重新確認授權並補傳。只有伺服器明確回報授權無效（到期、被撤銷）時，才會出現「需要授權金鑰」頁，詳見[授權金鑰](./license.md)。
- **剛換新裝置時需要網路。** 第一次登入要把雲端的資料整份拉下來，資料多的時候請用 Wi-Fi，並等它跑完再離開 App。
- **伺服器暫時連不上時。** 例如伺服器更新中，App 會跳出提示，「我的 → 雲端帳號與同步」的狀態會顯示「伺服器連不上」。你仍維持登入，記的帳先存在這支手機，伺服器恢復後會自動同步。

### 被登出時會怎麼樣

- **你自己按「登出」**（我的 → 雲端帳號與同步 → 登出）：會清除這支手機上的所有本機資料並回到歡迎畫面，還沒同步的變更會遺失，雲端上的資料不會被刪除。確認視窗會先說明這一點。
- **被遠端登出、登入失效**（例如在別的裝置被下線）：手機上的帳目與還沒上傳的變更都會保留，只是暫停雲端同步。App 會跳出「尚未登入雲端同步」的提醒，可以選「繼續離線使用」，或選「去登入」；也可以隨時從「我的 → 雲端帳號與同步 → 登入」重新登入。用同一個帳號重新登入，會接續同步。
- **改用另一個帳號登入**：App 會先清掉這支手機上屬於前一個帳號的資料，再開始同步，所以前一個帳號留在手機上的離線變更不會被傳到新帳號。

## 怎麼檢查同步狀態

### 📱 在 App 上

1. 點底部的「我的」。
2. 最上面的「雲端帳號與同步」副標會顯示目前連到的伺服器與同步狀態，例如「帳好嗎 Cloud v… · 已同步」。狀態有「已同步」「本機有更新」「雲端有更新」「未登入」「狀態取得失敗」「伺服器連不上」等。
3. 點進去是「雲端帳號與同步」管理首頁，由上到下是：
   - 目前使用的雲服務（帳好嗎 Cloud 與伺服器位址），以及「雲服務」（切換或設定雲端服務）。
   - 「雲端帳號」：登入的 email；還沒登入時顯示「登入」。
   - 「雲同步」：目前帳本的同步狀態，點進去看詳細內容。
   - 「裝置工作階段」：登入過你帳號的裝置，見[裝置與安全](./devices.md)。
   - 「登出」。
4. 點「雲同步」進入「雲同步」頁，可以看到：
   - 「二次驗證」狀態（已啟用或未啟用，要啟用請到 Web，見[裝置與安全](./devices.md)）。
   - 「雲端圖片下載」：選「即時下載」或「動態下載」。
   - 「同步狀態」：「本機與雲端一致」或「偵測到差異，已自動同步」，以及目前帳本與全部帳本的交易、附件、分類圖示、預算、帳戶、分類、標籤筆數，格式是「本機 N · 雲端 M」。
   - 「未推送變更」：還沒傳到雲端的變更數量，連上網路後應該會歸零。
5. 在這一頁往下拉，可以重新做一次「深度檢測」，比對手機與雲端的差異；有差異會自動同步。如果雲端的帳戶、分類或標籤比手機多、而且手機沒有待上傳的變更，會自動完整重新拉一次。

### 💻 在 Web 上

Web 直接讀取伺服器上的資料，所以不需要另外同步。想確認連線是否正常，可以到頭像選單 →「設定」→「雲端帳號與同步」，這裡會顯示目前登入的帳號、伺服器網址，以及「伺服器連線正常」或「連線檢查失敗，請重試。」；往下還有「裝置」與「健康」的入口，見[裝置與安全](./devices.md)。連線正常不代表所有裝置都已同步完成，帳本的變動仍是自動同步。

## 同步不動時怎麼辦

1. 先確認手機有網路，而且「我的 → 雲端帳號與同步」顯示的狀態不是「未登入」，也不是「伺服器連不上」。
2. 進入「雲端帳號與同步 → 雲同步」，往下拉做一次深度檢測，看「未推送變更」有沒有在減少。
3. 展開頁面上的「同步說明 · 為什麼有時同步不動？」，裡面有更多說明。
4. 還是不行，點裡面的「開啟日誌中心」，可以看到同步日誌，把錯誤訊息回報給管理員。

:::note 資料多的時候
第一次登入或換新裝置時的整份下載不能中途接續。中途斷網或 App 被系統關掉，會從頭再來，所以建議用穩定的網路等它跑完。日常記帳的同步則不受影響。
:::

## 注意事項／小提醒

- 如果「雲端帳號與同步」顯示「狀態取得失敗」，而且 App 提示要更新版本，代表你的 App 版本低於伺服器要求，更新後即可。
- 自己登出，或登出後改用另一個帳號登入，都會清掉這支手機上原本的資料，見[安裝與登入](../preface/install-login.md)。
- iCloud、WebDAV、S3、Supabase 這些舊的備份方式，4.0 的 App 已經沒有入口，見[其他備份方式](./other-backup.md)。
