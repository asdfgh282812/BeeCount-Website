刪過帳本、分類、附件之後，手機裡偶爾會留下一些「沒有主人」的殘留資料，例如指向已刪除交易的附件紀錄、沒有任何交易使用的圖片檔。這些殘留不會影響記帳，但會佔空間，也可能讓某些畫面出現怪怪的狀況。「資料清理」就是幫你找出來、讓你確認後再清掉。

> 📱 App（只清理這支手機上的資料）

## 為什麼這樣設計

清理前一定先掃描、列清單、讓你自己勾選，不會偷偷刪東西。刪除交易本身是很重的動作，所以遇到「交易的帳戶或分類已被刪掉」這類情況，只會把那一欄清空，不會把你的交易刪掉。

## 怎麼操作

1. 點底部的「我的」，進入「資料管理」。
2. 點「資料清理」（副標題是「檢查並清理本地孤兒資料」）。進入頁面就會自動掃描。
3. 掃描結果出現在頁面：
   - 如果顯示「本地資料乾淨，未發現孤兒資料」，就不用做任何事。
   - 否則上方會顯示「發現 N 項異常」和「可釋放空間約」多少，下面依類型分成三組。
4. 三組的意思：
   - 「資料庫孤兒」：資料庫裡指向已不存在對象的紀錄，例如預算指向已刪除的帳本或分類、附件指向已刪除的交易、標籤關聯指向已刪除的標籤、分期期數指向已刪除的分期計畫，或交易的帳戶、分類已被刪除。
   - 「磁碟檔案孤兒」：沒有任何紀錄在使用的附件圖片、自訂圖示檔。
   - 「同步狀態孤兒」：同步暫存裡，指向已不存在項目的待同步紀錄。
5. 勾選要清理的項目（每組都有「全選」「取消全選」）。預設都沒有勾選。
6. 按底部的「清理已選」，或點單筆項目的「刪除此項」。
7. 系統會問「確定清理…嗎？操作不可撤銷。」，按確認後開始清理。完成後會顯示「已清理 N 項」；若有失敗，會顯示成功與失敗各幾項。
8. 想再檢查一次，點右上角的「重新掃描」圖示。

## 注意事項／小提醒

:::warning 清理後無法復原
清理是直接刪除，沒有垃圾桶。不確定是什麼的項目，先不要勾選；每一項都有說明文字，會寫出是哪種殘留。
:::

![App 儲存空間管理頁：點選項目可清理對應的快取](/img/more/data-storage.png)
*圖中：① 點項目清理對應的快取　② 沒有可清理的項目時的提示*

- 交易的帳戶或分類已被刪除時，清理只會把該交易的帳戶或分類欄位清空，交易本身（金額、日期、備註）會保留，你可以之後自己補上。
- 這個功能只處理這支手機上的資料，不會去動伺服器上的內容。
- 如果只是想清掉暫存、釋放空間，另有「資料管理」→「儲存空間管理」（副標題是「清理快取釋放空間」）。
- 建議先確認雲端同步已完成再清理，見[雲同步與離線](../sync/overview.md)。
