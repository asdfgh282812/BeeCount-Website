記過帳，還記得昨天的晚餐花了多少嗎？4.3.0 起，每天第一次進入農場，會依你的帳務隨機出一道題目，**答對就獲得 10 好幣**。

> 📱 App　💻 Web

## 為什麼這樣設計

用一道短問答回顧自己的消費，比單純看數字多一點印象。題目混合**四選一與是非題**，一天只有一次機會，不需要另外報名或領取任務。

## 怎麼操作

### 📱 在 App 作答

1. 從首頁的農場小卡，進入**自己的農場**。
2. 如果今天還沒挑戰、帳務資料也足夠，題目會自動出現。
3. 題目準備好並顯示後，開始倒數 **15 秒**。看清楚題目裡的日期、分類與幣別，點一個答案。
4. 點選就會送出，**沒有第二次確認，也不能換答案**。結果出現後，按「關閉」回農場。

![每日帳務挑戰，題目明寫日期並顯示四個選項與剩餘秒數](/img/farm/daily-quiz-question.png)
*示意資料：題目直接寫出統計日期；載入與開啟畫面所花的時間不會扣掉作答的 15 秒。*

想先了解規則，可從「農場 → 設定 → 每日帳務挑戰」查看說明。

### 💻 在 Web 作答

登入帳好嗎 Cloud，從「頭像選單 → 農場排行榜」進入，符合條件時也會自動出題。需要先有雲端農場，且帳號目前可以寫入資料；尚未建立農場時，請先回 App 建立。

**App 和 Web 共用同一個雲端農場的每日機會**。在手機答過、答錯或離開，當天換到網頁或另一支手機也不能再答一次。

### 作答結果與好幣

| 情況 | 結果 |
|---|---|
| 答對 | 正確選項以綠色與「正確答案」標示，自動入帳 **10 好幣** |
| 答錯 | 選錯的選項以紅色與「你的答案（錯誤）」標示，正確答案以綠色標示；今天結束 |
| 15 秒內沒有作答 | 顯示逾時，今天結束，沒有獎勵 |
| 返回、關閉題目、離開頁面或切到背景 | 今天的機會結束，回來不會重新出題 |

![答錯時，選錯答案以紅色標示，正確答案以綠色標示](/img/farm/daily-quiz-result.png)
*示意資料：顏色搭配文字，清楚區分選錯的答案與正確答案。*

獎勵是**農場好幣**，不是「好好幣」，也不是記帳帳戶裡的真實金錢。答對後不必再按領取，可到 App「農場 → 好幣 → 週結算 → 交易紀錄」，或 Web「農場排行榜 → 農場錢包 → 交易紀錄」查看入帳。

## 題目在問哪段時間

題目本身會寫出日期，不必猜「這段期間」是多久；上方也會顯示完整日期，金額會附上幣別。

- **單日**：「11月8日的『晚餐』總共花了多少錢？」只計算 11 月 8 日。
- **多日**：「11月2日至11月8日總共支出多少錢？」包含起訖兩天。
- **跨年**：會把年份一起寫出，避免混淆。

題目可能取**昨天、截至昨天的最近 7 天或最近 30 天**，不包含還在持續變動的今天。實際範圍以當題顯示的日期為準。

### 可能遇到的題型

| 內容 | 例子 |
|---|---|
| 支出總額 | 指定日期總共支出多少錢？ |
| 收入總額 | 指定日期總共收入多少錢？ |
| 支出筆數 | 指定日期記了幾筆支出？ |
| 最大單筆支出 | 指定日期最大一筆支出是多少？ |
| 分類支出 | 指定日期的「晚餐」總共花了多少錢？ |
| 花費最多的分類 | 指定日期哪個分類的支出最多？ |
| 是否有支出 | 指定日期至少有一筆支出，對或錯？ |
| 支出是否超過某金額 | 指定日期總支出超過題目金額，對或錯？ |
| 分類支出是否超過某金額 | 指定日期的「晚餐」支出超過題目金額，對或錯？ |

系統會參考近期出題紀錄，盡量交替題型、日期範圍與分類。帳務資料較少時，可出的題目也較少，因此**不保證每天完全不重複**。

## 題目用的是哪一本帳

使用「農場 → 設定 → 計分帳本」指定的**個人非共享帳本**，金額以該帳本的本位幣計算。題目不會因為你切換首頁目前顯示的帳本而改變。

出題會排除不計入統計的交易、退款及其原交易、轉帳等不適用項目；分類題會依拆帳分類計算。答案在出題時就已確定，之後修改帳目不會更換當題答案。

雲端農場使用 **Cloud 已收到的帳務資料**。離線新增或修改的帳，請先完成[雲端同步](../sync/overview.md)，再進農場。

## 常見問題

### 今天怎麼沒有跳出題目？

可能已經用過今天的機會，或計分帳本尚未設定、沒有足夠的合格帳務資料。雲端農場也需要網路連線。沒有可出題資料時，當天不會反覆詢問；可以繼續記帳，明天再試。

### 關掉重開、改帳本或換裝置，可以重答嗎？

不行。**題目開始就會記錄當日機會**，不只答對才記錄。答錯、逾時、離開都算今天已結束；雲端農場的紀錄跟著帳號，重新整理或換裝置不會重設。

### 幾點換成新的一天？

雲端農場依伺服器的業務時區，通常是**台北時間午夜**；單機農場依手機本地日期。已開始的題目仍只有原本的 15 秒，不會因跨過午夜延長。

### 送出時網路斷了怎麼辦？

依畫面的提示處理；若可重試，只能重送剛才選定的答案，不能改選，也不會重新給 15 秒。伺服器會檢查期限並避免重複發獎，無法確認結果時不要假設已入帳，可恢復連線後查好幣交易紀錄。
