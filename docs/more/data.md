想把舊記帳軟體的資料搬進來、把帳單交給會計師，或換手機前自己留一份備份，都會用到匯入匯出。這一頁說明帳單（CSV）、附件、設定檔（YAML）三種東西怎麼進出，以及 Web 上有預覽的匯入流程。

> 📱 App　💻 Web

## 為什麼這樣設計

- 帳單用 CSV，因為 Excel、Google 試算表都打得開，方便檢查與修改。
- 設定檔用 YAML 純文字，要看內容或手動修改都很方便。
- Web 匯入先預覽、再確認，因為大量資料一旦寫錯很難一筆一筆改。整批匯入失敗時，系統會回復到匯入前的狀態。

## 怎麼操作


![App「我的 → 資料管理」頁：匯入／匯出資料、附件、分類、標籤、設定檔、儲存空間與資料清理](/img/more/data-1.png)
*圖中：① 匯入／匯出資料　② 匯出／匯入附件　③ 分類管理與分類遷移　④ 標籤管理　⑤ 對象設定（修改借還款對象的名稱）　⑥ 配置匯入匯出　⑦ 儲存空間管理（再往下是資料清理）*
### 📱 在 App 上：匯出帳單

1. 點底部的「我的」，進入「資料管理」。
2. 點「匯出資料」。
3. 按「匯出資料」（iOS 是「匯出並分享」）。匯出的是**目前帳本**的全部交易。
4. Android 會存到手機的 Download/BeeCount 資料夾；iOS 會跳出分享選單，可以存到「檔案」或傳給別人。

![App 匯出頁：說明支援的資料類型，按「匯出並分享」產生 CSV](/img/more/data-export.png)
*圖中：① 可匯出的資料類型　② 匯出並分享（產生 CSV）*

匯出的 CSV 欄位有：類型、分類、二級分類、金額、幣種、帳戶、轉出帳戶、轉入帳戶、備註、時間、標籤、附件，最後還有手續費、折損與稅、股票交易。

### 📱 在 App 上：匯入帳單

1. 「我的」→「資料管理」→「匯入資料」。
2. 「帳單類型」保持「通用CSV」，按「選擇檔案」，選 CSV、TSV 或 XLSX 檔。
3. 按「下一步」進入「確認對應」：把檔案的每一欄對應到日期、類型、金額、幣種、分類、二級分類、帳戶、轉出帳戶、轉入帳戶、備註、標籤、附件。檔案有表頭時，下拉選單會直接顯示表頭名稱。下方「資料預覽」會顯示前幾行讓你確認。
4. 再按「下一步」進入「分類對應」：左邊是檔案裡的分類名，右邊選要對應到系統裡哪個分類，或選「保持原名（自動建立／合併）」。
5. 按「開始匯入」。匯入中可以按「背景匯入」先離開，回到「資料管理」頁看進度；也可以按「取消匯入」。

![App 匯入頁：帳單類型可選通用 CSV、支付寶或微信，再選擇檔案](/img/more/data-import.png)
*圖中：① 帳單類型：通用 CSV、支付寶、微信　② 選擇檔案*

匯入完成後會顯示成功與失敗筆數。如果整批發生錯誤，畫面會提示「匯入失敗，已回滾所有更改」。

:::tip 直接用匯出檔回匯
App 匯出的 CSV 可以直接再匯入。匯入時是依表頭名稱對應，不認得的欄位會被忽略。
:::

### 📱 在 App 上：附件

「資料管理」頁的「匯出附件」會把所有附件圖片與自訂圖示打包成壓縮檔，旁邊的預覽按鈕可以先看會匯出哪些；「匯入附件」則從壓縮檔還原，遇到已存在的附件可選「跳過」或「覆蓋」。

:::warning 還原順序
要還原資料時，請先匯入附件包，再匯入帳本資料（CSV 或雲端同步），附件才會正確關聯到交易。
:::

### 📱 在 App 上：設定檔匯入匯出

1. 「我的」→「資料管理」→「配置匯入匯出」。
2. 「匯出配置」：先勾選要匯出的內容，可選帳本、分類、帳戶、標籤、預算、週期帳單、AI 智慧識別配置、其他設定（語言、外觀、提醒、預設帳戶等），確認預覽後存成 YAML 檔（檔名 beecount_config_時間.yml）。
3. 「匯入配置」：選 YAML 檔、勾選要還原的項目，確認預覽後匯入。部分設定要重新啟動 App 才會生效。

![App 配置匯入匯出頁：匯出或匯入 YAML 設定檔，並列出包含的設定項目](/img/more/data-config.png)
*圖中：① 功能說明（設定檔含敏感資訊，請妥善保管）　② 匯出配置　③ 匯入配置　④ 設定檔包含的項目*

:::warning 設定檔含敏感資訊
AI 配置裡有你填的 API Key，設定檔請妥善保管，不要隨手傳給別人或放到公開的地方。
:::

### 💻 在 Web 上：匯入帳單

Web 的匯入頁會先解析檔案、讓你預覽，確認沒問題才寫入。

1. 到「帳本」頁，在要匯入的帳本卡片選單點「匯入資料」；或按 ⌘K（Windows 是 Ctrl+K）打開命令面板，搜尋「匯入帳本資料」。
2. 頁面上方可切換要匯入「交易」「分類」或「帳戶」。
3. 把檔案拖進虛線框，或點一下選擇檔案。支援 CSV、TSV、Excel（.xlsx），單檔不超過 10 MB。不知道格式怎麼排，可在「下載範本：」旁按「CSV」或「Excel」取得範本。
4. 解析完成後進入預覽畫面，會看到：
   - 統計：總交易行數、時間範圍、淨額合計，以及將建立或合併的帳戶、分類、標籤數量；
   - 交易預覽：前 10 筆實際的樣子；
   - 解析警告與錯誤。有錯誤時必須先修好才能匯入。
5. 欄位對應預設自動識別，顯示「映射自動識別」。對應不準時點「編輯映射」手動指定，再按「套用並預覽」。
6. 在「匯入目標」選擇「匯入到帳本」，並選「衝突策略」：「去重（推薦）」會跳過重複的交易；「全部插入」則不管重複。
7. 按「確認匯入 N 筆」。匯入中可以按「取消（回滾）」，全部撤回。

![Web 匯入預覽畫面，顯示統計與交易預覽](/img/more/data-web-1.png)
*圖中：① 交易、分類、帳戶分頁　② 欄位映射（自動辨識，可手動編輯）　③ 解析結果統計　④ 將建立與合併的項目　⑤ 交易預覽　⑥ 匯入到哪個帳本、衝突策略　⑦ 確認匯入*

匯入若失敗，會顯示「匯入失敗，資料已回滾」，帳本不會有任何變化，修正檔案後重新上傳即可。

:::note 解析有時限
預覽畫面會寫「本次解析將於某時間過期」，過期了要重新上傳檔案。
:::

### 💻 在 Web 上：匯出 CSV

1. 到「交易」頁，套用想要的篩選（日期、類型、關鍵字、帳戶、分類、標籤、金額範圍）。
2. 按「匯出 CSV」，會依目前的篩選條件匯出當前帳本的交易。
3. 想快速匯出整個月或整年，可用 ⌘K 命令面板的「匯出本月 CSV」「匯出本年 CSV」。

## 注意事項／小提醒

- App 匯出的是「目前帳本」，有多個帳本要分別切換後匯出。
- 匯入時帳戶、分類、標籤不存在會自動建立或合併；想避免產生一堆新分類，請先在對應步驟把分類對應到現有分類。
- 日常備份建議以雲端同步為主，匯出的檔案當作額外保險。
