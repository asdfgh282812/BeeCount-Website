每天早上同一家早餐店 55 元、每個月固定把錢轉進悠遊卡……這些固定的消費，每次都要重選分類、重選帳戶、重打金額很煩。把它存成交易範本，下次在名稱欄點一下，類別、金額、帳戶、標籤全部自動填好，還能再改。

> 📱 App　💻 Web

## 為什麼這樣設計

範本是「你自己決定什麼時候按」的快捷，跟[週期性收支](./recurring.md)不同：週期性收支是設好後系統照時間自動產生，適合房租、訂閱這種固定日期的款項；範本適合早餐、咖啡這種**常常發生、但日期不固定**的消費。

蜜蜂記帳還會**記住你常用哪些範本**：每次用範本記帳並存檔，它的「使用次數」就加一，清單預設把用得最多、最近用過的排在最前面，不用自己整理順序。想自己排也可以，切到「手動排序」就行。

範本屬於**建立它的那本帳本**，不會跨帳本出現；App 和 Web 看到的是同一批範本，一邊新增、另一邊幾秒內就會出現。

## 範本會記住哪些欄位

| 欄位 | 說明 |
|---|---|
| 類型 | 支出、收入或轉帳 |
| 金額 | 可以留空（存成 0），表示「套用時再填」，適合每次金額不同的消費（例如加油） |
| 分類、帳戶 | 轉帳則是轉出帳戶與轉入帳戶 |
| 商家（Web 叫「商店」）、備註 | |
| 標籤、專案 | |
| 幣別 | 只在你明確選過幣別時才記住；沒選就跟著帳戶或帳本幣別走 |
| 手續費、折扣 | 含各自的名稱 |
| 不計入收支、不計入預算 | |
| 信用卡紅利回饋規則 | 支出且帳戶是信用卡時 |

範本**不記**日期（套用時一律是現在）、附件、拆帳、週期與分期設定。

## 怎麼操作

### 📱 在 App 上：把一筆記帳存成範本

1. 到「記帳」，照平常填好這筆：類別、金額、帳戶、備註、標籤……
2. 點「名稱」欄最右邊的 ☆（只有「支出」「收入」「轉帳」分頁有）。如果這本帳本已經有同名的範本，星星會變成黃色實心。
3. 輸入範本名稱，預設會帶入備註，可以直接改。名稱**不能和同一本帳本的其他範本重複**（不分大小寫）。
4. 點「確定」，提示「已存成範本」。

![App 記帳頁名稱欄的 ☆ 與「存成範本」視窗，名稱預設帶入備註](/img/record/template-app-5.png)
*圖中：點名稱欄的 ☆ 之後跳出「存成範本」，要填「範本名稱」*

存好之後，新範本馬上就會出現在「名稱」欄上方的範本列。

![存成範本之後，名稱欄上方的範本列多了「蛋餅+豆漿」](/img/record/template-app-6.png)

存好之後，名稱欄的 ☆ 會變成黃色實心，表示這個名稱已經是一個範本；再按一次就會問你要不要覆寫它。

![名稱和範本同名時，名稱欄最右邊的 ☆ 變成黃色實心](/img/record/template-app-star-saved.png)

:::tip 第一次用會有導覽
新增記帳頁第一次出現名稱欄的 ☆ 時，會用一個小導覽告訴你它的用途，點「完成」即可。之後可以在「我的 → 功能說明」重看。

![App 的交易範本導覽，框出名稱欄的 ☆](/img/record/template-app-tour.png)
:::

### 📱 在 App 上：套用範本

1. 到「記帳」，點「名稱」欄位。
2. 鍵盤上方會列出你的範本（每個前面有 ★），依「常用」或你設定的順序排列。
3. 一邊打字，範本會依關鍵字（比對範本名稱、商家、備註）即時篩選。
4. 點一個範本，類別、金額、帳戶、商家、標籤、專案、手續費、折扣等全部自動填入，之後都還能手動修改。

![App 記帳頁名稱欄聚焦時，鍵盤上方列出範本](/img/record/template-app-3.png)
*圖中：點「名稱」後，畫面下方出現帶 ★ 的範本，點一下就整組帶入*

![App 套用「早餐 - 蛋餅豆漿」之後：分類早餐、金額 55、帳戶悠遊卡、標籤早餐都已填好](/img/record/template-app-4.png)
*圖中：套用後各欄位都已填好，確認後按 ✓ 存檔*

- **範本的類型和目前分頁不同也沒關係**：例如在「支出」分頁點了轉帳範本，畫面會自動切到「轉帳」分頁，並帶入轉出、轉入帳戶與金額。
- **範本沒存金額時**（金額 0），套用不會動你已經輸入的金額；沒有金額就先填金額再存檔。
- **範本裡的類別、帳戶、標籤或專案後來被刪掉了**：那一欄會留空，其他欄位照常帶入，不會整個失敗。

![App 套用轉帳範本：自動切到轉帳分頁，轉出玉山銀行活存、轉入悠遊卡、金額 500](/img/record/template-app-9.png)
*圖中：套用「悠遊卡加值 500」，自動切到「轉帳」分頁*

存檔成功之後，這個範本的使用次數就加一。只是套用之後又取消、沒有存檔，不會算一次。

### 📱 在 App 上：管理範本

入口：「我的」→「交易範本」。

![App「我的」頁，功能列中的「交易範本」](/img/record/template-app-1.png)
*圖中：「我的」頁的「交易範本」入口*

![App 交易範本頁：搜尋列、常用／手動排序切換，範本依使用次數排列並顯示已用次數](/img/record/template-app-2.png)
*圖中：上方是搜尋與「常用／手動排序」；每列顯示分類、帳戶、金額與「已用 N 次」*

- **搜尋**：依範本名稱、商家、備註篩選。
- **排序**：
  - 「常用」（預設）：使用次數多的在前，次數相同看最近使用，從來沒用過的維持手動順序。
  - 「手動排序」：每列右邊出現把手，按住拖曳就能調整順序；這個順序也會同步到 Web。
  - 你選的排序方式只記在這支手機，不影響 Web。名稱欄上方的範本列也跟著這個設定排。
- **編輯**：點一個範本，可以改名稱、預設金額（填 0 表示套用時再填）、商家與備註。
- **刪除**：點右邊的垃圾桶，或把該列往左滑，確認後刪除。刪掉範本不會影響已經用它記好的交易。

![App 編輯範本視窗：範本名稱、預設金額、商家、備註](/img/record/template-app-8.png)
*圖中：編輯視窗只放最常改的四個欄位，並提示怎麼改其他欄位*

![App 範本頁切到「手動排序」，每列右邊出現拖曳把手](/img/record/template-app-7.png)

:::note 想改類別、帳戶或其他欄位？
App 的編輯視窗只放名稱、金額、商家、備註。其他欄位請用這個做法：到記帳頁**套用這個範本** → 改成你要的樣子 → 點名稱欄的 ☆ → 名稱**填一樣的**，會問「覆寫範本？」→ 點「覆寫」。使用次數與排序位置會保留，只換內容。
:::

![App 用同名儲存時出現的「覆寫範本？」確認視窗](/img/record/template-app-10.png)

### 💻 在 Web 上：建立、套用與管理

入口：右上角頭像（滑鼠移上去）→「工具」→「交易範本」。

![Web 交易範本頁：搜尋列、常用／手動排序切換，每張卡片顯示使用次數、分類、帳戶、標籤與備註](/img/record/template-web-1.png)
*圖中：卡片右上方是金額，下方有「套用」「編輯」「刪除」；「已用 N 次」是使用次數*

**建立或編輯**

1. 點右上角「新增範本」（或某張卡片的「編輯」）。
2. 填「範本名稱」，名稱不能與同一本帳本其他範本重複。
3. 選「類型」，填「金額」（可留空，表示套用時再填）。
4. 其他欄位依需要填：幣別、分類、帳戶（轉帳則是轉出、轉入帳戶，跨幣別轉帳再填「轉入金額」）、關聯專案、商店、標籤、備註、手續費、折扣、「不計入收支」「不計入預算」，信用卡支出還能勾選紅利回饋規則。
5. 點「新增範本」或「儲存」。

![Web 編輯範本視窗：類型、金額、幣別、分類、帳戶、專案、商店、標籤、備註、手續費、折扣與兩個不計入開關](/img/record/template-web-2.png)

範本的建立、編輯與刪除只有帳本擁有者可以操作；套用範本則是帳本的擁有者與編輯者都可以。

**套用**

1. 在列表找到範本，點「套用」。
2. 跳出「套用範本」視窗：可以改這筆交易的**交易時間**（預設現在）、金額與備註，其他欄位沿用範本。
3. 範本沒存金額的話，這裡一定要填金額才能按「套用」。
4. 範本使用外幣時，還要填「折合本位幣金額」（Web 不會自己查匯率）。
5. 按「套用」，立刻建立一筆真實交易，提示「已根據範本建立交易」，同時範本的使用次數加一。

![Web 套用範本視窗：可改交易時間、金額與備註](/img/record/template-web-3.png)

**搜尋與排序**：列表上方的搜尋框可依名稱、商店、備註篩選；「常用／手動排序」切換排序方式（手動順序是 App 拖曳排好的那個順序）。這個偏好只記在你這個瀏覽器。

## 注意事項／小提醒

:::note 名稱不能重複
同一本帳本裡，範本名稱要唯一（去掉前後空白、不分大小寫）。因為套用時是靠名稱挑的。不同帳本可以有同名的範本。舊資料裡如果本來就有重名，不會被擋，只是之後不能再改成已存在的名稱。
:::

:::note 使用次數怎麼合併
手機和 Web 各自累加後同步，系統取較大的次數、較新的使用時間，所以不會因為某一邊比較晚同步而變少。兩邊同時用同一個範本時，次數可能少算一兩次，只影響排序，不影響你的帳。
:::

- 範本不是交易，**不會**出現在統計、帳戶餘額或預算裡；只有套用並存檔之後，才會產生真正的交易。
- 拆帳中的記帳不能存成範本，點 ☆ 會提示。
