這個月錢花到哪去了？哪家店吃最多？信用卡回饋大概領了多少？統計報表把同一份帳目換不同角度看：每月、每週、每年各有一份預設報表，你也可以建一份「只看某個專案」「排除某個帳戶」的專屬報表。

> 📱 App　💻 Web

## 為什麼這樣設計

- **報表是「期間 + 篩選條件」的組合。** 同一份報表可以一直往前、往後翻期，不用每次重選日期。
- **「總覽」加一排維度 chip，看同一份資料。** 切換維度不會重新計算，所以很快。原本橫向捲動的十個分頁，在 4.0 收成「總覽」加維度 chip，一進來先看總覽，要換角度再點 chip。
- **只能點 chip 切換，不能左右滑。** 這是為了讓趨勢圖的左右滑（翻上一期、下一期）不會跟切換打架。

## 怎麼操作

### 📱 在 App 上

#### 報表清單

底部導覽第 4 個分頁「報表」，進去是報表清單。最上面固定有一張「年度帳單」卡，點進去是[年度回顧](./annual.md)；每年 12 月到隔年 1 月，這張卡會換成主色底、寫著「年度回顧準備好了」。下面是預設的「每週報表」「每月報表」「每年報表」，卡片上顯示該期的收入、支出、結餘。

![App 報表分頁：頂部是年度帳單卡，下方是每月、每週、每年三份報表，各顯示支出、收入與結餘](/img/analysis/statistics-1.png)
*圖中：最上面是「年度帳單」卡，下面是每月、每週、每年三份報表，各顯示支出、收入與結餘，右上角「＋」可新增自訂報表*

- 右上「+」新增報表；右上「恢復」圖示可以把刪掉的預設報表加回來（全部刪光後不會自動補回，要按「恢復預設報表」）。
- 卡片右側「⋯」可以「編輯」「複製」「刪除」。
- 長按卡片會開選單（編輯、複製、刪除…），要調整順序請選「編輯排序」，再拖曳卡片。

#### 看一份報表

點開一份報表，頂部可以：

![App 每月報表的總覽：上方是維度 chip 列，下面是支出收入結餘、主要支出類別與前三大支出](/img/analysis/statistics-2.png)
*圖中：頂部是期間切換，下面一排維度 chip（總覽、類別、帳戶、專案…），接著是支出、收入、結餘，以及主要支出類別與前三大支出*

- 點左右箭頭翻到上一期、下一期，點中間的期間文字可以選到更早的期間。選單只列到你帳本第一筆交易那一期，到頭就不能再往前翻。
- 右上「篩選」（有條件時顯示數字徽章）、「編輯」；只有「每 1 月」或「每 1 年」且沒有篩選的報表，才有「分享」海報按鈕。

頁面最上方是「總覽」，下面是一排可以橫向捲動的維度 chip，點一下就換成那個維度，點「總覽」回到預設：

| 維度 chip | 看什麼 |
|---|---|
| 總覽 | 支出、收入、結餘、筆數；主要支出類別前 5 名；TOP 3 支出；商家統計；最底下有「查看全部明細」 |
| 類別 | 圓餅圖、分類排行、趨勢，可切「支出／收入／結餘」，一級分類可展開子分類 |
| 帳戶、專案、名稱、商家、標籤和對象、帳戶分組 | 依該維度分組的金額與佔比 |
| 排行 | 單筆金額排行 |

原本的「明細」分頁改成總覽最底下的「查看全部明細」按鈕：點下去是獨立的一頁，上面是趨勢圖，下面是交易列表，可切換「支出／收入／結餘」，列表可選「新到舊／舊到新」，點圖上的點會捲到那一天。

![App 報表總覽最底下的「查看全部明細」按鈕，點開是趨勢圖加交易列表](/img/analysis/statistics-6.png)
*圖中：全部明細頁的趨勢圖與交易列表，可切換支出、收入、結餘*

全部明細裡的「結餘」會列出全部記錄，包含轉帳，這是轉帳在報表裡唯一會列出的地方。

#### 支出、收入、轉帳、回饋金切換

「帳戶」「專案」「帳戶分組」「名稱」「商家」「標籤和對象」「排行」這幾個維度，上方可以四選一：「支出／收入／轉帳／回饋金」。

![App 報表選了「帳戶」維度，上方可切換支出、收入、轉帳、回饋金](/img/analysis/statistics-3.png)
*圖中：選了「帳戶」維度後，上方可切換支出、收入、轉帳、回饋金，下面是各帳戶的金額與占比*

- **轉帳：** 只算轉帳（不含餘額調整）。帳戶和帳戶分組的轉帳金額是「轉入 + 轉出」，同一筆轉帳會同時出現在兩個帳戶，所以這兩個維度的佔比是用各列合計算的，頁面下方有註腳。
- **回饋金：** 依信用卡回饋規則**估算**的金額，算法跟回饋明細頁相同，實際入帳金額以發卡行為準。回饋規則怎麼設，見[紅利回饋](../credit-card/rewards.md)。
- 一筆記錄有多個標籤時，每個標籤都會算一次，各列加總可能大於總額。

#### 點進去看明細（下鑽）

點任一列，會開啟只列「同一類」的交易列表，標題下方標出目前是哪一類，例如「2026-09 · 支出」。在「支出」點某個專案，不會混進該專案的收入和轉帳。支出的下鑽列表也會列出扣在這些支出上的退款單，退款單雖然顯示為收入，金額已從合計扣掉，所以表頭合計和每一列加起來是對的。

#### 收支上色

金額顏色照你的「收支顏色方案」顯示（在「我的 → 一般 → 收支顏色方案」，「紅色收入 · 綠色支出」或「紅色支出 · 綠色收入」）。收入和回饋金用收入色、支出用支出色、轉帳用中性色；結餘大於等於 0 用收入色，小於 0 用支出色。分享海報和年度回顧也一起跟隨。

#### 新增或編輯報表

1. 清單右上點「+」，或在報表頁點「編輯」。
2. 填「名稱」。
3. 選「期間」類型：
   - 「重複循環」：每 N 日／週／月／年，會一期一期往前後翻。月和年依帳本的「每月起始日」切，每 N 月會對齊，例如每 3 月就是從 1、4、7、10 月起。
   - 「截至今天」：「最近 N 個單位」或「從指定日期起」，也可以選「全部時間」。
   - 「單一區間」：自己選開始與結束日期。
4. 回到報表頁點「篩選」，可以對記錄類型、分類、帳戶、專案、名稱、商家、標籤、對象設「包含」或「排除」，也可以限定金額範圍；頁首會顯示「已套用 N 個篩選條件」，「清除全部篩選」可以一次還原。
5. 儲存。

![App 新增報表頁：名稱、期間類型、單位與篩選條件](/img/analysis/statistics-5.png)
*圖中：新增報表頁，依序是報表名稱、期間類型（重複循環、截至今天、單一區間）、單位、每期長度與篩選條件*

#### 登入雲端後，報表跟著帳號走

登入**帳好嗎 Cloud** 後，你的報表清單、名稱、篩選、順序和刪除都會同步到帳號，換手機或重裝後會還原。兩台裝置同時離線各改一份報表時，以最後修改的那一份整份為準，不會逐筆合併。每份報表目前翻到第幾期不會同步。

### 💻 在 Web 上 {#web}

#### 開啟統計報表

1. 在桌面版頂部導覽點「報表」；手機瀏覽器則點底部的「報表」。
2. 選「統計報表」，會看到「每月報表」「每週報表」「每年報表」，以及你已儲存的自訂報表。
3. 點一份報表，先看「總覽」的收入、支出、結餘、轉帳與筆數，下面還有收支趨勢、主要支出類別、主要商家及前三筆支出。

![Web 報表頁的統計報表清單，包含每月、每週、每年報表與管理按鈕](/img/analysis/statistics-web-list.png)
*圖中：「報表」裡可切換統計報表與比較報表；統計報表清單上方提供新增、補回內建報表、編輯排序與年度記帳報告入口*

![Web 每月報表總覽，顯示收支結餘、轉帳、趨勢與重點摘要](/img/analysis/statistics-web-overview.png)
*圖中：上方可翻期、篩選或編輯報表，下面可切換分析項目；總覽的統計卡片與分類、商家摘要都能點開明細*

#### 切換分析項目與查看明細

- 點上方左右箭頭切換上一期、下一期；「截至今天」與「單一區間」不提供翻期，請到「編輯報表」修改期間。
- 分析列可橫向捲動，包含「總覽」「類別」「帳戶」「專案」「名稱」「商家」「標籤和對象」「排行」「帳戶分組」「明細」。
- 「類別」可切換「支出／收入／結餘」；支出、收入可選一級或二級分類，並展開下方的收支趨勢。
- 帳戶、專案、名稱、商家、標籤和對象、排行、帳戶分組可切換「支出／收入／轉帳／回饋金」。回饋金是估算值；標籤多選、轉帳兩端各計入時，各列合計可能大於整體金額。
- 「標籤和對象」裡還能再選「標籤」或「對象」；「排行」可切換金額由大到小或由小到大。
- 點分類或其他分組的名稱，右側會開啟相符交易的明細。再點一筆交易可查看完整內容。
- 看全部交易可點「明細」，或在總覽最下方點「查看全部明細」。明細每次顯示 50 筆，有更多資料時按「載入更多」。

#### 新增、編輯與儲存條件

1. 在統計報表清單點「新增報表」，或在既有報表點「編輯報表」。
2. 填「報表名稱」，選「期間類型」：
   - **重複循環**：設定每隔幾日、週、月或年為一期。
   - **截至今天**：選「最近幾個單位」或「從某一天開始」；選後者時，起始日留空代表全部歷史資料。
   - **單一區間**：選擇起始日與結束日，兩天都算在內。
3. 設定記錄類型、最低／最高金額，或展開帳戶、專案、分類、標籤、對象、名稱、商家，選「包含」或「排除」。勾選一級分類時，也會包含它的子分類；「（無）」可篩出沒有填該欄位的交易。
4. 按「儲存」。報表名稱、期間與儲存的篩選條件會和 App 共用。

![Web 自訂報表編輯頁，可設定名稱、期間與篩選條件](/img/analysis/statistics-web-edit.png)
*圖中：編輯頁的報表名稱、期間類型、每期長度、記錄類型與金額範圍；下方可展開各種包含／排除條件*

:::tip 臨時篩選與儲存篩選
報表檢視頁的「篩選」只套用這次檢視。想下次開啟時仍保留條件，請在「編輯報表」裡設定並儲存。金額範圍比對整筆交易的本位幣金額；分類篩選後的合計則只算命中的拆帳明細。
:::

#### 整理清單與開啟其他報表

- 每張卡片有「編輯報表」「複製」「刪除報表」；刪除前會再次確認，刪除結果也會同步到 App。
- 點「編輯排序」後，用向上／向下按鈕調整順序，最後點「完成」。不需要長按或拖曳卡片。
- 「補回內建報表」只補回缺少的預設報表，不會重設你已修改的報表。
- 「我的年度記帳報告」會開啟[年度回顧](./annual.md)；要並排比較月份，切換到同頁的「比較報表」，見[比較報表](./comparison.md)。

Web 與 App 共用同一份報表清單。名稱、期間、儲存條件、排序與刪除都會跟著帳號同步；同時在不同裝置修改時，以最後一次修改的整份清單為準，不會逐份合併。正在查看的期間與臨時篩選不會同步。

## 統計口徑

- 只算收入和支出。**轉帳和餘額調整不計入收支**，只出現在「全部明細」列表與「帳戶／帳戶分組」的轉入、轉出。
- 設為「不計入統計」的帳單不算，見[帳單標記](../record/flags.md)。
- 退款會扣回原本那筆的分類，詳見[拆帳與退款](../record/split-refund.md)。拆帳交易依明細金額分別歸到各分類。
- 外幣交易用折算後的本位幣金額。
- 統計時間看交易發生日，不看延後入帳日。
- 每月起始日不是 1 的帳本，期間依帳本設定切，見[帳本](../prepare/ledger.md)。

### 買股票為什麼報表上看不到

股票買賣是轉帳，不是支出，所以「支出」不會因為你買了 0050 而變多；股利是收入，會算進收入。為了讓你查得到錢去哪了，App 沒有套用篩選的報表「總覽」會多一行：

- 「投資淨投入 +X」，附「買進 · 賣出」與「未計入收入與支出」。
- 「手續費與證交稅 X（投資成本，不計入支出）」。
- 「股利收入 X（已計入收入）」。

期間內沒有任何股票買賣或股利時，這一塊不會出現；套了篩選的報表也不顯示（篩選範圍和股票明細對不上）。Web 統計報表目前沒有這段投資摘要；要查看股票買賣與持股，請從頭像選單開啟「投資」。

## 注意事項／小提醒

:::tip
翻報表的期間不會動到首頁的月份，兩邊各自獨立。
:::

:::note
目前不支援報表匯出 CSV，也不能自訂每份報表顯示哪些維度 chip。「類別」維度只有「支出／收入／結餘」，沒有轉帳和回饋金。
:::
