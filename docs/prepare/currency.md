出國刷日圓、網購付美金、帳戶裡放著一筆外幣定存，這些都不用另外開一個 App。蜜蜂記帳預設以新台幣（TWD）為主，遇到外幣時會依匯率折算回新台幣，讓淨資產、統計報表都用同一把尺。

只用新台幣的人可以直接略過這一頁，什麼都不用設定。

> 📱 App　💻 Web

## 為什麼這樣設計

外幣的金額不能直接跟新台幣相加，所以每筆外幣交易和帳戶，都要有一個「折算成主幣種」的數字。匯率預設自動取得，但實際換匯、刷卡的金額常常跟牌價有落差，所以所有需要匯率的地方，都讓你能手動修正成真實的金額。

## 兩個「主幣種」

| 名稱 | 設定位置 | 用在哪裡 |
|---|---|---|
| 帳本的主幣種 | 新建或編輯帳本 | 這個帳本的統計與外幣交易折算的目標 |
| 使用者的主幣種 | App「我的」→「個性化設定」→「主幣種」；Web「設定」→「個人資料」→「主幣種」 | 資產頁淨資產、資產構成的折算目標，以及匯率管理的基準 |

兩個預設都是 TWD，絕大多數人不用改。

## 怎麼操作

### 📱 在 App 上

**建立外幣帳戶**

![App 記帳頁的「選擇幣種」清單，每個幣別下方顯示目前的匯率](/img/prepare/currency-1.png)

1. 資產頁點右上角「＋」，進入「新建帳戶」。
2. 點「幣種」，在選擇清單裡挑外幣，例如日圓。清單上方會優先列出主幣種與你已經在用的幣別，並附國旗與匯率。
3. 填名稱與「初始資金」（以該幣別計）後儲存。

帳戶一旦有交易，幣種就不能再改。

**記外幣消費**

1. 新增支出或收入，在「帳戶」選外幣帳戶（清單會列出所有幣別的帳戶，外幣帳戶副標題會標幣別代碼）。
2. 輸入外幣金額，金額下方會顯示折算成主幣種的預覽，例如「≈ NT$1,830」。
3. 想核對或修正，點那一列開啟「幣別換算」：有「換算金額」與「匯率」兩欄，改任何一欄另一欄會跟著算。預設開著「採用線上匯率」，兩欄唯讀；關掉後就能手動輸入，以你填的為準。
4. 完成後送出。

你也可以不換帳戶、只改幣別：選好台幣帳戶後，點金額列的幣別，改選日圓，輸入日圓金額。交易會以日圓記錄，並折算回帳本主幣種。

**跨幣別轉帳**

轉出與轉入帳戶幣別不同時（例如台幣戶轉到日圓戶），轉帳頁會多出「轉入金額」與匯率列。預設用線上匯率自動算；銀行實際入帳的金額不同時，關掉「採用線上匯率」，手填真正入帳的金額。步驟見 [轉帳](../record/transfer.md)。

**查看與修正匯率**

1. 到「我的」→「個性化設定」→「匯率管理」。也可以在資產頁點齒輪「設定」進入，不過這個入口只有在你使用了兩種以上幣別時才會出現。
2. 最上方是「主幣種」，點它可更換。
3. 下方列出你正在使用的每個外幣，顯示目前匯率（1 外幣等於多少主幣種）、來源「自動」或「手動」與更新日期。還沒取得時顯示「未取得」。
4. 點某個幣別開啟「編輯匯率」，輸入你想用的匯率，儲存後來源會變成「手動」。要回到系統匯率，點「恢復自動」。
5. 右上角的重新整理圖示可以立刻重抓匯率，成功會提示「匯率已更新」。

頁面底部說明：匯率來源是開源匯率資料、每日更新，折算僅供參考，可能與銀行實際牌價有差異。

**更換主幣種**

「個性化設定」或「匯率管理」頁點「主幣種」，選新的幣別。如果新主幣種已經有你手動設過的匯率，會提示並立即套用，然後重新取得自動匯率。

### 💻 在 Web 上

1. 點右上角頭像，在「設定」群組選「個人資料」。
2. 「主幣種」下拉選單可更換使用者主幣種（提示說明為「資產折算的目標幣種，與 App 端同步」）。
3. 同一頁往下的「匯率管理」卡片，列出各外幣匯率，可「編輯匯率」或「恢復自動」，也可按「重新整理匯率」。
4. 帳本主幣種在「帳本」頁編輯帳本時設定。
5. 帳戶頁在涉及兩種以上幣別、且已設主幣種時，會顯示折算後淨資產；沒設定會提示「前往設定主幣種」。

![Web 個人資料頁的主幣種與匯率管理](/img/prepare/currency-3.png)

## 更換帳本主幣種

在「帳本管理」編輯帳本，把「主幣種」改成別的幣別時，系統會先確認：「修改本位幣將按當前匯率重算全部歷史交易的折算值」，並顯示將重算並同步幾筆交易。確認後會立即抓取最新匯率並重算。

如果某些外幣交易因為缺匯率而沒有折算，統計報表上會出現「偵測到該帳本有未折算的外幣交易」，點「按當前匯率重算折算」即可補上。

## 注意事項／小提醒

:::tip 登入後匯率更一致
登入 BeeCount Cloud 後，App 優先使用伺服器上的匯率，和 Web 看到的數字一致，所以 App 與 Web 算出的總資產不會差在匯率上。
:::

:::note 匯率更新頻率
自動匯率每 24 小時最多更新一次。要馬上用新匯率，到「匯率管理」按重新整理。
:::

:::warning 缺匯率的外幣不會算進淨資產
資產頁會標示「未折算」，並提示「某幣別未折算，點擊設定匯率」。補上匯率之後才會納入合計。
:::

:::note 週期性轉帳不支援跨幣別
定期自動轉帳的規則目前只能在同幣別帳戶之間設定。
:::
