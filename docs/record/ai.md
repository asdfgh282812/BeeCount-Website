收銀台前不想一格一格填欄位？拿手機對著發票拍一張、對著手機說一句「午餐 120」，或是把轉帳截圖丟進來，AI 會幫你辨識金額、分類、帳戶和時間，直接建立帳單。

> 📱 App　💻 Web（⌘K 命令面板可貼文字或圖片記帳，需先在 App 設定好 AI）

AI 記帳有五種入口：

| 入口 | 怎麼用 |
|---|---|
| 文字 | 在 AI 小助手對話裡打「買了杯咖啡 35 元」，詳見 [AI 聊天與查帳](./ai-chat.md) |
| 語音 | 長按底部中間的「+」→「語音」 |
| 拍照 | 長按底部中間的「+」→「拍照」 |
| 相簿／剪貼簿圖片 | 長按底部中間的「+」→「相簿」 |
| iOS 分享選單 | 截圖後分享給「蜜蜂記帳」，詳見 [自動記帳](./auto.md) |

## 為什麼這樣設計

AI 這一塊需要把你的帳單圖片、錄音或文字送到第三方 AI 服務商才能辨識，所以蜜蜂記帳不替你決定用誰：你自己選服務商、自己填金鑰，資料送去哪裡一清二楚。所有入口共用同一套服務商設定，設定一次，文字、語音、圖片都能用。

## 開始前：開啟並設定 AI

### 1. 開啟 AI 小助手

1. 在「我的」點「智慧記帳」。
2. 點「AI 小助手」。
3. 打開「啟用 AI 小助手」。

第一次從關閉切到開啟時，會跳出「開啟 AI 功能前，請知悉」的提示，說明資料會傳給哪個服務商、傳哪些內容、用在哪裡。按「同意並開啟」才會真的開啟；按取消，開關會維持關閉。

:::note
這個提示只在開關從「關」切到「開」時出現，每次都會問。如果 AI 已經在別台裝置開啟、設定同步下來，這台手機視為已經同意，不會再問。
:::

### 2. 新增服務商並填入金鑰

AI 服務商就是替你做辨識的那家公司。App 內建一個預設服務商（智譜GLM），沒填金鑰就不能用；你可以另外新增自己慣用的。

1. 在「AI 小助手」頁點「服務商管理」。
2. 點「新增服務商」。
3. 在「服務商名稱」輸入你看得懂的名字，例如「我的 Gemini」。
4. 選擇 API 體系：
   - 「Gemini 原生體系」：直接使用 Google 的 Gemini。選了之後「Base URL」會自動帶入 Google 的預設位址，不用自己填。
   - 「OpenAI 體系」：任何相容 OpenAI 標準聊天補全介面的服務（包含自架或第三方代理）。「Base URL」要填服務商給你的位址，例如 `https://api.example.com/v1`。
5. 在「API Key」貼上你的金鑰（右側眼睛圖示可切換顯示）。
6. 在「模型設定」填寫三種模型：「文字模型」「視覺模型」「語音模型」。留空代表這個服務商不提供該能力。
7. 按「一鍵測試全部」，確認三項都顯示測試通過，再按「儲存」。測試不是必要步驟，但能先抓出金鑰或模型名稱打錯的問題。

**Gemini 原生體系**一把金鑰就能同時處理文字、圖片和語音，最省事。欄位裡的提示範例是 `gemini-3.5-flash`，實際能用哪個模型，取決於你的 Google 帳戶與配額。Google 的 API Key 可以到 Google AI Studio 建立。

**OpenAI 體系**的提示範例是文字 `gpt-4o-mini`、視覺 `gpt-4o`、語音 `whisper-1`，換成你的服務商實際提供的模型名稱即可。

### 3. 綁定能力

新增完服務商還要告訴 App：文字、圖片、語音各交給誰處理。

1. 回到「AI 小助手」頁，找到「能力綁定」。
2. 分別點「文字對話」「圖片理解」「語音轉文字」。
3. 在清單中選擇剛剛新增的服務商。沒填對應模型的服務商不會出現在清單裡，沒填金鑰的會標示「未設定 API Key」。

:::tip
「進階設定」裡還有「執行策略」（雲端優先／僅雲端；本機模型還沒開放）和「提示詞編輯」。一般用預設就好。自訂提示詞後，AI 不會再輸出商家欄位，信用卡回饋的自動套用就不會生效。
:::

## 怎麼操作

### 📱 在 App 上

#### 用語音記帳

1. 長按首頁底部中間的「+」按鈕，手指不放，滑到「語音」上再放開。
2. 第一次使用會要求麥克風權限，選允許。
3. 說出來，例如「午餐 120，現金」。
4. 錄音結束後 AI 會辨識並直接建立帳單，畫面上方會跳出「✅ 支出帳單建立成功」之類的提示。

語音有兩種觸發方式，在「我的 → 智慧記帳」最下方的「語音觸發方式」切換：

- 「自動偵測停頓」：說完停一下就自動結束，適合短句快速記帳。「停頓結束時長」可以拖曳調整停多久算說完。
- 「按住說話」：按住錄音、放開結束，適合一次說比較多內容。

#### 用拍照或相簿記帳

1. 長按首頁底部中間的「+」按鈕，選「拍照」或「相簿」。
2. 拍下帳單，或從相簿挑一張截圖。
3. 等 AI 辨識，辨識中會出現進度動畫。
4. 完成後會直接建立帳單。一張圖裡有好幾筆時（例如一份帳單明細），會一次建立多筆。

**剪貼簿圖片**：如果你在別的 App 截圖或複製了一張圖片，再按「相簿」時，App 偵測到剪貼簿裡有圖片，會跳出選單讓你選「從剪貼簿貼上」或「從相簿選擇」。選前者就不用先把圖存進相簿。

**iOS 分享選單**：截圖後在分享選單點「蜜蜂記帳」，也會用同一套流程辨識，設定方式見 [自動記帳](./auto.md)。

#### AI 記完之後

- **自動附上原圖**：圖片或拍照記帳時，原圖預設會存成這筆帳的附件。要關閉，到「我的 → 智慧記帳」把「自動新增附件」關掉。附件的用法見 [附件](./attachment.md)。
- **自動加來源標籤**：預設會替帳單加上「圖片記帳」「拍照記帳」「語音記帳」「AI記帳」之類的標籤，方便日後篩選。要關閉，到同一頁把「自動關聯標籤」關掉。
- **信用卡回饋自動套用**：如果這筆帳記在信用卡帳戶，AI 辨識出商家，而且剛好只有一條你設定好的回饋規則符合，就會直接套用，不必事後再勾。有兩條以上符合、或一條都沒有時不會猜，帳單照常建立。詳見 [紅利回饋](../credit-card/rewards.md)。
- **外幣帳單**：拍到日圓收據時，AI 會辨識出幣別。如果你有日圓帳戶，會直接記進去；如果沒有，選了新台幣帳戶，金額會依匯率換算後再記，不會把「10,230 日圓」誤記成「10,230 元」。找不到匯率時，會先以 1:1 暫記並提示你到統計頁補折算。幣別的設定見 [多幣種與匯率](../prepare/currency.md)。
- **民國年**：發票或收據上的「115/09/20」這種民國年日期，AI 會自動換成 2026/09/20。

#### 找不到帳戶時

AI 會先用名稱比對你的帳戶。比對不到時：

- 在 App 內用語音、拍照、相簿、對話記帳：會跳出「選擇帳戶」，你選一個就繼續；按取消，這筆就略過不記，記完會提示「已略過幾筆」。
- 背景處理（截圖監聽、分享圖片）沒有畫面可以問：帳單照常建立，但標示為「待確認帳戶」。到「帳戶」頁，會出現「待確認帳戶」的卡片，點進去逐筆補選。

另外，信用卡「合併帳單的主帳戶」只是管理用的容器，AI 不會把帳單記到它身上，也不會出現在給 AI 挑選的帳戶清單裡。主帳戶的概念見 [帳戶](../prepare/account.md)。

#### 專案指定

如果你有用專案（例如「日本旅行」「新家裝潢」），可以決定 AI 記帳時怎麼處理專案。

1. 「我的 → 智慧記帳」，在「智慧記帳通用設定」區找到「AI 專案指定」。
2. 點進去選一種：
   - 「不帶入專案」：AI 記的帳不掛專案（預設）。
   - 「詢問使用者要用哪個專案」：每筆都跳出專案清單讓你選，也可以選「不指定專案」。
   - 「由 AI 自動判斷」：AI 看帳單內容挑最合適的專案，挑不出來才問你。

背景處理的帳單沒辦法問你，會標成「待確認專案」，到底部的「專案」分頁，點出現的「待確認專案」卡片逐筆補選。專案的用法見 [專案](../prepare/project.md)。

#### 標籤指定

同一區還有「AI 標籤指定」，決定 AI 記帳時怎麼加內容標籤（例如「午餐」「拉麵」）：

- 「不加標籤」
- 「詢問使用者要用哪些標籤」（背景處理不會問）
- 「AI 只從現有標籤挑選」：對不到的標籤會直接捨棄，不會新增。
- 「AI 判斷，必要時可新增標籤」：優先用你現有的標籤，沒有合適的才建立新標籤（預設）。

這個選項跟前面的「自動關聯標籤」是分開的：前者管 AI 判斷的內容標籤，後者管「圖片記帳」「語音記帳」這類來源標籤。標籤本身見 [標籤](../prepare/tag.md)。

### 💻 在 Web 上

1. 在 Web 任一頁按 ⌘K（Windows 是 Ctrl+K）開啟命令面板。
2. 貼上一段文字或一張圖片（⌘V）。
3. 選「AI 記帳」，按 Enter 開始識別。
4. 在跳出的「文字記帳」或「截圖記帳」視窗核對每一筆，勾選要留的，按「儲存所選」。

Web 沒有自己的 AI 設定，使用的是你在 App 設定好、同步上來的服務商與能力綁定。App 沒設定好的話，Web 會提示你先去 App 設定。

## 注意事項

:::warning
AI 辨識不是 100% 準確。金額、分類和帳戶建議在記完後掃一眼；記錯了可以在 AI 小助手的記帳卡片按「撤銷」，或到明細頁修改。
:::

:::note
**AI 設定會同步。** 服務商設定（包含你填的 API Key）、能力綁定、專案與標籤指定、語音設定，會隨 BeeCount Cloud 帳號同步到你的其他裝置，換手機不用重填。同步機制見 [雲同步與離線](../sync/overview.md)。
:::

- 看到「需要啟用AI並配置 GLM API」的提示，代表 AI 小助手沒開，或「語音轉文字」綁定的服務商沒填金鑰。這句話是 App 內建的固定提示，不代表你一定要用智譜。
- 辨識進度只是示意動畫，不是實際進度，卡住太久請稍等或重試。
- 辨識到不是帳單的圖片時，會提示「未識別到帳單資訊，請確認圖片是帳單後重試」。
- 免費的 API 額度通常有限，用量大時可能被限流而失敗。
