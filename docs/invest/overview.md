買了 0050、2330，想知道現在手上有幾股、成本多少、賺還是賠，又不想每次打開券商 App 再手動抄一遍？蜜蜂記帳把「證券戶」當成一個帳戶：每次買賣記一筆，股數、平均成本、市值、未實現損益就會自動算好。

> 📱 App　💻 Web

:::note
本功能僅供記錄，不構成投資建議。報價與損益是依資料來源與你填的費用試算的參考值，實際以券商對帳單為準。
:::

## 為什麼這樣設計

- **買賣是一筆轉帳，不是支出。** 買股票是把錢從「交割帳戶」（你的銀行活存）轉到「證券帳戶」，錢只是換了地方，所以不會算進你的月支出，也不會讓預算爆掉。同時記下「股數」，市值才能用「股數 × 現價」算。
- **股票市值不算淨資產。** 持股不是馬上能花的錢，所以新建的投資理財帳戶預設不計入淨資產，市值另外顯示在「投資市值（預估）」卡片。
- **手續費、交易稅都由你設定。** 每家券商折扣不同，所以費率、折扣、最低手續費都放在「費用設定」，記帳時自動試算，每一筆還能自己改。

## 怎麼操作

### 📱 在 App 上

#### 建立證券帳戶

1. 到底部的「資產」分頁，點右上角的「+」新增帳戶。
2. 帳戶類型先切到「估值帳戶」分頁，選「投資理財」，名稱例如「我的證券戶」。
3. 打開「持股功能」開關（見下方說明），存檔。
4. 新建的投資理財帳戶預設不計入淨資產。如果你是把既有帳戶改成投資理財類型，第一次記股票時 App 會問「要把這個帳戶排除在淨資產之外嗎？」，建議選「排除」，否則投入成本會被當成可以花的錢。

第一次編輯投資理財帳戶時，功能導覽會順便說明這個開關。

#### 持股功能：開或關

投資理財帳戶有「持股功能」開關，決定這個帳戶要不要走股票那一套流程。

| | 開啟 | 關閉（原始的投資理財帳戶） |
|---|---|---|
| 帳戶頁 | 有「持股」分頁，有報價、股利、定期定額、費用設定 | 沒有「持股」分頁，跟一般帳戶一樣顯示餘額 |
| 轉帳 | 轉進轉出會導向買賣表單，要填股數與成交價 | 一般轉帳，金額直接加減 |
| 調整餘額 | 不行（餘額是持股成本的帳面數） | 可以 |
| 滑動快捷 | 用「投資帳戶」那一組（買進、賣出） | 用一般帳戶那一組 |
| 計入總餘額 | 新建時預設不計入 | 新建時照舊計入 |

- **為什麼要有這個開關：** 有人把「投資理財」類型當成一般的資產帳戶（例如基金、儲蓄險），只想記餘額，不需要股數與報價。關掉持股功能，就能照一般帳戶操作。
- **舊帳戶不受影響：** 3.8.1 以前建立的投資理財帳戶，升級後仍是開啟狀態；只有明確關閉才會變成原始帳戶。新建帳戶時開關預設是「關」，要用股票功能請記得打開。
- **關掉之後資料還在：** 帳戶裡舊的買賣明細與連動的轉帳都不會被刪，只是不再計入投資市值、損益與報表；重新打開開關，就全部回來。

:::tip
先把你平常拿來扣款的銀行帳戶建好（例如「玉山銀行活存」），買賣時才有交割帳戶可以選。帳戶怎麼建，請看[帳戶](../prepare/account.md)。
:::

#### 買進

1. 在「資產」分頁點你的證券帳戶，進入「持股」分頁（第一個分頁）。（也可以在帳戶的「交易明細」分頁切到「轉出」或「轉入」，點右上角的「＋」，會直接開買賣表單：轉入是買進、轉出是賣出。）
2. 點「新增股票交易」，交易類型選「買進」。
3. 選「市場」（台股上市、台股上櫃、美股…），輸入「代號」，例如 0050。停一下，名稱和目前報價會自動帶入，欄位下方會顯示「已帶入目前報價（收盤價…）」。
4. 填「股數」和「成交價」。台股的股數是「股」不是「張」，1 張要填 1000。
5. 「手續費」會依帳戶的費用設定自動試算，不一樣就直接改。
6. 選「交割帳戶」，第一次記這個帳戶時要選，之後會自動記住上一次用的。
7. 儲存。

![App 新增股票交易頁：上方選交易類型，下方填市場、代號、股數、成交價與交割帳戶](/img/invest/overview-3.png)
*圖中：① 交易類型（買進、賣出、期初持股、配股…）　② 市場　③ 代號　④ 股數　⑤ 成交價　⑥ 手續費（自動試算）　⑦ 交割帳戶　⑧ 儲存*

存檔後，一般的交易列表會多一筆從交割帳戶轉到證券帳戶的轉帳，列上有「股票買進」標籤。

:::warning
這筆轉帳不能在一般轉帳表單裡單獨改，否則金額改了、股數沒跟著變，持股就對不上。點進去編輯，App 會直接帶你到「編輯股票交易」。
:::

> 💡 一般轉帳時，如果轉入帳戶選到證券帳戶，系統會視為買進、轉出帳戶選到證券帳戶視為賣出，並自動帶你到股票交易頁，另一邊的帳戶當交割帳戶。這個流程請看[轉帳](../record/transfer.md)。

#### 賣出

1. 在「持股」分頁點那一檔，進入持股詳情，按「賣出」（也可以從「新增股票交易」選「賣出」）。
2. 填「股數」和「成交價」。賣出股數不能超過持有股數，否則會提示「賣出股數不能超過持有股數（目前 N 股）」。
3. 「手續費」和「交易稅」自動試算。台股會依代號判斷稅率，並在稅欄下方顯示，例如「證交稅率 0.1%（ETF）」。
4. 確認「淨收入」和「交割帳戶」後儲存。

:::tip
投資理財帳戶在帳戶列表上可以直接滑動：預設右滑買進、左滑賣出，也可以改成「新增定期定額」。要改動作，到「我的 → 個性化設定 → 滑動快捷操作」。
:::

#### 一開始就已經有持股：期初持股

開始記帳前你就持有的股票，不用把過去每一次買進補記一遍。照券商 App「庫存」頁，每一檔記一筆：股數 + 平均成本。這樣持股成本、未實現損益會跟逐筆補記完全一樣，只是看不到記帳前的個別買進紀錄。

1. 「新增股票交易」→ 交易類型選「期初持股」。價格欄會變成「平均成本」，不產生金流，也不會自動估手續費（券商的成本均價通常已含手續費）。
2. 有很多檔時，點下方的「一次新增多檔期初持股」（帳戶還沒有任何持股時，也會直接出現在「新增股票交易」下面）。
3. 選「市場」、「持股日期」，「成本」選「平均成本」或「總成本」。
4. 每一檔填代號、股數、成本，點「新增一檔」加列；也可以點「從剪貼簿貼上」，格式是每行一檔：代號、股數、成本，用 Tab、空白或逗號分隔，可以直接從 Excel 或試算表複製，例如「0050 1000 120.5」。
5. 如果這個帳戶已經持有同一檔，該列會提示「已持有 N 股，會再加上去」。
6. 儲存。

#### 每一檔的股利再投入

股利要領現金還是再投入，過去是整個帳戶一個設定；現在每一檔股票各自決定。

1. 在證券帳戶的「持股」分頁，點進某一檔（例如 0050）。
2. 找到「股利預設再投入」開關。打開後，這一檔以後的待確認股利，確認頁會預設選「再投入」，而不是領現金。
3. 其他檔不受影響。例如高股息 ETF 想領現金、成長型 ETF 想再投入，可以分開設。

設計理由：不同標的的用途本來就不同，有人領股利當生活費、有人把另一檔滾存下去，一個帳戶一個開關不夠用。

:::note
這個開關只決定「確認股利時預設選哪一個」，確認頁上仍然可以臨時改選。如果你以前在費用設定打開過帳戶層級的「股利預設再投入」，沒有各自設定的股票會繼續沿用舊值；某一檔明確關掉，則以那一檔為準。
:::

#### 費用設定

在證券帳戶的「持股」分頁點「費用設定」。欄位留空就用市場預設值，預設值會顯示在欄位下方。

![App 費用設定頁：手續費率、折扣、最低手續費與證交稅率的預設值](/img/invest/overview-5.png)
*圖中：① 預設市場與交割帳戶　② 手續費率　③ 手續費折扣　④ 整股與零股最低手續費　⑤ 各種交易稅率（欄位留空就用預設值）*

| 設定 | 台股預設 | 說明 |
|---|---|---|
| 手續費率 | 0.1425% | 券商牌告費率 |
| 手續費折扣 | 不打折 | 6 折填 60 |
| 整股最低手續費 | 20 | 以 1,000 股為單位的整股 |
| 零股最低手續費 | 1 | 不足 1,000 股的零股 |
| 普通股交易稅率 | 0.3% | 賣出時課徵 |
| ETF 交易稅率 | 0.1% | 代號 00 開頭 |
| 債券 ETF 交易稅率 | 0% | 代號 00 開頭且以 B 結尾 |

另外還有預設市場、預設交割帳戶、股利手續費、預扣稅率、二代健保等（股利相關見[股利與已實現損益](./dividend.md)）。「股利預設再投入」從 3.8.2 起改成每一檔各自設定，不在這裡了，見下方〈每一檔的股利再投入〉。美股預設手續費率 0.25%、股利預扣稅 30%，其他市場預設都是 0，請自己填。

**手續費怎麼算：** 手續費 = 成交金額 × 費率 × 折扣，再跟最低手續費比，取較大的。台幣的成交金額、手續費、交易稅都是**無條件捨去**到整數。台股整股和零股是兩張不同的委託單，所以 1,050 股會拆成 1,000 股整股 + 50 股零股，各自算手續費和最低手續費再相加。

範例（金額虛構）：賣出 0050 共 50 股、成交價 160 元，成交金額 8,000 元：

- 手續費 = ⌊8,000 × 0.1425%⌋ = 11 元（高於零股最低 1 元）
- 交易稅（ETF）= ⌊8,000 × 0.1%⌋ = 8 元
- 淨收入 = 8,000 − 11 − 8 = 7,981 元

這個帳戶的「未實現損益扣除預估賣出費用」預設開啟，損益會先扣掉「現在賣掉要付的手續費和交易稅」，跟台灣券商 App 的算法一樣；關掉就是用毛市值算，列表上會標示「已扣預估賣出費用」。

:::note
如果你的券商整股或零股另有最低手續費，到「費用設定」自己改。舊的交易不會自動重算，要重新開啟並儲存一次才會套用新的取整方式。
:::

#### 報價從哪裡來

報價由 BeeCount Cloud 取得：台股收盤後會更新收盤價，盤中打開時如果快取超過 15 分鐘會補抓。資料以 Yahoo 為主，台股在 Yahoo 抓不到時才用證交所、櫃買公開資料備援。持股頁最上方會顯示報價時間，點右邊箭頭更新，或把整頁往下拉。沒連線 BeeCount Cloud 時，可以在每一檔持股裡手動輸入價格。

#### 漲跌顏色

台灣習慣「紅漲綠跌」，但你的收支顏色可能是「紅色收入、綠色支出」，兩種習慣互不影響。股票的賺賠顏色單獨設定：「我的 → 個性化設定 → 股票漲跌顏色」，選「紅漲 · 綠跌」或「綠漲 · 紅跌」，預設是紅漲綠跌，Web 同步。

### 💻 在 Web 上

1. 點右上角頭像，在選單的「工具」群組點「投資」。
2. 頁面上方是總市值，下面依證券帳戶列出持股表（代號、股數、平均成本、現價、今日、市值、未實現損益、預估淨值）。「已出清」可展開。
3. 每個帳戶卡片上有「新增交易」「定期定額」「期初持股」「費用設定」「交易紀錄」按鈕，欄位與 App 相同。
4. 也可以到「帳戶」頁點證券帳戶，看到的是同一份持股面板。
5. 首頁有「投資市值與未實現損益」等股票卡片，可用「自訂首頁」顯示或隱藏。

Web 的證券帳戶同樣不能手動調整餘額；要改數字請新增買進、賣出或期初持股。漲跌顏色在「設定 → 個人資料 → 同步偏好」，選「股票：紅漲綠跌」或「股票：綠漲紅跌」。

## 注意事項／小提醒

:::warning
- **證券帳戶的餘額是持股成本的帳面數**，不能「調整餘額」。要修正請新增或編輯股票交易。
- 股票交易的**手續費與證交稅不會算進月支出**，但會讓帳戶餘額減少。統計報表的「總覽」會補一行「投資淨投入」與「手續費與證交稅」讓你查得到錢去哪了，見[統計報表](../analysis/statistics.md)。
:::

- 買賣、期初持股、配股、股票分割都記在同一個地方：「新增股票交易」的交易類型。「配股」不增加成本，平均成本會降低；「股票分割」輸入「1 股變成幾股」（1 拆 4 填 4，2 合 1 反向分割填 0.5），總成本不變。
- 台股代號以 00 開頭視為 ETF、結尾 B 視為債券 ETF，其他當普通股。當沖、ETN、權證、REITs 的特殊稅率不會自動判斷，需要時自己改交易稅欄。
- 買賣金額可能是外幣（例如美股）。交割帳戶幣別跟證券不同時，要填「交割金額」，也就是交割帳戶實際扣款或入帳的金額。
- 淨資產卡片會說明「不含投資理財帳戶，買進股票會讓淨資產減少（是轉帳，不是支出）」；若有投資帳戶仍計入淨資產，會提醒可能與投資市值重複計算。淨資產走勢也不含投資理財帳戶，買進當天會呈現下降。
- 匯出 CSV 時，轉帳列尾端多「手續費」「折損與稅」「股票交易」三欄。期初持股、配股、分割因為沒有現金流，不在 CSV 裡；要完整備份請用同步或備份功能，見[匯入與匯出](../more/data.md)。
- 不同幣別的市值、損益各自分開顯示，不會相加；缺匯率的幣別會提示「缺少匯率未計入」。
- 在 AI 聊天可以直接問持股、損益、股利，見[AI 聊天與查帳](../record/ai-chat.md)。
