午餐剛吃完，付了 120 元，想把這筆錢記下來。這一頁帶你從頭走一遍：開啟記帳畫面、選分類、輸入金額、選帳戶、送出。記完第一筆之後，其他欄位怎麼用請看[記帳欄位](./fields.md)。

> 📱 App　💻 Web

## 開始前先確認三件事

記帳至少要有「帳本」「分類」「帳戶」三樣東西，缺一個就無法送出：

- **帳本**：登入後預設就有一本，不用另外建。要分開記個人與家庭開銷再看[帳本](../prepare/ledger.md)。
- **分類**：App 一開始會有預設分類，夠用就直接記。想自訂請看[分類](../prepare/category.md)。
- **帳戶**：每一筆交易都要指定錢是從哪裡出去（現金、銀行、信用卡…）。還沒建的話先看[帳戶](../prepare/account.md)。

## 為什麼這樣設計

分類回答「這筆錢花在什麼事情上」，帳戶回答「錢實際從哪裡出去」。兩個都記，報表才看得出各類花費，帳戶餘額也才會跟你的實際存款、信用卡帳單對得上，所以帳戶是必填。

## 怎麼操作

### 📱 在 App 上

App 的記帳入口在底部導覽列中間那顆按鈕。它有兩種狀態：

- 你在別的分頁時，它顯示「首頁」，點一下會切到首頁（月曆與當日交易）。
- 你已經在「首頁」分頁時，它變成「記帳」，點一下才會開啟新增交易頁。
- 不管在哪個分頁，**長按**它都會展開快速選單（拍照、相簿、語音、範本），見[快速入口與桌面小工具](./quick.md)。

App 開啟後預設就停在「首頁」，所以多數時候直接點「記帳」就能開始。

1. 在底部導覽列點中間的「記帳」。如果它寫的是「首頁」，先點一次切到首頁，按鈕就會變成「記帳」。

2. 新增交易頁上方有四個分頁：「支出」「收入」「轉帳」「借貸」，預設停在「支出」。分頁下面（新增模式的支出、收入分頁）有一排「建議分類」：依時段與你的記帳習慣排出最可能要記的分類，點一個就會自動選好分類，收入分類還會自動跳到「收入」分頁。剛開始沒有歷史紀錄時，這一排可能是空的或只有幾個。你也可以直接在分類格自己選。

   ![新增交易頁：上方四個分頁，下方一排建議分類，停在「支出」分頁](/img/record/first-record-2.png)
   *圖中：分頁列的「支出」「收入」「轉帳」「借貸」，以及分頁下方可橫向捲動的建議分類*

3. 在「支出」分頁的分類格裡點「餐飲」。分類格一次顯示兩行，點到有子分類的分類，整個格子會換成它的子分類，第一格「返回」可以回上一層。

4. 點金額那一格，畫面下方會出現計算機鍵盤。輸入 `120`。

5. 點「帳戶」那一列，選付款用的帳戶，例如「現金」。如果你在資產頁設定過預設支出帳戶，這一列已經幫你選好了。

6. 想補一句說明，在「名稱…」欄位打「午餐」。這個欄位就是備註。

7. 點金額列右邊的勾勾，或計算機鍵盤上的「✓」送出。畫面會關閉，回到首頁，今天的交易列表就會多出這一筆。

   ![填好餐飲 120 元、帳戶為現金的支出分頁](/img/record/first-record-3.png)
   *圖中：已選好分類「餐飲」、金額 120、帳戶「現金」，金額列右邊是送出勾勾*

沒填完就送出時，畫面會提示缺什麼：「請選擇分類」「請輸入金額」「請選擇帳戶」。

:::tip 也可以用手勢送出
表單捲到底之後再往上拉，會出現「上拉送出」，超過一定距離變成「放開送出」，放手就等於按了送出。條件沒填齊時一樣會出現上面的提示。
:::

### 💻 在 Web 上

Web 版要先用瀏覽器登入你的**帳好嗎**伺服器，登入方式見[安裝與登入](../preface/install-login.md)與 [Web 版](../sync/web.md)。

1. 在上方導覽列選「交易」（手機寬度時導覽列在畫面底部），右上角點「建立交易」。也可以按 `⌘K`（Windows 為 `Ctrl+K`）開啟命令面板，選「新建交易」。

2. 彈出的「建立交易」視窗最上面是「帳本」，預設是目前帳本。下面一排切換「支出」「收入」「轉帳」（帳本擁有者還有「應收」「應付」，見[借還款](./debt.md)），選「支出」。

3. 「分類」點開後選「餐飲」。Web 版沒有建議分類那一排，分類要自己選。

4. 「金額」輸入 `120`。Web 的金額欄可以直接打算式，例如 `60+60`，按 `=` 或 Enter 就會算出結果。

5. 「帳戶」選付款用的帳戶。

6. 「備註」寫「午餐」。「時間」預設是現在，補記昨天的帳時改這裡。

7. 點右下角「建立交易」。視窗關閉，這筆交易出現在交易列表。

   ![Web 的建立交易視窗，已填好支出、餐飲、120、現金與備註](/img/record/first-record-web-1.png)

## 四個分頁各做什麼

| 分頁 | 用途 | 只在哪裡 |
|---|---|---|
| 支出 | 花錢，例如午餐、交通、刷卡購物 | 📱 App　💻 Web |
| 收入 | 進帳，例如薪水、利息、退回的款項 | 📱 App　💻 Web |
| 轉帳 | 錢在自己的帳戶之間移動，例如提款、存錢、繳信用卡，詳見[轉帳](./transfer.md) | 📱 App　💻 Web |
| 借貸 | 借錢給別人或向別人借錢，分頁頂部切換「應收」（別人欠你）或「應付」（你欠別人），詳見[借還款](./debt.md)。4.0 起把原本分開的「應收」「應付」兩個分頁合併成這一個 | 📱 App（Web 到「借還款」頁新增） |

**「建議分類」這一排怎麼看：** 4.0 起，原本獨立的「建議」分頁變成「支出」「收入」分頁上方的一排建議分類，只出現在新增交易時；轉帳、借貸分頁與編輯既有交易時不顯示。點一下就選好分類，不用再多切一個分頁。

在共享帳本裡你是編輯者時，建議分類只會推薦帳本主人的分類，跟分類格看到的一致。不想要這一排，可以到「我的 → 記帳偏好」關掉「新增交易的建議分類」。

在 App 切換「支出」「收入」「轉帳」「借貸」分頁時，已經輸入的金額、日期、名稱、商家、標籤與帳戶會帶到新的分頁，不用重打（借貸分頁沒有標籤欄，商家會對應成「對象」）。分類、附件、幣別與紅利回饋不會帶過去。

## 注意事項／小提醒

:::note 日期會跟著月曆
在首頁月曆先點某一天（例如下週一）再點「記帳」，新增頁的日期會直接是那一天，時間沿用現在。沒點日期就是今天。
:::

:::tip 想關掉建議分類
到「我的」→「記帳偏好」，關掉「新增交易的建議分類」。關掉之後新增交易頁最上方就不再出現這一排。
:::

:::tip 常用的記帳存成範本
固定的記帳（例如每天一杯拿鐵）可以點分頁列右上角的 ☆ 存成範本，下次在名稱欄或長按中間鍵的「範本」一鍵帶入，見[交易範本](./template.md)。
:::

:::note 補記或提前記
日期可以選未來。預先登記下週要扣的訂閱費沒問題，但固定每月發生的款項建議直接設成[週期性收支](./recurring.md)。
:::
