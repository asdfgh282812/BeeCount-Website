收銀台前不想一格一格填欄位？拿手機對著發票拍一張、對著手機說一句「午餐 120」，或是把轉帳截圖丟進來，AI 會幫你辨識金額、分類、帳戶和時間，直接建立帳單。

> 📱 App　💻 Web（⌘K 命令面板可貼文字或圖片記帳，Web 也有浮動 AI 助手與智慧記帳設定頁）

AI 記帳有五種入口：

| 入口 | 怎麼用 |
|---|---|
| 文字 | 在 AI 小助手對話裡打「買了杯咖啡 35 元」，詳見 [AI 聊天與查帳](./ai-chat.md) |
| 語音 | 長按底部中間鍵（在任何分頁都可以）→「語音」；或「我的 → 智慧記帳」→「語音記帳」 |
| 拍照 | 長按底部中間鍵 →「拍照」；或「我的 → 智慧記帳」→「拍照記帳」 |
| 相簿／剪貼簿圖片 | 長按底部中間鍵 →「相簿」；或「我的 → 智慧記帳」→「相簿記帳」 |
| iOS 分享選單 | 截圖後分享給「帳好嗎」，詳見 [自動記帳](./auto.md) |

## 為什麼這樣設計

AI 這一塊需要把你的帳單圖片、錄音或文字送到第三方 AI 服務商才能辨識，所以帳好嗎不替你決定用誰：你自己選服務商、自己填金鑰，資料送去哪裡一清二楚，App 也不內建任何服務商。所有入口共用同一套服務商設定，設定一次，文字、語音、圖片都能用。

## 開始前：開啟並設定 AI

4.0 起，原本分開的「智慧記帳」與「AI 小助手」兩頁合併成「我的 → 智慧記帳」一頁：常用偏好、立即記帳、語音設定與自動化都在這裡，服務商與模型則放在下一層的「AI 服務管理」。

![App「我的 → 智慧記帳」頁：常用記帳偏好、AI 服務管理、立即記帳、語音記帳與自動化記帳](/img/record/ai-hub-1.png)
*圖中：由上到下是「常用記帳偏好」、「AI 服務管理」、「立即記帳」（拍照、相簿、語音）、「語音記帳」設定，以及「自動化記帳」（自動記帳、捷徑）*

### 1. 開啟 AI 小助手

1. 在「我的」點「智慧記帳」。
2. 在「常用記帳偏好」打開「啟用 AI 小助手」。

![App「智慧記帳」頁的常用記帳偏好：啟用 AI 小助手、顯示浮動氣泡、自動新增附件、記帳來源標籤、AI 專案指定與 AI 標籤指定](/img/record/ai-1.png)
*圖中：「常用記帳偏好」區的開關與選項，下面一列是進入「AI 服務管理」的入口*

第一次從關閉切到開啟時，會跳出「開啟 AI 功能前，請知悉」的提示，說明資料會傳給哪個服務商、傳哪些內容、用在哪裡。按「同意並開啟」才會真的開啟；按取消，開關會維持關閉。

![App 開啟 AI 功能前的提示：說明資料傳給誰、傳什麼、用在哪，下方「取消」「同意並開啟」](/img/record/ai-consent-1.png)
*圖中：提示列出「傳送給誰」「傳送什麼」「用途」三點，最下方可點「隱私政策」*

:::note
這個提示只在開關從「關」切到「開」時出現，每次都會問。如果 AI 已經在別台裝置開啟、設定同步下來，這台手機視為已經同意，不會再問。
:::

### 2. 新增服務商並填入金鑰

AI 服務商就是替你做辨識的那家公司。App 不內建服務商（4.0 起移除了預設的智譜 GLM），第一次使用要自己新增，並填入該服務商給你的 API Key。

![App 服務商管理頁：已新增的 My AI 與文字、視覺、語音能力](/img/record/ai-2.png)
*圖中：已新增的服務商與支援能力；右上角的「＋」可新增，點選服務商可編輯設定*

![App 新增服務商頁：選 OpenAI 體系或 Gemini 原生體系，填網址、金鑰與各項模型](/img/record/ai-3.png)
*圖中：新增服務商頁，由上到下是服務商名稱、API 體系、Base URL、API Key 與各用途的模型（文字、視覺、語音），可以按「一鍵測試全部」*

1. 在「智慧記帳」頁點「AI 服務管理」，再點「服務商管理」。
2. 點右上角的「＋」（或「新增服務商」）。
3. 在「服務商名稱」輸入你看得懂的名字，例如「我的 Gemini」。
4. 選擇 API 體系：
   - 「Gemini 原生體系」：直接使用 Google 的 Gemini。選了之後「Base URL」會自動帶入 Google 的預設位址，不用自己填。
   - 「OpenAI 體系」：任何相容 OpenAI 標準聊天補全介面的服務（包含自架或第三方代理）。「Base URL」要填服務商給你的位址，例如 `https://api.example.com/v1`。
5. 在「API Key」貼上你的金鑰（右側眼睛圖示可切換顯示）。
6. 在「模型設定」填寫三種模型：「文字模型」「視覺模型」「語音模型」。留空代表這個服務商不提供該能力。
7. 按「一鍵測試全部」，確認三項都顯示測試通過，再按「儲存」。測試不是必要步驟，但能先抓出金鑰或模型名稱打錯的問題。

![App 新增服務商：一鍵測試全部後，API Key 與文字、視覺、語音三個模型都顯示「測試通過」](/img/record/ai-test-1.png)
*圖中：每個模型旁的「測試通過」，最下方的按鈕也會變成「測試通過」；任何一項失敗會在該欄旁顯示原因*

**Gemini 原生體系**一把金鑰就能同時處理文字、圖片和語音，最省事。欄位裡的提示範例是 `gemini-3.5-flash`，實際能用哪個模型，取決於你的 Google 帳戶與配額。Google 的 API Key 可以到 Google AI Studio 建立。

**OpenAI 體系**的提示範例是文字 `gpt-4o-mini`、視覺 `gpt-4o`、語音 `whisper-1`，換成你的服務商實際提供的模型名稱即可。

### 3. 綁定能力

新增完服務商還要告訴 App：文字、圖片、語音各交給誰處理。

![App「AI 服務管理」頁：服務商管理、能力綁定、執行策略與提示詞編輯](/img/record/ai-4.png)
*圖中：「AI 服務管理」頁，依序是服務商管理、能力綁定（文字對話、圖片理解、語音轉文字）、執行策略與提示詞編輯*

1. 回到「智慧記帳」頁，點「AI 服務管理」，找到「能力綁定」。
2. 分別點「文字對話」「圖片理解」「語音轉文字」。每一項下面會顯示目前綁定的服務商，還沒綁就顯示「尚未設定」。
3. 在清單中選擇剛剛新增的服務商。沒填對應模型的服務商不會出現在清單裡，沒填金鑰的會標示「未設定 API Key」。

![App 點「文字對話」跳出服務商清單：沒填金鑰的服務商標示未設定 API Key](/img/record/ai-bind-1.png)
*圖中：選擇文字對話要用哪個服務商；已選的是勾選的那一個*

![App 能力綁定：文字對話、圖片理解、語音轉文字都綁到「My AI」](/img/record/ai-bind-2.png)
*圖中：三項能力各自綁定的服務商顯示在每一列，可以分別選不同家*

:::tip
同一頁的「執行策略」（雲端優先／僅雲端；本機模型還沒開放）和「提示詞編輯」一般用預設就好。自訂提示詞後，AI 不會再輸出商家欄位，信用卡回饋的自動套用就不會生效。
:::

## 怎麼操作

### 📱 在 App 上

#### 用語音記帳

1. 長按底部中間鍵（不用在首頁，任何分頁都可以），手指不放，滑到「語音」上再放開。也可以到「我的 → 智慧記帳」，在「立即記帳」區點「語音記帳」，會直接開始錄音（還沒設定好需要的模型時會提示你先到 AI 服務管理設定）。

![App 長按底部中間鍵：展開拍照、相簿、語音、範本四個圓形按鈕，手指滑到「語音」上亮起](/img/record/ai-voice-menu-1.png)
*圖中：長按中間鍵展開的四個選項，手指所在的「語音」會放大並加白框*

2. 第一次使用會要求麥克風權限，選允許。
3. 說出來，例如「午餐 120，現金」。
4. 錄音結束後 AI 會辨識並直接建立帳單，畫面上方會跳出「✅ 支出帳單建立成功」之類的提示。

![App 語音記帳的錄音視窗：「請開始說話…」與錄音時長，下方「完成」「取消」](/img/record/ai-voice-1.png)
*圖中：自動偵測模式的錄音視窗，會計算錄音時長；說完可按「完成」提早結束，或「取消」放棄*

如果開場幾秒都沒說話，視窗會自動關閉並提示「未檢測到語音輸入」：

![App 語音記帳沒偵測到聲音：底部跳出「未檢測到語音輸入」](/img/record/ai-voice-empty-1.png)
*圖中：沒說話時的提示*

語音有兩種觸發方式，在「我的 → 智慧記帳」的「語音記帳」區點「語音觸發方式」切換：

- 「自動偵測停頓」：說完停一下就自動結束，適合短句快速記帳。選了這個模式才會出現「停頓結束時長」滑桿，可以拖曳調整停多久算說完。
- 「按住說話」：按住錄音、放開結束，適合一次說比較多內容。

![App 智慧記帳頁的「語音記帳」區：「語音觸發方式」與「停頓結束時長」滑桿](/img/record/ai-voice-settings-1.png)
*圖中：「語音觸發方式」目前是「自動偵測停頓」，下方滑桿調整停頓多久算說完*

![App 語音觸發方式視窗：自動偵測停頓、按住說話](/img/record/ai-voice-mode-1.png)
*圖中：點「語音觸發方式」跳出的兩個選項*

選「按住說話」後，錄音視窗會寫「按住 說話」，手指按住中間的麥克風圖示說話，放開才開始辨識：

![App 按住說話模式：錄音視窗中間的麥克風圖示，下方「取消」](/img/record/ai-voice-2.png)
*圖中：「按住說話」的錄音視窗*

放開後會出現辨識動畫「正在仔細聽你說的話…」，辨識完成就直接建立帳單，並提示「語音記帳成功」：

![App 語音辨識中：「正在仔細聽你說的話…」與進度條](/img/record/ai-voice-progress-1.png)
*圖中：辨識動畫與進度條（示意，不是實際進度）*

![App 語音記帳完成：底部「語音記帳成功」，列表最上方出現新帳單](/img/record/ai-voice-result-1.png)
*圖中：記好後回到首頁，底部提示「語音記帳成功」*

#### 用拍照或相簿記帳

1. 長按底部中間鍵，選「拍照」或「相簿」。也可以到「我的 → 智慧記帳」的「立即記帳」區，直接點「拍照記帳」或「相簿記帳」。

![App 長按底部中間鍵展開的拍照、相簿、語音、範本](/img/record/ai-5.png)
*圖中：長按中間鍵展開的四個選項，由左到右是拍照、相簿、語音、範本*

2. 拍下帳單，或從相簿挑一張截圖。

3. 等 AI 辨識，辨識中會出現進度動畫。
4. 完成後會直接建立帳單。一張圖裡有好幾筆時（例如一份帳單明細），會一次建立多筆。

![App 圖片辨識中：「收到相片了，請稍等一下～」與進度動畫，下方跳出選專案](/img/record/ai-progress-1.png)
*圖中：辨識動畫；設了「詢問使用者要用哪個專案」時，下方會跳出選專案*

![App 圖片記帳完成：底部「支出帳單建立成功」，新帳單帶「圖片記帳」「AI記帳」標籤與附件數](/img/record/ai-photo-result-1.png)
*圖中：記好的帳單，名稱旁的備註是辨識出的品項，下方兩個標籤是自動加的來源標籤，「1」是自動附上的原圖*

**剪貼簿圖片**：如果你在別的 App 截圖或複製了一張圖片，再選「相簿」時，App 偵測到剪貼簿裡有圖片，會跳出選單讓你選「從剪貼簿貼上」或「從相簿選擇」。選前者就不用先把圖存進相簿。

**iOS 分享選單**：截圖後在分享選單點「帳好嗎」，也會用同一套流程辨識，設定方式見 [自動記帳](./auto.md)。

#### AI 記完之後

- **自動附上原圖**：圖片或拍照記帳時，原圖預設會存成這筆帳的附件。要關閉，到「我的 → 智慧記帳」的「常用記帳偏好」把「自動新增附件」關掉。附件的用法見 [附件](./attachment.md)。
- **自動加來源標籤**：預設會替帳單加上「圖片記帳」「拍照記帳」「語音記帳」「AI記帳」之類的標籤，方便日後篩選。要關閉，到同一頁把「記帳來源標籤」關掉。

![App 首頁列表：AI 記的帳單帶「AI記帳」標籤](/img/record/ai-tags-1.png)
*圖中：列表裡每筆 AI 記的帳都有「AI記帳」標籤，圖片記帳另外有「圖片記帳」*
- **信用卡回饋自動套用**：如果這筆帳記在信用卡帳戶，AI 辨識出商家，而且剛好只有一條你設定好的回饋規則符合，就會直接套用，不必事後再勾。有兩條以上符合、或一條都沒有時不會猜，帳單照常建立。詳見 [紅利回饋](../credit-card/rewards.md)。
- **外幣帳單**：拍到日圓收據時，AI 會辨識出幣別。如果你有日圓帳戶，會直接記進去；如果沒有，選了新台幣帳戶，金額會依匯率換算後再記，不會把「10,230 日圓」誤記成「10,230 元」。找不到匯率時，會先以 1:1 暫記並提示你到統計頁補折算。幣別的設定見 [多幣種與匯率](../prepare/currency.md)。
- **民國年**：發票或收據上的「115/09/20」這種民國年日期，AI 會自動換成 2026/09/20。

#### 找不到帳戶時

AI 會先用名稱比對你的帳戶。比對不到時：

- 在 App 內用語音、拍照、相簿、對話記帳：會跳出「選擇帳戶」，你選一個就繼續；按取消，這筆就略過不記，記完會提示「已略過幾筆」。

![App 找不到帳戶時跳出「選擇帳戶」：依銀行卡、現金、信用卡分組](/img/record/ai-account-pick-1.png)
*圖中：選一個帳戶才會繼續記帳*
- 背景處理（截圖監聽、分享圖片）沒有畫面可以問：帳單照常建立，但標示為「待確認帳戶」。到「資產」頁，會出現「待確認帳戶」的卡片，點進去會到待處理中心的「待處理」分頁，逐筆補選。

另外，信用卡「合併帳單的主帳戶」只是管理用的容器，AI 不會把帳單記到它身上，也不會出現在給 AI 挑選的帳戶清單裡。主帳戶的概念見 [帳戶](../prepare/account.md)。

#### 專案指定

如果你有用專案（例如「日本旅行」「新家裝潢」），可以決定 AI 記帳時怎麼處理專案。

1. 「我的 → 智慧記帳」，在「常用記帳偏好」區找到「AI 專案指定」。
2. 點進去選一種：
   - 「不帶入專案」：AI 記的帳不掛專案（預設）。
   - 「詢問使用者要用哪個專案」：每筆都跳出專案清單讓你選，也可以選「不指定專案」。
   - 「由 AI 自動判斷」：AI 看帳單內容挑最合適的專案，挑不出來才問你。

![App「AI 專案指定」視窗：不帶入專案、詢問使用者要用哪個專案、由 AI 自動判斷](/img/record/ai-6.png)
*圖中：三個選項與各自的說明，目前選的是「不帶入專案」*

選了「詢問」之後，每次 AI 記帳前會跳出專案清單，旁邊標著各專案剩餘預算：

![App AI 記帳前詢問專案：「不指定專案」與各專案剩餘預算](/img/record/ai-project-1.png)
*圖中：選一個專案，或「不指定專案」*

背景處理的帳單沒辦法問你，會標成「待確認專案」，到底部的「規劃」分頁，點出現的「待確認專案」卡片，會到待處理中心的「待處理」分頁逐筆補選。專案的用法見 [專案](../prepare/project.md)。

#### 標籤指定

同一區還有「AI 標籤指定」，決定 AI 記帳時怎麼加內容標籤（例如「午餐」「拉麵」）：

- 「不加標籤」
- 「詢問使用者要用哪些標籤」（背景處理不會問）
- 「AI 只從現有標籤挑選」：對不到的標籤會直接捨棄，不會新增。
- 「AI 判斷，必要時可新增標籤」：優先用你現有的標籤，沒有合適的才建立新標籤（預設）。

![App「AI 標籤指定」視窗：不加標籤、詢問、只從現有標籤挑選、AI 判斷必要時新增](/img/record/ai-tag-1.png)
*圖中：四個選項與各自的說明*

這個選項跟前面的「記帳來源標籤」是分開的：前者管 AI 判斷的內容標籤，後者管「圖片記帳」「語音記帳」這類來源標籤。標籤本身見 [標籤](../prepare/tag.md)。

### 💻 在 Web 上

**用命令面板記帳**

1. 在 Web 任一頁按 ⌘K（Windows 是 Ctrl+K）開啟命令面板。
2. 貼上一段文字或一張圖片（⌘V）。
3. 選「AI 記帳」，按 Enter 開始識別。
4. 在跳出的「文字記帳」或「截圖記帳」視窗核對每一筆，勾選要留的，按「儲存所選」。

![Web 命令面板：貼上文字後，「AI 記帳」那一項右側寫「開始識別」](/img/record/ai-web-1.png)
*圖中：⌘K 命令面板；貼上文字後，三個預設動作裡的「AI 記帳」按 Enter 開始識別（「問 AI」是搜尋說明文件，不是記帳）*

![Web「文字記帳」視窗：識別到 1 筆，可改類型、金額、分類、帳戶、時間與備註，下方「儲存所選」](/img/record/ai-web-2.png)
*圖中：每一筆前面有勾選框，可修改後再存；左下角「自動加『AI 記帳』標籤」預設勾選*

**設定 AI**

4.0 起 Web 也有 AI 設定，入口是右上角頭像（滑鼠移上去）→「設定」→「智慧記帳」：

- 「智慧記帳」頁有「常用記帳偏好」（啟用 AI 小助手、專案指定、標籤指定）和「App 語音偏好」（錄音觸發方式、停頓判定時長）。第一次開啟 AI 同樣會先跳出資料共享說明，按「同意並開啟」才生效。
- 點「AI 服務管理」進入下一層：服務商、能力綁定、執行策略與自訂擷取提示詞。

這些設定與 App 同步，換邊操作不用重填。浮動助手、來源標籤與圖片附件是各裝置自己的偏好，Web 不提供；拍照、相簿、錄音與背景記帳也只能在 App 操作。

![Web「智慧記帳」設定頁：常用記帳偏好、AI 服務管理入口與 App 語音偏好](/img/record/ai-web-3.png)
*圖中：Web 的智慧記帳頁，由上到下是常用記帳偏好、「AI 服務管理」入口與 App 語音偏好*

**浮動 AI 助手**

Web 右下角的 AI 助手可以用對話記帳與查帳，見 [AI 聊天與查帳](./ai-chat.md#-web-的-ai-助手)。

## 注意事項

:::warning
AI 辨識不是 100% 準確。金額、分類和帳戶建議在記完後掃一眼；記錯了可以在 AI 小助手的記帳卡片按「撤銷」，或到首頁、「全部交易」找到那一筆修改。
:::

:::note
**AI 設定會同步。** 服務商設定（包含你填的 API Key）、能力綁定、專案與標籤指定、語音設定，會隨帳好嗎 Cloud 帳號同步到你的其他裝置，換手機不用重填。同步機制見 [雲同步與離線](../sync/overview.md)。
:::

- 看到「請先在智慧記帳開啟 AI，再開始記帳」，代表 AI 小助手沒開；看到「請先到 AI 服務管理設定所需模型與 API Key」，代表對應能力（拍照與相簿需要圖片理解，語音需要語音及文字模型）還沒綁定服務商，或服務商沒填金鑰。
- 辨識進度只是示意動畫，不是實際進度，卡住太久請稍等或重試。
- 辨識到不是帳單的圖片時，會提示「未識別到帳單資訊，請確認圖片是帳單後重試」。
- 免費的 API 額度通常有限，用量大時可能被限流而失敗。
