這一頁幫你先抓到「這本手冊怎麼對應到畫面」。看過一次，後面各章就不太會迷路。

## 為什麼這樣設計

帳好嗎功能不少，有些功能要先有別的東西才能用。例如要記信用卡刷卡，得先有一個信用卡帳戶；要看股票持股，得先有投資帳戶。手冊照「先準備、再記帳、再分析」的順序排章節，就是為了讓你不用跳來跳去。

## 手冊裡的寫法

- **「」括起來的字**是畫面上真的看得到的按鈕或選單名稱，例如「我的 → 授權金鑰」代表先點下方的「我的」，再點「授權金鑰」。
- **📱 App、💻 Web**標在頁面開頭，表示支援的平台。App 與 Web 操作不同時，頁面裡會分成「在 App 上」與「在 Web 上」兩段。
- **🔖** 是進階功能，新手可以先跳過。
- 範例裡的帳戶名稱、金額都是虛構的，例如「玉山銀行活存」「國泰 CUBE 卡」，只是方便說明。

## 建議的上手順序

1. **登入**：[安裝與登入](./install-login.md)。全新帳號登入後會有一段首次登入個人化引導，帶你調好外觀、建立第一本帳本與第一個帳戶。
2. **確認帳本與帳戶**：首次登入引導已經幫你建好第一本帳本，帳戶也可以在最後一步先建一個。接著補上你平常會用的帳戶，例如錢包、銀行活存、信用卡，到底部的「資產」分頁新增。見[帳本](../prepare/ledger.md)、[帳戶](../prepare/account.md)。
3. **確認分類**：帳好嗎 Cloud 會幫你建好預設分類，先不用動，等用到再調整。見[分類](../prepare/category.md)。
4. **記第一筆帳**：[記第一筆帳](../record/first-record.md)
5. **需要時再往下**：專案預算、週期性收支、信用卡、投資等，用到再翻；固定支出、分期、應收應付、訂金尾款、交易範本這些「未來的錢」都集中在底部的「規劃」分頁。
6. **想玩玩看**：首頁的「農場」，用記帳換遊戲幣種菜，見[農場](../farm/overview.md)。

## 哪些功能要先準備什麼

| 你想做的事 | 要先有 | 參考 |
|---|---|---|
| 記一般收支 | 帳本、至少一個帳戶 | [帳戶](../prepare/account.md) |
| 刷信用卡、看帳單 | 一個「信用卡」類型的帳戶，並設好結帳日與繳款日 | [設定信用卡](../credit-card/setup.md) |
| 記股票買賣、看持股 | 一個投資理財帳戶 | [股票持股](../invest/overview.md) |
| 預算 | 一個專案（預算設在「規劃」分頁的專案裡）與分類 | [預算](../prepare/budget.md) |
| 跟朋友共用帳本 | 雙方都有帳號與授權 | [共享帳本](../sync/shared-ledger.md) |
| AI 記帳 | 先設定 AI 服務 | [AI 記帳](../record/ai.md) |
| 玩農場 | 登入帳好嗎 Cloud 的帳號 | [農場](../farm/overview.md) |

:::note
記帳時一定要選一個帳戶，所以建議在記第一筆帳前就先建好帳戶。
:::

## App 與 Web 畫面對照

兩邊資料互通，只是畫面的排法不同。

![App「我的」分頁上半：頭像與統計、雲端帳號與同步、授權金鑰、資料管理、智慧記帳](/img/preface/my-tab-1.png)
*圖中：「我的」分頁上半，最上面是頭像與記帳統計，往下依序是雲端帳號與同步、授權金鑰、資料管理、智慧記帳*

![App「我的」分頁下半：待處理中心、提醒、外觀等設定，以及新功能、功能說明、關於、使用說明](/img/preface/my-tab-2.png)
*圖中：「我的」分頁下半，包含待處理中心、提醒、設定（外觀、一般、記帳偏好、隱私與安全、桌面小工具），最後是新功能！、功能說明、關於、使用說明*

| 要找的東西 | 📱 App | 💻 Web |
|---|---|---|
| 記一筆帳 | 在「首頁」點底部中間的「記帳」鍵；在任何分頁長按它，可以直接拍照、選相簿、語音或套用範本 | 「交易」頁，或 ⌘K 選「新建交易」 |
| 看明細 | 「首頁」的月曆與當天的帳，頁首的「全部交易」看清單 | 「交易」 |
| 帳戶 | 底部「資產」 | 頂部「帳戶」 |
| 專案、預算、週期、分期、應收應付、訂金尾款、交易範本 | 底部「規劃」 | 「專案」，其餘在頭像選單的「記帳工具」 |
| 報表 | 底部「報表」，年度帳單在頂部 | 「首頁」、右上角的日曆圖示、「比較報表」，年度報告在頭像選單 |
| 帳本、分類、標籤、匯入匯出 | 「我的 → 資料管理」 | 頭像選單的「帳本」，或頂部的「分類」「標籤」 |
| 設定 | 底部「我的」，分成外觀、一般、記帳偏好、隱私與安全 | 頭像選單 → 個人資料 等 |
| 待處理的事 | 首頁右上角的鈴鐺，或「我的 → 待處理中心」 | 通知鈴鐺與「待完成交易」 |
| 農場 | 首頁的「農場」入口 | 頭像選單 → 農場排行榜（只看排名） |

App 底部有五個分頁：資產、規劃、首頁（在首頁時中間那顆是「記帳」）、報表、我的。想讓 App 一頁一頁帶你看，可以到「我的 → 功能說明」，見[功能說明與新功能紀錄](./tour.md)。東西搬到哪裡了，見[常見問題](../faq.md#以前的功能搬到哪裡了)。
