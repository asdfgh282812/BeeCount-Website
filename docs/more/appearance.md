每個人看帳的習慣不太一樣：有人喜歡黃黃的蜜蜂色、有人晚上只想看深色；有人習慣收入紅色、支出綠色，有人剛好相反；看股票時，台灣人又習慣「紅漲綠跌」。這一頁把所有「看起來怎麼樣」的設定集中在一起。

> 📱 App　💻 Web（Web 只有其中一部分，下面會註明）

## 為什麼這樣設計

收支顏色和股票漲跌顏色是兩個獨立的開關，因為台灣記帳與看盤的習慣不一定一致。外觀設定大多會跟著帳號走，換手機或打開 Web 時，看到的是同一套樣子。

## 怎麼操作

### 📱 在 App 上

1. 點底部的「我的」。
2. 點「個性化設定」，進入設定清單（副標題寫著「主題、字體、語言、應用鎖等」）。

清單分成幾個區塊，由上到下是：

**樣式與顯示**

| 設定 | 說明 |
|---|---|
| 外觀模式 | 選「跟隨系統」「亮色模式」或「暗黑模式」。 |
| 主題色 | 進入後有一整排顏色卡（蜜蜂黃、晴空藍、薰衣草…），最後一張「自訂」可以用色相、飽和度、亮度自己調色。 |
| 皮膚 | 頁首的背景圖案，可用「全部／動態／靜態」篩選。標示「自帶配色」的皮膚會連主題色一起換掉。 |
| 節日 | 日曆的節日標記與節日主題，見下方〈節日〉。 |
| 面板動效 | 關掉後，動態皮膚會停在靜止畫面，比較省電。 |
| 減少動畫 | 開啟後全站動畫精簡，省電，也比較不容易眼花。 |
| 可愛類別圖示 | 分類圖示換成手繪風，分類顏色改用底線表示。 |
| 顯示縮放 | 調整文字和介面大小，詳見下方〈顯示縮放〉。 |

*圖中：① 外觀模式（淺色、深色、跟隨系統）　② 主題色　③ 節日　④ 餘額顯示格式（完整、簡潔）*

**資料怎麼呈現**

**餘額顯示格式：完整金額或簡潔顯示**

帳戶餘額數字很大時，一長串數字不好讀。到「我的」→「個性化設定」→「餘額顯示格式」，選「簡潔顯示」，大金額就縮寫成「萬」為單位，例如 12.3萬。繁體中文介面會用繁體的「萬」，不會出現簡體的「万」。

![App「餘額顯示格式」視窗：完整金額與簡潔顯示兩個選項](/img/more/appearance-amount.png)
*圖中：① 目前選用的格式（打勾）　② 「簡潔顯示」：大金額縮寫，例如 12.3萬（只對帳戶餘額生效）*

![App 資產頁選簡潔顯示後，淨資產與各帳戶餘額以「萬」為單位](/img/more/appearance-wan.png)
*圖中：① 淨資產、總資產與總負債都以「萬」顯示　② 走勢圖座標軸是另一套縮寫（w 代表萬、k 代表千），不是同一個設定*

這個設定只影響「帳戶餘額」的顯示（資產頁、帳戶列表、帳本卡片等），不會改到交易金額；想看精確到小數的數字，把它改回「完整金額」即可。

**其他資料呈現設定**

| 設定 | 說明 |
|---|---|
| 餘額顯示格式 | 「完整金額」顯示 123,456.78；「簡潔顯示」把大金額縮成 12.3萬。只影響帳戶餘額。 |
| 顯示交易時間 | 帳單列表多顯示「時：分」，編輯時也能選時間。預設關閉。 |
| 新增交易的建議分頁 | 新增交易頁會多一個「建議」分頁，依你的習慣排出可能要記的分類。關掉後分頁就消失。預設開啟。 |
| 備註顯示方式 | 「分類優先」：顯示分類名，備註用括號附在後面。「備註優先」：有備註就顯示備註，沒有才顯示分類名。 |
| 歷史備註 | 設定輸入備註時的建議清單：範圍（全部分類／目前分類）、排序（使用頻次／最近使用）、顯示數量（1 到 100 筆）。 |
| 收支顏色方案 | 二選一：「紅色收入・綠色支出」或「紅色支出・綠色收入」。預設是前者。 |
| 股票漲跌顏色 | 「紅漲・綠跌」（台灣習慣，預設）或「綠漲・紅跌」（國際習慣）。 |
| 每週起始日 | 「星期一」或「星期日」，日曆與週統計都會照這個排。預設星期一。 |

**其他**

- 「左滑操作」「右滑操作」：帳戶總覽頁每一列左右滑動時露出的快捷動作（例如調整餘額、新增交易）。兩邊都選「無」就是關閉。
- 「投資帳戶・右滑操作」「投資帳戶・左滑操作」：投資理財帳戶專用的滑動動作（買進、賣出、新增定期定額）。
- 「主幣種」與「匯率管理」：見[多幣種與匯率](../prepare/currency.md)。
- 「語言」「桌面小工具」「App 鎖」也放在這個清單裡；App 鎖的說明在[裝置與安全](../sync/devices.md)。

#### 顯示縮放

點「顯示縮放」，可以用「快速檔位」（從「極小」到「極大」）一鍵切換，或拉「自訂調整」的滑桿，範圍是 0.7 倍到 1.5 倍。頁面上方有即時預覽，覺得太大太小，按「重設到1.0x」就回到標準。

#### 節日

點「節日」可以設定：

![App「個性化設定 → 節日」頁：選擇要顯示哪些國家／地區的節日與主要國家](/img/more/appearance-holiday-1.png)
*圖中：① 顯示節日開關　② 勾選要顯示哪些國家或地區的節日　③ 「主要國家」：節日台詞與節日主題以它為準*

![同一頁往下：節日主題開關（節日當天才換色）與節日資料來源](/img/more/appearance-holiday-2.png)
*圖中：① 選定主要國家　② AI 節日台詞（需開啟 AI）　③ 節日當天換上節日主題（圖中頂端紅色就是春節、國慶這類主題）　④ 節日資料來源與更新*

1. 「顯示節日」：在明細日曆標出節日，點到那天會出現應景台詞。
2. 「國家／地區」：複選要顯示哪些地方的節日（台灣、中國、香港、日本、韓國、美國）。
3. 「主要國家」：多個國家同一天都有節日時，只顯示主要國家的。
4. 「節日主題」：節日當天，主題色和頁首會自動換成應景樣式，隔天換回來。預設開啟。
5. 「應景台詞」：沒設定 AI 時用內建台詞；開啟 AI 後，月底會請 AI 寫下個月的台詞，只會送出節日名稱與日期，不含任何帳目。

節日主題只是「暫時換裝」，不會改掉你自己選的主題色和皮膚。節日當天進到「主題色」或「皮膚」頁，最上面會有提示條，可以直接跳到「節日設定」。

### 💻 在 Web 上

Web 的外觀設定比較精簡：

1. 點右上角頭像，在「設定」區選「個人資料」。
2. 點「主題色」膠囊，選整站的主色（按鈕、邊框、高亮都會跟著換）。
3. 在「同步偏好」卡片可以調整：收支配色、股票漲跌顏色、皮膚、餘額顯示格式、備註顯示方式、顯示交易時間、可愛類別圖示。這些設定與 App 同一份，改完會同步過去。
4. 深色模式不在設定頁：點頭像，在「偏好」區的「切換主題」選「跟隨系統」「淺色」或「深色」三個按鈕之一（滑鼠停在按鈕上會顯示名稱）。
5. 節日主題由 App 的設定決定：App 開著節日主題，Web 在節日當天也會自動換色。

## 注意事項／小提醒

:::note 主題色在 Web 和 App 的差別
App 改主題色會自動傳到 Web；但你在 Web 上自己改過主題色後，主題色只存在那個瀏覽器，不會回傳到 App，之後 App 的變更也不會蓋掉它。
:::

:::tip 皮膚會鎖住主題色
選了標示「自帶配色」的皮膚，「主題色」頁會暫時不能改，並出現「換皮膚」按鈕。換回一般皮膚，就會恢復你原本選的顏色。
:::

- 「新增交易的建議分頁」只存在這支手機，不會同步到其他裝置。
- 「每週起始日」目前以 App 的設定為準；Web 日曆的週起始日依瀏覽器語系決定，中文環境為星期一。
- 桌面小工具不跟節日主題換色，只在 App 更新它時才會重畫。
