銀行帳單寄來了，你想確認：自己有沒有漏記？有沒有哪一筆其實是下個月才會入帳？對帳模式就是做這件事的工具。拿著銀行帳單，在蜜蜂記帳這一期的清單上逐筆點確認，最後把「已確認金額」和銀行帳單的總額比一比，對上了就代表沒漏。

> 📱 App　💻 Web

## 為什麼這樣設計

- 信用卡消費日和銀行入帳日常常差幾天，月底刷的一筆可能要到下個月才出現在帳單上。所以每一筆都可以「延後入帳」，把它歸到真正入帳的那一期。
- 對帳是逐筆即時存檔：點一下就生效，沒有「暫存」，離開頁面就好。App 與 Web 的確認狀態會互相同步。

## 怎麼操作

### 進入對帳模式

**📱 在 App 上**

1. 「資產」點進信用卡（或合併帳單主帳戶），切到「交易明細」分頁。
2. 先在帳單彙總切到要對的那一期。
3. 點彙總下方的「對帳模式」那一列，右邊的 `3/12` 表示這一期已確認 3 筆、總共 12 筆。

對帳頁是獨立的頁面，標題下方顯示這一期的「上次結帳日 – 本次結帳日」。頁面上沒有換期按鈕，要換期請回上一頁，在帳單彙總切好再點進來。

**💻 在 Web 上**

1. 左側選單點「帳戶」，點開信用卡。
2. 用標題旁的箭頭切到要對的那一期。
3. 點「對帳模式」，彈出視窗就是這一期的清單。

:::note 入口出現的條件
這張卡（或主帳戶）要設好帳單日與還款日，才會有「對帳模式」。合併帳單的子卡如果沒看到入口，請從主帳戶進入。
:::

### 逐筆核對

頁面最上方是這一期的統計：

- 帳單筆數
- 新增消費
- 已確認筆數
- 已確認金額

下面是交易清單。每一列從左到右：

1. 確認按鈕：點一下，圓圈變成綠色勾勾，代表「這筆有出現在銀行帳單上」；再點一次取消。
2. 分類或備註、日期、金額，以及標籤：「轉帳」、「回饋」、「已延後」。
3. 編輯鉛筆：打開這筆交易，可以直接修改金額，改完回到清單馬上更新。
4. 延後按鈕：見下方說明。

核對完，把「已確認金額」和銀行帳單上的金額比對。對不上的，就是漏記、多記或金額輸入錯誤的那幾筆，點未確認的一一檢查。

![Web 對帳模式視窗，顯示統計與逐筆確認按鈕](/img/reconciliation/mode-3.png)

合併帳單主帳戶的清單會依子卡分組，每組標題顯示卡名、這期筆數與小計；沒有交易的子卡不佔位。Web 把同一條回饋規則這一期的回饋金合併成一列，標示「共N筆」，點進去逐筆查看，也可以在裡面修改單筆回饋金額。

### 銀行帳單上有、你卻沒記的交易

點右上角選單（Web 是「更多操作」）→「新增遺漏的交易」，補記一筆。新增的交易會落在這一期。

### 延後入帳

某一筆消費銀行還沒入帳，會算在下一期帳單。

**📱 在 App 上**：點那一列的「延後」，選日期。預設是下一期帳單的第一天。確定後這筆就移到那一天所在的那一期，在新的那一期顯示「已延後」標籤，按鈕變成「取消延後」，點一下直接取消。

**💻 在 Web 上**：點「延後入帳」，在「延後到下期帳單」視窗選「實際入帳日期」，按「延後」。這筆交易會從目前這一期移走，出現在新日期所在的那一期。要取消，編輯這筆交易，把「實際入帳日(選填)」清空。

延後入帳的交易，帳單的新增花費、剩餘帳款和紅利回饋，都改成按延後後的入帳日算，不是原本的消費日。

:::tip 什麼時候用延後
- 月底刷卡，銀行帳單要下個月才出現。
- 海外刷卡因為清算延遲，入帳日和消費日差好幾天。
:::

### 其他操作

右上角選單還有：

- 「最新在前」／「最早在前」：切換排序。
- 「取消全部選取」：把這一期已確認的交易全部恢復成未確認，會先二次確認。已延後的標記不受影響。

📱 App 離開頁面直接按返回即可。💻 Web 對帳完按「完成對帳」關閉視窗，上方的帳單數字會跟著更新。

### 哪些交易會出現在清單

會列出：

- 這張卡這一期的支出與收入（依入帳歸屬日落在哪一期；延後入帳的算在延後後那一期）。
- 回饋金收入，帶「回饋」標籤。
- 你手動記的、轉入這張卡的轉帳，帶「轉帳」標籤。它被視為收入，會減少這期的新增消費。

不會列出：

- 用「繳款」功能或自動扣繳產生的繳款轉帳（備註是「信用卡繳款(帳單 …」「自動扣繳(帳單 …」等），不論繳的是哪一期。繳款不是帳單上的消費，不用核對。
- 轉出這張卡的轉帳。
- 繳款時為了抵扣溢繳而產生的那一對收支（備註「信用卡繳款抵扣（…）」）。

### 手續費與折扣小字

有填手續費或折扣的交易，在 App 清單的日期下方會多一行灰色小字，讓你不用心算就能核對淨額：

```
原始金額 2,407.00 + 手續費 36.00 − 折扣 10.00
```

清單右邊的金額是淨額（原始金額加手續費再減折扣）。轉帳不顯示這行。外幣交易的符號會改用幣別縮寫，例如 JPY。Web 的清單則是在日期下方以「手續費 36 · 折扣 10」顯示。

## 注意事項／小提醒

:::note 清單的標題怎麼顯示
App 的對帳清單標題會跟著「個性化設定」的「備註顯示方式」切換：分類優先時顯示分類，備註以括號接在後面；備註優先時有備註就顯示備註。轉帳固定顯示「轉帳」。
:::

- 延後入帳在 App 只能從對帳頁操作；記帳表單沒有「延後入帳日」欄位。Web 的新增與編輯交易表單有「實際入帳日(選填)」，兩邊填的是同一個欄位。
- 帳單週期以台灣時間為準，結帳日當天的消費算在「這個結帳日結束的那一期」。詳見[設定信用卡](../credit-card/setup.md)。
- 餘額調整產生的交易不在對帳清單裡，詳見[餘額調整](./adjust.md)。
- 在清單裡編輯或刪除交易後，如果數字沒馬上更新，離開頁面再進來即可。
