# 專案

> ⚠️ **僅 Cloud 版可用**：本頁功能是 BeeCount Cloud（自建服務端）獨有的進階功能，純 App 本機記帳沒有這個入口。

旅遊、裝修、辦婚禮這類「有明確起訖、想單獨看花費」的計畫，可以開一個專案來追蹤，跟日常分類統計分開看。

## 開啟入口

頂部導覽列緊鄰「標籤」右側的 **專案**（`/app/projects`）。

## 建立專案

| 欄位 | 說明 |
|---|---|
| 名稱、圖示 | emoji 圖示方便辨識 |
| 預算 | 選填，不填代表純追蹤、不設金額上限 |
| 週期類型 | 單次（自訂起訖日，適合旅遊/裝修）／每月／每年 |
| 起訖日 | 週期類型選「單次」時必填 |
| 預算結轉 | 開啟後，這期沒花完的預算會累加到下一期（適合每月/每年週期） |
| 首頁顯示 | 是否要在首頁看到這個專案的進度 |

## 記帳時歸屬專案

建立/編輯交易時，除了分類、帳戶，還可以選「專案」欄位——記一筆消費的同時指定它屬於哪個專案。這是**手動指定**，系統不會自動猜測，僅支援收入/支出類型的交易。

專案彼此是平行關係，不分層級，一筆交易只能歸屬一個專案。

## 常見問題

**專案跟分類重複了嗎？**
不會，分類是「這筆錢花在什麼類型上」（餐飲、交通……），專案是「這筆錢屬於哪個計畫」（日本旅遊、裝修……）——同一筆交易可以同時有分類又有專案，兩個維度互不影響，可以分別統計查看。
