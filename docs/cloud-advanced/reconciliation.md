# 對帳與延後入帳

> ⚠️ **僅 Cloud 版可用**：本頁功能是 BeeCount Cloud（自建服務端）獨有的進階功能，純 App 本機記帳沒有這個入口。

信用卡月底刷的一筆消費，銀行可能要到下個月才真正請款、算進帳單。如果直接照消費日記帳，會發生「這筆錢到底算哪一期帳單」對不起來的問題——這個功能就是處理這個落差。

## 延後入帳

在交易明細裡，把某筆信用卡交易標記「延後入帳」，指定一個實際入帳日期。之後所有「這筆錢算哪一期」的統計（帳單試算、回饋計算……）都會改用這個入帳日，而不是原本的消費日。

## 對帳模式

信用卡帳戶詳情頁的「對帳模式」，列出這期帳單所有交易，讓你一筆一筆跟銀行實際帳單核對：

- 核對沒問題的交易，點「確認這筆在帳單上」標記已確認
- 標記「已延後」的交易會特別顯示，提醒你這筆錢實際算到下一期

![對帳模式](https://photo.pnsgzomf.synology.me/i/2026/08/11/6a79f908e8b47.png)

畫面上方會顯示「帳單筆數 / 已確認筆數」跟「新增消費 / 已確認金額」，一眼看出還有幾筆沒對完。

## 什麼情況該用延後入帳

- 月底刷卡，銀行帳單要下個月才出現這筆
- 分期消費的某一期實際扣款日跟預期不同
- 海外刷卡因為清算延遲，入帳日跟消費日差好幾天

## 常見問題

**一定要用對帳模式才能記信用卡交易嗎？**
不用，對帳模式是選擇性核對用的輔助工具，不影響一般記帳；只是如果你想確保 Web 上的信用卡帳單金額跟銀行帳單完全對得上，建議定期用這個功能核對一次。
