想在年底前存 6 萬元去日本旅行，或是每週多存一點，湊出新手機的錢。把目標設成存錢桶，之後每存一筆就看得到進度條往前走；定期存還會把期間切成一格一格，存滿一格就亮起來，像打卡一樣有成就感。

> 📱 App　💻 Web　存錢桶跟著**帳本**走：換到別的帳本，就是另一組存錢桶。登入**帳好嗎 Cloud** 後，App 與 Web 的存錢桶會互相同步。

## 入口

- **📱 App**：底部「規劃」→「未來的錢」→「存錢桶」。入口卡片右邊顯示存錢桶的數量，下面一行是置頂那個桶子的名稱與進度。
- **💻 Web**：右上角頭像選單 →「記帳工具」→「存錢桶」。

![App 規劃分頁「未來的錢」裡的存錢桶入口，顯示桶子數量與置頂桶子的進度](/img/record/savings-1.png)
*圖中：規劃分頁「未來的錢」，在「應收應付款項」「分期付款」下面就是「存錢桶」，右邊顯示「4 個存錢桶」與置頂的「日本旅行 · 77%」*

## 先決定：隨意存或定期存

點存錢桶頁右上角的「＋」，先選「存錢類型」：

| 類型 | 適合 | 怎麼存 |
|---|---|---|
| 隨意存 | 預備金、想到才存的目標 | 想存多少就存多少，沒有格子，只有進度與紀錄 |
| 定期存 | 有固定節奏的目標，例如每月存一筆、每週挑戰 | 依每天、每週或每月切成格子，一格一格存 |

![「存錢類型」選單：隨意存與定期存](/img/record/savings-3.png)
*圖中：點「＋」後的「存錢類型」，隨意存不設格子，定期存依每天、每週或每月切成格子*

## 兩種存錢桶：綁定帳戶與純記錄

建立存錢桶時有一個「存放帳戶」欄位，它決定這個桶子怎麼運作：

- **不指定（純記錄）**：桶子只是一本小帳，在桶子裡直接記「存錢」「取錢」，不會動到任何帳戶餘額，也不會新增交易。適合只想追蹤進度的目標。
- **指定存放帳戶（綁定桶）**：桶子裡的錢真的放在那個帳戶。存錢、取錢必須透過真實的收入、支出或轉帳，再用[帳單標記](./flags.md)選這個存錢桶，桶子才會增加或減少。這樣桶子的金額一定對得上帳戶，不會憑空生錢。

:::caution 存放帳戶建立後不能改
存放帳戶只能在新增時設定，之後編輯頁只能看、不能換；純記錄的桶子也不能事後再綁定帳戶。要換的話，請新增一個新的存錢桶。存放帳戶的幣別必須跟存錢桶一樣。
:::

## 怎麼新增存錢桶

### 📱 在 App 上

1. 到「規劃 → 未來的錢 → 存錢桶」，點右上角「＋」，選「隨意存」或「定期存」。
2. 填「名稱」（例如「日本旅行」）與「目標金額」。
3. 選「圖示」與「顏色」。圖示有一排常用的，點「更多圖示」可以從圖庫挑；顏色除了預設色盤，最後一顆彩色圓點可以自訂任意顏色。
4. 設「開始日期」與「結束日期」。隨意存的結束日期可以不設，設了之後桶子頁會算出「每天約存多少就能準時達標」。定期存一定要有結束日期。
5. 定期存另外要選：
   - 「存錢頻率」：每天、每週或每月。
   - 「每格金額」：「每格一樣」，或「逐格遞增（52 週挑戰）」，從小到大一格比一格多。
   - 設定的同時會顯示「共 N 格」。
6. 打開「未存滿時提醒」（定期存才有）可以設提醒，見下面的[到期提醒](#reminder)。
7. 需要的話選「存放帳戶」、寫備註，點「儲存」。

![新增存錢桶頁上半部：名稱、目標金額、圖示與顏色、開始與結束日期、存錢頻率與每格金額](/img/record/savings-4.png)
*圖中：新增定期存桶子，上半部是名稱、目標金額、圖示、顏色與日期，下面是存錢頻率與每格金額，最後一行顯示「共 28 格」*

![新增存錢桶頁下半部：未存滿時提醒、存放帳戶與備註](/img/record/savings-5.png)
*圖中：往下捲是「未存滿時提醒」開關、「存放帳戶」（預設「不指定（純記錄）」）與備註*

:::note 定期存的金額限制
- 定期存的目標金額必須是整數。
- 目標金額不能太低：每格至少要有 1 元，「逐格遞增」的最低金額則是 1 + 2 + 3 +…加到最後一格。低於下限時會提示「目標金額過低，此週期下至少需設定為 N 元」，不能儲存。
- 每格的金額由系統自動算好，加起來剛好等於目標金額；除不盡的零頭會補在後面幾格。
:::

### 💻 在 Web 上

到「頭像選單 → 記帳工具 → 存錢桶」，右上角「新增存錢桶」，欄位與 App 相同。差別是提醒通知由 App 發送，Web 只負責設定「未存滿時提醒」與時間。

## 定期存的格子

「格子」分頁會依你設的頻率切成一格一格，上方寫著進度，例如「已存滿 4 / 6 個月」。

- 每一格顯示計畫金額與期間的起始日。目前所在的那一格有粗框。
- 一格存滿就整格亮起並打勾；只存了一部分，就由下往上填色，一眼看得出還差多少。
- 「每週」「每月」的期間都是從開始日期起算的滾動區間，不是日曆上的自然週或自然月。例如從 1 號開始的每月存錢桶，每一格都是「這個月 1 號到下個月 1 號前一天」。

![綁定桶的格子頁：前四格已存滿亮起，第五格存了一部分，第六格還空著](/img/record/savings-6.png)
*圖中：每月定期存的「日本旅行」，共 6 格、每格 10,000，已存滿 4 格；第 5 格（11/01）存了 6,000，所以填了六成*

選「逐格遞增」時，每一格的金額一格比一格多：

![每週逐格遞增的格子頁：100、200 一路到 1,000，前七格已存滿](/img/record/savings-13.png)
*圖中：每週遞增的「新手機」，10 格從 100 一路加到 1,000，已存滿 7 格*

### 點格子與〔存錢〕

- 點一個**還沒存滿的格子**：開出存錢視窗，金額預設帶入「這格的計畫金額減掉已存」，並且鎖定在這一格。
- 點一個**已亮起的格子**：看這格的紀錄，也可以按「再存一筆」。
- 直接按底部〔存錢〕：系統自動挑「最小的、還沒存滿的那一格」，一樣預填差額。全部都存滿之後再存，就變成不屬於任何格子的「未歸格存款」，只會增加總進度。
- 某一格存超過計畫金額也可以，那一格照樣亮起，但多出來的金額**不會**自動算到下一格。

### 取錢從最新一期往回扣

〔取錢〕不會指定某一格，而是把總取款額從**最新的一期**開始往回扣，扣完再往前一期。例如三格各 100，已存 100、100、50 時取 150：最後一格的 50 先扣掉，再扣第二格的 100，結果只剩第一格亮著。

這樣早期已經存滿的格子會一直亮著，被退回去的是最近存的那幾期，之後按〔存錢〕會先補回最前面、還沒存滿的那一格。

## 純記錄桶：存錢與取錢

純記錄桶的底部有〔取錢〕與〔存錢〕兩顆鈕，點了開出表單：

1. 填「金額」，系統預設日期是今天，也可以改日期。
2. 需要的話寫備註，點「確定」。

![存錢表單：第 8 格、金額預填 500、日期與備註](/img/record/savings-14.png)
*圖中：在定期存桶子按〔存錢〕，表單上方標示鎖定的格子（第 8 格），金額預填還差的 500*

![取錢表單：金額、日期、備註與說明](/img/record/savings-16.png)
*圖中：取錢表單，下方說明這個存錢桶沒有存放帳戶，只做記錄*

存錢桶的金額不會是負的：取錢超過目前已存會被擋下，並提示「已存金額不足，目前已存 N」。已存是 0 時，〔取錢〕鈕是停用的。

## 綁定桶：用交易存錢與取錢

有存放帳戶的桶子，按底部〔存錢〕或〔取錢〕不會開簡單的視窗，而是開**新增交易**頁：

- 〔存錢〕開「收入」，〔取錢〕開「支出」，帳戶已經預設是存放帳戶，並且已經標記這個存錢桶。定期存會預填金額與格子。
- 你仍然可以在同一頁切成「轉帳」，例如把活存裡的錢轉進存放帳戶。

![綁定桶〔存錢〕開出的收入表單：帳戶是存放帳戶，金額已預填](/img/record/savings-10.png)
*圖中：在「日本旅行」按〔存錢〕開出的收入頁，帳戶預設「旅遊基金專戶」，金額預填第 5 格還差的 4000，標籤列最右邊的旗子就是帳單標記*

### 自己記帳時標記存錢桶

不從桶子進來，平常記帳時也能標記：

1. 新增或編輯一筆**收入、支出或轉帳**，選好帳戶。
2. 收入、支出：點標籤列最右邊的旗子，開出[帳單標記](./flags.md)視窗，「存錢桶」一列右邊點開。轉帳：表單上直接有「存錢桶」這一列。
3. 選要記到哪個桶子，或選「不標記」。
4. 存檔。

![帳單標記視窗裡的「存錢桶」一列，右邊顯示已選的「日本旅行」](/img/record/savings-11.png)
*圖中：帳單標記視窗，除了「不計入收支」，還有「存錢桶」一列，說明是「記到存錢桶，這筆算存錢」*

![選擇存錢桶：不標記與日本旅行](/img/record/savings-12.png)
*圖中：點開後的選單，只列出存放帳戶就是這筆交易所用帳戶的桶子，目前選的有打勾*

什麼樣的交易可以標記，規則是這樣：

| 這筆交易 | 算什麼 |
|---|---|
| 收入進存放帳戶 | 存錢 |
| 支出從存放帳戶出去 | 取錢 |
| 轉帳「轉入」存放帳戶 | 存錢 |
| 轉帳「轉出」存放帳戶 | 取錢 |

- 選單裡只會出現「存放帳戶就是這筆交易帳戶」「同一個帳本」「還沒封存」的桶子，所以沒選對帳戶時，看不到存錢桶很正常。
- 標記「取錢」時如果桶子裡的錢不夠，交易會照常儲存，但這筆不會被標記，並提示「交易已儲存，但存錢桶只有 N，這筆沒有標記」。
- 之後修改這筆交易的金額、日期或收支方向，存錢桶的紀錄會跟著變；把交易改到別的帳戶（不再是存放帳戶），這筆就會從桶子拿掉、交易本身保留；刪除交易，桶子裡對應的紀錄也一起消失。

### 綁定桶的紀錄：查看、取消標記、刪除交易

綁定桶的「紀錄」分頁，每一筆右邊有一個「↔」圖示，表示它來自一筆交易。點一筆紀錄，選單有三個選項：

![綁定桶的紀錄列表：每筆紀錄的右邊有來自交易的標記](/img/record/savings-7.png)
*圖中：日本旅行的紀錄，每筆都標示金額、日期與所屬的格子，右邊的「↔」表示這筆紀錄來自一筆交易*

![點紀錄後的選單：查看交易、取消標記、刪除交易](/img/record/savings-8.png)
*圖中：紀錄的操作選單*

| 選項 | 效果 |
|---|---|
| 查看交易 | 開啟原本那筆交易的編輯頁，要改金額、日期、備註都在那裡改 |
| 取消標記 | 只把這筆從存錢桶拿掉，交易本身保留（金額、帳戶餘額都不變） |
| 刪除交易 | 連**原本的交易**一起刪除，存錢桶的紀錄也跟著消失，**無法復原** |

![刪除交易確認：這筆交易和存錢桶裡的紀錄都會刪除，無法復原](/img/record/savings-9.png)
*圖中：選「刪除交易」後會再確認一次*

:::note 哪些交易刪不掉
分期付款管理的交易、即時回饋產生的交易，仍然照原本的規則保護，不能從存錢桶這裡刪除；請到各自的頁面處理。
:::

純記錄桶的紀錄則是「編輯紀錄」與「刪除紀錄」，只動紀錄本身。

## 達標了！

存到目標金額的那一次，畫面會先放一陣**花朵往四面散開**的慶祝動畫（約 2.6 秒），**播完才**問你要不要封存。

![達標瞬間的花朵慶祝動畫，花朵從畫面中央往四周散開](/img/record/savings-17.png)
*圖中：在「聖誕禮物」存下最後的 200 元，已存達到 NT$3,000，花朵從畫面中央散開*

![達標了！詢問是否封存：繼續存或封存](/img/record/savings-18.png)
*圖中：動畫播完後問「已經存到目標金額，要封存嗎？」，可以選「繼續存」或「封存」*

- 「封存」：桶子移到上方「已封存」分頁，不再出現在進行中。需要時可以取消封存。
- 「繼續存」：桶子照常使用。存超過目標也可以，進度條停在 100%，並標示超額的金額。
- 如果到了結束日期還沒存滿，桶子會標示「已逾期」，仍然可以繼續存。
- 手機設定了「減少動態效果」的話，會跳過動畫，直接問你要不要封存。
- 💻 Web 在畫面上看到桶子由未達標變成達標時也會播放花朵動畫，例如從交易編輯視窗標記完成之後。

## 到期提醒（定期存） {#reminder}

編輯定期存的桶子時打開「未存滿時提醒」，再選一個提醒時間（預設 21:00）。**每一期（格子）結束的那一天**，到了提醒時間，如果這一格還沒存滿，就會收到通知：「『日本旅行』這一期還沒存滿」，內文寫「計畫存 N，還差 N」。

- 通知由**每一台裝置的 App 在本機發出**，不需要連上雲端。
- 存滿了就不會再提醒；已經過去的期不會補發。
- 如果你在另一台裝置或 Web 先存滿了，這一台還沒同步之前仍可能照舊提醒，同步後就會消失。
- 💻 Web 只負責設定開關與時間，不會發通知。

## 管理存錢桶

- **長按**列表上的桶子：開出選單，有「編輯」「置頂」（已置頂則是「取消置頂」）「封存」「刪除」。要找回封存的桶子，到上方「已封存」分頁，長按選「取消封存」。
- **編輯**：可以改名稱、圖示、顏色、目標、日期、頻率、每格金額與提醒；類型（隨意存或定期存）與存放帳戶不能改。
- **刪除**：會連桶子裡的所有紀錄一起刪，**標記過的交易會保留**，只是不再屬於任何存錢桶。

![長按存錢桶出現的選單：編輯、置頂、封存、刪除](/img/record/savings-19.png)
*圖中：長按「緊急預備金」開出的選單*

## 注意事項

- 一般方案的**隨意存與定期存分開算**，每類預設未封存 2 個、含封存共 8 個，跨自己擁有的帳本加總。新增會檢查兩個上限，取消封存要有未封存名額；支持者有效期間免除此限制。
- 每加購一個對應類型的名額，未封存與含封存上限都加一；買隨意存不會增加定期存的名額。因方案變更而超額的桶子，不能新增存取紀錄或交易標記，原有內容保留。詳見[方案額度與購買名額](../sync/limits.md)。

- 存錢桶的幣別就是建立時帳本的幣別，建立後不能改，也沒有多幣別或跨帳本的存錢桶。
- 改開始日期、結束日期、頻率或每格金額造成格子數量改變時，**不會動到已經存的紀錄**：超出新格數的存款只是變成「未歸格存款」。
- 存錢桶與[農場](../farm/overview.md)的好幣沒有任何關係。
- 目前存錢桶**還不能附圖片**。
