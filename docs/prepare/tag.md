分類一筆交易只能選一個，但生活裡的帳常常有好幾個面向。一杯咖啡，分類是「飲品」，但它同時是「出差」期間花的、而且「可報帳」。標籤就是用來補上這些分類以外的註記，一筆交易可以掛多個標籤。

> 📱 App　💻 Web

## 為什麼這樣設計

分類管「花在什麼上」，標籤管「為什麼花、花在什麼場合」。把這兩件事分開，報表才不會因為多一個用途就要硬加一堆分類。想知道這趟出差總共花多少，只要查「出差」標籤，不必在每個分類裡翻找。

標籤跟分類一樣，是所有帳本共用的。

## 怎麼操作

### 📱 在 App 上

**進入標籤管理**

1. 點底部的「我的」。
2. 進入「資料管理」。
3. 點「標籤管理」。

**新增標籤**

1. 點右上角「更多」，選「新增標籤」。
2. 輸入「標籤名稱」，選「標籤顏色」。
3. 點「儲存」。

標籤名稱不能重複。

**記帳時使用標籤**

在新增交易的頁面，點「標籤」那一列開啟「選擇標籤」，可以多選；畫面上有「最近使用」和「全部標籤」，找不到想要的就點「新建標籤」，不必離開記帳頁。

**查看、修改與刪除**

1. 在「標籤管理」頁點標籤卡片，進入「標籤詳情」，可看到交易筆數、總支出、總收入，以及所有掛這個標籤的交易。
2. 點詳情頁右上角的鉛筆圖示，進入「編輯標籤」修改名稱或顏色。
3. 要刪除，回到「標籤管理」頁，點卡片右下角的垃圾桶圖示並確認。

刪除標籤**不會**影響已經掛著它的交易，只是這些交易少了這個標籤。

**其他功能**

「更多」選單裡還有：

- 「產生預設標籤」：一次建好一組預設標籤，已有同名的不會被覆蓋。
- 「匯入標籤」：從標籤設定檔匯入，可選「合併」或「覆蓋」。
- 「清理未使用」：刪除沒有任何交易使用的標籤。

右上角的分享圖示可以把標籤設定存成檔案，方便搬到別台裝置。

### 💻 在 Web 上

1. 點上方導覽的「標籤」。
2. 點「建立標籤」，輸入「標籤名稱」並選顏色，下方預覽會顯示標籤的樣子。
3. 點「建立標籤」儲存。要改的話點卡片上的「編輯」，按「更新標籤」。
4. 卡片會顯示每個標籤被用了幾筆。

## 注意事項／小提醒

:::tip 標籤不要貪多
標籤好用在「想起來就能查」。建議先想好幾個真的會查的主題，例如「出差」「可報帳」「跟朋友聚餐」，不要每筆都掛一堆。
:::

:::note 預設標籤偏向中國大陸商家
「產生預設標籤」建出來的標籤包含不少中國大陸的商家名稱，台灣使用者通常用不到。建議自己建需要的標籤，或產生後刪掉不要的。
:::

:::note 自動掛上的標籤
用 AI、語音或圖片記帳時，系統可能會自動掛上對應的來源標籤；AI 記帳要不要自動新增標籤，可在記帳設定裡調整，見 [AI 記帳](../record/ai.md)。
:::
