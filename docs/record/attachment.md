買家電留下的保固單、報帳要用的收據、水電費繳費單……這些紙本很容易遺失。記帳時順手拍一張附在交易上，之後翻帳目就能看到當時的憑證。

> 📱 App（可新增、預覽、刪除）　💻 Web（可檢視與預覽）　圖片同步與下載模式需要 BeeCount Cloud。

## 為什麼這樣設計

照片會越累積越多，每次同步都全部抓到手機，流量和儲存空間很快就被吃光。所以雲端圖片提供兩種下載模式，讓你依自己的手機空間決定要不要先抓全部。

## 怎麼操作

### 📱 在 App 上新增附件

1. 在新增或編輯交易頁，標籤列（標籤、禮物、圖片、旗子那一排）找到圖片圖示。
2. 還沒有附件時點它，選「拍照」或「從相簿選擇」。相簿一次可選多張。
3. 附件加好後，圖示變成實心，旁邊顯示張數，例如「2」。
4. 照常送出交易。新增交易時附件會在儲存時一起存下；編輯既有交易時，加進來的附件會立刻存下。

### 📱 預覽、再新增或刪除

1. 已經有附件時，再點圖片圖示會進入預覽頁，上面顯示共幾張圖片。
2. 左右滑動切換，雙指可縮放。
3. 預覽頁上有新增（圖片加號）與刪除（垃圾桶）圖示，新增同樣是「拍照」或「從相簿選擇」，刪除前會問「確定刪除此附件？」。

在明細月曆點交易，交易資訊卡中間的大圖就是第一張附件，沒有附件才顯示分類圖示。

### 💻 在 Web 上

Web 的交易列表有「附件」欄，顯示張數，點開可預覽、用「上一張」「下一張」切換。「交易詳情」視窗也會列出「N 個附件」。

Web 目前沒有在記帳視窗新增附件的欄位，要新增附件請在 App 操作。只有已上傳到雲端的圖片才能預覽，還沒上傳完的會提示「僅中繼資料」；不是圖片的檔案提示「該附件不是圖片，暫不支援預覽」。

## 限制與壓縮

- 一筆交易最多 9 張，超過會提示「已達到最大附件數量」。
- 圖片會自動壓縮：長邊最多 1920 像素，品質約 80%，另外產生縮圖，所以不用擔心手機原圖太大。
- AI 拍照或圖片記帳時，可以讓系統自動把原圖加為附件，開關在「智慧記帳」設定的「自動新增附件」，見 [AI 記帳](./ai.md)。

## 雲端圖片下載模式 📱

登入 BeeCount Cloud 後，附件會自動備份到雲端（「附件同步」）。這些雲端圖片要怎麼下載到手機，由你選：

| 模式 | 做法 | 適合 |
|---|---|---|
| 即時下載 | 同步時把所有雲端附件一次載到手機 | 圖片少於約 1,000 張，想隨時離線也能看 |
| 動態下載 | 同步只更新資料，檢視含圖片的交易時才下載那一張 | 圖片很多，想省手機儲存空間與流量 |

1. 「我的」→「雲服務」→ 進入 BeeCount Cloud 同步頁，找到「雲端圖片下載」（登入後才會出現）。
2. 點開選「即時下載」或「動態下載」。

登入 BeeCount Cloud 後的第一次（舊版升級上來的也一樣），會跳出選擇視窗，預設選「即時下載」，不能取消也不能點視窗外關閉，一定要選一個。還沒選之前，視同動態下載。

:::note 這個設定只存在這台裝置
手機與平板可以各選不同模式，不會跟著帳號同步，因為儲存空間是裝置自己的事。
:::

:::tip 切換的影響
切到「即時下載」會在背景補齊所有帳本的圖片（提示「正在背景下載雲端圖片…」）。切到「動態下載」不會刪掉已經下載的圖片。動態下載時如果沒有網路，尚未下載的圖片會顯示破圖，連上網路再看就好。上傳不受這個設定影響。
:::

## 注意事項／小提醒

:::note 備份還原要先匯入附件
換手機或還原資料時，請先匯入附件包，再匯入帳本資料，附件才會正確對應到交易。附件匯出與匯入見[匯入與匯出](../more/data.md)。
:::
