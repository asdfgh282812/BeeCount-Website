這座農場最像真實世界的地方，就是它的天氣：你設定的城市下雨，你的菜就在淋雨；進了冬天，夏天的作物就種不活。這一頁說明季節、天氣和日夜怎麼影響你的田，以及你可以用哪些道具應對。

> 📱 App

## 為什麼這樣設計

- **讓真實世界的時間感進到遊戲裡。** 季節、天氣、日夜都取自真實資料，打開農場就知道今天外面是什麼天氣。
- **換季是最大的規劃重點。** 作物只能在所屬季節播種，換季時還在田裡的作物會枯萎，逼你想一想「這一批來不來得及收」，也是農場裡最需要提前安排的事。
- **壞天氣不是死路。** 風雨寒熱會影響生長與收成，但你可以靠道具保護作物，花好幣換穩定。

## 怎麼操作

### 📱 季節

季節跟著真實月份走，以台北時間為準：

| 季節 | 這季可以種的作物 |
|---|---|
| 春 | 萵苣、玉米、竹子、胡蘿蔔、番茄、小麥 |
| 夏 | 芹菜、茄子、甜椒、洋蔥、番茄、小麥 |
| 秋 | 蘿蔔、馬鈴薯、竹子、南瓜、葡萄、甜菜根 |
| 冬 | 萵苣、韭蔥、花椰菜、胡蘿蔔、莓果、青花菜 |

- 有些作物橫跨兩個季節，所以會在兩邊都出現。
- 不是上表的每一種你一開始都能種，作物是隨著等級**逐級解鎖**的，見[等級、商店與佈置](./growth-shop.md)。
- 點農場畫面上的季節圖示，可以看到**下次換季的日期**。農場裡的樹木也會隨季節換色。

![點季節圖示後的氣泡，顯示目前季節與下次換季日期](/img/farm/season-weather-1.png)
*圖中：點季節膠囊，氣泡裡寫著目前的季節和下次換季的日期*

#### 換季時會發生什麼事

- 作物**只能在所屬的季節播種**，不是當季的種子在清單裡會變灰。
- **換季的那一刻，還在田裡的作物會枯萎**，不管是還沒長完，還是已經成熟了卻沒收。枯萎的作物會留下枯草，要清掉才能再種。
- 有兩個例外：番茄是少數可以撐過一次換季的作物；溫室罩也能讓田裡的作物多撐過一次換季。
- 為了避免你不小心踩雷，播種時如果預計來不及在換季前成熟，會先提醒你；雲端農場在換季前會用通知提醒你還有作物在田裡（只在你真的有作物在田裡的時候才會提醒），換季當下也會通知；這些通知可以在設定裡關掉。

![換季後枯萎的作物變成枯草，需要清除](/img/farm/season-weather-2.png)
*圖中：換季後來不及收成的作物枯萎，留下枯草*

:::tip
換季前幾天，就該開始想：哪些作物收得完、哪些不要再種。能收的先收，來不及的作物乾脆等換季後再種當季的新品種。
:::

### 📱 天氣

農場的天氣取自你在設定裡選的城市，每次進到農場時會更新。點畫面上的**天氣膠囊**，可以看到目前的氣溫和降雨，並手動重新整理。

![點天氣膠囊後的氣泡，顯示氣溫與降雨量，可重新整理](/img/farm/season-weather-3.png)
*圖中：點天氣膠囊，氣泡裡顯示目前氣溫與降雨，並可重新整理*

天氣怎麼影響你的田：

| 天氣 | 影響 |
|---|---|
| 下雨 | **自動澆水**，不用動用水壺 |
| 晴天 | 喜歡陽光的作物長得比較快，但天氣太熱時水分也掉得比較快 |
| 陰天 | 喜歡陰天的作物長得比較順 |
| 豪雨 | 有些作物（耐旱的）泡太多水反而長得慢 |
| 寒流 | 不屬於冬天的作物長得比較慢 |
| 強風、颱風 | 沒有防護的田可能受損，影響收成 |
| 連續高溫潮濕 | 比較容易長蟲 |

- 壞天氣如果沒有防護，除了生長變慢，**收成的結果也會更不穩定、平均更差**。想穩定收成，就用道具保護。
- 抓不到天氣資料的時候（沒有網路或服務暫時出問題），農場會暫時當作「多雲、氣溫舒適、沒下雨」，不會因此懲罰你。
- 農場畫面會真的反映天氣：下雨有雨滴與濕土，低溫降水會下雪，風大時畫面會有風吹的動態，晚上有星月和暖色燈光。

![下雨天的農場，田地變濕、畫面有雨滴](/img/farm/season-weather-4.png)
*圖中：下雨的農場，土壤變濕，雨滴落在田上*

### 📱 日夜

日出與日落時間取自你所選城市的資料，農場的天色也跟著換：夜晚畫面變成深藍色，農舍和路燈亮起暖色的燈光。

- **多數作物在夜晚長得比較慢**，白天（尤其合它脾胃的天氣）長得比較快。
- 生長燈可以讓那塊田在夜晚也像白天一樣生長。

![夜晚的農場，夜色與暖色燈光](/img/farm/season-weather-5.png)
*圖中：夜晚的農場，整座農場覆上夜色，農舍與路燈亮著暖色的燈*

### 📱 道具：用來保護或加速作物

道具能改變**小範圍**的天氣或狀況，只影響你自己的田，不會改變顯示出來的真實天氣，也不會影響別人。道具只能用在**已播種**的田。

| 道具 | 影響範圍 | 用途 |
|---|---|
| 晴天娃娃 | 附近一小區的田 | 這一帶當作晴天，作物照常生長 |
| 雨雲罐 | 附近一小區的田 | 這一帶當作下雨，自動補水 |
| 灑水器 | 附近一小區的田 | 讓土壤保持濕潤 |
| 生長燈 | 被選的那塊田 | 夜晚也能生長 |
| 溫室罩 | 被選的那塊田 | 擋住壞天氣，並能讓作物多撐過一次換季 |
| 防颱網 | 整座農場 | 防止強風損壞 |
| 肥料 | 被選的那塊田 | 加速生長，直到收成 |
| 驅蟲劑 | 被選的那塊田 | 清掉蟲害，並在一段時間內擋住新的蟲害 |

- 「附近一小區」是以你選的那塊田為中心，加上周圍相鄰的田；靠邊的田自然就少一點。
- 怎麼用：點已播種的田 →「使用道具」→ 選道具。用過之後，被影響的每塊田都會顯示道具圖示；點作物可以看到**效果與到期時間**（台北時間）。
- 道具從哪來：[商店](./growth-shop.md)可以買；升級時的寶箱、偷菜成功的獎勵、排行榜的獎勵也可能抽到。
- 商店裡每個道具卡片都會寫明範圍和效果，買之前看一下。

![田地的使用道具選單，列出庫存中的道具與效果](/img/farm/season-weather-6.png)
*圖中：點作物 →「使用道具」，列出你有的道具與它們的效果*

![已使用道具的田地，作物氣泡顯示生效中的道具與到期時間](/img/farm/season-weather-7.png)
*圖中：用過道具後，點作物會看到生效中的道具與有效時間*

### 📱 設定天氣城市

進入「農場 → 設定 → 天氣城市」，可以選台灣的各縣市和部分海外城市，也可以選「使用目前位置」：只有在你選這一項的當下才會要求定位權限，取得後只記下大略的位置，不會保存精確座標，也不要求你一定要開定位。

換城市時，農場會先把舊城市的時間算完，再套用新城市，不會把新城市的天氣套到已經過去的時間。

![天氣城市選單：使用目前位置與各縣市](/img/farm/season-weather-8.png)
*圖中：農場設定的「天氣城市」，可選使用目前位置或各縣市*

### 減少動態

農場畫面裡的雨、雪、風的動畫，飄出來的表情和開寶箱動畫，都會尊重「我的 → 外觀 → 減少動畫」的設定。開啟之後會變成靜止的畫面，田地仍然可以正常操作，詳見[外觀](../more/appearance.md)。

## 注意事項／小提醒

:::note
- 季節、天氣、日夜都以**真實時間**為準，沒有「跳過」的方法；想體驗不同季節，就等到那個月份。
- 換季提醒只有雲端農場才有通知，單機農場請自己留意季節圖示上的換季日期。
- 道具的效果有時間限制，到期就失效，用的時機很重要，不要太早用。
:::
