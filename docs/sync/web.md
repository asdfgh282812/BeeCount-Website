在電腦前整理帳目、匯入一大批資料、看大張的報表，用網頁版會比手機順手。Web 版和手機 App 共用同一個帳號和同一份資料，兩邊的修改幾秒內就會互相同步，不用另外安裝。

> 💻 Web

## 為什麼這樣設計

手機適合隨手記一筆，電腦適合「坐下來好好整理」。所以網頁版保留了大部分功能，又多了幾個在大螢幕上才好用的東西：批次處理交易、比較報表，以及鍵盤驅動的 ⌘K 命令面板。

## 怎麼操作

### 登入

1. 用瀏覽器開啟你的帳好嗎 Cloud 網址（和 App 輸入的伺服器位址相同，向管理員確認）。
2. 按「使用 SSO 登入」，在跳轉的頁面完成登入，完成後會自動回到帳好嗎。
3. 如果登入後出現「需要授權金鑰」，輸入金鑰並按「啟用」，見[授權金鑰](./license.md)。管理員帳號不會看到這一頁。
4. 全新的帳號第一次進來，會先出現全螢幕的「歡迎」引導，依序設定語言、主題色與外觀模式、Liquid Glass 質感與造型、每週起始日、App 的行事曆預設顯示與顏色習慣、AI；接著要建立你的第一本帳本（名稱與帳本幣別，必填），最後可以新增第一個帳戶（可略過）。App 或 Web 任一端完成或略過後，就不會再出現。
5. 進到首頁後，如果還沒有任何帳本，頂部會有「新建帳本」按鈕。

:::note
登入用的是 SSO，這個版本不開放自己註冊。如果登入失敗出現「SSO 登入發生錯誤」，請稍後重試，持續出現請洽管理員。
:::

### 安裝成 PWA（可選）

Web 版可以「安裝」成像 App 一樣的獨立視窗，有自己的圖示，不顯示瀏覽器網址列。

1. 使用 Chrome 或 Edge 等支援的瀏覽器，多開幾次網頁版（在 7 天內進入 3 次以上）。
2. 畫面右下角會出現「把帳好嗎加入桌面?」的提示，按「加入」。
3. 完成後會顯示「已安裝，可在 dock / 主畫面找到『帳好嗎』」。安裝後的 App 名稱就是「帳好嗎」（完整名稱「帳好嗎 TallyCheck」），圖示是新的帳好嗎 logo。

如果你按了提示上的「不再提示」，這個提示就不會再出現。想手動安裝，可以用瀏覽器網址列右邊的「安裝」圖示或瀏覽器選單裡的「安裝應用程式」。

有新版本時，畫面上方會出現「偵測到新版本」，按「立即更新」即可。

![PWA 安裝提示](/img/sync/web-2.png)
*圖中：瀏覽器跳出「把帳好嗎加入桌面?」提示，按「加入」就能把帳好嗎裝成桌面或主畫面的 App*

:::tip iPhone 或 iPad 怎麼加到主畫面
Safari 不會跳出上面的提示，請按「分享」按鈕，選「加入主畫面」。
:::

### 介面導覽

4.0 的 Web 換上新色票（新芽綠）與 Liquid Glass 玻璃質感：頂部列、導覽列、分段選項與面板都是半透明的玻璃效果。想調整玻璃的通透程度，到頭像選單 →「設定」→「個人資料」的「Liquid Glass」，可選「清透」「平衡」「厚霧」。

**頂部列**由左到右是：

| 位置 | 內容 |
|---|---|
| 左側 | 帳好嗎標誌與名稱（點一下回首頁）、目前的版本號、帳本選擇器（切換帳本，共享帳本會標 🤝 與人數），旁邊的齒輪按鈕可直接開啟目前帳本的帳本設定 |
| 中間 | 導覽：首頁、交易、帳戶、分類、標籤、專案、比較報表（視窗比較窄時，導覽會換到頂部列下方一排） |
| 右側 | 「搜尋」（開啟 ⌘K 命令面板）、日曆圖示、通知鈴、頭像 |

把滑鼠移到右上角**頭像**上（或用鍵盤移到頭像），會展開選單。選單依用途分成幾個可收合的分類，一次只展開一組，目前所在頁面的那一組會自動展開並標示：

| 分類 | 項目 |
|---|---|
| 記帳工具 | 週期性收支、分期付款、應收應付款項、待完成交易、交易範本 |
| 投資 | 投資、已實現損益 |
| 帳本與回顧 | 帳本、農場排行榜、年度報告 |
| 設定 | 信用卡繳費提醒、雲端帳號與同步、個人資料、智慧記帳、開發者 |

分類下方還有直接可用的：

| 分組 | 項目 |
|---|---|
| 資訊 | 關於 |
| 偏好 | 主題（跟隨系統、淺色、深色）、語言 |
| 操作 | 登出 |

選單最上面會顯示你的 email 與角色（「一般使用者」或「管理員」）。管理員另外會多出「管理」分類，那是維運用的，一般使用者看不到，這本手冊也不介紹。

![Web 頂部列與頭像選單](/img/sync/web-3.png)
*圖中：頂部列與展開的頭像選單，記帳工具、投資、帳本與回顧、設定四個分類可收合，下方是關於、主題與語言、登出*

**在手機瀏覽器上**使用網頁版時，畫面下方會改成五個分頁：首頁、交易、帳戶、分類、標籤，其他項目都在頭像選單裡。

:::note 個人資料頁
頭像選單 → 設定 → 個人資料，可以改頭像、暱稱、主題色、Liquid Glass 質感，以及收支與股票顏色、標題皮膚、餘額顯示格式、每週起始日、行事曆預設顯示、可愛類別圖示、顯示幣種等偏好，也可以看到「授權」與「二次驗證」。「行事曆預設顯示」會標示「此設定僅於 App 生效。」；Web 可以代為保存這個偏好，但 Web 日曆仍從月檢視開始。這些外觀選項見[外觀](../more/appearance.md)，兩步驟驗證見[裝置與安全](./devices.md)。
:::

:::note 4.0 的調整
- 4.0 起沒有獨立的預算頁（App 也拿掉了總預算），要控制花費請用專案裡的預算；舊的預算網址會直接帶到首頁。
- 原本在頭像選單裡的「裝置」與「健康」，現在放在「設定 → 雲端帳號與同步」裡，見[裝置與安全](./devices.md)。
- 原本的「AI 設定」改叫「智慧記帳」，仍在「設定」分類裡。
:::

#### 回饋與評價

頭像選單的「資訊」區新增「回饋與評價」，可給 1～5 星並描述問題。管理員在同一位置看到的是「使用者回饋」，能查看所有人的評分和內容，也會收到新回饋通知。每月自動提示與完整操作見[回饋與評價](../more/feedback.md)。

#### 浮動 AI 助手

登入後，畫面右下角會有 AI 助手的圖示（「開啟 AI 助手」）。點一下會展開像聊天軟體的小視窗，可以：

- 輸入「記一筆，或問問你的帳務…」，像聊天一樣記帳或查帳，例如「這個月花了多少錢？」，也可以點輸入框上方的快捷問題，按「換一組建議」換一批。
- 如果你說的是要記一筆帳，助手只會先整理成記帳草稿，按「確認記帳」檢查、必要時修改，儲存後才會真的寫入。
- 視窗可以放大、收起；「清除對話」只會清掉這個瀏覽器裡這個帳本的聊天紀錄，已儲存的交易不受影響。
- 「連續記憶」預設關閉，開啟後後續提問會把最近 8 則對話一起送給你設定的 AI 服務商。

使用前需要先設定 AI 文字服務商，否則會看到「先設定 AI 文字服務商，就能開始對話」；視窗裡的「AI 設定」可以直接前往，做法見[AI 記帳](../record/ai.md)。對話紀錄保留在這個瀏覽器，不會同步到 App；拍照、語音等仍在 App 操作。

![Web 右下角的浮動 AI 助手視窗，顯示問候語與快捷問題](/img/sync/web-5.png)
*圖中：展開的 AI 助手視窗，有問候語、輸入框與「試著問問」的快捷問題*

#### 農場排行榜

頭像選單 →「帳本與回顧」→「農場排行榜」，可以看每週的記帳榜、豐收榜、神偷榜、守護榜，以及歷史週次。排行榜只顯示農場暱稱、頭像與遊戲分數，不會有真實金額或電子郵件。Web 只提供排行榜，農場本身的玩法在 App，見[農場](../farm/overview.md)。

![Web 的農場排行榜頁，列出四個榜單與本週名次](/img/sync/web-6.png)
*圖中：農場排行榜頁，可切換記帳榜、豐收榜、神偷榜、守護榜與週次*

#### 彩色類別圖庫與選圖器

在 App 開啟「可愛類別圖示」（我的 → 設定 → 外觀）或在 Web 的「個人資料」開啟「可愛類別圖示」後，分類的圖示會換成彩色圖庫。Web 的「分類」頁新增或編輯分類時，點圖示會開啟選圖器：上方有搜尋框（可以輸入繁體中文或英文關鍵字，多個關鍵字用空格分開），下方是依圖標包分組的圖庫，點開一個圖標包再挑圖。

![Web 分類的圖示選圖器：搜尋框與彩色圖標包](/img/sync/web-7.png)
*圖中：分類圖示選圖器，上方是搜尋框，下方是可展開的彩色圖標包*

### ⌘K 命令面板

命令面板是用鍵盤操作網頁版最快的方法：不用找按鈕，打字就能搜尋、跳頁、執行動作。

**開啟方式**：

- Mac 按 `⌘ K`，Windows 或 Linux 按 `Ctrl K`。任何頁面都可以按。
- 或是點頂部列的「搜尋」。
- 按 `Esc` 關閉，`↑` `↓` 選擇，`Enter` 執行。

![⌘K 命令面板](/img/sync/web-4.png)
*圖中：命令面板輸入關鍵字後，第一項是「在交易中搜尋」，下方是符合的交易與快速操作*

**直接輸入文字**可以做這些事：

| 選項 | 做什麼 |
|---|---|
| 在交易中搜尋 | 跳到交易頁，用你輸入的關鍵字篩選 |
| 問 AI | 把你輸入的問題交給 AI，AI 會根據使用手冊的內容回答怎麼操作，需要先設定 AI 服務 |
| AI 記帳 | 把你輸入或貼上的一段文字，交給 AI 辨識成帳目，見[AI 記帳](../record/ai.md) |
| 交易、分類、帳戶、標籤 | 面板會即時列出符合關鍵字的項目，選一個就開啟 |

**不輸入文字時**，會列出「快捷操作」和「頁面導覽」：

| 分組 | 項目 |
|---|---|
| 快捷操作 | 新建交易、年度報告、匯出本月 CSV、匯出本年 CSV、匯入帳本資料、切換到淺色／深色主題、管理目前帳本成員、加入共享帳本、登出 |
| 切換帳本 | 列出你所有的帳本，選一個就切換 |
| 頁面導覽 | 首頁、交易、日曆、帳戶、分類、標籤、專案、比較報表、農場排行榜、帳本、個人資料 |

:::tip 貼上截圖記帳
開著命令面板時直接貼上（`⌘ V` 或 `Ctrl V`）一張帳單截圖，面板會出現「AI 記帳」選項，按 `Enter` 開始辨識。需要先設定 AI 服務，見[AI 記帳](../record/ai.md)。
:::

## 注意事項／小提醒

- Web 版沒有 App 鎖定，也沒有自動記帳與桌面小工具，這些是 App 才有的功能。
- 「比較報表」只有 Web 版有；「交易範本」App 與 Web 都有。
- 管理員專屬的功能不在這本手冊的範圍內。
