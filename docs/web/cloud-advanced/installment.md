# 分期付款

> ⚠️ **僅 Cloud 版可用**：本頁功能是 BeeCount Cloud（自建服務端）獨有的進階功能，純 App 本機記帳沒有這個入口。

買手機、家電這類大額消費用分期付款時，建一個分期計畫，系統會自動算好每一期要繳多少、哪天到期。

## 開啟入口

右上角**頭像** → 「工具」分組 → **分期付款**（`/app/installment-plans`）。

## 建立計畫

| 欄位 | 說明 |
|---|---|
| 總金額、期數 | 分期的總金額跟要分幾期 |
| 帳戶 | 通常選信用卡帳戶，也可以是一般帳戶 |
| 分類 | 分期一定要選分類 |
| 攤還方式 | 見下方說明 |
| 年利率 | 輸入框直接打整數百分比（例如 6 代表年利率 6%），不用自己換算成小數 |
| 計息方式 | 按月或按日計息 |
| 寬限期 | 前幾期只繳利息、不還本金 |

### 三種攤還方式

- **等額本金**：每期還的本金固定，利息隨剩餘本金遞減——所以總繳金額會越後面越少（見下圖，第 1 期 2,120、第 12 期只剩 2,010）。
- **等額本息**：每期總繳金額固定（銀行房貸最常見的算法），前期利息占比高、後期本金占比高。
- **固定利息**：每期本金固定，但利息是按「總金額」算，不會隨著已還本金減少——通常繳的利息總額會比等額本金高。

![分期付款期數明細](https://photo.pnsgzomf.synology.me/i/2026/08/11/6a79f9073233a.png)

取整後如果有零頭尾差，預設會塞進最後一期（也可以選塞第一期）。

## 中途調整

分期列表每筆計畫下方有幾個操作按鈕，對應不同情境：

| 操作 | 用途 |
|---|---|
| 部分還本 | 額外還一筆本金，之後未到期的期數會重新攤算 |
| 提前結清 | 一次結清剩餘本金 + 估算利息，未到期的期數直接刪除 |
| 調整利率 | 改變利率或攤還方式，未到期的期數重新計算 |
| 終止未來分期 | 不再產生後面未到期的期數（跟「提前結清」的差別是不會多出一筆結清交易） |
| 單期退款 | 針對某一期單獨做退款，該期標記為已退款 |

## 常見問題

**利率要填百分比還是小數？**
畫面上直接打整數百分比就好，例如年利率 6% 就打 `6`，系統會自動換算，不用自己心算成 `0.06`。

**信用卡分期跟信用卡本身的帳單試算會不會衝突？**
不會，分期付款是獨立算的，信用卡帳單試算（見[信用卡帳單試算與自動扣款](./credit-card-billing.md)）看的是帳戶上的一般消費 + 分期應繳兩者加總後的當期應繳總額。
