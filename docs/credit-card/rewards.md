「這張卡網購 3%、每月上限 300」「這個月限時活動指定通路 5%」——回饋規則一堆，月底到底拿了多少？在蜜蜂記帳為每張信用卡設好回饋規則，記帳時勾一下是哪條回饋，之後就能隨時看到這期預估拿多少、離上限還差多少，到期還能自動把回饋金記成一筆收入。

> 📱 App　💻 Web　　回饋金自動入帳需要 BeeCount Cloud 並登入

## 為什麼這樣設計

- 一筆消費通常只適用一種回饋方案，哪一條要套用，你比系統更清楚。所以由你在記帳時勾選，系統不會用分類去猜，避免同一筆錢被算進兩條規則。
- 門檻和上限這些「金額」的判斷交給系統算，你只需要把規則設好。
- 實際入帳由雲端排程計算，兩端用同一套算法，數字才對得上。手機和網頁上看到的預估是方便你記帳當下參考，實際入帳以雲端為準。

## 怎麼操作

### 📱 在 App 上：新增回饋規則

1. 「資產」點進信用卡，切到「帳戶資訊」分頁，點「紅利回饋」那一列（右邊會顯示「N組回饋條件」）。也可以在「交易明細」分頁的「紅利回饋 (N)」卡片，點右上角的清單圖示。
2. 進入「紅利回饋列表」，點右上角「＋」。
3. 填寫「活動名稱」，例如「網購 3%」。
4. 選「回饋方式」：「按照%數」或「每筆固定金額」，再填數值。
5. 在「回饋機制」設定計算區間與入帳時機（見下方說明）。
6. 需要的話設定「回饋啟動門檻」、「計算方式」、「回饋上限」。
7. 在「其他設定」選「回饋入帳帳戶」（預設是這張卡本身），並設定活動開始與結束日。
8. 儲存。

列表分成「進行中 (N)」與「已結束 (N)」，進行中的規則可以長按拖曳排序。每一列右側的「⋯」有「複製」與「刪除」。

### 💻 在 Web 上：新增回饋規則

1. 左側選單點「帳戶」，點開信用卡，找到「紅利回饋」區塊。
2. 按「+ 新增規則」。
3. 填「規則名稱」、「回饋方式」（百分比或固定金額）與數值。
4. 選「計算週期」、「回饋入帳時機」、門檻與上限。
5. 選「回饋帳戶」，按「儲存」。

規則列上有「編輯」、「複製」、「刪除」。已結束或停用的規則會收在「顯示已結束的活動(N)」裡。

![Web 新增回饋規則視窗](/img/credit-card/rewards-3.png)
*圖中：① 回饋方式與百分比　② 回饋入帳時機　③ 回饋金入帳的帳戶　④ 儲存*

### 規則欄位怎麼填

| 欄位 | 說明 |
|---|---|
| 回饋方式 | 百分比（例如 1.5%），或每筆固定金額 |
| 計算區間（Web：計算週期） | 「依照帳單區間」「依照自然月」「指定活動區間」三選一，見下方說明 |
| 回饋計算基準（僅 App） | 以「消費日期」或「入帳日期」決定算在哪一期 |
| 回饋入帳時機 | 「消費後立即入帳」「入帳日後結算」是逐筆入帳，可填天數，0 是當天、1 是隔天；「區間結束後」是整期結束一次結算；「僅手動入帳」是不自動入帳 |
| 期間累積消費門檻 | 這一期累積消費要達到多少才開始算回饋，預設無門檻 |
| 單筆消費門檻 | 單筆金額要達到多少才算，預設無門檻 |
| 計算方式 | 單筆、總額各自選「無條件捨去」「四捨五入」「無條件進位」「保留小數」。要和發卡行的算法一致才對得上 |
| 總額上限 | 這一期最多拿多少回饋，預設無上限 |
| 共同上限 | 多條規則填同一個代碼，會共用同一份上限額度（只在設了上限時才需要） |
| 回饋入帳帳戶 | 回饋金存進哪裡，選這張卡本身會直接抵扣帳單；選別的帳戶，則當成一般收入存進去 |
| 活動開始／結束 | 規則的有效期間，起訖日都算有效 |

:::note 逐筆入帳與累積門檻
「消費後立即入帳」、「入帳日後結算」是每筆各自入帳，等不到整期結束，所以「期間累積消費門檻」不適用。需要累積門檻的活動，請選「區間結束後」。
:::

### 指定活動區間（自訂期間）

限時活動不一定跟帳單日一致。「計算區間」選「指定活動區間」之後，「活動開始」與「活動結束」都必須填，整段活動（含起訖日）算作單一期，上限與門檻以整段活動累計，不隨帳單週期往前往後翻。活動結束後，規則會留在卡片上，直到你停用或刪除。

### 基本回饋與回饋金專案

在「其他設定」還有兩個選項：

- 「基本回饋」：每筆刷這張卡都適用的常態回饋可以打開。之後記帳時選這張卡，只要在活動日期內，就會自動勾選這條規則，不想要時仍可手動取消。複製規則時不會帶上這個開關，避免兩條同時被勾選而重複計算。
- 「回饋金專案」：預設回饋金會歸到原消費所屬的專案。想歸到別的專案就在這裡選；點右邊的清除鈕，改回「跟隨原消費專案」。只列出目前帳本中啟用的專案。

### 記帳時套用回饋

**📱 在 App 上**

![App 記帳頁選信用卡帳戶並輸入金額後，標籤列旁出現可勾選的回饋規則，下方顯示「預計可獲得回饋」](/img/credit-card/rewards-5.png)
*圖中：① 先選信用卡帳戶　② 可勾選的回饋規則　③ 預計可獲得的回饋*

1. 新增支出，帳戶選一張信用卡。
2. 在標籤和附件那一列，會多出一個回饋圖示，點開「選擇紅利回饋」。
3. 勾選這筆適用的規則，可以多選。畫面下方會顯示「預計可獲得回饋：NT$30」。
4. 如果這一期已經有其他交易用掉了額度，會顯示「網購 3% 已達上限，本筆僅能獲得 NT$12」之類的提示。

只有啟用中、而且目前在有效期間內的規則才會列出來。有開「基本回饋」的規則，選信用卡時會自動勾好，編輯已有的交易不會被自動改動。

**💻 在 Web 上**

新增交易時，選了信用卡帳戶之後，會出現「紅利回饋規則」一排小標籤，點選要套用的規則即可。基本回饋同樣會自動帶入。

用 AI 記帳記一筆信用卡支出時，系統也會幫你比對商家與已選過的回饋規則，剛好只對到一條才會自動套用，否則不套。詳見[AI 記帳](../record/ai.md)。

### 查看回饋明細

**📱 在 App 上**

![App 紅利回饋明細：期間累積回饋、剩餘額度提示，以及每筆消費的入帳日期標籤](/img/credit-card/rewards-6.png)
*圖中：① 這期累積的回饋　② 距離上限還剩多少額度　③ 每筆消費的回饋金額與入帳日*

1. 信用卡「交易明細」分頁，帳單彙總下方的「紅利回饋 (N)」卡片，每條規則一行，顯示名稱、回饋率、期間與這一期累積的回饋。
2. 點進去是「紅利回饋明細」，列出這一期套用此規則的每筆交易、各自的預估回饋，以及「將於 某日 入帳」或「已於 某日 入帳」。
3. 上限提示會告訴你「回饋無上限」「回饋上限 NT$300」「剩下 NT$2,000 的消費可達到最高回饋」或「已達最高回饋」。
4. 點交易資訊卡，也會看到「紅利回饋：」區塊。

從帳單彙總切到哪一期，點進明細就會停在同一期，在明細裡還是可以再用箭頭獨立翻頁。合併帳單的子卡，週期依主帳戶的結帳日。

**💻 在 Web 上**：在「紅利回饋」區塊點規則，會看到這一期符合條件的消費、本期回饋、還可再賺多少、還可以刷多少，以及入帳日期。

### 自動入帳、手動入帳與退款

- 自動入帳：登入 BeeCount Cloud 後，雲端會依「回饋入帳時機」到期自動新增一筆收入，分類是「回饋金」，記在你選的回饋帳戶。逐筆入帳的回饋金，在交易資訊卡上可以點進去查看原始消費。
- 手動入帳（Web）：在規則的明細裡按「手動入帳」，指定入帳金額與帳戶，記一筆回饋收入。適合銀行實際入帳金額和系統算的有零頭落差時使用。
- 退款：對有套回饋的消費做退款，回饋會跟著減少。全額退款，回饋歸零；部分退款，依淨額重新計算。已經入帳的回饋金，雲端會自動補一筆「退款沖銷回饋金」。
- 事後才補勾回饋規則的交易，整期結算後會補發差額，備註會註明「補發」。

## 注意事項／小提醒

:::warning 預估值不等於入帳金額
手機與網頁上的回饋金額是估算，沒有把「期間累積消費門檻」、「共同上限」這類要靠雲端整期資料判斷的條件算進去。實際入帳以 BeeCount Cloud 為準。
:::

:::note 規則用過之後會鎖定
規則一旦有交易引用或入帳紀錄，回饋方式、比例、區間、門檻、上限、入帳時機這些計算相關欄位就不能再改，只能改名稱、備註、啟用狀態與活動日期。要變更算法，請新增一條新規則，舊的停用。
:::

![App 編輯已有交易的回饋規則：頂端橘色提示說明計算欄位已鎖定，只能改名稱、備註、啟用狀態與活動日期](/img/credit-card/rewards-locked.png)
*圖中：① 已有消費紀錄的規則，計算欄位會鎖定　② 只能改名稱、備註　③ 灰色欄位無法修改*

- 已被交易使用過的規則無法真的刪除，刪除時會改成停用，移到「已結束」。沒被使用過才會真的刪掉。
- 上限是整個週期共用的額度：同一期內所有套用這條規則的交易依時間先後消耗額度，用完之後的交易回饋為 0。交易資訊卡上若被別筆吃掉額度，會多一個「已達上限」標籤。
- 規則以自然月計算、但帳單週期橫跨兩個月時，明細會分月顯示、各自計算上限。
- 週期性交易換信用卡後，只會顯示屬於新那張卡的規則。
- 回饋規則不會依分類自動比對交易，記帳時要自己勾選（或靠基本回饋自動勾）。
- 回饋入帳要用 BeeCount Cloud，沒登入或用其他同步方式時，只有預估，不會自動入帳。
- 紅利回饋明細頁的標題仍固定備註優先，不受「備註顯示方式」影響。
