這裡整理每個版本使用者看得到的重點，由新到舊排列。App 內「我的」→「新功能！」可以選版本回頭看，內容與這裡一致。

## 3.8.3

- **使用說明換成新的說明書**：我的 → 使用說明 改成開啟新的蜜蜂記帳說明書網站，各項功能都有一步一步的操作說明。
- **分類顏色可自訂、可一鍵平均分配**：編輯分類時可以用自訂調色盤挑任何顏色；也可以點一下調色盤圖示，把所有分類的顏色平均分配在整個色盤上。入口：我的 → 資料管理 → 分類管理（右上角調色盤圖示）；自訂顏色在編輯分類的顏色列最後面。
- **簡潔顯示改用繁體「萬」**：餘額顯示格式選「簡潔顯示」時，繁體中文介面的大金額單位原本會出現簡體的「万」，現在改成「萬」（例如 12.3萬）。入口：我的 → 外觀 → 餘額顯示格式 → 簡潔顯示。
- **股票定期定額改用成交日開盤價，並避開休市日**：股票定期定額現在以「成交日當天的開盤價」成交，開盤前會等待，不再拿前一天的價格去買。遇到週末或休市日：每月、每年、每 N 週的規則順延到下一個交易日，每日與每週指定星期幾的規則略過該天。休市日表跟節日資料一起自動更新，不用等 App 改版。入口：資產 → 投資理財帳戶 → 定期定額（下次執行日會顯示實際成交日）。
- **Cloud 通知在 App 沒開時也能跳出來**：BeeCount Cloud 的通知（信用卡帳單、繳款日、提醒等）現在會在背景定期拉取，即使沒有開著 App 也會跳出系統通知。喚醒時機由系統決定，可能延遲數分鐘到數小時，而且從多工畫面把 App 滑掉後就不會再喚醒。入口：不用設定，登入 BeeCount Cloud 後自動生效；通知列表在首頁右上角的鈴鐺。
- **信用卡通知不開 App 也會準時跳**：登入 BeeCount Cloud 時，信用卡提醒（帳單已結算、到期前 7 天、今天到期、已逾期）現在會直接排程在手機上，不用開著 App 也會準時跳出來。時機與文案跟你原本在通知列表看到的 Cloud 通知一致，提醒時間沿用 我的 → 自動化 → 信用卡繳費提醒 裡設定的時間。金額是你上次使用 App 時的快照，每次開啟或離開 App 時會更新。入口：不用設定，登入 BeeCount Cloud 後自動生效。
- **通知可以看完整內容**：點通知現在會彈出詳情面板，顯示完整標題、全文與確切時間，太長的公告不會再被截斷。如果通知有對應的項目（信用卡、欠款等），面板上有「前往查看」按鈕可以直接跳過去。入口：首頁右上角鈴鐺 → 點任一則通知。

## 3.8.2

- **投資理財帳戶：持股功能可以自己選**：新增或編輯投資理財帳戶時多了「持股功能」開關。關閉就是原始的投資理財帳戶（一般轉帳、可調整餘額）；開啟則有「持股」分頁，轉帳（包含帳戶內下方的新增交易）會直接開買賣表單。入口：帳戶 → 新增或編輯投資理財帳戶。
- **股利再投入改成各檔設定**：「再投入」開關從帳戶的費用設定移到每一檔股票的頁面，每檔可以各自決定要再投入或領現金。入口：帳戶 → 持股 → 點一檔股票。
- **外幣帳戶顯示幣別，一鍵換算主幣種**：外幣帳戶現在會在金額前面標示幣別，並有 ⇌ 按鈕可以切換成換算後的主幣種金額。換算後預設無條件捨去到整數（台幣）；可以在 帳戶 → 設定 → 換算金額取整 依帳本調整，並跟著雲端帳號同步。

## 3.8.1

- **資產頁走勢圖更精簡**：淨值趨勢圖變扁，左側標示收入／支出長條金額、右側標示淨資產金額。點圖下方的日期會直接跳到「明細」當天的交易。見[資產總覽與淨值](./prepare/account-overview.md)。
- **全新的年度回顧**：年度帳單改成全螢幕、一章一個重點的限動式回顧，最後揭曉年度稱號；分享長圖也換成同一套風格。新的一年開始時，首頁會出現去年的回顧卡片。見[年度回顧](./analysis/annual.md)。
- **報表與順序跟著帳號同步**：新增、編輯、刪除報表與拖曳調整的順序，換手機或登入其他裝置都會一致。見[統計報表](./analysis/statistics.md)。
- **拆帳每筆明細有自己的備註**：備註欄跟著選中的那一筆，圖示下方優先顯示備註。見[拆帳與退款](./record/split-refund.md)。
- **「新功能！」可選版本**：可以回頭看每個版本新增了什麼。見[功能說明與新功能紀錄](./preface/tour.md)。

## 3.8.0

**AI**

- **AI 對話全新介面與連續記憶**：可自行開啟「連續記憶」讓 AI 接續最近的對話，預設關閉。見[AI 聊天與查帳](./record/ai-chat.md)。
- **AI 助手變成浮動氣泡**：每個頁面都看得到，可拖動、自動吸附邊緣，拖到底部的 ✕ 可隱藏。見[快速入口與桌面小工具](./record/quick.md)。
- **AI 標籤指定**：AI 記帳處理標籤的方式可選「不加」「詢問我」「只從現有標籤挑」或「必要時新增」，設定隨帳號同步。見[AI 記帳](./record/ai.md)。
- **AI 辨識有動畫與進度提示**，**AI 同意視窗只在「關閉→開啟」時出現**。見[AI 記帳](./record/ai.md)。
- **AI 推薦該刷哪張信用卡**：用口語問「YouTube 訂閱刷哪張卡？」，再說「幫我記 199」就能直接記帳。見[刷卡建議與一鍵記帳](./credit-card/swipesmart.md)。

**日曆與外觀**

- **日曆加入節日**：明細日曆標出你選的國家的節日，點選會出現應景台詞；開啟 AI 後月底會為下個月寫台詞。
- **節日主題**：春節、中秋、萬聖節、聖誕節等節日當天自動換上應景主題色與頁首，隔天換回，Web 也會跟著換色。以上見[外觀](./more/appearance.md)。
- **新增交易的「建議」分頁加入收入，並可關閉**。見[外觀](./more/appearance.md)。

**記帳與列表**

- **週期帳單狀態篩選**（近期／進行中／已結束／全部），見[週期性收支](./record/recurring.md)。
- **借還款篩選**（近期／未還款／已還款／全部）與**欠款對象歷史建議**。見[借還款](./record/debt.md)。
- **拆帳改用原本的分類格**，同一個分類可用在多筆明細。見[拆帳與退款](./record/split-refund.md)。
- **轉帳手續費顯示修正**：轉出端顯示實際扣款金額（金額加手續費）。見[轉帳](./record/transfer.md)。

**信用卡**

- **紅利回饋可指定活動區間、設為基本回饋，並指定回饋金歸屬的專案**。見[紅利回饋](./credit-card/rewards.md)。
- **手動轉帳算收入、不算繳款**；**繳款分攤不再出現小數，群組內溢繳會自動抵給仍短少的卡**，繳款記錄依帳單期間歸屬。見[信用卡繳款](./credit-card/payment.md)。

**其他**

- **年度報告加入股票頁與年度稱號**。見[年度回顧](./analysis/annual.md)。
- **每個頁面都有功能導覽**：第一次進到頁面會用聚光燈逐步說明，隨時可到「我的」→「功能說明」重看。見[功能說明與新功能紀錄](./preface/tour.md)。
- **雲端圖片下載模式**：可選即時下載，或檢視記錄時才下載，照片很多時能省空間。見[雲同步與離線](./sync/overview.md)。
- **換帳號登入不再混到舊資料**：用與上次不同的帳號登入時，會先清掉前一個帳號留在本機的資料，未同步的修改會被捨棄。見[安裝與登入](./preface/install-login.md)。
- **帳戶頭像被「資料清理」誤刪的問題已修正**，消失的頭像會在下次同步時自動補回。見[資料清理](./more/cleanup.md)。

## 3.7.0

- **股票持股**：在投資理財帳戶記錄買賣，自動追蹤股數、平均成本與市值；台股、美股的報價收盤後自動更新。見[股票持股](./invest/overview.md)。
- **股利入帳**：除息日後依持股算出股利，請你確認現金入帳或再投入。見[股利與已實現損益](./invest/dividend.md)。
- **股票定期定額**：到期時依報價自動買進，台股只買整數股，美股可買碎股。見[定期定額](./invest/dca.md)。
- **一次輸入目前持股**：照券商庫存頁輸入股數與成本，也可從試算表貼上。見[股票持股](./invest/overview.md)。
- **投資帳戶滑動買賣**：帳戶列表右滑買進、左滑賣出，動作可自訂。見[外觀](./more/appearance.md)。
- **股票漲跌顏色可單獨設定**（預設紅漲綠跌），並與 Web 同步。見[外觀](./more/appearance.md)。
- **零股手續費與券商一致**，並修正報價有時停在前一個交易日的問題。見[股票持股](./invest/overview.md)。
- **週期交易「修改連同未來週期」改動全欄位同步**，與 Web 一致。見[週期性收支](./record/recurring.md)。
- **通知設定跟著帳號走**：記帳提醒與信用卡提醒換裝置會自動套用。見[通知與提醒](./more/notifications.md)。

## 3.6.1（含 3.6.0）

- **Android 可在 App 內更新**：有新版本時跳出「發現新版本」，按「立即更新」自動下載安裝；也可到「我的」→「關於」→「檢查更新」。見[通知與提醒](./more/notifications.md)。
- **新增授權金鑰**：使用 App 需登入並輸入授權金鑰，連網確認後可離線使用 7 天。見[授權金鑰](./sync/license.md)。
- **「報表」分頁改版為統計報表**：可儲存多份報表，內建每週、每月、每年，也能自行新增。見[統計報表](./analysis/statistics.md)。
- **退款自動沖銷**：退款直接扣回原交易的分類，報表與年度報告的數字與網頁版一致。見[拆帳與退款](./record/split-refund.md)。
- **iOS 分享選單直接圖片記帳**：從「照片」分享圖片選「蜜蜂記帳」即可。見[自動記帳](./record/auto.md)。
- **主帳戶群組與帳戶明細頁改進**：群組可關閉「信用卡合併帳單」當一般群組使用；子帳戶明細頁可切換同群組的其他帳戶。見[帳戶](./prepare/account.md)。
- **AI 助手可依帳戶查詢消費**，例如「這個月用○○卡花了多少」。見[AI 聊天與查帳](./record/ai-chat.md)。
- **雲端同步資料保護**：修正幾個可能讓雲端分類、帳戶資料被舊資料蓋掉的同步問題。見[雲同步與離線](./sync/overview.md)。
- 其他：底部導覽新動畫、修正 iOS 左緣右滑返回與新裝置首次同步失敗、全新安裝預設幣種改為新台幣。

## 3.5.7

- **資產頁互動走勢圖**：長條（收入／支出）加折線（淨資產），可切日／週／月／年，點按或拖曳看某天數字。見[資產總覽與淨值](./prepare/account-overview.md)。
- **AI 記帳新增「商家」欄位**，並自動套用你設好的信用卡回饋規則。見[AI 記帳](./record/ai.md)。
- **AI 對話更聰明**：能分辨「提問」與「記帳」，用備註、商家或分類名稱查全部期間的加總。見[AI 聊天與查帳](./record/ai-chat.md)。
- **信用卡帳單顯示更清爽，紅利回饋計算更精準**，見[帳單週期與提醒](./credit-card/billing.md)。
- **轉帳看得出「轉出→轉入」帳戶**，跨幣別金額改用實際入帳金額。見[轉帳](./record/transfer.md)。
- **專案功能修正**：退款分類金額、新裝置首次同步後專案列表、AI 專案指定跨裝置同步。見[專案](./prepare/project.md)。
- 修正部分 iOS 26/27 裝置無法開啟 App 的問題。

## 3.4.0

- **「可愛類別圖示」主題**：分類圖示換成手繪風，用底線顏色標示分類色。見[外觀](./more/appearance.md)。
- **報表改版**：圓餅圖與分類排行榜一起顯示，趨勢折線圖移到下方並預設收合。見[統計報表](./analysis/statistics.md)。
- **帳戶可單獨隱藏金額**：帳戶頁每一列有眼睛圖示。見[帳戶](./prepare/account.md)。
- **信用卡通知會跳出系統通知橫幅**（App 執行中）。見[通知與提醒](./more/notifications.md)。
- **建立或編輯交易可任意選擇幣別**；AI 記帳配對不到同幣別帳戶時，會列出所有幣別帳戶並依匯率換算。見[多幣種與匯率](./prepare/currency.md)。

## 3.3.0

- **AI 記帳可以指定專案**：在「智慧記帳」設定選「AI 自行判斷」或「詢問我」。見[AI 記帳](./record/ai.md)。
- **可自訂每週起始日**：日曆與週統計依設定從週一或週日算起。見[外觀](./more/appearance.md)。
- **AI 圖片記帳支援從剪貼簿貼上**。見[AI 記帳](./record/ai.md)。
- **刷卡建議新增排除項提示**：消費屬於回饋排除項目時會提醒你。見[刷卡建議與一鍵記帳](./credit-card/swipesmart.md)。
- **交易列表顯示專案，標籤太多會自動換行**。見[日曆與明細](./analysis/calendar.md)。
