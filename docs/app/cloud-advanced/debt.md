# 借還款

> ⚠️ **僅 Cloud 版可用**：本頁功能是 BeeCount Cloud（自建服務端）獨有的進階功能，純 App 本機記帳沒有這個入口。

借給朋友的錢、跟人借的錢，用這個功能追蹤，不用另外開 Excel 記。

## 開啟入口

右上角**頭像** → 「工具」分組 → **借還款**（`/app/debts`）。

## 建立一筆欠款

| 欄位 | 說明 |
|---|---|
| 方向 | 「別人欠我」（借出）或「我欠別人」（借入） |
| 對方名稱 | 必填 |
| 本金 | 必填 |
| 到期日 | 選填 |

方向跟本金建立後不能再改（如果打錯了要刪掉重建）。

![借還款列表](https://photo.pnsgzomf.synology.me/i/2026/08/11/6a79f9066c52b.png)

## 記錄還款 / 收款

點「記一筆收款」（或「記一筆還款」），系統會建一筆跟這筆欠款關聯的交易。可以分好幾次部分還款，**剩餘金額是即時用所有關聯交易加總反算出來的**，不是存一個固定數字，所以還多還少都會立刻反映在列表上。

## 結案

還清了、或者對方賴帳不追了，可以點「結案」，欠款會標記為已結案（不會再出現在待辦提醒），需要的話也可以「重新開啟」。

刪除一筆欠款前，要先確定沒有任何還款交易還關聯著它。

## 常見問題

**還款會不會影響帳戶餘額？**
會，還款本身就是一筆真實的交易（有金額、有帳戶），會正常反映在帳戶餘額跟收支統計裡；欠款本身只是拿來追蹤「這筆錢的來龍去脈」，不會另外重複計入收支。
