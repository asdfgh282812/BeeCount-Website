在電腦前整理帳目、匯入一大批資料、看大張的報表，用網頁版會比手機順手。Web 版和手機 App 共用同一個帳號和同一份資料，兩邊的修改幾秒內就會互相同步，不用另外安裝。

> 💻 Web

## 為什麼這樣設計

手機適合隨手記一筆，電腦適合「坐下來好好整理」。所以網頁版保留了大部分功能，又多了幾個在大螢幕上才好用的東西：批次處理交易、交易範本、比較報表，以及鍵盤驅動的 ⌘K 命令面板。

## 怎麼操作

### 登入

1. 用瀏覽器開啟你的 BeeCount Cloud 網址（和 App 輸入的伺服器位址相同，向管理員確認）。
2. 按「使用 SSO 登入」，在跳轉的頁面完成登入，完成後會自動回到蜜蜂記帳。
3. 如果登入後出現「需要授權金鑰」，輸入金鑰並按「啟用」，見[授權金鑰](./license.md)。管理員帳號不會看到這一頁。
4. 進到首頁後，如果還沒有任何帳本，頂部會有「新建帳本」按鈕。

:::note
登入用的是 SSO，這個版本不開放自己註冊。如果登入失敗出現「SSO 登入發生錯誤」，請稍後重試，持續出現請洽管理員。
:::

### 安裝成 PWA（可選）

Web 版可以「安裝」成像 App 一樣的獨立視窗，有自己的圖示，不顯示瀏覽器網址列。

1. 使用 Chrome 或 Edge 等支援的瀏覽器，多開幾次網頁版（在 7 天內進入 3 次以上）。
2. 畫面右下角會出現「把蜜蜂記帳加入桌面?」的提示，按「加入」。
3. 完成後會顯示「已安裝，可在 dock / 主畫面找到『蜜蜂記帳』」。

如果你按了提示上的「不再提示」，這個提示就不會再出現。想手動安裝，可以用瀏覽器網址列右邊的「安裝」圖示或瀏覽器選單裡的「安裝應用程式」。

有新版本時，畫面上方會出現「偵測到新版本」，按「立即更新」即可。

![PWA 安裝提示](/img/sync/web-2.png)

:::tip iPhone 或 iPad 怎麼加到主畫面
Safari 不會跳出上面的提示，請按「分享」按鈕，選「加入主畫面」。
:::

### 介面導覽

**頂部列**由左到右是：

| 位置 | 內容 |
|---|---|
| 左側 | 蜜蜂記帳標誌（點一下回首頁）、目前的版本號、帳本選擇器（切換帳本，共享帳本會標 🤝 與人數） |
| 中間 | 導覽：首頁、交易、帳戶、分類、標籤、專案、比較報表 |
| 右側 | 「搜尋」（開啟 ⌘K 命令面板）、日曆圖示、通知鈴、頭像 |

把滑鼠移到右上角**頭像**上會展開選單：

| 分組 | 項目 |
|---|---|
| 工具 | 預算、週期性收支、分期付款、借還款、投資、已實現損益、交易範本、帳本、年度報告 |
| 設定 | 個人資料、AI 設定、健康、裝置、開發者 |
| 資訊 | 關於 |
| 偏好 | 主題（跟隨系統、淺色、深色）、語言 |
| 操作 | 登出 |

選單最上面會顯示你的 email 與角色（「一般使用者」或「管理員」）。管理員另外會多出管理分組，那是維運用的，一般使用者看不到，這本手冊也不介紹。

![Web 頂部列與頭像選單](/img/sync/web-3.png)

**在手機瀏覽器上**使用網頁版時，畫面下方會改成五個分頁：首頁、交易、帳戶、分類、標籤，其他項目都在頭像選單裡。

:::note 個人資料頁
頭像選單 → 個人資料，可以改頭像、顯示名稱、主題與收支顏色、標題皮膚、金額顯示方式、主幣種，也可以看到「授權」與「二次驗證」。這些外觀選項見[外觀](../more/appearance.md)，兩步驟驗證見[裝置與安全](./devices.md)。
:::

### ⌘K 命令面板

命令面板是用鍵盤操作網頁版最快的方法：不用找按鈕，打字就能搜尋、跳頁、執行動作。

**開啟方式**：

- Mac 按 `⌘ K`，Windows 或 Linux 按 `Ctrl K`。任何頁面都可以按。
- 或是點頂部列的「搜尋」。
- 按 `Esc` 關閉，`↑` `↓` 選擇，`Enter` 執行。

![⌘K 命令面板](/img/sync/web-4.png)

**直接輸入文字**可以做這些事：

| 選項 | 做什麼 |
|---|---|
| 在交易中搜尋 | 跳到交易頁，用你輸入的關鍵字篩選 |
| AI 記帳 | 把你輸入或貼上的一段文字，交給 AI 辨識成帳目，見[AI 記帳](../record/ai.md) |
| 交易、分類、帳戶、標籤 | 面板會即時列出符合關鍵字的項目，選一個就開啟 |

**不輸入文字時**，會列出「快捷操作」和「頁面導覽」：

| 分組 | 項目 |
|---|---|
| 快捷操作 | 新建交易、年度報告、匯出本月 CSV、匯出本年 CSV、匯入帳本資料、切換到淺色／深色主題、管理目前帳本成員、加入共享帳本、登出 |
| 切換帳本 | 列出你所有的帳本，選一個就切換 |
| 頁面導覽 | 首頁、交易、日曆、帳戶、分類、標籤、專案、比較報表、預算、帳本、個人資料 |

:::tip 貼上截圖記帳
開著命令面板時直接貼上（`⌘ V` 或 `Ctrl V`）一張帳單截圖，面板會出現「AI 記帳」選項，按 `Enter` 開始辨識。需要先設定 AI 服務，見[AI 記帳](../record/ai.md)。
:::

## 注意事項／小提醒

- Web 版沒有 App 鎖，也沒有自動記帳與桌面小工具，這些是 App 才有的功能。
- 「交易範本」「比較報表」只有 Web 版有。
- 管理員專屬的功能不在這本手冊的範圍內。
