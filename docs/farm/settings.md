農場的設定不多，都集中在同一頁：選城市、選計分帳本、調音樂、決定要收哪些通知，不想玩的話也可以在這裡整個關掉。這一頁把每個選項講清楚，最後附上常見問題和一些小技巧。

> 📱 App

## 為什麼這樣設計

- **農場是輔助，不該打擾你。** 所以它可以整個關閉；通知可以按種類開關，會讓人覺得吵的提醒（作物可以收成）預設是關的。
- **你的隱私你決定。** 暱稱、匿名都能自己選，排行榜上不會出現真實金額或信箱。

## 怎麼操作

### 📱 進入農場設定

有兩個入口，進去的是同一頁：

- 在農場畫面右上角點**設定**（滑桿圖示）。
- 「我的 → 一般 → 農場設定」。就算首頁的農場小卡被你隱藏了，也可以從這裡找回來。

### 📱 設定項目一覽

| 項目 | 做什麼 | 單機也有？ |
|---|---|---|
| 單機農場 / 雲端農場 | 顯示你現在用哪一種存檔；雲端時點它可以重新整理同步 | ✅ |
| 農場暱稱 | 拜訪、互動紀錄與排行榜都用這個名字，有字數限制 | 雲端 |
| 排行榜匿名 | 公開排行榜上隱藏暱稱與大頭貼，顯示成匿名農友 | 雲端 |
| 農場通知 | 決定哪些農場事件出現在通知中心 | 雲端 |
| 排行榜裝飾獎勵 | 榜首獲得的免費樹木額度，有的時候才會出現，點進去可去佈置農場 | 雲端 |
| 良心值、新手保護、小偷標記 | 只是讓你看目前的狀態，點開有說明 | 雲端 |
| 看門狗 | 花好幣購買保護整座農場的看門狗 | 雲端 |
| 農場社交 | 進入社交頁 | 雲端 |
| 啟用農場 | 整個開關農場 | ✅ |
| 背景音樂、音量 | 農場配樂的開關與音量 | ✅ |
| 點按音效 | 點作物、建築、擺設、物品卡的輕巧木質聲，可單獨開關 | ✅ |
| 天氣城市 | 農場的天氣與日夜跟著這個城市 | ✅ |
| 計分帳本 | 週結算依這本帳本的記帳情況計分 | ✅ |

單機農場的設定頁最上面的那一列會寫「農場儲存在這台裝置，包含於快照備份；登入**帳好嗎 Cloud** 後使用帳號的雲端農場。」，單機農場沒有的項目就不會顯示。

只想短時間保護某一格作物時，請回到農場，點有活作物的田地 →「**佈置小看門狗**」。它的入口在田地氣泡，不在設定頁；只保護當期作物，拜訪者看不到。完整操作與兩種狗的差異見[小看門狗：只守一格田](./social.md#little-guard-dog)。

### 📱 農場名稱怎麼改？修改農場暱稱 {#farm-rename}

想幫農場改名，或修改農友拜訪、互動紀錄與排行榜上顯示的名字，請找設定中的**「農場暱稱」**。農場名稱／農場改名在這裡操作，不是在「佈置農場」裡改建築名稱。

1. 在 App 首頁點農場小卡，進入自己的農場。
2. 點農場畫面右上角的**設定**（滑桿圖示）。
3. 點**農場暱稱**，輸入新的名字。
4. 按**確認**，連線儲存成功後就會使用新的農場暱稱。

也可以從「我的 → 一般 → 農場設定 → 農場暱稱」進入，或在「農場社交」頁右上角點名牌圖示修改，這幾個入口改的是同一個暱稱。

- 名字可用 **1～20 個字**，不能全是空白，也不能包含換行或控制字元；不需要和其他農友不同。
- 第一次建立雲端農場時會要你取一個暱稱；之前沒取過的人，下次連線進入農場時會提示補填。
- **這是雲端農場的設定，需要登入帳好嗎 Cloud 並保持連線。** 單機農場不會顯示「農場暱稱」；Web 目前只有排行榜，想改名請到 App 操作。
- 「佈置農場」裡選取建築後的**店鋪名稱**，只會更改那一棟建築的名字，不會修改農場暱稱。

### 📱 排行榜匿名

開啟「排行榜匿名」之後，公開榜單上只會顯示成「匿名農友」，隱藏暱稱與大頭貼。已經改好農場暱稱卻仍在榜上看到「匿名農友」時，請先檢查這個開關。

### 📱 農場通知（雲端農場）

「農場 → 設定 → 農場通知」可以按種類決定要不要收：

| 通知 | 什麼時候來 | 預設 |
|---|---|---|
| 每週結算 | 週結算完成可以領取；計分帳本被共享或刪除時，也會提醒你重新選 | 開 |
| 排行榜獎勵 | 每週排行榜公布 | 開 |
| 作物被偷 | 顯示被偷的植物名稱與數量；兩小時內多次被偷會合併成一則，同種植物的數量加總 | 開 |
| 看門狗抓到偷菜 | 你的看門狗抓到小偷 | 開 |
| 作物可收成 | 有作物成熟 | **關** |
| 季節更換 | 換季前的提醒（有作物在田裡才會提醒）與換季當下 | 開 |

收到的農場通知會集中在「待處理中心」的「**農場**」分頁（首頁頂部的鈴鐺，或「我的 → 待處理中心」進去），不會混進「系統」分頁。點通知的「前往查看」可以直接跳到農場、週結算、排行榜或社交頁。**手機 App 的 Cloud 通知靠定期讀取，不能保證即時跳出**；背景更新、手動關閉 App 或省電限制都可能影響接收。若只看到待處理中心有紀錄，可以另外在手機或電腦啟用[瀏覽器背景通知](../more/notifications.md#browser-push)，再用「傳送測試通知」確認裝置是否顯示；完整限制見[App 沒跳通知時](../more/notifications.md#app-no-banner)。

![農場通知的選單：每週結算、排行榜獎勵、作物被偷等各種通知可以個別開關](/img/farm/settings-4.png)
*圖中：農場通知的開關，作物可收成預設是關的*

#### 查看被偷了什麼 {#stolen-crops}

被偷通知會直接寫出植物名稱與數量，例如「**蘿蔔 × 5 被偷走了**」。兩小時內又被偷時，會在同一則通知列出各種植物，同種植物的數量會加總，不會只留下最後一次的損失。

1. 在首頁點鈴鐺，進入「待處理中心」，切到「**農場**」。
2. 點「**農場有人來偷菜**」閱讀完整內容；植物種類較多時，列表可能顯示不完。
3. 想回禮，點「**前往查看**」進入農場社交，再找最近互動的「回禮」按鈕。是否能回禮仍依期限與當下狀態判定，見[社交：回禮](./social.md#return-gift)。

![待處理中心的農場分頁，被偷通知列出蘿蔔五個與南瓜三個](/img/farm/settings-5.png)
*圖中：多次被偷合併成一則通知，植物名稱與數量會一起列出*

![App 被偷通知詳情，顯示完整損失、休耕與回禮提醒，以及前往查看按鈕](/img/farm/stolen-app-detail.png)
*圖中：點通知後閱讀全文，再按「前往查看」進入農場社交*

Web 頁首鈴鐺也會顯示相同的植物名稱與數量；點選通知可以閱讀全文，但 Web 沒有農場拜訪或回禮畫面。見[通知與提醒](../more/notifications.md#stolen-crops-web)。

單機農場沒有通知，請自己打開農場看，特別是換季前記得留意。

### 📱 音樂與音效

- **背景音樂**：依天氣和日夜換曲，進農場自動播放，逛商店、倉庫、設定時也持續播放；離開農場就停止，App 進到背景會暫停，回來接續。預設開啟，可以用滑桿調音量，也可以整個關掉。
- **點按音效**：獨立於背景音樂，可以單獨關閉。
- iOS 上音樂會尊重手機的靜音開關。
- 音樂不受「減少動畫」影響；想要安靜，請用上面的開關。「減少動畫」影響的是畫面上的雨雪風動畫、飄出的表情與開寶箱動畫，見[季節、天氣與日夜](./season-weather.md)。

### 📱 關閉農場

不想玩了，可以在「農場設定」把**啟用農場**關掉（會先跳出確認）：

- 首頁的農場小卡會消失，週結算停止，也不會再發農場通知。
- **存檔會保留**，田地、庫存與好幣都還在；作物仍然依真實時間生長（所以沒收的作物可能枯萎）。
- 雲端農場關閉後，你不會再出現在農友列表，也不會被偷。
- 想再玩，到「我的 → 一般 → 農場設定」重新開啟就好。

![關閉農場前的確認對話框](/img/farm/settings-6.png)
*圖中：關閉農場時的確認，說明存檔會保留、可以從我的 → 一般 → 農場設定重新開啟*

## 注意事項／小提醒

### 常見問題

**首頁看不到農場小卡？**
可能是農場被關閉了。到「我的 → 一般 → 農場設定」重新打開。

**為什麼沒領到週獎勵？**
週結算要自己**點進去領取**，好幣才會入帳。另外也要確認：那週有記帳、計分帳本是非共享帳本、農場在那週有開著。

**好幣不見了、不知道花去哪裡？**
點農場上方的「好幣」膠囊進「週結算」，再點「交易紀錄」，可以看近 7 天每一筆好幣收入與支出，見[好幣交易紀錄](./bookkeeping.md#wallet-history)。市場貨款要點攤位領取後才會列入。

**大頭菜為什麼不能放到市場賣？**
大頭菜只能在大頭菜頁（週一到週六）或到農友農場賣，不能上架市場攤位，見[賣出、倉庫與大頭菜](./market.md#turnips)。

**水壺用完了怎麼辦？**
到「商店 → 道具 → 買水」，每 5 好幣補充 1 次，付款後立即可用，次數不會累積到隔天。也可以等隔天補滿，當天有記帳還能多補一些；下雨時作物會自動澆水，不用水壺。

**我的菜怎麼枯掉了？**
常見原因是：換季時還在田裡、一直缺水沒澆、成熟後放著不收超過換季。見[田地玩法](./gameplay.md)與[季節、天氣與日夜](./season-weather.md)。

**為什麼收成失敗？**
倉庫和板條箱都滿了。先賣掉一些、擴充倉庫，或多擺幾個板條箱，見[賣出、倉庫與大頭菜](./market.md)。

**為什麼偷不了菜？**
主人還在農場遊戲裡、有新手保護、這座農場剛偷過在冷卻、今天或這週的次數用完、你的良心值太低，或你的倉庫放不下，都會偷不了，見[社交](./social.md)。

**找不到社交的按鈕？**
社交只有雲端農場才有。沒登入**帳好嗎 Cloud** 的單機農場，畫面上不會出現。

**換手機之後農場還在嗎？**
雲端農場：登入同一個帳號就會自動載入。單機農場：農場資料包含在快照備份裡，從備份還原才會回來，細節見[其他備份方式](../sync/other-backup.md)。

**離線能玩嗎？**
單機農場可以。雲端農場離線時只能看最後同步的畫面，操作要連線。

**手機時間改過，農場不能操作？**
單機農場偵測到手機時間往回調，會暫停操作；等時間恢復正常就好。

**好幣可以換成真錢嗎？**
不行，好幣只存在遊戲裡，跟你的真實帳戶完全無關。

### 小技巧

:::tip
- 記完帳順手進農場，今天的水壺是補得最足的時候。
- 看一眼天氣再決定要不要澆水，下雨天可以省下水壺。
- 換季前幾天，先把能收的收完。
- 道具存著待用很方便，但快到壞天氣之前才用才划算，效果有時間限制。
- 收成前先看倉庫還有沒有空位。
- 好幣不夠買想要的東西，先去賣作物、領週結算，別急著買大頭菜。
:::
