帳戶和分類都準備好之後，最後一步是替自己訂下上限：這個月最多花多少。設定預算後，每次記帳，專案卡片都會告訴你已經用掉幾成，不用等到月底看報表才驚覺超支。

> 📱 App　💻 Web

:::note 4.0 起沒有「帳本總預算」了
舊版的「設定總預算」「本月預算」卡片、首頁頂端的預算進度條、Web 的「預算」頁，在 4.0 都已移除。要控制花費，請改用「規劃」分頁裡**專案的預算**，做法見下面，完整的專案設定見 [專案](./project.md)。
:::

## 為什麼這樣設計

現在預算只有一層：每個專案各自有自己的預算、週期、每日額度和超標提醒。

- **每月循環的專案**：適合「每月咖啡」「每月餐費」這類常態開銷，起算日跟著帳本的「每月起始日」，見 [帳本](./ledger.md)。
- **固定期間的專案**：適合旅行、裝修、婚禮這類一次性的計畫，填起訖日就好。
- 專案還能再把預算分配給各個分類（旅行預算 5 萬，其中住宿 2 萬、餐飲 1 萬）。

預算只會計算「記帳時歸到這個專案」的支出，所以想管哪一類花費，就在記帳時把它歸到對應的專案。

## 怎麼操作

### 📱 在 App 上

**設定每月預算**

1. 點底部導覽列的「規劃」。
2. 點右上角的「＋」，進入「新增專案」。
3. 輸入「專案名稱」，例如「每月咖啡」。
4. 在「預算金額」輸入每月上限，例如 3000；「週期」選「每月」。
5. 點「儲存」。

之後記帳時，在「專案」欄選這個專案，這筆支出就會算進它的預算。其他欄位（結轉上期結餘、每日預算、預算超標提醒等）都在 [專案](./project.md) 說明。

![App 規劃分頁的專案卡片：每個專案顯示預算進度條、已用與剩餘](/img/prepare/budget-4.png)
*圖中：「規劃」分頁下半部的專案卡片，每張卡片有預算進度條、已用與剩餘金額*

**看預算進度**

- 「規劃」分頁的專案卡片，顯示進度條、「已用」金額與「剩餘」金額。剩餘為正數時是綠色，超支變紅色。
- 點專案卡片進入專案詳情，可以看這一期的支出、各分類的預算分配與每日預算。
- 設了「預算超標提醒」的專案，使用率超過門檻時會收到通知，見 [通知與提醒](../more/notifications.md)。

首頁的預算進度條已經移除；首頁不再顯示預算，要看進度請到「規劃」分頁。

**修改或刪除**

1. 到「規劃」分頁，點專案卡片進入詳情，點右上角的鉛筆。
2. 改金額後按「儲存」；要刪除，在編輯頁選刪除並確認。已經有交易的專案會改為封存，不會真的刪除。

### 💻 在 Web 上

1. 點上方導覽的「專案」。
2. 點「新增專案」，填「名稱」「預算金額（可選）」「週期」等欄位後儲存。
3. 專案卡片會顯示預算使用情況；展開「顯示分類子預算」，可以再用「新增分類預算」把預算分配給各個分類。

Web 的獨立「預算」頁在 4.0 也已移除。預算是各帳本獨立的，請先確認頁面頂端選的是想設定的帳本。

## 舊版的總預算資料怎麼辦

從舊版升級的人，原本設定的總預算與分類預算並沒有被刪除，只是 App 與 Web 都已經沒有畫面可以查看或修改。原本的「分類預算」若是在更早的版本升級時，已經自動變成專案，見 [專案](./project.md)。

## 注意事項／小提醒

:::tip 預算怎麼抓
可以先看過去兩三個月的實際支出（統計報表有各月合計），抓一個略低於平均的數字當專案預算，之後再慢慢調整。見 [統計報表](../analysis/statistics.md)。
:::

:::note 預算只看支出
專案預算計算的是支出，轉帳不會算進已用金額。如果希望專案裡的收入也能增加可用預算（例如旅費有人幫你出），可以打開專案的「收入併入預算」。
:::

:::note 「不計入預算」標記
記帳時的「不計入預算」標記（見 [帳單標記](../record/flags.md)）是給舊的總預算用的；專案預算的「已用」金額不受這個標記影響。想讓某筆支出不佔用專案預算，記帳時請不要把它歸到該專案（選「不指定專案」）。
:::

:::note 沒有歸到專案的支出不會被算到
專案預算只計算有選到該專案的支出。AI 記帳無法判斷專案時，交易會先進「待確認專案」，記得到「待處理中心」補選，見 [專案](./project.md)。
:::
