午餐剛吃完，付了 120 元，想把這筆錢記下來。這一頁帶你從頭走一遍：開啟記帳畫面、選分類、輸入金額、選帳戶、送出。記完第一筆之後，其他欄位怎麼用請看[記帳欄位](./fields.md)。

> 📱 App　💻 Web

## 開始前先確認三件事

記帳至少要有「帳本」「分類」「帳戶」三樣東西，缺一個就無法送出：

- **帳本**：登入後預設就有一本，不用另外建。要分開記個人與家庭開銷再看[帳本](../prepare/ledger.md)。
- **分類**：App 一開始會有預設分類，夠用就直接記。想自訂請看[分類](../prepare/category.md)。
- **帳戶**：每一筆交易都要指定錢是從哪裡出去（現金、銀行、信用卡…）。還沒建的話先看[帳戶](../prepare/account.md)。

## 為什麼這樣設計

分類回答「這筆錢花在什麼事情上」，帳戶回答「錢實際從哪裡出去」。兩個都記，報表才看得出各類花費，帳戶餘額也才會跟你的實際存款、信用卡帳單對得上，所以帳戶是必填。

## 怎麼操作

### 📱 在 App 上

App 的記帳入口在底部導覽列中間那顆按鈕。它有兩種狀態：

- 你在別的分頁時，它顯示「明細」，點一下會切到明細分頁（月曆）。
- 你已經在「明細」分頁時，它變成「記帳」，點一下才會開啟新增交易頁。

App 開啟後預設就停在「明細」，所以多數時候直接點「記帳」就能開始。

1. 在底部導覽列點中間的「記帳」。如果它寫的是「明細」，先點一次切到明細分頁，按鈕就會變成「記帳」。

2. 新增交易頁上方有五個分頁：「建議」「支出」「收入」「轉帳」「欠款」。第一次記帳先看「建議」：它會把你最可能要記的分類排在前面，點一個分類就會自動跳到「支出」或「收入」分頁並選好分類。剛開始沒有歷史紀錄時，會列出所有分類。你也可以直接點「支出」分頁自己選。

   ![新增交易頁上方的五個分頁，目前停在「建議」](/img/record/first-record-2.png)
   *圖中：① 五個分頁：建議、支出、收入、轉帳、欠款　② 「建議」分頁的快速分類*

3. 在「支出」分頁的分類格裡點「餐飲」。分類格一次顯示兩行，點到有子分類的分類，整個格子會換成它的子分類，第一格「返回」可以回上一層。

4. 點金額那一格，畫面下方會出現計算機鍵盤。輸入 `120`。

5. 點「帳戶」那一列，選付款用的帳戶，例如「現金」。如果你在資產頁設定過預設支出帳戶，這一列已經幫你選好了。

6. 想補一句說明，在「名稱…」欄位打「午餐」。這個欄位就是備註。

7. 點金額列右邊的勾勾，或計算機鍵盤上的「✓」送出。畫面會關閉，回到明細月曆，今天的格子下面就會多出這一筆。

   ![填好餐飲 120 元、帳戶為現金的支出分頁，標出金額、帳戶與送出勾勾](/img/record/first-record-3.png)
   *圖中：① 金額　② 帳戶　③ 按勾勾送出*

沒填完就送出時，畫面會提示缺什麼：「請選擇分類」「請輸入金額」「請選擇帳戶」。

:::tip 也可以用手勢送出
表單捲到底之後再往上拉，會出現「上拉送出」，超過一定距離變成「放開送出」，放手就等於按了送出。條件沒填齊時一樣會出現上面的提示。
:::

### 💻 在 Web 上

Web 版要先用瀏覽器登入你的蜜蜂記帳伺服器，登入方式見[安裝與登入](../preface/install-login.md)與 [Web 版](../sync/web.md)。

1. 在上方導覽列選「交易」（手機寬度時導覽列在畫面底部），右上角點「建立交易」。也可以按 `⌘K`（Windows 為 `Ctrl+K`）開啟命令面板，選「新交易」。

2. 彈出的「建立交易」視窗最上面是「帳本」，預設是目前帳本。下面一排切換「支出」「收入」「轉帳」，選「支出」。

3. 「分類」點開後選「餐飲」。Web 版沒有「建議」分頁，分類要自己選。

4. 「金額」輸入 `120`。Web 的金額欄可以直接打算式，例如 `60+60`，按 `=` 或 Enter 就會算出結果。

5. 「帳戶」選付款用的帳戶。

6. 「備註」寫「午餐」。「時間」預設是現在，補記昨天的帳時改這裡。

7. 點右下角「建立交易」。視窗關閉，這筆交易出現在交易列表。

   ![Web 的建立交易視窗，已填好支出、餐飲、120、現金與備註](/img/record/first-record-web-1.png)

## 五個分頁各做什麼

| 分頁 | 用途 | 只在哪裡 |
|---|---|---|
| 建議 | 依你的記帳習慣排出最可能要記的分類，點一下直接帶到支出或收入分頁 | 📱 App |
| 支出 | 花錢，例如午餐、交通、刷卡購物 | 📱 App　💻 Web |
| 收入 | 進帳，例如薪水、利息、退回的款項 | 📱 App　💻 Web |
| 轉帳 | 錢在自己的帳戶之間移動，例如提款、存錢、繳信用卡，詳見[轉帳](./transfer.md) | 📱 App　💻 Web |
| 欠款 | 借錢給別人或向別人借錢，詳見[借還款](./debt.md) | 📱 App（Web 到「借還款」頁新增） |

**「建議」分頁怎麼看：** 建議把常用的支出與收入分類混在一起排序，所以每個圖標右下角都有一個小圓圈，「支」是支出分類、「收」是收入分類，一眼就分得出來；圓圈的顏色跟「我的 → 外觀」設定的收支配色走（紅漲綠跌或相反），切換設定後會跟著互換。

![App「建議」分頁：每個分類圖標右下角的小圓圈標示支出（支）或收入（收）](/img/record/suggested-1.png)
*圖中：每個圖標右下角的「支」「收」小圓圈；最後一格的「＋」可以新增分類*

在共享帳本裡你是編輯者時，「建議」只會推薦帳本主人的分類，跟「支出」「收入」分頁看到的一致；以前會誤推薦你自己本機的分類，3.9.0 已修正。不想要這個分頁，可以到「我的 → 外觀」關掉「新增交易的建議分頁」。

在 App 切換「支出」「收入」「轉帳」分頁時，已經輸入的金額、日期、名稱、商家、標籤與帳戶會帶到新的分頁，不用重打。分類、附件、幣別與紅利回饋不會帶過去。

## 注意事項／小提醒

:::note 日期會跟著月曆
在明細月曆先點某一天（例如下週一）再點「記帳」，新增頁的日期會直接是那一天，時間沿用現在。沒點日期就是今天。
:::

:::tip 想關掉「建議」分頁
到「我的」→「個性化設定」，關掉「新增交易的建議分頁」。關掉之後從「記帳」進來會直接停在「支出」。
:::

:::note 補記或提前記
日期可以選未來。預先登記下週要扣的訂閱費沒問題，但固定每月發生的款項建議直接設成[週期性收支](./recurring.md)。
:::
