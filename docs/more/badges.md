記下第一筆帳、養成連續記帳習慣，或試用不同功能，都有機會解鎖稱號。到「我的稱號」可以查看獲得日期與解鎖條件，再選幾枚喜歡的徽章顯示在名字下方。

> 📱 App　💻 Web（4.2.0 起）

本頁圖片使用虛構示範資料；App 圖片以正式介面元件呈現，未包含手機系統狀態列。

## 怎麼進入

### 📱 在 App 上

1. 點底部導覽的「我的」。頁首左側是頭像，右側是問候語與名字，名字下方是稱號列。
2. 點主稱號或任一枚徽章，進入「我的稱號」。還沒有顯示徽章時，點「稱號」也能進入。
3. 頁面上方的「佩戴中」有三個位置，下方依類別列出所有徽章與已獲得數量。

主稱號會顯示圖示和名稱，其他佩戴中的徽章只顯示圓形圖示。頁首下方仍可查看記帳天數、總筆數與帳本結餘；帳本切換與管理請使用[帳本](../prepare/ledger.md)原有的入口。

*圖中：點名字下方的「支持者」主稱號或旁邊的圓形徽章，進入「我的稱號」。*

![App「我的稱號」頁，上方為三個佩戴位置，下方列出已獲得與尚未解鎖的徽章](/img/more/badges-app-list.png)
*圖中：上方顯示佩戴中與已獲得數量；彩色徽章代表已解鎖，鎖頭代表尚未解鎖。*

### 💻 在 Web 上

1. 展開右上角頭像選單，選「我的稱號」；也可以點選單內的佩戴徽章列。
2. 或按 Ctrl／⌘K，搜尋「我的稱號」。
3. 進入後，一樣能查看徽章、調整佩戴與主稱號。

![Web 頭像選單，顯示支持者身分、稱號徽章列與「我的稱號」入口](/img/more/badges-web-menu.png)
*圖中：「帳本與回顧」裡的「我的稱號」，以及信箱下方可直接點選的徽章列。*

![Web「我的稱號」頁，顯示佩戴中的三枚徽章與各類稱號](/img/more/badges-web-list.png)
*圖中：Web 也能查看佩戴中、解鎖條件與已獲得的徽章。*

## 佩戴與主稱號

1. 點一枚徽章，查看說明與獲得日期；還沒達成的會顯示「尚未解鎖」。
2. 已獲得的徽章可以按「佩戴」，最多同時佩戴 **3 枚**。已滿時先選另一枚「取消佩戴」，再換上新的。
3. 按「設為主稱號」，讓這一枚連名稱一起顯示。若它還沒佩戴，會一起加入佩戴，因此也需要有空位。
4. 不想顯示主稱號時，可以「取消主稱號」；不想顯示某枚徽章時，選「取消佩戴」。取消佩戴不會失去已獲得的徽章。

已獲得的徽章是彩色的，尚未解鎖的會呈現灰色；佩戴中的徽章另有勾選標記。

![App 徽章詳情，顯示獲得日期、取消佩戴與設為主稱號](/img/more/badges-app-detail.png)
*圖中：已佩戴的「半年老手」，可取消佩戴或改成主稱號。*

![Web 徽章詳情視窗，顯示獲得日期與佩戴、主稱號設定按鈕](/img/more/badges-web-detail.png)
*圖中：Web 點同一枚徽章，也能調整佩戴與主稱號。*

第一次還沒調整過佩戴時，系統會優先選支持者徽章，再從資歷、連續記帳與累積筆數中挑選已獲得的最高階徽章，最多三枚，第一枚作為主稱號。之後以你自己的選擇為準。

## 有哪些徽章

4.3.0 起共有 **39 枚**，分成七類（新增六枚活動徽章）；點徽章就能看到各自的條件。

| 類別 | 解鎖方式 |
|---|---|
| 記帳資歷 | 從第一筆交易日期起算，滿 1 個月、3 個月、半年、1 年、2 年 |
| 累積筆數 | 累積 1、100、500、1,000、5,000 筆交易 |
| 連續記帳 | 連續 7、30、100、365 天有交易記錄 |
| 功能探索 | 使用預算、信用卡、存錢桶、專案、範本、週期記帳、分期、借還款、股票、附件、AI 對話或共享帳本等功能，共 12 枚 |
| 活動 | 有綁消費的活動累積 1、10、50、100 個，同月 5 個，或單一活動綁定 10 筆消費，共 6 枚 |
| 支持者 | 領有支持者授權 |
| 農場 | 雲端農場的開通、收成、畜牧、週結算與友善互動，共 6 枚 |

### 記帳資歷、筆數與連續記帳怎麼算

- **所有帳本一起算**，不是只看目前選取的帳本。
- 資歷以第一筆交易的日期起算，不是安裝 App 或註冊帳號的日期；滿月遇到該月沒有的日期時，以月底為準。
- 連續記帳依交易日期判定；目前週期自動產生的交易，以及共享帳本中其他成員的交易，也可能計入筆數與連續天數。
- 這和[農場週結算](../farm/bookkeeping.md)看「新增交易的那一天」、只算一本計分帳本的規則不同。

### 農場徽章

| 徽章 | 條件 |
|---|---|
| 農場開張 | 開通自己的雲端農場 |
| 初次收成 | 收成第一批作物 |
| 百次收成 | 累積收成 100 次 |
| 畜牧新手 | 養了第一隻動物 |
| 週週達標 | 農場週結算連續 4 週達標 |
| 好鄰居 | 拜訪、留下表情或幫忙過其他農友；偷菜與回禮不算 |

農場徽章需要登入**帳好嗎 Cloud** 並使用雲端農場，單機農場不會解鎖。它們會在 App 啟動，或 Web 開啟稱號頁／頭像選單時讀取，不會在每次農場操作後立刻出現。

![App 稱號頁的農場類別，列出農場開張、初次收成、百次收成、畜牧新手、週週達標與好鄰居](/img/more/badges-app-farm.png)
*圖中：往下捲動可找到「農場」類別；這份示範資料已解鎖農場開張、初次收成與好鄰居。*

## 獲得新稱號的慶祝 {#badge-celebration}

4.3.0 起，App 在記帳後等重新判斷稱號的時機，若發現最近達成的新稱號，會先播放花朵散開動畫，再顯示稱號卡片；按「看我的稱號」可前往佩戴，不必先進「我的」。一次最多展示三枚，其餘仍可到稱號頁查看。

只對達成日為今天或昨天的新稱號顯示慶祝。新裝置登入或升級時補記較早達成的稱號，會直接加入清單；App 在背景時也不跳慶祝卡片。未解鎖的徽章仍以條件說明呈現，沒有「還差幾筆」的進度。

## 同步與小提醒

### 排行榜也會顯示佩戴中的徽章

App 與 Web 的四種農場排行榜，會在農友名稱下顯示最多三枚目前佩戴的徽章；主徽章帶名稱，其他只顯示圖示。歷史週次也會使用**目前**的佩戴設定，並非當時的紀錄。匿名農友不顯示徽章，包含自己的匿名列。畫面與說明見[排行榜佩戴徽章](../farm/social.md#leaderboard-badges)。

### 帳號同步與保留

- 登入同一個**帳好嗎 Cloud** 帳號並完成同步後，App 與 Web 會共用已獲得的稱號、佩戴選擇與主稱號。
- **已獲得的徽章會保留**：刪除交易、移除功能資料、連續記帳中斷，都不會收回已解鎖的徽章。
- 支持者徽章獲得後，授權到期也會保留；它代表曾獲得這枚稱號，**目前授權是否有效仍以「授權金鑰」頁為準**。點徽章會進稱號頁，要查到期日請到「我的 → 授權金鑰」。
- 一般記帳、活動與功能徽章由 App 在啟動、記帳後等時機判斷，再同步到 Web。若一直只用 Web，這些徽章不會由 Web 自行補算；可先開啟 App，等資料同步完成後重新啟動。農場徽章由 Cloud 判斷，Web 也能直接讀取。
- Web 載入農場徽章時請稍等；若載入失敗，先重新整理並確認徽章顯示完整，再調整佩戴。
