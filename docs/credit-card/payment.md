銀行帳單出來了，你從活存轉一筆錢去繳卡費。如果只是隨手記一筆「轉帳」，**帳好嗎**不知道你繳的是哪一期帳單，帳單上的「已繳金額」「剩餘帳款」也對不起來。所以請用專門的「繳款」功能：它會幫你記好轉帳、寫上對應的帳單期間，剩餘帳款也會跟著更新。

> 📱 App　💻 Web

## 為什麼這樣設計

- 繳款本質上是一筆「從付款帳戶轉到信用卡」的轉帳，所以兩邊餘額都會正確變動。
- **帳好嗎**靠轉帳的備註辨識「這是繳款」。備註裡寫著帳單期間，才知道這筆錢沖的是哪一期。你自己手動記的轉帳不會被當成繳款，詳見下方說明。
- 同一家銀行的卡合併帳單時，你只會收到一張帳單、繳一筆錢，所以群組繳款也設計成「一次繳，系統分給各張卡」。

## 怎麼操作

### 📱 在 App 上：單張信用卡繳款

1. 「資產」點進信用卡，切到「交易明細」分頁，選到要繳的那一期。
2. 在「繳款記錄」區塊右邊點「＋」。
3. 如果這一期還有沒核對過的交易，會先跳出「尚有未對帳交易」的提醒，可以選「取消」回去對帳，或「繼續繳款」。這只是提醒，不會擋你。
4. 開啟轉帳頁，轉入帳戶、金額（這期剩餘帳款）和備註已經帶好。選「轉出帳戶」，確認金額後儲存。

![按「繳款記錄」旁的加號後，若本期還有未對帳的交易，會先跳出確認提醒](/img/credit-card/payment-dialog.png)
*圖中：提醒本期還有幾筆交易未對帳，確定要繳就按「繼續繳款」，要先對帳就按「取消」*

![App 繳款轉帳頁：轉出帳戶、轉入的信用卡、金額與備註都已帶入](/img/credit-card/payment-1.png)
*圖中：轉出的銀行帳戶、轉入的信用卡、繳款金額（已帶入應繳）都已帶好，確認後儲存*

下次繳這張卡時，轉出帳戶會自動帶入你上次繳這張卡用的帳戶，不同卡各自記得。

### 📱 在 App 上：合併帳單群組繳款

1. 「資產」點進合併帳單主帳戶，在「交易明細」分頁點「繳款記錄」旁的「＋」。
2. 進入「群組繳款」頁，選「付款來源帳戶」。只會列出跟群組同幣別的帳戶。
3. 「繳款總額」預設是目前應繳總額，可以改成你實際要繳的金額。
4. 看一下「分攤預覽」，確認每張卡分到多少。
5. 按「確認繳款」。成功後會提示「已建立 N 筆繳款交易」。

![App 群組繳款頁：選付款來源帳戶後，下方「分攤預覽」逐卡列出各自要繳的金額](/img/credit-card/payment-2.png)
*圖中：選好付款來源帳戶與繳款總額後，「分攤預覽」逐卡列出各自要繳的金額*

建立出來的每一筆都是各自獨立的轉帳，可以分別編輯或刪除。

### 💻 在 Web 上：繳款

1. 頂部導覽列點「帳戶」，點開信用卡（或主帳戶）。
2. 在「信用卡帳單」區塊右上角按「繳款」。
3. 在「信用卡繳款」視窗填「繳款金額」（預設帶入目前應繳），選「付款帳戶」。
4. 按「確認繳款」，出現「繳款成功」。

![Web 信用卡繳款視窗，顯示繳款金額與付款帳戶](/img/credit-card/payment-3.png)
*圖中：Web 繳款視窗的繳款金額與付款帳戶*

付款帳戶同樣只列同幣別的帳戶，而且會記住你上次繳這張卡用的帳戶。

### 分攤規則：繳的金額不等於應繳時

群組繳款（App 的「群組繳款」、Web 在主帳戶按「繳款」）會依下面的規則把一筆錢分給各子卡：

- **剛好或繳比較多**：每張卡各自繳清。多出來的錢（溢繳）記在欠款最多的那張子卡上，整筆都是溢繳的話，備註會多一個「（溢繳結轉）」。如果所有卡都沒欠款，就記在第一張同幣別的子卡。
- **繳比較少**：欠款最少的卡先繳滿，剩下的全部給欠款最多的那張。不會按比例切成零碎小數，整數金額維持整數，尾數只會集中在一張卡。
- **有卡溢繳、你的金額落在「淨應繳」和「欠款總和」之間**：銀行會把同一家的溢繳折抵在整張帳單上，繳完每張卡都是 0。**帳好嗎**也這樣做，「分攤預覽」會多一行「溢繳抵扣：A → B」，表示把 A 卡的溢繳挪給 B 卡。繳完之後每張卡都歸零。

舉例：A 卡欠 1,000、B 卡欠 500、C 卡溢繳 200，淨應繳是 1,300。你繳 1,300，預覽會顯示 B 繳 500、A 繳 800，另外多一行「溢繳抵扣：C → A」，把 C 的 200 挪給 A 補上差額。三張卡繳完都是 0。

溢繳抵扣是一對「不計入統計與預算」的收支，備註是「信用卡繳款抵扣（…）」，日期放在這期帳單結帳日當天中午。它不會出現在對帳清單裡，也不影響你的收支報表。

### 備註格式

繳款產生的轉帳備註會自動寫成：

```
信用卡繳款(帳單 2026-08-05~2026-09-05)
```

期間是「上次結帳日~本次結帳日」。備註有帶期間的繳款，會直接算在那一期，同一次繳款拆到各子卡的幾筆也會留在同一期，不會被切到不同期。

:::warning 不要改掉備註開頭
**帳好嗎**只認這幾種備註是「繳款」：備註開頭是「信用卡繳款」、開頭是「自動扣繳(帳單 」，以及舊版 App 留下的純日期備註（像 `2026/08/01 – 2026/09/01`）。把前面的字改掉，這筆就會被當成一般轉帳。
:::

### 手動轉入算收入，不算繳款

如果你自己用「轉帳」功能記一筆轉入信用卡的錢（備註不是上面那幾種），**帳好嗎**視為「這張卡收到一筆錢」，也就是收入：

- 會列在對帳清單裡，減少這一期的「新增花費」和應繳金額。
- **不會**算進「已繳金額」，也不會出現在「繳款記錄」。
- 它只影響所在的那一期，不會去沖更早的欠款。

所以用手動轉帳繳掉的帳單，會一直顯示「可繳款」，直到你用繳款功能再繳，或把備註改成繳款格式。要繳卡費，請用「繳款」按鈕。

### 🔖 自動扣繳

不想每個月自己按繳款，可以讓系統在繳款截止日自動從你指定的帳戶轉帳繳清。

![App 編輯信用卡：開啟自動扣繳後，選擇扣款來源帳戶](/img/credit-card/payment-4.png)
*圖中：開啟自動扣繳後，選擇扣款來源帳戶*

> 需要使用**帳好嗎 Cloud** 並登入，扣款由雲端伺服器的排程執行。

**📱 在 App 上**

1. 編輯獨立信用卡，或編輯合併帳單主帳戶。
2. 主帳戶要先打開「信用卡合併帳單」開關，「自動扣繳」才會顯示出來。
3. 打開「自動扣繳」開關。
4. 點「扣款來源帳戶」，選一個帳戶。開著卻沒選的話，儲存時會提示「請選擇自動扣繳的來源帳戶」。
5. 儲存。

**💻 在 Web 上**

1. 在「帳戶」頁編輯信用卡或主帳戶，在額度、帳單日、還款日區塊下方打開「自動扣繳」。
2. 選「扣款來源帳戶」，按「更新帳戶」。

- 到了繳款截止日，系統會從來源帳戶轉帳繳清應繳金額，備註是「自動扣繳(帳單 …」，和手動繳款一樣算繳款。
- 來源帳戶餘額不夠時，會先跳過並通知你，之後持續重試，直到餘額足夠，或你自己把帳單繳掉。
- 來源帳戶不能選主帳戶（群組）或這張卡自己。
- 掛在主帳戶底下的子卡看不到這個選項，要在主帳戶設定。
- 只用 App、沒有 Cloud 的話，App 本身不會代你扣款，也不會產生轉帳。
- 自動扣繳只能在信用卡（或主帳戶）的「編輯」頁設定。4.0 起，信用卡詳情的「帳戶資訊」分頁已經沒有「自動扣繳」與「可用額度不足提醒」這兩個只有顯示、沒有作用的項目。

## 注意事項／小提醒

:::tip Web 請在主帳戶或獨立信用卡的頁面繳款
合併帳單底下的子卡，在 Web 上自己的詳情頁按「繳款」，只會單純記一筆轉帳到那張卡，不是整組分攤。想一次繳整組，請點開主帳戶再按「繳款」。
:::

- 繳款不分日期，一律先沖最舊還沒繳清的欠款，也就是先進先出。
- 不支援跨幣別繳款，付款帳戶必須和信用卡同幣別。
- 沒有「整批復原」，要修改請到繳款記錄裡逐筆編輯或刪除。
- 已經繳出去的舊交易，不會因為規則更新而被自動改寫。
