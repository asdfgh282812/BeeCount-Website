想維持每月投資的習慣，又希望價格低於季均價時多投入、高於季均價時少投入，可以在既有的[定期定額](./dca.md)計畫開啟「智慧加減碼」。每一期依當期資料獨立判斷，沒有達到條件就使用原本的每期金額。

> 📱 App　💻 Web　支援台股上市、上櫃與美股的股票／ETF。

:::note 截圖與數字
下圖使用 App 4.3.0 的實際畫面與虛構資料。0050、AAPL 的收盤價、均價、金額及股數都是操作示例，不代表即時行情。本功能用於試算與記帳，不會連線券商下單。
:::

## 先準備好

- 已有投資理財帳戶，以及與證券相同幣別的交割帳戶。台股使用 TWD，美股使用 USD；智慧定期定額目前不自動換匯。
- 能連線帳好嗎 Cloud，取得完整的歷史收盤資料。
- 手機與其他會自動產生交易的裝置都已更新到支援智慧加減碼的版本，雲端服務也支援此功能。避免舊版裝置按基本金額產生交易。

## 📱 建立或編輯計畫

1. 到「資產 → 投資理財帳戶 → 持股 → 定期定額」建立計畫；已有計畫時，點「定期定額計畫」清單中的項目編輯。
2. 選市場、輸入代號，填「每期投入金額」並選交割帳戶。這裡的金額是**沒有觸發條件時使用的基本金額**。
3. 往下找到「智慧加減碼」，開啟「逢低調整」、「逢高調整」，或只開其中一側。

![App 台股計畫的市場、0050 代號、每期投入 3000 元與交割帳戶，下方接智慧加減碼設定](/img/invest/smart-dca-1.png)
*圖中：基本金額為 TWD 3,000，交割帳戶是「示範銀行」。編輯已儲存的計畫時，市場與股票代號不能修改。*

### 設定條件與金額

每側都填兩個欄位：

| 欄位 | 怎麼填 |
|---|---|
| 與季均價差距達 (%) | 填正數，例如 5 代表差距達 5%；有效範圍為大於 0、最多 100 |
| 本期投入金額改為 | 填觸發後當期要投入的完整金額，必須大於 0；不是「再多加多少」 |

例如基本金額 TWD 3,000，設定逢低 5% 改為 5,000、逢高 10% 改為 2,000：

| 前一交易日收盤價相對季均價 | 當期投入金額 |
|---|---|
| 低於季均價達 5%，含剛好 5% | TWD 5,000 |
| 高於季均價達 10%，含剛好 10% | TWD 2,000 |
| 兩側條件都沒達到 | TWD 3,000 |

每一期重新判斷。例如這期改用 5,000，下一期沒達條件就回到 3,000，不會把上期增加的金額繼續累加。關閉某一側後，那一側就不參與判斷；兩側都關閉，恢復一般定期定額。

### 更新試算並儲存

1. 按「更新試算」。
2. 核對「市場交易日」、收盤基準日、季均價與乖離率。
3. 查看基本金額會改成多少，以及目前報價下的預估股數、手續費與扣款。
4. 繼續確認頻率、下次執行時間、手續費，最後按右上角「儲存」。

![App 智慧加減碼設定，逢低 5% 改為 5000、逢高 10% 改為 2000，試算顯示乖離負 6% 並達逢低條件](/img/invest/smart-dca-2.png)
*圖中：前一交易日收盤 94、季均價 100，乖離 −6%，達到逢低 5% 條件，因此本期由 TWD 3,000 改成 5,000。示範手續費設為 0；請依自己的券商設定。*

:::tip 試算和到期記帳使用不同時點的價格
加減碼條件看的是「前一交易日收盤價與季均價」；畫面上的預估股數使用目前報價。到期產生紀錄仍需取得成交日當天的開盤價，所以試算的股數不保證等於最後紀錄，更不等於券商實際成交。
:::

## 美股也可以用

建立時把市場選成「美股」，輸入 AAPL 等代號，金額以 USD 填寫，交割帳戶也要是 USD。條件判斷與台股相同；股數依既有美股規則允許小數，手續費另外扣。

![App 美股智慧加減碼，基本金額 100 美元，逢低後改為 150 美元，以示範價格 100 美元估算 1.5 股](/img/invest/smart-dca-3.png)
*圖中：基本 USD 100，逢低 5% 改為 USD 150，逢高 10% 改為 USD 70；試算觸發逢低，預估 1.5 股。*

台股上市、上櫃只買整數股，投入金額包含手續費，買不足一股的零頭留在交割帳戶；美股投入金額用來買碎股，費用另外計算。詳見[台股整股與美股碎股怎麼算](./dca.md#台股整股與美股碎股怎麼算)。

## 季均價實際怎麼算

這裡的「季均價」固定採 **60 個交易日的收盤價簡單平均**，不是最近 90 個日曆天，也不是成交量加權平均。

1. 先確認這一期的市場交易日；休市如何處理，沿用[定期定額的順延／略過規則](./dca.md#成交日與成交價遇到休市日怎麼辦)。
2. 找出買進日前一個市場交易日，作為收盤基準日。
3. 取包含基準日在內、往前共 60 個交易日的完整收盤價，相加後除以 60。
4. 計算「乖離率 =（前一交易日收盤價 ÷ 季均價 − 1）× 100%」，再比對設定的門檻。

例如買進日是 2026/11/9（週一），正常開市下，收盤基準日就是 11/6（週五）。**買進當天的盤中價格不會放進這 60 筆資料。** 美股按美國市場的交易日期判斷，不直接套用台灣日期。

資料採同一口徑的股票分割調整收盤價，並非含股息再投資的報酬序列。這是帳好嗎的計算方式，不保證每次結果與券商的季均價完全相同。

## 買進之前，資料什麼時候取得

不需要每天先手動按一次試算，也不必讓手機累積 60 天資料。雲端會向行情來源取得歷史收盤資料，手機只讀取計算結果。

- **按「更新試算」時**，會請求所選市場交易日的指標，成功後保存供後續共用。
- **計畫到期、產生交易時**，也會自行取得該期指標；不以你有沒有先按試算為條件。若雲端的定期檢查有啟用，也會在到期處理時取得。
- **只有新增計畫或更新最新股價**，不代表已經計算季均價。尚未到期、也沒要求試算的日期，可能還沒有指標。
- 目前不會在每個買進日的前一天，替所有未到期計畫預先準備資料。

要試看資料，先按「更新試算」確認畫面上的市場交易日與狀態即可，不必把計畫日期往過去改。

### 沒有試算結果或沒有產生交易

| 情況 | 會怎麼處理 |
|---|---|
| 前一交易日尚未收盤，或資料仍未完成 | 等完整收盤資料可用後再試 |
| 上市時間太短、缺少某個交易日，無法湊齊完整 60 筆 | 顯示資料不足，暫緩該期 |
| 網路失敗、行情來源暫時無法使用 | 保留該期，之後重試 |
| 季均價已取得，但買進日尚未開盤 | 等待該日開盤價；有季均價不代表立刻產生交易 |
| 交割餘額不足，或台股預算連一股都買不起 | 依一般定期定額規則處理，核對畫面提示 |

智慧計畫缺少指標時，**不會偷偷改用基本金額產生交易**。但仍有原本的 **7 天補期上限**，超過上限的舊期數會略過，並不是無限等待。

## 查看已產生交易的判斷

到「資產 → 投資理財帳戶 → 持股 → 點選股票」，在「交易紀錄」查看「當期智慧加減碼判斷」。

![持股詳情的買進紀錄顯示當期達逢低條件、基準日收盤價、季均價、乖離率及投入金額變化](/img/invest/smart-dca-4.png)
*圖中：這筆買進保留當時由 TWD 3,000 改為 5,000 的依據。事後修改計畫，不會回頭重算這筆歷史判斷。*

請用券商對帳單核對實際成交價、股數與費用，需要時到投資頁編輯交易。

## 💻 在 Web 上

從投資帳戶的「定期定額」入口建立或編輯計畫，在同一個表單設定基本金額、逢低／逢高條件並更新試算。門檻、金額幣別、資料不足時暫緩，以及歷史判斷的規則與 App 相同。基本入口見[定期定額的 Web 操作](./dca.md#-在-web-上)。
