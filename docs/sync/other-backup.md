如果你在「我的 → 雲服務」看到「備份同步」，裡面有 iCloud、自訂 WebDAV、S3、Supabase，可能會想：我可不可以把帳本備份到自己的 NAS 或雲端硬碟？先說結論：這個版本不建議這樣用，下面說明原因。

> 📱 App　🔖 進階功能，一般使用者可以略過

## 為什麼這樣設計

這些備份服務是原版 App 留下來的功能，運作方式是把整個帳本「整包上傳、整包下載覆蓋」，不是即時同步。而這個版本要求所有人都要登入 BeeCount Cloud 並通過授權檢查，才能進入 App。所以：

- App 檢查授權時，只認 BeeCount Cloud 的登入狀態。
- 在「雲服務」切換成其他備份服務時，系統會提示「切換雲端服務將登出目前帳號。確認切換？」
- 依照目前程式的行為，登出 BeeCount Cloud 之後，App 會回到「請登入 BeeCount Cloud」的全螢幕畫面，必須重新輸入伺服器位址並登入，才能繼續使用。

換句話說，在這個版本裡，其他備份服務無法取代 BeeCount Cloud，也無法和它同時運作。

:::note 待確認
上面描述來自程式邏輯，建議實際在手機上試過再依賴。如果你只是好奇，請不要在存有重要資料、且尚未同步的手機上測試。
:::

## 入口在哪裡

1. 點底部「我的」，點最上面的「雲服務」。
2. 上方有三個切換頁籤：「離線模式」「備份同步」「雲端協同」。
3. 「備份同步」裡有「自訂 WebDAV」「自訂 S3」「自訂 Supabase」；使用 iPhone 時還會多一個 iCloud。
4. 「雲端協同」裡是 BeeCount Cloud，也就是你平常在用的方式。

![App「我的 → 雲服務」頁：離線模式、備份同步、雲端協同三個分頁，目前選在雲端協同](/img/sync/overview-1.png)

## 更適合的備份做法

資料已經放在 BeeCount Cloud 上，等於有一份雲端備份，通常不需要再另外備份。如果你想自己留一份在手邊：

- **匯出 CSV**：把交易匯出成表格，Excel 就能開。見[匯入與匯出](../more/data.md)。
- **匯出設定檔**：帳本、帳戶、分類的設定可以匯出成設定檔，需要時再匯入。
- **附件**：交易的圖片附件可以在「資料管理」單獨匯出。

這些做法不需要切換雲服務，也不會把你登出。

## 注意事項／小提醒

- 不要為了試用而切換「離線模式」或其他備份服務，因為會登出目前帳號，登回來還要重新輸入伺服器位址。
- 即使真的切換成其他備份服務，共享帳本、AI 查帳、股票報價、信用卡自動扣繳等需要伺服器的功能也都用不了。
