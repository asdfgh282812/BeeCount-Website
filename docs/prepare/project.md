分類告訴你「錢花在什麼東西上」，專案告訴你「錢是為了哪件事花的」。一趟 5 天的日本旅行，會花到交通、餐飲、住宿、購物好幾個分類；裝修新家，會花到建材、家具、家電。把這些交易都歸進同一個專案，就能一眼看到這件事總共花了多少、預算還剩多少。

> 📱 App　💻 Web

## 為什麼這樣設計

只用分類的話，旅行的餐飲會和平常的餐飲混在一起，月底看報表分不清哪些是旅行多花的。專案在分類之外多一個維度：每筆支出照常記在原本的分類，另外標上屬於哪個專案。

專案還能設定期間、預算、每日額度和超標提醒，所以也可以拿來管「每月的咖啡預算」這種常態開銷。專案是各帳本自己的。

:::note 舊的分類預算
從舊版升級的人，原本設定的「分類預算」會自動變成專案，該分類過去的支出也會自動掛上對應專案。整個帳本的「總預算」不受影響，見 [預算](./budget.md)。
:::

## 怎麼操作

### 📱 在 App 上

**專案總覽**

底部導覽列的「專案」分頁就是專案總覽：

- 最上方是這個帳本的總預算長條（沒設定時顯示「設定總預算」）。
- 下方是專案卡片，顯示進度條、花費、剩餘與週期，已封存的專案會標「已封存」，沒設預算的標「純記錄」。
- 右上角的眼睛圖示可切換「顯示已封存」與「隱藏已封存」，「＋」是新增專案。

![專案總覽頁，上方總預算長條與兩張專案卡片](/img/prepare/project-1.png)

**新增專案**

1. 在「專案」分頁點右上角的「＋」（還沒有專案時可點「新增專案」）。
2. 輸入「專案名稱」，例如「日本旅行」。
3. 選「圖示」。
4. 輸入「預算金額」；只想記花費不設預算的話，打開「純記錄」。
5. 選「週期」：「每月」「每年」，或「固定期間」（要再選「起始日期」與「結束日期」）。
6. 視需要打開下方的選項（見下一節）。
7. 點「儲存」。

![新增專案頁，含名稱、預算、週期與各項開關](/img/prepare/project-2.png)

**專案的各項設定**

| 設定 | 作用 |
|---|---|
| 結轉上期結餘 | 上一期沒花完的預算，會加到這一期（只往前結轉一期；固定期間用不到） |
| 顯示於首頁 | 預設開啟，決定這個專案要不要出現在首頁相關區塊（目前主要影響 Web 的總覽頁） |
| 收入併入預算 | 這個專案裡記的收入，會加進可用預算（例如旅費有人幫你出） |
| 顯示每日預算 | 把預算平均到每天，顯示「每日預算」；可選「固定金額」或「按照比例」，固定期間與純記錄不能用 |
| 預算超標提醒 | 使用率超過門檻時推播通知；門檻可選 50%、80%、100%、120%，或用「自訂百分比」；預設 80% |
| 啟用中 | 編輯專案時才有；關掉就是停用，記帳時不會再選到 |

**記帳時指定專案**

1. 新增支出或收入時，找到「專案」欄位，點開「選擇專案」。
2. 選要歸入的專案，不想歸入就選「不指定專案」。

這個欄位只有在帳本已經有專案時才會出現。選專案時會顯示該專案目前的剩餘額度。用 AI 記帳時要不要自動判斷專案，見 [AI 記帳](../record/ai.md)；如果 AI 無法判斷，交易會先進「待確認專案」，專案總覽頁會出現入口讓你逐筆補選。

**專案詳情**

點專案卡片進入詳情頁：

1. 週期為「每月」或「每年」的專案，頂端有期間列，用左右箭頭翻到前後期，或點中間文字在「選擇區間」選過去 12 期。固定期間的專案只顯示起訖日。
2. 統計條顯示「出帳」「入帳」「總計」。
3. 預算卡顯示預算、「結轉」、「未分配」或「超額分配」，開啟每日預算時還有「每日預算」。
4. 下方的分類依序分成「已分配預算」「未分配預算」「未設定預算」三組，點分類可看它在這一期的交易。

右上角的鉛筆是「編輯專案」，齒輪是「分類子預算」。

**分類子預算**

想在專案預算裡再分配給各個分類（旅行預算 5 萬，其中住宿 2 萬、餐飲 1 萬）：

1. 在專案詳情點右上角齒輪，進入「分類子預算」頁。
2. 列出所有一級分類，在想設定的分類打開「設定子預算」。
3. 選「固定金額」或「按照比例」（0 到 100）並輸入數字。
4. 頁尾會顯示「已分配 X / 總預算 Y」，超過也不會擋你儲存，只是詳情頁會顯示「超額分配」。
5. 點「儲存」。

**刪除與封存**

在「編輯專案」頁刪除。專案如果沒有任何交易，會永久刪除；已經有交易時，會改為封存，既有交易仍保留專案連結，需要時可在專案總覽用眼睛圖示顯示已封存的專案。

### 💻 在 Web 上

1. 點上方導覽的「專案」。
2. 點「新增專案」，填「名稱」「圖示」「預算金額（可選）」「週期」等欄位，儲存。
3. 欄位對應 App：「預算自動結轉到下一期」就是結轉、「顯示在總覽頁」就是顯示於首頁、另有「收入併入預算」「顯示每日預算」「啟用預算超支提醒」與「提醒門檻（%）」。
4. 專案卡片上點「查看明細」可看交易。展開「顯示分類子預算」，用「新增分類預算」設定每個分類的「分配方式」（固定金額或百分比）。
5. 刪除時，已有交易的專案會改為停用而不是真的刪除，歷史交易不受影響。

Web 的專案圖示欄位可以直接輸入 emoji（例如 ✈️），同步後 App 的專案清單、詳情與記帳時的專案選擇都會顯示同一個 emoji。App 上選圖示則是從圖示庫挑。

![Web 的專案頁與新增專案視窗](/img/prepare/project-6.png)

## 注意事項／小提醒

:::tip 週期怎麼選
- 平常的固定開銷（每月零食、咖啡）：選「每月」，起算日跟著帳本的「每月起始日」，見 [帳本](./ledger.md)。
- 一次性的計畫（旅行、裝修、婚禮）：選「固定期間」，填起訖日。
:::

:::note 超標提醒
預算超標提醒是 App 在你記帳後，發現使用率超過門檻時發出的本機通知，每一期只會提醒一次。
:::

:::note 專案與預算的差別
專案預算是針對某個計畫；整個帳本每月能花多少，要用「總預算」。兩者獨立計算，見 [預算](./budget.md)。
:::

:::warning 注意幾個不會帶入專案的情況
退款交易不會自動帶入原交易的專案。在支出與收入分頁之間切換時，已選的專案會一起帶過去。
:::
