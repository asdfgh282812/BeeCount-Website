想知道「上次朋友聚餐總共花多少」，不必把餐費、交通費分散在不同分類裡慢慢加。把這幾筆交易綁到同一個「活動」，就能一起查看；也可以直接從手機行事曆的行程開始記帳。

> 📱 App：讀取手機行事曆與活動管理。　💻 Web：管理已建立的活動、綁定交易與查看統計。

:::note 截圖使用示範資料
下圖為 App 4.3.0 的實際畫面；「朋友聚餐」、「示範餐廳」與金額都是虛構資料。
:::

## 📱 開啟行事曆整合

1. 到「我的 → 提醒 → 行事曆整合」。
2. 開啟「使用手機行事曆」，依手機的系統提示允許行事曆存取。
3. 開啟「在首頁顯示」，就會在首頁選中日期的交易上方顯示行程。
4. 回到首頁，選擇有行程的日期；月曆有活動的日期也會顯示小點。

![行事曆整合設定，包含使用手機行事曆、在首頁顯示、活動列表、過濾與提醒](/img/record/activities-1.png)
*圖中：已開啟行事曆與首頁顯示；「活動」列可進入活動列表，下方可調整過濾與提醒。*

若曾拒絕權限，依 App 的提示到手機系統設定重新允許。手機行事曆本來沒有事件，或事件不在選取日期時，不會憑空出現行程。

### 折疊首頁行程 {#home-strip-collapse}

4.3.1 起，首頁的行程卡可以收合，行程多的日子不必一直占著畫面。

- **收合**：行程卡展開時，底部「查看所有活動」那一列的最右邊有一個向上箭頭，點一下收合。
- **收合後**：只剩一行，顯示色條、時間與行程名；當天不只一筆時，右側會帶「+N」與向下箭頭。
- **顯示哪一筆**：以現在的時間為準，進行中的行程優先，其次是最早開始的未來行程，再來是最近結束的行程，整天行程排最後。所以看過去的日子會顯示最晚的一筆，看未來的日子則顯示最早的一筆。
- **展開**：點整列即可，展開後仍有「查看所有活動」。
- **記憶**：收合或展開的狀態只記在這支手機上，不會同步到其他裝置。Web 沒有對應的首頁行程卡，所以沒有這項設定。

![首頁行程卡展開時列出三筆行程，底部「查看所有活動」右側有向上的收合箭頭](/img/record/activities-collapse-1.png)
*圖中：展開時列出當天行程，底部最右邊的向上箭頭可以收合*

![收合後只剩一行「09:30 團隊早會」，右側是「+2」與向下箭頭](/img/record/activities-collapse-2.png)
*圖中：收合後只剩最接近現在的一筆，「+2」代表另外還有兩筆行程，點整列即可展開*

示範圖的行程與交易皆為虛構，收合後顯示哪一筆會依你看圖當下的時間而不同。

### 隱藏不需要的行程

設定頁的「過濾」可以隱藏整本行事曆，或依事件條件隱藏：

- **隱藏的行事曆**：例如不想把工作行事曆放進記帳頁。
- **標題規則**：符合「包含」、「完全相同」或正規表示式的標題就隱藏，比對不分英文大小寫。
- **隱藏全天事件**、**隱藏短事件**、**隱藏已婉拒的邀請**、**隱藏週期性事件**：依自己的記帳習慣調整。短事件門檻不套用在全天事件上。

頁面下方的「今天的行程（預覽）」可協助核對。找不到事件時，先檢查日期、權限與這些過濾設定。設定只存在目前這支手機，換裝置要重新選擇。

## 從行程開始記一筆

1. 在首頁選中活動日期，點當天的行程。
2. 還沒建立活動的行程，可選「記一筆」或「綁定已記的消費」。
3. 選「記一筆」後，填金額、分類與帳戶；記帳表單的活動列會帶入這個行程。
4. 儲存交易，這筆消費就會歸到活動裡。已有活動時，也能從活動詳情按「記一筆」繼續新增。

![從朋友聚餐活動進入的記帳表單，專案下方的活動列已帶入朋友聚餐](/img/record/activities-5.png)
*圖中：「朋友聚餐」已帶進專案列下方的活動欄，仍需填寫金額與其他交易資料後儲存。*

也可以照平常的方式新增或編輯交易，再點「活動」列選擇。這一列會在開啟行事曆整合，或該筆交易原本已有活動時顯示。

:::tip 選了行程，取消記帳會怎樣？
只選取行事曆事件、最後取消儲存，不會留下空活動。事件會在實際儲存綁定的交易時，才建立成活動快照。
:::

## 把已記的消費綁進來

餐費已經記過，不需要重新輸入一次：

1. 打開活動詳情，按「綁定消費」。
2. 從活動前後的收支清單，勾選要歸到這次活動的交易。
3. 按「儲存」。活動的筆數與收支合計就會更新。

![綁定消費面板，朋友聚餐的餐費 1200 元與交通費 120 元已勾選，下方為儲存按鈕](/img/record/activities-4.png)
*圖中：勾選聚餐費用 TWD 1,200 與往返交通 TWD 120。清單依活動前後的日期列出交易，不是整本帳本的所有交易。*

**一筆交易只能綁一個活動。** 已歸到別的活動的交易會標示出來，改綁前先確認。要解除某筆的綁定，回到這個面板取消勾選，再儲存；不會刪掉交易本身。

## 查看活動、搜尋與收支

在首頁行程下方按「查看所有活動」，或到「我的 → 提醒 → 行事曆整合 → 活動」。列表屬於目前選用的帳本，可搜尋標題、地點、備註。

![活動列表顯示手動建立的週末小旅行，以及已綁兩筆消費、淨花費 1320 元的朋友聚餐](/img/record/activities-2.png)
*圖中：「朋友聚餐」有 2 筆交易，淨花費 TWD 1,320；手動建立的「週末小旅行」尚未綁消費，所以是 0 筆、TWD 0。*

列表右側的金額是**淨花費 = 支出 − 收入**。例如支出 1,200、收入 200，顯示 1,000；收入比支出多時會顯示負值。

點活動進入詳情，則分別顯示支出、收入、筆數，下方列出綁定的交易。點交易可看原本的交易詳情。

![朋友聚餐的活動詳情，支出 1320 元、收入 0 元、兩筆交易，並提供綁定消費與記一筆](/img/record/activities-3.png)
*圖中：餐費與交通費仍是各自獨立的交易，但能一起查看這次聚餐的花費。*

合計使用帳本幣別；設為「不計入收支」的交易仍可在活動詳情列出，但不算進合計。

## 手動建立、編輯與刪除活動

### 沒有行事曆行程，也能建立

在活動列表按右上角「新增活動」，填標題、開始／結束日期與時間，視需要設定「全天」、地點與備註，按「儲存」。建立後再到詳情記帳或綁定交易。

### 編輯既有活動

在詳情按右上角「編輯」，可修改活動標題、時間、地點與備註。手動新增也使用同一組欄位。

![編輯活動頁，可修改朋友聚餐的標題、全天、開始結束時間、地點與備註](/img/record/activities-6.png)
*圖中：編輯的是帳好嗎內的活動資料，不會修改手機行事曆的原始事件。*

### 刪除與解除綁定的差別

| 操作 | 結果 |
|---|---|
| 在「綁定消費」取消某筆勾選並儲存 | 只解除那筆交易與活動的關聯，活動和交易都還在 |
| 在詳情刪除活動並確認 | 刪除這筆活動，解除相關交易的綁定；原交易保留 |
| 關閉「使用手機行事曆」 | 停止讀取手機行事曆，已建立的活動與交易仍保留 |

以上操作都不會刪除手機行事曆中的原始行程。

## 活動結束後提醒記帳

到「行事曆整合 → 提醒」，開啟「活動結束後提醒記帳」，選擇結束多久後提醒，並允許通知。

- 只提醒過濾後、尚未綁消費的非全天事件。
- 每次安排未來 7 天的事件，最多 40 則；App 啟動或回到前景時會重新整理排程。
- 點提醒會開啟 App，再從首頁行程接續記帳；目前不會直接跳進某個活動。

## 報表與查帳

- **交易搜尋**：到首頁搜尋的「篩選 → 活動」，只看某個活動的交易。
- **統計報表**：使用「活動」維度或活動篩選，比較不同活動的收支。
- **AI 助理**：可問「朋友聚餐花多少」「上週有哪些活動」；查詢的是已建立、已記帳的活動資料。
- **月回顧與年度回顧**：資料符合條件時會整理活動花費；有綁消費的活動也會累積活動類徽章。

## 💻 在 Web 上

Web 的「資料 → 活動」分頁可查看目前帳本的活動，手動新增、編輯或刪除，從詳情按「記一筆」會帶入活動。要把已記的交易歸入活動，可編輯交易表單的活動欄位；App 的「綁定消費」勾選面板不在 Web 詳情內。日曆與報表也可查看已建立的活動資料。

**Web 不會直接讀手機行事曆。** 手機允許讀取的整份行事曆不會因此上傳；只有你綁定消費後建立的活動快照，或手動建立的活動，才會跟著帳本同步到其他裝置與 Web。活動資料含標題、時間、地點等資訊，共享帳本使用者應留意內容。

活動是建立當時的快照，之後手機行事曆有修改，不代表活動會持續自動跟著更新；需要時在活動詳情編輯。
