## 為什麼這樣設計

蜜蜂記帳功能不少，有些功能要先有別的東西才能用。例如要記信用卡刷卡，得先有一個信用卡帳戶；要看股票持股，得先有投資帳戶。手冊照「先準備、再記帳、再分析」的順序排章節，就是為了讓你不用跳來跳去。

## 手冊裡的寫法

- **「」括起來的字**是畫面上真的看得到的按鈕或選單名稱，例如「我的 → 授權金鑰」代表先點下方的「我的」，再點「授權金鑰」。
- **📱 App、💻 Web**標在頁面開頭，表示支援的平台。App 與 Web 操作不同時，頁面裡會分成「在 App 上」與「在 Web 上」兩段。
- **🔖** 是進階功能，新手可以先跳過。
- 範例裡的帳戶名稱、金額都是虛構的，例如「玉山銀行活存」「國泰 CUBE 卡」，只是方便說明。

## 建議的上手順序

1. **登入**：[安裝與登入](./install-login.md)
2. **建帳本與帳戶**：登入時已經幫你建好一本「預設帳本」，接著建立你平常會用的帳戶，例如錢包、銀行活存、信用卡。見[帳本](../prepare/ledger.md)、[帳戶](../prepare/account.md)。
3. **確認分類**：如果歡迎流程選了預設分類，這一步可以先略過，等用到再調整。見[分類](../prepare/category.md)。
4. **記第一筆帳**：[記第一筆帳](../record/first-record.md)
5. **需要時再往下**：預算、週期性收支、信用卡、投資等，用到再翻。

## 哪些功能要先準備什麼

| 你想做的事 | 要先有 | 參考 |
|---|---|---|
| 記一般收支 | 帳本、至少一個帳戶 | [帳戶](../prepare/account.md) |
| 刷信用卡、看帳單 | 一個「信用卡」類型的帳戶，並設好結帳日與繳款日 | [設定信用卡](../credit-card/setup.md) |
| 記股票買賣、看持股 | 一個投資理財帳戶 | [股票持股](../invest/overview.md) |
| 預算 | 帳本與分類 | [預算](../prepare/budget.md) |
| 跟朋友共用帳本 | 雙方都有帳號與授權 | [共享帳本](../sync/shared-ledger.md) |
| AI 記帳 | 先設定 AI 服務 | [AI 記帳](../record/ai.md) |

:::note
記帳時一定要選一個帳戶，所以建議在記第一筆帳前就先建好帳戶。
:::

## App 與 Web 畫面對照

兩邊資料互通，只是畫面的排法不同。

| 要找的東西 | 📱 App | 💻 Web |
|---|---|---|
| 記一筆帳 | 底部中間的「記帳」 | 「交易」頁，或 ⌘K 選「新建交易」 |
| 看明細 | 「記帳／明細」分頁 | 「交易」 |
| 帳戶 | 底部「帳戶」 | 頂部「帳戶」 |
| 專案 | 底部「專案」 | 頂部「專案」 |
| 報表 | 底部「報表」 | 「首頁」、右上角的日曆圖示、「比較報表」，年度報告在頭像選單 |
| 預算 | 入口請看[預算](../prepare/budget.md) | 頭像選單 → 預算 |
| 設定 | 底部「我的」 | 頭像選單 → 個人資料 等 |

App 底部有五個分頁：帳戶、專案、記帳（在明細頁時這顆叫「記帳」，在其他分頁時叫「明細」）、報表、我的。想讓 App 一頁一頁帶你看，可以到「我的 → 功能說明」，見[功能說明與新功能紀錄](./tour.md)。
