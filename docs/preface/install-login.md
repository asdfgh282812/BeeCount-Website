想開始記帳之前，要先把 App 裝好，再登入你的帳好嗎 Cloud 帳號。這個版本不是從 App Store 或 Google Play 下載的，安裝方式和一般 App 稍微不同，不過只要做一次。

> 📱 App

## 為什麼這樣設計

你的帳本存放在帳好嗎 Cloud 伺服器上，手機、平板和網頁共用同一份資料，所以 App 一定要先登入才能使用。授權金鑰則用來確認你是被允許使用的人，由管理員發給你。換手機或重灌時，登入之後資料就會自動回來，不用另外備份還原。

## 先準備好三樣東西

向提供帳好嗎給你的管理員索取：

1. **安裝檔的取得方式**：Android 是 APK 下載連結，iOS 是 SideStore 的軟體源（Source）網址。
2. **伺服器位址**：像 `example.com` 這樣的網址，登入時要輸入。
3. **授權金鑰**：格式像 `BC-XXXXX-XXXXX-XXXXX-XXXXX`。管理員帳號不需要金鑰。

## 怎麼操作

### 📱 Android：安裝 APK

1. 用手機瀏覽器開啟管理員給你的下載連結，下載 APK 檔。
2. 下載完成後，點開這個檔案。
3. 如果系統跳出「不允許安裝來自這個來源的應用程式」之類的提示，依畫面指示到設定允許，再回來繼續安裝。實際文字會因手機廠牌而不同。
4. 安裝完成後，點「開啟」。

:::tip 下載頁有好幾個檔案怎麼選
有些版本會同時提供 arm64 與 universal 兩種。近幾年的手機選 arm64 即可，不確定就選 universal。裝好之後，App 之後會自己挑對的版本更新。
:::

### 📱 iOS：用 SideStore 安裝

1. 先在 iPhone 上準備好 SideStore。SideStore 是第三方側載工具，設定方式請參考它自己的說明。
2. 在 SideStore 的「Sources」加入管理員給你的軟體源網址。
3. 在這個軟體源裡找到「TallyCheck - 帳好嗎記帳」，點「Install」。
4. 安裝完成後，從主畫面開啟。主畫面上的圖示名稱，中文系統顯示「帳好嗎」，英文系統顯示「TallyCheck」。

:::note 從舊版升級
手機上已經裝著 3.x 的話，不用解除安裝，直接用同一個管道更新就會覆蓋安裝，資料與登入狀態都會保留。Android 在 App 內檢查更新即可，見下方[更新 App](#更新-app)。
:::

### 📱 第一次開啟：歡迎流程

第一次開啟 App 會進入歡迎畫面，依序完成下面幾步。畫面下方有「上一步」可以往回修改，上方的圓點是目前的進度。

1. **選語言。** 歡迎畫面的清單只有「繁體中文」與「English」，預設依手機語言決定（中文系統選繁體中文，其他語言選 English）。確認好後按「下一步」，這個選擇會被存起來，之後可以到「我的 → 一般」改。

   ![App 歡迎畫面第一頁：「歡迎使用帳好嗎」與語言清單，下方有「下一步」](/img/preface/install-login-1.png)
   *圖中：歡迎使用帳好嗎的語言頁，清單只有繁體中文與 English，勾選的是目前語言*

2. **輸入伺服器位址。** 在「伺服器位址」輸入管理員給你的網址，按「連接」。連得上才會進下一步；如果出現「請輸入有效的伺服器位址」或「無法連接該伺服器，或伺服器未啟用 SSO」，請檢查網址有沒有打錯、手機有沒有連上網路。

   ![App 伺服器位址頁：標題「伺服器位址」、輸入框與「連接」按鈕](/img/preface/install-login-2.png)
   *圖中：伺服器位址頁，輸入框填入管理員給的網址後按「連接」*

3. **登入。** 按「使用 SSO 登入」，App 會開啟手機瀏覽器，請在瀏覽器裡完成登入。登入成功後會自動跳回 App。你不需要在 App 裡輸入帳號密碼。

   ![App 登入頁：「使用您的 SSO 帳號登入」與「使用 SSO 登入」按鈕](/img/preface/install-login-3.png)
   *圖中：登入頁，按「使用 SSO 登入」會開啟瀏覽器完成登入*

4. **輸入授權金鑰。** 如果你的帳號還沒有有效授權，會多出「需要授權金鑰」這一頁。輸入金鑰後按「啟用」，成功會顯示「授權已啟用，有效至 …」。已經有授權或是管理員帳號就不會看到這一頁。金鑰的詳細規則見[授權金鑰](../sync/license.md)。

   ![App 授權金鑰頁：標題「需要授權金鑰」，金鑰輸入框與「啟用」按鈕](/img/preface/install-login-4.png)
   *圖中：需要授權金鑰頁，輸入管理員給的金鑰後按「啟用」*

登入（與授權）完成後：

- **帳號在雲端已經有帳本**（例如你在網頁版用過、或這是換手機）：直接進到首頁，資料會同步下來，不會再被問一輪設定。
- **全新的帳號**（雲端還沒有任何帳本）：進入下面的「首次登入個人化引導」。

> 4.0 起，歡迎頁不再有「老用戶？匯入配置」的按鈕，也不再有選幣種與選分類模式的頁面，這些都併進了下面的引導或移到設定。要匯入舊的設定檔，登入後到「我的 → 資料管理」，見[匯入與匯出](../more/data.md)。

### 首次登入個人化引導

> 📱 App　💻 Web　（4.0 新）

全新帳號第一次登入後，App 會自動帶你走一段引導，把偏好調好、建好第一本帳本，再開始記帳。上方圓點是進度，共 6 步，每一步下方有「上一步」「下一步」：

1. **歡迎！先調成你的樣子**：挑「主題色」和「外觀模式」（跟隨系統、亮色模式、暗黑模式）。效果會直接呈現在這個畫面上。
2. **質感與造型**：選 Liquid Glass 的質感（清透、平衡、厚霧），以及每一頁頁首背後的「造型」（預設純色，也可以點「看全部造型」）。
3. **習慣怎麼看帳**：選每週起始日（星期日或星期一）、行事曆預設顯示（一週或一個月，預設一週）、餘額顯示格式（完整金額或簡潔顯示）、收支顏色方案，以及股票漲跌顏色。「行事曆預設顯示」僅於 App 生效；之後可到「我的 → 一般 → 行事曆預設顯示」修改。
4. **AI 智慧記帳**：決定要不要「啟用 AI 小助手」（打開時會先顯示隱私說明），也可以直接「設定服務商與金鑰」。不想現在設定也沒關係，之後再到「我的 → 智慧記帳」設。
5. **建立你的第一本帳本**：輸入帳本名稱（必填，沒填會提示「請輸入帳本名稱」），並選擇幣種，預設 TWD。按「下一步」才會真的建立帳本，沒有帳本就沒辦法開始記帳。
6. **新增你的第一個帳戶**：按「新增帳戶」建立現金、銀行或其他帳戶，帳戶的幣別會預先帶入帳本的幣種。也可以略過，之後到「資產」分頁新增。最後按「開始使用」就進到首頁。

*圖中：個人化引導第 1 步，挑主題色與外觀模式，效果當場套用*

![App 首次登入引導第 4 步：「AI 智慧記帳」，啟用 AI 小助手開關與「設定服務商與金鑰」](/img/preface/install-login-6.png)
*圖中：個人化引導第 4 步，AI 小助手的開關與設定入口，可以略過之後再設*

![App 首次登入引導第 5 步：「建立你的第一本帳本」，帳本名稱與幣種](/img/preface/install-login-7.png)
*圖中：個人化引導第 5 步，輸入帳本名稱並選擇幣種，這一步必填*

![App 首次登入引導第 6 步：「新增你的第一個帳戶」，「新增帳戶」按鈕](/img/preface/install-login-8.png)
*圖中：個人化引導第 6 步，新增第一個帳戶，也可以略過之後再到資產分頁新增*

幾件事先知道：

- 右上角的「略過」可以跳過前面的外觀與 AI 設定，直接跳到「建立你的第一本帳本」，因為帳本一定要建。最後一步的「略過」則是直接結束引導。
- 分類不需要在這裡選：帳好嗎 Cloud 會幫你建好預設分類，之後到「我的 → 資料管理 → 分類管理」調整，見[分類](../prepare/category.md)。
- 這段引導只有「雲端還沒有任何帳本、而且這個帳號沒做過」才會出現，而且是跟著帳號走：在另一支手機登入、或網頁版已經做完，就不會再問一次。目前沒有「重看一次」的入口，之後想改設定到「我的 → 外觀、一般、智慧記帳」即可。
- 💻 Web：全新帳號第一次進入網頁版時，也會跳出對應的全螢幕歡迎引導（外觀、AI、建立帳本與帳戶），做法與 App 一致，見[Web 版](../sync/web.md)。

### 登入之後第一次：圖片下載模式

第一次登入後，App 會問你「雲端圖片下載」要用哪一種：

- **即時下載**：所有雲端記錄的圖片自動下載到手機，花流量也佔空間，圖片少於 1,000 張時適合。
- **動態下載**：打開有圖片的記錄時才下載，省空間。

不確定就選動態下載，之後可以到「我的 → 雲端帳號與同步」裡的「雲端圖片下載」改。附件的用法見[附件](../record/attachment.md)。

## 更新 App

### 📱 Android

- **自動提示**：開啟或回到 App 時，如果有新版本，會跳出「發現新版本 x.y.z」，按「立即更新」就會下載並開啟系統安裝畫面。按「稍後」的話，同一個版本 24 小時內不會再自動提示。
- **手動檢查**：「我的 → 關於 → 檢查更新」，會顯示目前版本，已是最新會告訴你「當前已是最新版本」。

### 📱 iOS

iOS 不能由 App 自己安裝更新。有新版本時會跳出「有新版本可用」，提醒你回到取得安裝檔的管道（SideStore）更新。你可以按「知道了」，或「不再提示此版本」。

:::warning 版本太舊會被擋住
管理員可以設定「最低可同步版本」。如果你的 App 版本低於這個版本，App 會顯示「請更新 App」，更新前不能使用。更新完成後按「我已更新，重新檢查」即可。
:::

## 注意事項／小提醒

:::warning 自己登出會清掉這支手機上的資料
在「我的 → 雲端帳號與同步」按「登出」，確認後 App 會清空這支手機上的帳本資料並回到歡迎畫面，雲端的資料不受影響。上一個帳號還沒同步到雲端的修改會一併消失，所以登出或換帳號前請確認已經同步完成。換成另一個帳號登入時，也不會把前一個帳號的資料混進來。
:::

:::note 登入過期或被遠端登出，不會讓你不能記帳
如果登入過期、或這支手機在帳好嗎 Cloud 的裝置清單被移除，App 會跳出可以關閉的重新登入提醒，按「繼續離線使用」就能回到記帳畫面，本機的帳都還在，離線新增的帳也會保留。之後從「我的 → 雲端帳號與同步 → 登入」登入同一個帳號，就會接續同步。這和自己按「登出」不一樣，不會清除本機資料。
:::

:::note 沒有網路也能記帳嗎
可以。離線時記的帳會先存在手機，連上網路後自動補傳。授權至少每 7 天要連網確認一次，詳見[授權金鑰](../sync/license.md)。
:::

- 只有伺服器明確告訴 App「授權金鑰無效」時，App 才會顯示全螢幕的授權畫面，輸入有效金鑰之前無法使用；一般的登入問題、暫時連不上伺服器都不會把你擋在外面。
- 登入用的是瀏覽器完成的 SSO，App 本身沒有「註冊」按鈕。需要新帳號請洽管理員。
