每天早上同一家早餐店 65 元、每次搭捷運同一個帳戶扣款……這些固定又不定時出現的消費，每次都重選分類、重選帳戶很煩。把它存成交易範本，之後只要按「套用」，一筆交易就建好了。

> 💻 Web　僅 Web 有這個功能，App 沒有交易範本。

## 為什麼這樣設計

交易範本是「手動一鍵建立」，跟[週期性收支](./recurring.md)不同：週期性收支是設好後系統照時間自動產生，適合固定日期的款項（房租、訂閱）；範本是你自己決定什麼時候按，適合常常發生、但日期不固定的消費（早餐、咖啡）。

## 怎麼操作

### 建立範本

1. 右上角頭像（滑鼠移上去）→「工具」→「交易範本」。
2. 點右上角「新增範本」。
3. 填「範本名稱」，例如「早餐」。
4. 選「類型」：支出、收入或轉帳。
5. 填金額。
6. 支出與收入選「分類」與「帳戶」；轉帳則選「轉出帳戶」與「轉入帳戶」（轉帳要兩個都選才能儲存）。
7. 需要的話寫「備註」。
8. 點「新增範本」儲存。

![交易範本頁：新增範本視窗，已填早餐、支出、65、餐飲與帳戶](/img/record/template-web-1.png)

名稱與金額（要大於 0）一定要填。範本的建立、編輯與刪除只有帳本擁有者可以操作。

### 套用範本

1. 在交易範本列表找到範本，點右邊的「套用」。
2. 跳出「套用範本」視窗：可以改這次交易的時間（預設現在）、金額與備註，其他欄位沿用範本。視窗裡時間欄的標題目前顯示為「下次執行時間」，在這裡指的就是這筆交易的發生時間。
3. 再按「套用」，系統立刻建立一筆真實交易，提示「已根據範本建立交易」。

![套用範本視窗：可覆寫時間、金額、備註](/img/record/template-web-2.png)

### 編輯與刪除

每個範本列有「編輯」與「刪除」。刪除範本不會影響已經用它建好的交易。

:::note 欄位標題
範本表單的金額欄標題目前顯示為「預算金額」，這是畫面用詞，實際上填的是每次套用時的預設金額。
:::

## 注意事項／小提醒

:::tip 想要手機也能一鍵記
App 沒有範本，但有[建議分頁與常用金額](./fields.md)，在手機新增交易時能自動帶入常用的分類、帳戶與金額，操作也只要幾下。
:::

:::note 範本不含的資料
範本只存類型、金額、分類、帳戶與備註。標籤、專案、商家等其他欄位，套用後請到那筆交易再編輯。
:::
