# 信用卡帳單試算與自動扣款

> ⚠️ **僅 Cloud 版可用**：本頁功能是 BeeCount Cloud（自建服務端）獨有的進階功能，純 App 本機記帳沒有這個入口。

信用卡消費不像現金帳戶那樣「刷了就扣」，是累積到帳單日才結算、還款日才要繳。這個功能會依你設定的帳單日/還款日，自動算出「這期應繳多少、還剩多少沒繳」。

## 設定信用卡帳戶

建立帳戶時把類型選「信用卡」，填：

| 欄位 | 說明 |
|---|---|
| 帳單日 | 每月固定結算日（1–31） |
| 還款日 | 每月固定應繳日（1–31） |
| 信用額度 | 選填，用來顯示可用額度 |
| 銀行名稱 / 卡號末四碼 | 選填，方便辨識 |

多張卡如果是「同一份帳單合併繳款」（例如主卡+附卡），可以建一個「帳戶群組」類型的帳戶當容器，把實際刷卡的卡片設為它的子帳戶——實際消費記在子卡上，但應繳金額是整個群組合併計算。

## 查看帳單

點進信用卡帳戶詳情，會看到目前這期的：

- 本期新增消費、上期未繳欠款、應繳總額、已繳金額、剩餘應繳
- 分期付款目前欠款（跟一般消費分開統計但合併進總應繳）
- 可以左右翻頁看歷史或未來的帳單週期

![信用卡帳單總覽](https://photo.pnsgzomf.synology.me/i/2026/08/11/6a79f90573cc6.png)

多繳的錢不會憑空消失，會自動結轉到下一期抵扣。

## 自動扣款

在帳戶設定裡開啟「自動扣繳」，指定一個扣款來源帳戶。到了還款日，系統背景排程（每 15 分鐘跑一次）會自動嘗試扣款：

- 來源帳戶餘額足夠 → 自動轉帳繳清應繳金額
- 餘額不夠 → 先跳過並發通知，之後持續每輪重試，直到餘額足夠或你手動繳清為止

## 手動繳款

不想開自動扣繳的話，帳單頁面點「繳款」按鈕手動記一筆繳款交易即可，指定來源帳戶跟金額。如果繳的金額不夠清償合併帳單下所有子卡欠款，系統會按各卡應繳比例分攤。
