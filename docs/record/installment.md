用信用卡分 12 期買手機、把卡費轉成 6 期、或是有一筆要慢慢還的貸款，每個月要繳的錢其實都是事先講好的。與其每月手動記一筆，不如一開始就建好整個分期計畫，報表與預算就不會漏掉未來的支出。

> 📱 App　💻 Web　需登入**帳好嗎 Cloud**（計畫與各期交易會與 Web 同步）。

## 為什麼這樣設計

分期的每一期金額（本金加利息）是依總額、期數與利率算出來的，所以計畫建立時一次產生全部各期交易，各期的日期從首期起每月一次。每一期的金額不能隨便亂改，不然整體的攤還就對不起來，所以改動都走「計畫」的專用操作（修改某一期或連同之後各期、編輯整個計畫、調整利率、部分還本、提前結清），系統會幫你保護「已手動改過的期」不被後續重算蓋掉。設錯首次日期、總額或期數也不用刪掉重建，直接編輯就好。

攤還的算法與**帳好嗎 Cloud** 完全一致，App 與 Web 建出的計畫金額相同。

## 先看懂三種還款方式

| 還款方式 | 每一期本金 | 每一期利息 | 感覺 |
|---|---|---|---|
| 等額本金 | 每期一樣 | 依剩餘本金計算，越繳越少 | 前期壓力大，總利息較少 |
| 等額本息 | 本金逐期增加 | 逐期減少 | 每期繳的總額一樣，最好規劃 |
| 固定利息（Web 稱「固定利率」） | 每期一樣 | 以總額計算，每期一樣 | 常見於「每期手續費」的分期 |

年利率填 0 就是無息分期。利息可選「月息」（每期固定年利率 ÷ 12）或「日息」（依每期實際天數計算，月份長短會讓每期略有差異）。「寬限期」是前幾期只還利息不還本金，寬限月數必須小於總期數。「金額取整」會把每期金額取到整數元，湊不齊的尾差放在「第一期」或「最後一期」。

## 怎麼建立

### 📱 在 App 上（方式一：從記帳表單）

1. 新增交易頁選「支出」，填好分類、總金額、帳戶。金額就是分期總額，日期就是第一期的日期。
2. 在表單最底下的「一般／週期／分期／訂金」分段選擇選「分期」，下面展開分期欄位。這一格只在新增「支出」時出現，收入與編輯舊交易都沒有。
3. 設定「期數」（1 到 600）、「還款方式」、「年利率」（輸入 6 就是 6%）。
4. 需要的話展開欄位裡的「進階設定」：「計息週期」、「寬限期(月)」、「金額取整」、「尾差歸屬」。
5. 照常送出。系統會一次建立分期計畫與每一期的支出交易。期數或寬限期填得不合法時，送出會被擋下並提示。

4.0 之前，分期設定要點表單底部的「單次」列，開「進階設定」視窗再切到「分期」頁籤；現在直接在表單底部切換。

![表單底部選了「分期」：展開期數、還款方式、年利率](/img/record/installment-1.png)
*圖中：底部分段選擇停在「分期」，下方是期數、還款方式（等額本金、等額本息、固定利息）與年利率*

### 📱 在 App 上（方式二：從資產頁）

1. 底部「規劃」分頁 →「未來的錢」，點「分期付款」卡片。卡片右邊會顯示「尚有應繳」金額或「無未繳分期」。4.0 之前這張卡片放在「資產」頁最下方的「其他」分組，現在已搬到規劃分頁。
2. 在「分期付款」頁點右上角新增，進入「新增分期計畫」。
3. 填「總額」「期數」「首期日期」「還款方式」「年利率」，必要時展開「進階設定」。
4. 選「分類」（必填）與「帳戶」，需要時寫備註，儲存。

### 💻 在 Web 上

1. 右上角頭像（滑鼠移上去）→「記帳工具」→「分期付款」，點右上角「新增計畫」。
2. 填「總金額」「期數」「首期時間」，選「攤還方式」「年利率 (%)」「計息方式」，需要時填寬限期、「尾差歸入」、「金額取整」。
3. 選「分類」與「帳戶（如信用卡）」，儲存。

也可以在「建立交易」視窗打開「設為分期付款」（只有新增支出時才有）。

:::tip 設錯了不用重來
首期日期、總額、期數、利率建立後都能改，見下方[編輯整個計畫](#編輯整個計畫)與[修改這一期與之後各期](#修改這一期與之後各期)。
:::

## 調整計畫

### 📱 在 App 上

進行中的計畫可以做這些事：

| 操作 | 說明 |
|---|---|
| 編輯計畫 | 計畫卡上的「編輯」，開啟編輯整個計畫的頁面，補救首次日期、總額、期數、利率設錯。見[編輯整個計畫](#編輯整個計畫) |
| 修改這一期 | 展開各期後，點該期右邊的鉛筆，先選「修改此記錄」或「修改此記錄與之後各期」，再進入跟記帳一樣的編輯表單。見[修改這一期與之後各期](#修改這一期與之後各期) |
| 調整利率／還款方式 | 點該期的計算機圖示，從該期起換新的年利率或還款方式，重新攤還後面各期。已改過的期不會被動到 |
| 部分還本 | 輸入還款金額與日期，帳戶留空就用計畫的預設帳戶。系統產生一筆「分期部分還本」交易並重新攤還未來各期。全部還清則計畫變「已結清」 |
| 提前結清 | 彈窗顯示「預估結清金額」，確認後把未到期的期數全部清掉，產生一筆結清交易，計畫變「已結清」。預估金額僅供參考 |
| 終止未來分期 | 二次確認後刪除所有未到期的期數與交易，不產生任何交易，計畫變「已終止」 |
| 刪除 | 刪除整個計畫與所有相關交易，包含已發生的期，無法復原 |

已結清或已終止的計畫只剩「刪除」。

*圖中：「部分還本」視窗，填還款金額與日期，帳戶留空就用計畫預設帳戶*

![App 分期計畫的「提前結清」視窗：顯示預估結清金額與結清日期](/img/record/installment-4b.png)
*圖中：「提前結清」視窗，顯示預估結清金額、結清日期與帳戶*

### 💻 在 Web 上

計畫卡有「查看期數」、「編輯」、「調整利率」（可指定從第幾期開始）、「部分還本」、「提前結清」、「終止未來分期」、「刪除」。每一期的編輯流程與 App 相同：先選「修改此記錄」或「修改此記錄與之後各期」，改金額時再問後面各期怎麼處理。已手動改過的標示「已單獨編輯」。

## 修改這一期與之後各期

點分期交易的編輯（交易詳情的鉛筆，或「分期付款」頁展開後每期的鉛筆），先選要改多大範圍，然後進入跟一般記帳相同的編輯表單。表單上方會有一條提示，例如「正在修改第 4 期（僅此期）」或「正在修改第 4 期與之後各期」，類型固定是支出。

![App 點分期某一期的鉛筆後，底部彈出「這一期要怎麼修改？」，可選修改此記錄或修改此記錄與之後各期](/img/record/installment-5.png)
*圖中：點某一期的鉛筆，先選範圍：「修改此記錄」只改這一期，「修改此記錄與之後各期」把日期、分類、帳戶、備註套用到之後每一期*

![App 分期編輯表單：頂部顯示「正在修改第 4 期與之後各期」，其餘欄位與一般記帳相同](/img/record/installment-6.png)
*圖中：選了「與之後各期」後開啟的編輯表單，頂部多一條範圍提示，其餘跟一般記帳相同*

| 你改了什麼 | 修改此記錄（僅此期） | 修改此記錄與之後各期 |
|---|---|---|
| 日期 | 只動這一期 | 這期改成新日期，之後每期都落在**後續每個月的同一天**（31 號遇到小月會落在月底，下個月再回到 31）。改第 1 期等於改首次日期 |
| 金額 | 問你後面各期怎麼處理（見下） | 問你後面各期怎麼處理（見下） |
| 分類、帳戶、備註、商家 | 只改這一期 | 這一期與之後每一期一併改，計畫本身的預設值也跟著更新 |

只改日期不會鎖住金額，之後若再調利率仍會重算。已退款的期不會被平移。

**改金額時，後面各期怎麼辦？** 儲存時只要金額真的變了、而且後面還有期數，就會跳出選單：

- **只改這一期**：其他期不動，分期總額跟著增減。
- **之後每一期都改成這個金額**（僅「與之後各期」時出現）：手動鎖定過的期數保持不變，總額跟著變。
- **自動調整之後各期金額**：分期總額不變，差額依目前的利率與還款方式攤到後面各期。後面沒有可重算的期、或剩下的本金不夠攤時，這項不會出現。

取消選單就整個不儲存。整個修改在同一個動作內完成，失敗會整個回復。

## 編輯整個計畫

📱 App：「規劃 → 未來的錢 → 分期付款」，進行中的計畫卡上點「編輯」。💻 Web：計畫卡上的「編輯」。進入「編輯分期計畫」頁，欄位與新增時相同。

- **只改首次日期**：每一期平移成「新首期日 + 每月」，金額不變。
- **改總額、期數、利率、還款方式或進階設定**：存檔前會問「重新計算所有期數？」，確認後依新設定重算每一期，期數變多會補上、變少會刪掉多的。
- **改分類、帳戶、備註**：套用到所有未退款的期。

兩個限制：計畫裡只要有手動改過金額或已退款的期，總額、期數、利率、還款方式就會被鎖住（以免洗掉你手動改的金額），請到那一期用「修改此記錄與之後各期」；用「沖銷現有欠款」建立的計畫不能改總額與帳戶。已結清或已終止的計畫不能編輯。

## 從單筆交易操作

在首頁（或全部交易、搜尋）點分期產生的那筆交易，不會進一般編輯頁，而是依動作問你要怎麼處理：

- **編輯**：跳出「這筆交易由分期計畫管理」，五選一：「修改此記錄」（只改這一期）、「修改此記錄與之後各期」（日期、分類、帳戶、備註一併套用到之後每一期）、「調整利率／還款方式」（從這期起重新攤還）、「提前還本」、「提前繳清」。前兩項都會開啟跟記帳一樣的編輯表單，見[修改這一期與之後各期](#修改這一期與之後各期)。計畫已結清或已終止時沒有後三項。
- **退款**：二選一。「只退這一期」可改退款金額（改小就是部分退款）、日期與備註（預設「分期退款」），建立一筆收入退款，那一期標為已退款，原本那期交易保留。「整筆退款」要二次確認，會刪除整個分期計畫與所有期數交易。同一期不能重複退款。
- **刪除**：二選一，「只刪除這一筆」（只刪該期，不重算其他期；刪光最後一期會連計畫一起收掉）或「刪除整個分期計畫」（二次確認後全刪）。

Web 的對應視窗是「這是一筆分期付款交易」。

## 信用卡帳單分期：沖銷現有欠款 📱

把信用卡已經欠下的消費改成分期，卻不想再多記一筆新消費時，用「沖銷現有欠款」：

![App 從信用卡帳單點「轉為分期」：自動帶入帳戶，填總額、期數、首期日期、還款方式與年利率](/img/record/installment-bill.png)
*圖中：從信用卡帳單轉分期時，自動帶入帳戶，填分期總額、期數、首期日期、還款方式與年利率後儲存*

1. 在信用卡帳戶詳情頁「交易明細」分頁，帳單彙總卡片下方點「轉為分期」。也可以在「新增分期計畫」頁選一張信用卡帳戶，出現「沖銷現有欠款」卡片。
2. 打開「沖銷現有欠款」開關，畫面顯示「目前應繳餘額：…」。分期總額最多填到這個金額，比它小就是部分沖銷。
3. 設定期數、利率、還款方式後儲存。各期交易照常產生，但帳單的「應繳金額」會自動扣掉被沖銷的部分，舊消費不會被重複算成欠款。

沖銷不會刪除或修改舊交易，只影響「應繳金額」，不影響已用額度與淨資產，所以分期各期陸續到期期間，淨資產可能暫時比實際欠款更負，全部繳清後才回到正確。合併帳單群組（主帳戶）目前不支援沖銷，需改選單一信用卡。刪除該分期計畫後，沖銷自動失效。帳單相關說明見[帳單週期與提醒](../credit-card/billing.md)。

## 注意事項／小提醒

:::warning 與其他功能互斥
分期不能和週期性收支、拆帳同時使用，也不支援手續費／折扣。分期以帳本主要幣別計算，沒有幣別欄位。
:::

:::note 刪除要小心
在搜尋頁批次刪除時，分期交易會被略過，最後提示「刪了 N 筆、M 筆屬分期未刪」。要刪請到單筆交易或分期付款頁處理。若分期付款入口顯示有未繳、列表卻是空的，可到「我的」→「資料管理」→「資料清理」掃描並清掉孤兒資料。
:::
