帳戶建好、開始記帳之後，最常打開的就是資產頁：我現在有多少錢、欠多少、這個月是變多還是變少。這一頁說明資產頁每個區塊在看什麼，以及點進單一帳戶後會看到什麼。

> 📱 App　💻 Web

## 為什麼這樣設計

單看一個帳戶的餘額，看不出整體財務狀況。資產頁把所有帳戶（跨帳本）的餘額加總成「淨資產」，再用走勢圖同時呈現收支與淨值變化，一張圖就能知道錢是怎麼變的。

## 淨資產怎麼算

淨資產 ＝ 總資產 － 總負債。

- 現金、銀行卡等資產帳戶的餘額算資產；信用卡、貸款算負債。
- 外幣帳戶會依匯率折算成你的「顯示幣種」（預設 TWD）再加總，見 [多幣種與匯率](./currency.md)。缺匯率的幣別不會算進去，會在卡片上提示「未折算」。
- 在帳戶資訊裡關閉「納入總餘額」的帳戶不計入。
- 「投資理財」帳戶預設不納入，股票市值另外顯示在「投資市值（預估）」卡上。

## 怎麼操作

### 📱 在 App 上

**資產頁的區塊（由上而下）**

![App 資產頁的淨值趨勢圖：點選某一天會顯示當天的淨值](/img/prepare/account-overview-2.png)
*圖中：走勢圖上點任一天看當天的淨值；圖下方是日期、當天收支與「按日」區間切換，點日期可跳到「首頁」當天*

1. 淨資產卡：顯示淨資產、總資產、總負債，下方是走勢圖。
2. 「投資市值（預估）」卡：有持股才會出現，見 [股票持股](../invest/overview.md)。
3. 「待確認帳戶」：有交易還沒指定帳戶時才會出現，點一下會到「待處理中心」的「待處理」分頁逐筆補選。
4. 資產帳戶、負債帳戶分組：依類型分組列出帳戶。登入**帳好嗎 Cloud** 時，「信用卡」分組的標題列右邊有一顆 SwipeSmart 刷卡建議的設定按鈕，見 [SwipeSmart 刷卡建議](../credit-card/swipesmart.md)。
5. 「已隱藏」：被隱藏的帳戶。

應收應付（借還款）與分期付款不再放在資產頁，4.0 起搬到底部「規劃」分頁的「未來的錢」，見 [借還款](../record/debt.md) 與 [分期付款](../record/installment.md)。資產頁右上角由左到右是：眼睛（隱藏金額）、展開圖表、「＋」新增帳戶、齒輪（設定）。

每個分組標題旁有帳戶數量，後面還有兩個金額：「納入總額的小計」與「這一類全部帳戶的小計」。如果兩個數字不同，就代表其中有帳戶關了「納入總餘額」。

![資產頁，淨資產卡與資產帳戶分組](/img/prepare/account-overview-1.png)
*圖中：淨資產、總資產與總負債，可切換「淨值趨勢」與「資產構成」，下方是投資市值（預估）卡片與各分組*

**看走勢與構成**

1. 在淨資產卡上，點「淨值趨勢」或「資產構成」切換圖表。
2. 「淨值趨勢」是長條加折線：長條是收入與支出，折線是淨資產。直接在圖上點或拖曳，可以看某一天的數字。
3. 圖下方一列是「日期 ›　● 支出　● 收入　按日 ⌄」：左邊是選取那天的日期，中間是**那天的支出與收入**，分別用兩種顏色標示（例如 ● 0　● +52,003）；欄位放得下就顯示完整數字，放不下才兩個一起縮寫成 k／w，最右邊是統計區間按鈕。以前這裡只有收支相抵後的一個淨額。

![App 資產頁走勢圖：選取 10/10，下方列出當天支出與收入](/img/prepare/account-overview-chart-1.png)
*圖中：點選長條後，上方氣泡是當天淨資產；圖下方列出日期、當天的支出與收入，最右邊是「按日」區間按鈕*

4. 點圖下方列最右邊的「統計區間」按鈕（預設顯示「按日」），選「按日」「按週」「按月」或「按年」。
5. 點圖下方的日期標籤，會跳到「首頁」並選中那一天；按週、月、年則跳到該區間的第一天。
6. 圖表佔太多畫面時，點右側的箭頭可以折疊，再點一次展開。

**看大圖**

點資產頁右上角的「展開圖表」圖示（眼睛的右邊），會進入「收支與淨值走勢」全螢幕頁，畫面自動轉橫向。這裡也可以切換統計區間，兩邊各自記住你選的區間。

**單一帳戶的期間檢視**

點資產頁的一般帳戶（現金、銀行卡等），進入帳戶明細，在「交易明細」分頁會看到：

![App 一般帳戶的交易明細：本月收支統計、餘額趨勢與交易列表](/img/prepare/account-overview-4.png)
*圖中：一般帳戶的「交易明細」分頁，由上而下是期間列、本期收支統計、餘額趨勢、依類型分頁的交易列表*

1. 最上方是日期區間列，用左右箭頭翻月，點中間可以選更早的區間。區間照帳本的「每月起始日」算（見 [帳本](./ledger.md)）。
2. 往下是摘要橫條，只列出這個區間有資料的項目（支出、收入、轉出、轉入），並有「總計」。
3. 接著是餘額趨勢折線圖：右側有金額刻度，標題列右邊顯示選取那天的日期與完整餘額（預設是最新一天）。手指在圖上點一下或左右滑動，就會出現垂直線、圓點與金額氣泡，看到任何一天的餘額；選取的日期在下方軸上會加粗。隱藏金額時以 ** 遮住。

![App 帳戶餘額趨勢：點選 10/10，顯示當天餘額 168,459 的氣泡](/img/prepare/balance-trend-1.png)
*圖中：餘額趨勢圖，右側是金額刻度，標題列顯示選取的日期與餘額，圖上有金額氣泡*
4. 最下面是「支出」「收入」「轉出」「轉入」四個分頁，列出該區間交易；清單標題列的排序圖示可選「最新在前」或「最早在前」。

轉帳只會出現在「轉出」或「轉入」，不會混進支出或收入。信用卡與合併帳單主帳戶則是依帳單週期顯示，見 [信用卡帳單週期與提醒](../credit-card/billing.md)。

### 💻 在 Web 上

1. 點上方導覽的「帳戶」。
2. 頂端的卡片顯示「淨值（資產 - 負債）」，旁邊是資產與負債合計。
3. 卡片裡可以在「走勢」與「組成」之間切換，Web 會記住你上次看的是哪一個。
4. 帳戶涉及兩種以上幣別、而且已設定「顯示幣種」時，會出現折算後的淨資產卡，點「詳情」可看分幣種明細。還沒設定會提示「前往設定主幣種」，點下去就是設定「顯示幣種」。
5. 點帳戶卡片，開啟帳戶詳情視窗，向下捲動可看這個帳戶的交易。

Web 的淨資產卡會把借還款裡尚未結清的應收（加）與應付（減）一併算進去；App 的淨資產卡則不含借還款，借還款在「規劃」分頁的「應收應付款項」另外顯示。兩邊數字若差了借還款的金額，就是這個原因。

## 注意事項／小提醒

:::tip 數字對不上時先看這三件事
1. 有沒有帳戶關了「納入總餘額」。
2. 有沒有外幣帳戶缺匯率（卡片會顯示「未折算」，點一下可去設定匯率）。
3. 是不是看了不同裝置、還沒同步完。
:::

:::note 缺匯率的處理
缺少匯率的外幣帳戶不會計入合計。到「匯率管理」補上匯率（📱 我的 → 一般 → 匯率管理），或等自動匯率更新後就會算進來。
:::

:::note 圖表只算到今天
走勢圖當期只算到今天，沒有任何帳戶時顯示「暫無資料」。「隱藏金額」開啟時（資產頁頁首的眼睛，或「我的」→「隱私與安全」），圖兩側的金額軸會以 ** 遮住。
:::
