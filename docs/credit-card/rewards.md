「這張卡網購 3%、每月上限 300」「這個月限時活動指定通路 5%」——回饋規則一堆，月底到底拿了多少？在**帳好嗎**為每張信用卡設好回饋規則，記帳時勾一下是哪條回饋，之後就能隨時看到這期預估拿多少、離上限還差多少，消費一存檔，入帳日就會出現一筆對應的回饋收入，而且會跟著消費即時更新。

> 📱 App　💻 Web　　回饋交易的自動產生需要**帳好嗎 Cloud** 並登入

## 為什麼這樣設計

- 一筆消費通常只適用一種回饋方案，哪一條要套用，你比系統更清楚。所以由你在記帳時勾選，系統不會用分類去猜，避免同一筆錢被算進兩條規則。
- 門檻和上限這些「金額」的判斷交給系統算，你只需要把規則設好。
- 回饋交易由雲端在你記帳的當下算好，兩端用同一套算法，數字才對得上。手機和網頁上看到的預估是方便你記帳當下參考，實際金額以回饋交易為準。

## 怎麼操作

### 📱 在 App 上：新增回饋規則

1. 「資產」點進信用卡，切到「帳戶資訊」分頁，點「紅利回饋」那一列（右邊會顯示「N組回饋條件」）。也可以在「交易明細」分頁的「紅利回饋 (N)」卡片，點右上角的清單圖示。
2. 進入「紅利回饋清單」，點右上角「＋」。
3. 填寫「活動名稱」，例如「網購 3%」。
4. 選「回饋方式」：「按照%數」或「每筆固定金額」，再填數值。
5. 在「回饋機制」設定計算區間與入帳時機（見下方說明）。
6. 需要的話設定「回饋啟動門檻」、「計算方式」、「回饋上限」。
7. 在「其他設定」選「回饋入帳帳戶」（預設是這張卡本身），並設定活動開始與結束日。
8. 儲存。

列表分成「進行中 (N)」與「已結束 (N)」，進行中的規則可以長按拖曳排序。每一列右側的「⋯」有「複製」與「刪除」。

### 💻 在 Web 上：新增回饋規則

1. 頂部導覽列點「帳戶」，點開信用卡，找到「紅利回饋」區塊。
2. 按「+ 新增規則」。
3. 填「規則名稱」、「回饋方式」（百分比或固定金額）與數值。
4. 選「計算週期」、「回饋入帳時機」、門檻與上限。
5. 選「回饋帳戶」，按「儲存」。

規則列上有「編輯」、「複製」、「刪除」。已結束或停用的規則會收在「顯示已結束的活動(N)」裡。

### 規則欄位怎麼填

| 欄位 | 說明 |
|---|---|
| 回饋方式 | 百分比（例如 1.5%），或每筆固定金額 |
| 計算區間（Web：計算週期） | 「依照帳單區間」「依照自然月」「指定活動區間」三選一，見下方說明 |
| 回饋計算基準（僅 App） | 以「消費日期」或「入帳日期」決定算在哪一期 |
| 回饋入帳時機 | 「消費後立即入帳」「入帳日後結算」是逐筆入帳，可填天數，0 是當天、1 是隔天；「區間結束後」是整期結束一次結算；「僅手動入帳」是系統不產生回饋交易、由你自己入帳（見下方「僅手動入帳的規則」） |
| 回饋入帳月份偏移、回饋日期（僅「區間結束後」） | 整期回饋要在哪個月的幾號入帳：偏移 0 是期間結束的當月、1 是次月；日期是該月第幾號，超過月底就取月底。兩格都不填，就在期間結束當天入帳 |
| 期間累積消費門檻 | 這一期累積消費要達到多少才開始算回饋，預設無門檻 |
| 單筆消費門檻 | 單筆金額要達到多少才算，預設無門檻 |
| 計算方式 | 單筆、總額各自選「無條件捨去」「四捨五入」「無條件進位」「保留小數」。要和發卡行的算法一致才對得上 |
| 總額上限 | 這一期最多拿多少回饋，預設無上限 |
| 共同上限 | 多條規則填同一個代碼，會共用同一份上限額度（只在設了上限時才需要） |
| 回饋入帳帳戶 | 回饋金存進哪裡，選這張卡本身會直接抵扣帳單；選別的帳戶，則當成一般收入存進去 |
| 活動開始／結束 | 規則的有效期間，起訖日都算有效 |

:::note 逐筆入帳與累積門檻
「消費後立即入帳」、「入帳日後結算」是每筆各自入帳，等不到整期結束，所以「期間累積消費門檻」不適用。需要累積門檻的活動，請選「區間結束後」。
:::

### 指定活動區間（自訂期間）

限時活動不一定跟帳單日一致。「計算區間」選「指定活動區間」之後，「活動開始」與「活動結束」都必須填，整段活動（含起訖日）算作單一期，上限與門檻以整段活動累計，不隨帳單週期往前往後翻。活動結束後，規則會留在卡片上，直到你停用或刪除。

### 基本回饋與回饋金專案

在「其他設定」還有兩個選項：

- 「基本回饋」：每筆刷這張卡都適用的常態回饋可以打開。之後記帳時選這張卡，只要在活動日期內，就會自動勾選這條規則，不想要時仍可手動取消。複製規則時不會帶上這個開關，避免兩條同時被勾選而重複計算。
- 「回饋金專案」：預設回饋金會歸到原消費所屬的專案；整期彙總入帳的回饋金（一期只有一筆，沒有單一來源消費），則不歸專案，除非在這裡指定。想歸到別的專案就在這裡選；點右邊的清除鈕，改回「跟隨原消費專案」。只列出目前帳本中啟用的專案。

### 回饋交易：消費一存檔就出現（4.0 起）

4.0 起，回饋金不再等到入帳日才由排程「生」出一筆收入，而是跟消費即時連動：消費一存檔（App 同步上來、Web 輸入、週期性交易產生都算），同一次就在入帳日建好一筆專屬的回饋交易。例如自然月、次月 5 號入帳，10 月的消費一存，11/5 那天就已經有一筆回饋收入在等了。

- **整期結算**（回饋入帳時機是「區間結束後」）：同一條規則、同一期只有**一筆**回饋交易。這期新增、刪除、改金額、改勾選、退款，金額都會即時重算；累積消費跨過門檻才會出現，退回門檻之下就會消失，不會留 0 元的空交易。
- **逐筆結算**（「消費後立即入帳」「入帳日後結算」）：每筆消費、每條勾選的規則各一筆回饋交易。同一筆消費勾了 3 條規則就有 3 筆；取消勾選其中一條，只會刪掉那一筆；刪掉消費，它的回饋交易也一起刪掉。有同期上限時，依消費日期先後分配額度。
- **在哪裡看**：入帳日那天的「回饋金」收入，在交易列表第二行有「回饋」標籤。點開那筆收入，詳情裡有「信用卡回饋」區塊，列出規則名稱、期別（整期）或來源消費（逐筆）、目前計入幾筆消費、「預計 M/D 入帳」或「已入帳」，並有「查看計入的消費」可以跳去看是哪些消費。反過來，點開一筆消費，詳情的「這筆消費的回饋」會列出它產生的逐筆回饋交易，可以直接點過去。
- **可以改**：金額可以直接改，改掉的差額會像拆帳一樣多出一條「手動調整」（多拿是正、扣掉是負），交易詳情會分開列出「回饋計算」和「手動調整」，之後消費變動、系統重算時，只會動「回饋計算」的部分，你的調整一直保留。日期、帳戶、分類、備註、專案、標籤也都能自己改，之後重算會保留你改過的欄位。
- **不能改、不能做**：類型固定是收入、幣別跟著入帳帳戶，不能退款，也不能直接刪除（刪除會被擋下）。要讓它消失，請到消費上取消勾選那條回饋規則，或停用規則。

![App 回饋交易的詳情：「信用卡回饋」區塊列出規則、期別、計入消費筆數與預計入帳日，並有「查看計入的消費」](/img/credit-card/rewards-8.png)

![App 編輯回饋交易：金額下方顯示「回饋計算」與「手動調整」，改金額會多一條手動調整](/img/credit-card/rewards-9.png)
*圖中：金額下方即時顯示「回饋計算 X · 手動調整 ±Y」，改金額就會變成一條手動調整*

**已入帳之後**：回饋交易的日期到了（已入帳），整期的回饋就不再自動調整，事後再補勾或刪除那一期的消費，已入帳的金額不會跟著動，避免改到你對過帳的歷史，需要的話請自己編輯那筆回饋交易。逐筆的回饋則只有「它自己那筆消費」被改動時才會重算。改規則（回饋率、門檻、上限等）只重算**還沒入帳**的回饋，已入帳的不動。

**退款**：對有勾回饋規則的消費做退款，回饋會跟著減少：全額退款，回饋歸零；部分退款，依淨額重新計算。

**通知**：整期回饋剛入帳時，會在「待處理中心」的通知裡提醒你；逐筆回饋不通知。

:::note 4.0 之前已經勾好的消費
升級前已經勾選好回饋規則的消費，仍照原本的方式，到了入帳日才由雲端入帳，不會被改寫。只有升級後新勾的消費才走即時連動。同一期混到新舊兩種消費時，系統會自動合併計算，不會重複入帳。
:::

### 僅手動入帳的規則

回饋入帳時機選「僅手動入帳」的規則，系統**不會**自動產生回饋交易（編輯規則時下拉選單下方也會這樣提醒你）。要入帳時：

- 📱 App：信用卡「交易明細」分頁的「紅利回饋 (N)」卡片，點這條規則進入「紅利回饋明細」，按「手動入帳」。會開啟記帳頁，已經帶好收入、「回饋金」分類、這一期的預估回饋、入帳帳戶（規則設定的帳戶，沒設就用這張卡）和備註，確認後儲存。

![App 紅利回饋明細頁：摘要卡下方的「手動入帳」按鈕（僅手動入帳的規則才有）](/img/credit-card/rewards-10.png)
*圖中：僅手動入帳的規則，明細頁摘要卡下方多一顆「手動入帳」按鈕*

- 💻 Web：在規則的明細裡按「手動入帳」，指定入帳金額與帳戶，記一筆回饋收入。適合銀行實際入帳金額和系統算的有零頭落差時使用。

App 按完「手動入帳」存檔回到明細頁後，不會標示這一期已經入帳，再按一次會再記一筆，請自己留意。

## 注意事項／小提醒

:::warning 預估值不等於回饋交易的金額
手機與網頁上的預估是估算，沒有把「期間累積消費門檻」、「共同上限」這類要靠雲端整期資料判斷的條件算進去，也不含你對回饋交易做的「手動調整」。實際金額以回饋交易（由**帳好嗎 Cloud** 計算）為準，所以紅利回饋卡上的數字，可能和入帳日那筆回饋收入對不上。
:::

:::note 規則不再鎖定
4.0 起，規則有消費或回饋交易之後，回饋方式、比例、區間、門檻、上限、入帳時機這些欄位都還能修改。儲存後會提示「已儲存，尚未入帳的回饋會依新規則更新」：只有還沒入帳的回饋交易會重算，已入帳的不動。
:::

- 已被交易使用過的規則無法真的刪除，刪除時會改成停用，移到「已結束」。沒被使用過才會真的刪掉。
- 上限是整個週期共用的額度：同一期內所有套用這條規則的交易依時間先後消耗額度，用完之後的交易回饋為 0。交易資訊卡上若被別筆吃掉額度，會多一個「已達上限」標籤。
- 規則以自然月計算、但帳單週期橫跨兩個月時，明細會分月顯示、各自計算上限。
- 週期性交易換信用卡後，只會顯示屬於新那張卡的規則。
- 回饋規則不會依分類自動比對交易，記帳時要自己勾選（或靠基本回饋自動勾）。
- 回饋交易要用**帳好嗎 Cloud**，沒登入或用其他同步方式時，只有預估，不會產生回饋交易。
- 紅利回饋明細頁的標題仍固定備註優先，不受「備註顯示方式」影響。
