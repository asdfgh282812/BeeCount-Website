title: 設定信用卡
description: 設定信用卡的額度、結帳日與繳款日（可遇假日順延、單期調整），讓帳好嗎幫你切出每一期帳單；多張卡共用帳單時可用合併帳單主帳戶統一管理。
---

信用卡不像現金「刷了就扣」，而是累積到結帳日才出帳，再到繳款日前繳掉。**帳好嗎**只要知道你的「結帳日」和「繳款日」，就能幫你把消費切成一期一期的帳單、算出這期該繳多少、快到期時提醒你。

這一頁教你把一張信用卡設定好；如果同一家銀行的幾張卡共用額度和帳單，也會教你怎麼用「合併帳單主帳戶」一次管理。

> 📱 App　💻 Web

## 為什麼這樣設計

- 一期帳單是「上次結帳日的隔天，到本次結帳日」，因為銀行就是這樣切的。所以一定要先設結帳日，後面的帳單、對帳、提醒才算得出來。
- 同銀行的多張卡常常共用同一個額度、同一個結帳日和繳款日，也合併成一張帳單繳款。所以額度、結帳日、繳款日可以設在一個「主帳戶」上，底下的卡（子卡）不用各設一次。

## 怎麼操作

### 📱 在 App 上：新增一張獨立信用卡

1. 底部點「資產」，在「資產管理」頁點右上角的「＋」（新增帳戶）。
2. 帳戶類型選「信用卡」，輸入帳戶名稱，例如「國泰 CUBE 卡」。
3. 在「信用卡設定」區填寫「信用額度」、「帳單日」、「還款日」。三個都是必填，帳單日與還款日可選每月 1 到 31 日。
4. 想自己備忘的話，可以再填開戶行、卡號後四位（例如 1234）。
5. 如果這張卡建立時已經有欠款，「初始餘額」填負數，例如 -12,000。
6. 儲存。

![App 新增帳戶頁：類型選信用卡後，出現信用額度、帳單日、還款日與自動扣繳設定](/img/credit-card/setup-1.png)
*圖中：選了信用卡之後出現的信用額度、帳單日、還款日與自動扣繳設定*

設好之後，信用卡會出現在資產頁的「負債帳戶」區。上一期帳單還有欠款時，名稱旁會出現紅色的「可繳款 截止日」標籤。點進這張卡，就是這張卡唯一的家：帳單、對帳、繳款、紅利回饋，還有這張卡自己的繳費提醒，都從這裡進去。

### 💻 在 Web 上：建立一張獨立信用卡

1. 頂部導覽列點「帳戶」，按「建立帳戶」。
2. 輸入帳戶名稱，帳戶類型選「信用卡」。
3. 在「信用額度 / 帳單日 / 還款日」區塊填入三個欄位，帳單日與還款日填 1 到 31。
4. 「掛靠主帳戶」維持「不掛靠（獨立計算帳單）」，按「建立帳戶」。

![Web 建立信用卡的表單，顯示信用額度、帳單日、還款日欄位](/img/credit-card/setup-2.png)
*圖中：類型選「信用卡」後，填入信用額度、帳單日、還款日，再按「建立帳戶」*

:::note
帳單日與還款日一定要填，沒填的話，帳單、對帳、提醒這些功能都不會出現。
:::

### 🔖 合併帳單主帳戶

同一家銀行的幾張卡共用額度和帳單，可以先建一個「主帳戶（群組）」，再把各張卡掛到它底下。額度、帳單日、還款日只在主帳戶設一次。

![App 編輯主帳戶：群組設定裡的「信用卡合併帳單」開關，下方是共用的額度、帳單日與還款日](/img/credit-card/setup-3.png)
*圖中：開啟「信用卡合併帳單」後，下方是整組共用的信用額度、帳單日與還款日*

**📱 在 App 上**

1. 「新增帳戶」，類型選最後一個「主帳戶(群組)」，名稱例如「國泰世華」。
2. 在「群組設定」卡片打開「信用卡合併帳單」開關。
3. 填寫整組共用的信用額度（選填）、帳單日、還款日。
4. 儲存。
5. 回到各張信用卡，編輯該卡，在「主帳戶(群組)」選剛建好的群組。也可以在這個下拉選單最上方點「＋新增主帳戶」，現場建一個，建好會自動把目前這張卡掛上去。

掛靠之後，信用卡的編輯頁不再顯示額度、帳單日、還款日，改成「額度/帳單日/還款日已移至主帳戶「國泰世華」管理」，旁邊有「前往設定」可以直接跳過去。

**💻 在 Web 上**

1. 「建立帳戶」，帳戶類型選「主帳戶(群組)」。
2. 在「主帳戶設定(合併帳單)」區塊填共用的信用額度、帳單日、還款日，按「建立帳戶」。
3. 編輯各張信用卡，「主帳戶(群組)」選這個群組，按「更新帳戶」。

Web 的主帳戶一定是合併帳單，沒有「信用卡合併帳單」開關；這個開關是 App 才有，用來讓主帳戶也能當一般群組（例如把同一家銀行的台幣戶和外幣戶收在一起）。群組裡只要有信用卡，開關就會固定開著、不能關。

### 帳單週期與選擇區間

進入信用卡（或主帳戶）的明細頁，會看到「上次結帳日 – 本次結帳日」的帳單彙總，例如 7/05 – 8/05。

![App 信用卡交易明細點期間文字後的「選擇區間」清單，可以切到前幾期帳單](/img/credit-card/setup-4.png)
*圖中：點期間文字後跳出「選擇區間」清單，選要看的帳單期間*

- 📱 App：用左右箭頭一期一期切換；點中間的期間文字，會跳出「選擇區間」清單，直接選要看的那一期。清單只列到最早有資料的那一期。
- 💻 Web：在彈出視窗標題旁用左右箭頭切換；點中間的日期範圍會展開清單，直接挑一期。

一進來會先停在「最早還沒繳清的那一期」，全部繳清了才停在目前這一期。每一期各自怎麼算、提醒怎麼設，在[帳單週期與提醒](./billing.md)說明。

### 結帳日遇假日與繳款期限 📱

銀行的結帳日常常跟日曆對不上：遇到週末或國定假日會順延，或是某一期臨時不一樣。3.9.0 起，編輯信用卡時有三個設定，讓**帳好嗎**切出來的帳單期間和銀行帳單一致。（Web 的帳戶編輯視窗也有，見本節最後。）

**① 結帳日遇非工作日**

到「資產 → 信用卡（或合併帳單主帳戶）→ 右上角編輯」，在「帳單日／還款日」區塊往下找：

![App 編輯信用卡：繳款期限方式、結帳日遇非工作日開關與下次結帳日預覽](/img/credit-card/flex-edit-1.png)
*圖中：繳款期限方式的兩個選項與「結帳日遇非工作日」開關，開關下方一行是「下次結帳日」預覽*

打開「結帳日遇非工作日」後：

![App 打開結帳日遇非工作日：延後或提前、依地區假日，並預覽下次結帳日](/img/credit-card/flex-edit-2.png)
*圖中：選「延後」或「提前」與哪個地區的假日，預覽會寫出實際結帳日與原定日期*

- **延後／提前**：結帳日落在非工作日時，自動往後或往前挪到工作日。
- **依地區假日**：台灣、中國、香港、日本、韓國、美國擇一。非工作日 ＝ 週末 ＋ 該地區放假的日子（含補假，不含不放假的紀念日），假日資料沿用[節日](../more/appearance.md)功能，會自動更新。
- 設定下方會預覽「下次結帳日」，例如「2026/10/12（原定 2026/10/10）」。

這個日期會被所有地方採用：帳單期間的切分、紅利回饋期間、對帳、結帳隔天與繳款日的提醒，以及帳戶頁的「距還款日 N 天」。

:::note 補班日與繳款日
節日資料沒有「週六補班」的資訊，補班的週六仍視為週末。繳款期限**不會**因假日順延，照你設定的規則算出來的日期顯示。
:::

**② 繳款期限方式**

- 「每月固定日」：原本的做法，例如每月 25 號。
- 「結帳日後第 N 天」：有的銀行是結帳後固定幾天內要繳。選這個時，欄位會改成「結帳後天數」，填 1～31，例如結帳日是 10 號、第 15 天，繳款期限就是 25 號。

繳款日必須晚於結帳日；設成同一天時，會落到下個月。**帳好嗎 Cloud** 的提醒與自動扣繳日也改成同一個算法，已經設成同一天的卡，提醒日會從結帳當天變成下個月。

**③ 調整本期結帳日**

銀行某一期的結帳日臨時不一樣時，不用改整張卡的設定，只調那一期。到信用卡的「交易明細」，先翻到要調整的那一期，點期間列最右邊的日曆編輯圖示：

![App 調整本期結帳日：帳單期間、目前結帳日、預設結帳日，與「僅這一期」「每一期都變更」兩個選項](/img/credit-card/flex-adjust-1.png)
*圖中：上半部列出帳單期間、目前結帳日與預設結帳日，中間填銀行帳單上實際的結帳日，下方選套用範圍*

1. 在「帳單上實際的結帳日」選銀行帳單寫的那一天。只能選在上一期結帳日之後、下一期結帳日之前，避免期間順序亂掉。
2. 選套用範圍：
   - 「僅這一期」：只改這一期，下一期恢復原本的結帳日。
   - 「每一期都變更」：等同把帳戶的結帳日改成每月這一天，並清掉所有單期調整。
3. 這一期若有延後入帳的記錄（落在原本下一期第一天的那些），視窗會多一個核取方塊，可以一併移到新的下一期第一天。
4. 按「套用」。

調整過的期間，日曆圖示會變成強調色。再點開，會看到「目前結帳日」（強調色）與「預設結帳日」，還有「還原預設結帳日」按鈕；沒調整過的期間沒有這顆按鈕。

![App 已調整過的期間：目前結帳日 10/12 與預設結帳日 10/10 並排，並有「還原預設結帳日」](/img/credit-card/flex-adjust-4.png)
*圖中：目前結帳日與預設結帳日分開顯示，左下角有「還原預設結帳日」*

:::warning 改結帳日會重設個別調整
在編輯頁修改結帳日、遇非工作日規則或地區，儲存後先前「僅這一期」的個別調整都會被清掉。
:::

**合併帳單的子卡**：子卡沒有自己設結帳日時，「結帳日這一包」（結帳日、假日規則、地區、單期調整）整組沿用主帳戶；「繳款期限這一包」（繳款日與方式）則獨立判斷，各自退回主帳戶。在子卡上調整單期，實際寫在存放結帳日的那個帳戶（主帳戶）上。

**限制**：共享帳本裡別人的信用卡，目前一律當作沒有任何調整計算。

**💻 Web**：在「帳戶」頁編輯信用卡，帳單日／還款日區塊同樣有「繳款期限方式」與「結帳日遇非工作日」（延後／提前、依地區假日）。「調整本期結帳日」目前在 App 上操作。

![Web 編輯信用卡：繳款期限方式與結帳日遇非工作日開關](/img/credit-card/flex-web-1.png)
*圖中：Web 帳戶編輯視窗裡的「繳款期限方式」與「結帳日遇非工作日」*

## 注意事項／小提醒

:::tip 子卡沿用主帳戶
合併帳單底下的子卡，帳單週期一律跟著主帳戶的結帳日。子卡自己的明細頁、帳單彙總都會顯示成同一個週期。額度、繳款日、自動扣繳也只在主帳戶設定。取消掛靠後，子卡原本自己的設定會還原。
:::

:::note 結帳日當天的消費算哪一期
一期帳單的範圍是「上次結帳日隔天到本次結帳日（含）」。結帳日當天刷的消費，算在「這個結帳日結束的那一期」，隔天才開始算下一期。例如結帳日是 5 號，8/5 當天刷的算進 7/06 – 8/05 這期，8/6 的消費算下一期。時間以台灣時區（Asia/Taipei）為準。
:::

:::note 月底的結帳日
帳單日選 29、30、31 時，遇到沒有那一天的月份，會自動改成當月最後一天（例如選 31，二月就算 28 或 29 日）。
:::

:::warning 同一家銀行的卡才適合合併
只有銀行真的把幾張卡合成一張帳單、一起繳款，才建議用主帳戶。各自出帳的卡，請各自當獨立信用卡設定。
:::

- 記帳時的帳戶選擇器不會列出主帳戶本身，消費只能記在子卡上。
- 群組裡的子卡幣別可以不同，群組的帳單彙總一律換算成帳本的本位幣顯示。
