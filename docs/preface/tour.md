功能多了之後，打開一個頁面看到一排按鈕，不一定知道每個是做什麼的。App 會在你第一次進到各個頁面時，用「聚光燈」一步一步指給你看；錯過了或想再看一次，也隨時可以回來重播。每次更新後新增了什麼，則可以在「新功能！」查詢。

> 📱 App

## 為什麼這樣設計

導覽只在「第一次進到頁面」出現，不會每次都打擾你；而且「看過了沒」的紀錄會跟著你的帳號走，換手機或重灌後不用從頭再看一遍。想複習時，有一個固定的入口可以重播。

## 怎麼操作

### 第一次進頁面時的導覽

1. 第一次進到某個頁面，例如底部各分頁、新增一筆帳的畫面，畫面會變暗，並用一個框框圈出要說明的地方。
2. 看完說明卡，按「下一步」往下走，或按「上一步」回到前一步；最後一步按「完成」。
3. 說明卡上的「n / 總步數」會告訴你目前在第幾步。
4. 不想看，可以按「跳過這個導覽」略過這一個，或按「全部略過」一次略過所有導覽。

![App 功能導覽：畫面變暗並圈出目前介紹的區域，說明卡有「下一步」「跳過這個導覽」「全部略過」](/img/preface/tour-1.png)
*圖中：畫面變暗並圈出正在介紹的區域，旁邊的說明卡有「下一步」「跳過這個導覽」「全部略過」*

:::note
編輯既有的交易不會跳導覽，只有「新增」時才會。畫面上暫時沒有東西可以說明的步驟（例如還沒設預算），會自動跳過。
:::

### 重看功能導覽：「我的 → 功能說明」

1. 點底部的「我的」。
2. 點「功能說明」（在最下面「新功能！」「功能說明」「關於」「使用說明」那一組）。副標題會顯示「還有 N 個沒看過」，全部看過則顯示「重看任何一頁的功能導覽」。
3. 清單依頁面分組，依序是「主畫面」「記帳頁」「帳戶」「信用卡」「股票投資」「規劃」「報表」「我的」「農場」。每一項會寫出名稱、一句話說明和步數（例如「5 步」），右邊標示「已看過」「未看過」或「看了一部分」。
4. 點任何一項，App 會帶你到對應的頁面並重播這個導覽。

![App「我的 → 功能說明」頁：依主畫面、記帳頁等分組，右側標示每個導覽「已看過」或「未看過」，右上角是重設圖示](/img/preface/tour-2.png)
*圖中：功能說明頁依頁面分組列出所有導覽，每一項標示已看過、未看過或看了一部分，右上角的圖示可以全部重設*

信用卡與股票投資的導覽需要有資料才能示範。沒有的話不會硬開，會提示你缺什麼，例如「請先新增一張信用卡，才能重看這個導覽。」「請先新增一個投資理財帳戶。」先建好資料再來看即可。

:::tip 4.0 之後的東西搬到哪了
4.0 重新整理了功能入口。想知道某個功能現在在哪，最快的方法是從這裡點對應頁面的導覽，說明卡會直接圈出按鈕；也可以看[常見問題](../faq.md#以前的功能搬到哪裡了)的對照表。
:::

### 全部重設

在「功能說明」頁面右上角點重設圖示（提示文字是「全部重設」），確認「重設所有導覽？」後，之後第一次進各頁面時所有導覽都會再出現一次，並顯示「已重設所有導覽」。

:::warning
「全部重設」會影響你所有裝置上的導覽紀錄，想再看一次單一導覽的話，直接從清單點進去重播就好，不需要重設。
:::

### 查看「新功能！」

每次更新到新版本後，第一次開啟 App 會跳出「新功能！」，列出這個版本新增或修正的項目，看完按「知道了」。

![App 更新後第一次開啟跳出的「新功能！」視窗，列出這個版本的項目](/img/preface/whats-new.png)
*圖中：更新後第一次開啟跳出的「新功能！」，列出這個版本新增或修正的項目（例如 4.0.0 的「東西搬家了」「記帳頁新排版與快速記帳」），看完按「知道了」關閉*

![App「我的 → 新功能！」版本清單：最新版排最上面，標示「目前版本」與每版的項目數](/img/preface/tour-3.png)
*圖中：版本清單最新的在最上面，標示「目前版本」與每一版的項目數，點任一版看那一版新增與修正的內容*

想回頭看舊版本：

1. 點底部的「我的」。
2. 點「新功能！」。
3. 清單會列出有紀錄的版本（新的在前面），標出「目前版本」以及每個版本有幾項。
4. 點一個版本，就會顯示那個版本的內容。

這裡只能看到 3.3.0 之後有登記內容的版本。完整、依主題整理的版本說明請見[更新紀錄](../changelog.md)。

## 注意事項／小提醒

- 導覽目前涵蓋：底部導覽列、首頁（帳本、待處理中心、隱藏金額、日曆）、全部交易與搜尋篩選、通知分類、AI 助手、新增一筆帳（含拆帳、轉帳、借貸）、資產、規劃、報表與年度回顧、我的（雲端管理、智慧記帳與 AI 服務管理、帳本設定、分類顏色、Liquid Glass），以及信用卡、股票投資與農場的各個頁面。
- 4.0 起每個頁面只有一份導覽，不會同一頁跳好幾輪。舊版看過的步驟會被記得，升級之後不會整份重播，只會補顯示新增的內容。
- 如果某個導覽只看到一部分，清單會標「看了一部分」，下次進到那個頁面時會補顯示剩下的步驟。
- 全新帳號登入後的[首次登入個人化引導](./install-login.md#首次登入個人化引導)是另一件事：它帶你設定外觀、建帳本與帳戶，做完之後才會輪到各頁面的導覽。
- 網頁版沒有這套導覽，Web 的操作介紹見[Web 版](../sync/web.md)。
