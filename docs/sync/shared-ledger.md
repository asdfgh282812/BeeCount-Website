跟另一半一起管家用、跟朋友分攤旅費，大家各記各的最後還要湊在一起很麻煩。共享帳本讓幾個人在同一本帳裡一起記，每個人的手機都看得到最新的結果，也看得出每一筆是誰記的。

> 📱 App　💻 Web　共享帳本需要登入**帳好嗎 Cloud**，參加的每個人都要有自己的帳號與授權。

## 為什麼這樣設計

邀請用「6 碼邀請碼」而不是直接指定某個 email，是因為你不一定知道對方登入用的帳號。邀請碼有效期間短、只能用一次，被你傳給誰就由誰加入。帳本的所有人（所有者）掌管邀請與成員，其他人是「編輯者」，可以記帳，但不能刪掉整本帳或改帳本設定，避免誤操作。

## 角色與限制

| 角色 | 可以做什麼 |
|---|---|
| 所有者 | 建立帳本的人。可以邀請成員、移除成員、編輯與清空帳本、刪除帳本 |
| 編輯者 | 受邀加入的人。可以在帳本裡記帳與修改，可以查看成員，也可以自己離開帳本，不能邀請或移除別人，也不能編輯、清空或刪除帳本 |

- 每本共享帳本最多 5 位成員（含所有者）。
- 一本帳本同時最多有 10 個有效的邀請碼。
- 邀請碼是 6 個英文字母與數字（不含容易混淆的 O、0、I、1），一個碼只能讓一個人使用。
- 目前邀請出去的角色固定是「編輯者」。

## 怎麼操作

### 📱 在 App 上邀請別人（所有者）

帳本的設定與成員都集中在「帳本設定」頁。進入的方式有兩種：

- 點「我的 → 資料管理 → 帳本管理」，長按要共享的帳本，或點帳本右邊的 ⋯，在跳出的選單點「設定」。
- 在首頁點左上角的帳本名稱，在跳出的選單裡點目前帳本旁邊的設定按鈕（齒輪）。

接著：

1. 在「帳本設定」頁點「成員管理」。
2. 點「邀請新成員」。
3. 選「有效期」，可選 1 天、3 天或 7 天，按「產生邀請碼」。
4. 畫面會顯示邀請碼，可以按：
   - 「複製邀請碼」
   - 「分享給好友」：用系統分享，例如傳到 LINE
   - 「複製連結」

   需要另一組邀請碼時，按「產生另一個邀請碼」。
5. 把邀請碼傳給對方。如果邀請碼不小心外洩，請盡快撤銷（見下面 Web 的「撤銷邀請碼」）。

*圖中：帳本設定頁，可以看到帳本名稱、帳本幣種、每月起始日，下方有「成員管理」與「成員收支」*

![App 邀請新成員：產生後顯示的邀請碼與複製、分享按鈕](/img/sync/shared-ledger-2.png)
*圖中：產生邀請碼後，畫面會顯示邀請碼、失效時間，以及複製與分享的按鈕*

:::warning
不要把邀請碼貼到公開的群組。拿到碼的人都可以加入你的帳本。
:::

:::note 關於邀請連結
分享出去的連結長得像 `https://你的伺服器/invite/邀請碼`。對方點開後會在瀏覽器開啟網頁版：還沒登入會先登入，登入後自動跳出「加入共享帳本」並預覽邀請，按「接受邀請」就加入了。如果想用 App 加入，按這個對話框下方的「用 App 開啟」，App 會直接打開「加入共享帳本」頁並自動填好邀請碼。手機上點連結不會直接跳進 App，一律先開瀏覽器。最保險的做法，還是直接把 6 碼邀請碼給對方，請對方在 App 或網頁輸入。
:::

### 📱 在 App 上加入別人的帳本

1. 對方要先有帳號並登入，授權也要有效。
2. 點「我的 → 資料管理 → 帳本管理」（或首頁左上角的帳本名稱，在跳出的選單按「管理帳本」）。
3. 點最上方的「加入共享帳本」。
4. 輸入 6 碼邀請碼，按「驗證邀請碼」。如果是從邀請連結的「用 App 開啟」進來的，邀請碼會已經填好。
5. 會顯示「某某 邀請你加入」、你的角色，以及邀請還剩多久的有效期。確認沒問題，按「加入帳本」。
6. 成功後會顯示「已加入『帳本名稱』」，帳本會出現在你的帳本清單裡，帳本卡片上會有成員人數。

![App 加入共享帳本：輸入邀請碼並驗證後，顯示邀請人、角色與有效期](/img/sync/shared-ledger-3.png)
*圖中：輸入並驗證邀請碼後，畫面會顯示誰邀請你、你的角色與邀請的有效期，下方是「加入帳本」*

如果訊息是「邀請碼無效或已過期，請向邀請人索取新碼」，請對方重新產生；「你已經是該帳本成員」表示你已經加入了；「該帳本成員已滿，請聯絡帳本所有者」表示人數到上限了。

### 📱 管理成員

在「帳本設定」頁（進入方式見上面）點「成員管理」：

- 清單會列出每位成員與角色，你自己旁邊標「你」。
- 所有者可以點成員右邊的移除按鈕，確認後該成員立刻無法再使用這本帳本。
- 編輯者可以點「離開帳本」自己離開。離開後就看不到這本帳的交易了。

![App 成員管理：成員清單與角色，下方是邀請新成員](/img/sync/shared-ledger-4.png)
*圖中：成員管理頁，列出每位成員與角色，所有者可以移除成員或邀請新成員*

### 📱 查看成員收支

1. 進入共享帳本的「帳本設定」頁（「我的 → 資料管理 → 帳本管理」，長按帳本或點 ⋯ → 設定）。
2. 點「成員收支」（只有共享帳本才有）。
3. 上方可以切換「月」「年」「全部」。
4. 畫面會列出每位成員的總收入、總支出與筆數。右上角的重新整理按鈕可以更新資料。

:::note
共享帳本裡的交易，會在明細上顯示是誰記的（例如「小美 記的」），方便對帳。
:::

### 💻 在 Web 上

**加入共享帳本**

1. 點頭像選單「帳本與回顧」裡的「帳本」進入帳本頁，按右上的「加入共享帳本」；或按 ⌘K，選「加入共享帳本」。
2. 輸入邀請碼，按「預覽」。確認邀請者與「加入後角色」，再按「接受邀請」。

如果是點邀請連結進來，登入後會自動跳出這個視窗並填好邀請碼，視窗下方的「用 App 開啟」可以改在 App 裡加入。

**邀請與管理成員**

1. 在帳本頁找到要共享的帳本卡片，點卡片上的「成員/邀請」圖示；也可以點 ⋯ →「帳本設定」進入設定頁，再按「成員/邀請」；或在 ⌘K 選「管理目前帳本成員」。
2. 「成員」區可以看到所有成員，所有者可以移除成員，編輯者可以選「退出帳本」。
3. 「邀請碼」區選好有效期（1 小時、24 小時、3 天、7 天），按「產生邀請碼」。每個邀請碼旁邊有「複製邀請碼」與「分享」。

![Web 的「成員與邀請」視窗：成員清單，以及邀請碼的有效期與產生按鈕](/img/sync/shared-ledger-web-1.png)
*圖中：Web 的「成員與邀請」視窗，上方是成員與角色，下方可以選有效期、產生與撤銷邀請碼*

**撤銷邀請碼**

邀請碼還沒被使用但不想要了，在邀請碼清單按「撤銷」，確認後立即失效。目前只有 Web 可以撤銷。

**成員收支**

共享帳本的卡片上有「成員收支」按鈕（也在帳本設定頁裡），可以切換「本月」「本年」「全部」，看總收入、總支出、總筆數，以及「成員收支對比」和「支出佔比」圖表。

## 注意事項／小提醒

- 離開帳本時，這支手機上該帳本的資料會被清除，雲端資料不受影響。
- 帳本被所有者刪除後，其他成員手機上可能留有殘餘資料，可以到該帳本的「帳本設定」頁，在「危險操作」裡用「僅刪除本機帳本」清理。
- 所有者目前沒有轉讓所有權的功能。
