農場不會要求你「必須記帳才能玩」，它只是把記帳這個好習慣變成讓種田更輕鬆的小獎勵。記帳和農場之間有兩條線：**每天的水壺**，和**每週的結算**。

> 📱 App

## 為什麼這樣設計

- **跟自己比，不跟金額比。** 週結算看的是記帳習慣、支出和平常相比穩不穩定、近期有沒有結餘，不是看你花了多少、賺了多少。所以收入高低不會影響能拿多少好幣。
- **習慣比一次補登重要。** 「記帳日」看的是你**新增這筆交易的那一天**，不是交易發生的日期。週日晚上一口氣補登整週的帳，只算補登那天有記帳，不能這樣刷分。
- **下雨天不逼你記帳。** 下雨時作物會自動澆水，沒記帳也不會因此渴死；水壺只是讓晴天的照顧更從容。記帳是加分，不是門檻。
- **只算一本帳本。** 不同帳本可能幣種不同，合併起來會失真；共享帳本的交易又很難說清楚算誰的。所以農場只看你指定的**一本非共享帳本**。

## 怎麼操作

### 📱 水壺：每天記帳，澆水更輕鬆

- 水壺是「今天還能澆幾次水」。每天（台北時間）會補滿，**沒用完的不會累積到隔天**。
- 當天你在計分帳本裡新增了收入或支出，水壺就會**再多補一些**，同一天不會重複補。
- 只有「澆水」會用到水壺；除草、除蟲、收成都不需要。
- 點農場上方的水壺膠囊，可以看到今天還剩幾次。

![點水壺膠囊後彈出的氣泡，顯示水壺還有幾次](/img/farm/bookkeeping-1.png)
*圖中：點上方水壺膠囊，氣泡裡顯示今天水壺還剩幾次*

哪些記錄算「今天有記帳」：計分帳本裡新增的**收入、支出**。轉帳、退款、勾選「不計入統計」的交易都不算。

### 📱 週結算：每週依記帳表現領好幣

每週一凌晨，農場會結算**上一週**（週一到週日，與你在設定裡選的「每週起始日」無關），依這週的記帳表現算出分數並發好幣。分數主要看：

- **記帳習慣**：這週有多常記帳。
- **支出控管**：這週的支出和你平常相比是否穩定，也會考量你有沒有認真記帳。
- **存錢率**：近期收支的結餘情形。沒有收入的話這一項不納入評分。
- **預算達成**：看這週支出和預算的關係。沒有可用的預算時不納入評分，目前週結算畫面上會顯示為缺項。

可計分的項目會依資料是否足夠而調整；每週獎勵有上限。實際結果與加成請查看週結算明細。

#### 怎麼看、怎麼領

1. 在農場上方點**好幣**膠囊，進入「週結算」。有尚未領取的週數時，膠囊上會顯示數量。
2. 清單依週列出每一週的結果與「待領取」或「已領取獎勵」。
3. 點某一週，可以看到各項分數、基本獎勵、連續達標的加成，以及最後可領的好幣。
4. 按「領取好幣」，好幣才會存進農場錢包；已領過的週不能重複領。

![週結算清單：每週的分數與好幣，待領取的週有「領取好幣」按鈕](/img/farm/bookkeeping-2.png)
*圖中：週結算頁，每一週列出結果，尚未領取的週可以直接領取*

:::note
- 結算**只進行一次**。結算之後才補登或修改上週的交易，不會重新計算。
- 算出來還沒領的獎勵會一直保留，不會過期。不過單機農場如果你隔了很久才打開，太久以前的週不會再補算。
- 好幣是遊戲裡的獎勵，領取不會動到你任何真實帳戶。
:::

### 📱 計分帳本：選哪一本算分

進入「農場 → 設定 → 計分帳本」（或「我的 → 一般 → 農場設定」），可以挑一本帳本來計分。

- 第一次開啟農場時，預設是你當時正在使用的帳本；如果那本是共享帳本，會改用你自己的第一本非共享帳本。
- 清單只列出**非共享帳本**。如果你只有共享帳本，會提示先建立一本個人帳本才能參加週結算，種田本身不受影響。
- 計分帳本之後如果被設成共享，或被刪除，計分和水壺的記帳補充會暫停，農場會提醒你重新選一本（雲端農場也會發通知，點「前往查看」可以直接回到設定）。

![農場設定裡的計分帳本，點開後只列出非共享帳本](/img/farm/bookkeeping-4.png)
*圖中：計分帳本選單，只會列出非共享的帳本*

![農場畫面左下的警示膠囊，提示要選一本非共享帳本才能參加週結算](/img/farm/bookkeeping-5.png)
*圖中：沒有可計分的帳本時，農場左下會出現提醒，點它可以回到設定改選*

### 雲端農場要注意同步

雲端農場的週結算由伺服器用**已同步的交易**計算。如果你離線記了帳，記得在結算前後一小段時間內讓 App 連上線同步，否則那幾筆可能算不到。日常有網路的情況下不用特別在意，同步的細節見[雲同步與離線](../sync/overview.md)。

## 注意事項／小提醒

:::note
- 記帳日以「新增交易的那一天」判定，補登不能偷渡成好幾天。
- 單機農場在你打開農場時，才會檢查並補算已經過去的週；雲端農場則由伺服器照時間結算，不需要你打開 App。
- 想看每個人這週表現如何，可以看[社交：每週排行榜](./social.md)的記帳榜，榜上只會出現分數與名次，不會出現任何真實金額。
:::
