授權金鑰是你使用這個版本蜜蜂記帳的「通行證」。管理員發給你一組金鑰，輸入一次之後，手機 App 和網頁版都可以使用；快到期時再輸入一把新的，就能接著用。

> 📱 App　💻 Web

## 為什麼這樣設計

這個版本是由管理員架設、提供給特定的人使用，所以需要一個方式確認「誰可以用」。金鑰綁在你的帳號上，而不是綁在某支手機，因此你的手機、平板與網頁版共用同一份授權，換手機也不用重新啟用。管理員帳號本身不需要金鑰。

## 授權的基本規則

| 項目 | 規則 |
|---|---|
| 格式 | 像 `BC-XXXXX-XXXXX-XXXXX-XXXXX`，英文字母與數字，輸入時鍵盤預設大寫 |
| 綁定對象 | 綁你的帳號，不是綁手機 |
| 能用幾次 | 一把金鑰只能啟用一次，用過就不能再用 |
| 有效期間 | 從你啟用的那一天開始算，預設一年（管理員發放時可以調整，實際天數以管理員為準） |
| 快到期時 | 輸入新的金鑰，新金鑰的天數會接在目前到期日之後，不會吃掉剩下的天數 |
| 過期後 | 要輸入一把新的金鑰才能繼續用，舊的金鑰不能重複啟用 |
| 管理員帳號 | 免金鑰 |

## 怎麼操作

### 📱 第一次輸入金鑰

第一次登入時，如果帳號還沒有授權，會自動出現「需要授權金鑰」頁。

1. 在輸入框填入管理員給你的金鑰。
2. 按「啟用」。
3. 成功後會顯示「授權已啟用，有效至 yyyy-MM-dd」，並繼續後面的設定。

這個流程也是[安裝與登入](../preface/install-login.md)歡迎流程的一部分。

### 📱 查看到期日、輸入新金鑰

1. 點底部的「我的」。
2. 點「授權金鑰」（在「資料管理」下方）。
3. 上方會顯示「授權到期日：yyyy-MM-dd」。如果你是管理員，會顯示「管理員帳號，免授權」。
4. 「離線可用至：yyyy-MM-dd」是在沒有網路時，這支手機最久可以用到哪一天。
5. 要延長授權，在下方輸入新的金鑰，按「啟用」。畫面上的提示是「輸入新的金鑰會從目前到期日往後延長該金鑰的天數。」

### 💻 在 Web 上

1. 第一次用 Web 登入時，如果帳號沒有授權，登入後會直接看到「需要授權金鑰」頁，請輸入金鑰並按「啟用」。
2. 想查看或延長，從右上角頭像選單進「個人資料」，找到「授權」區塊。會顯示「授權到期日」，沒授權時顯示「尚未啟用授權」，已到期則標「已到期」。
3. 在這裡輸入另一把金鑰，按「延長授權」。

## 離線 7 天規則

App 每次連上伺服器確認授權有效後，就可以離線使用 7 天，而且不會超過金鑰本身的到期日。例如金鑰還剩 3 天到期，離線期限就只有 3 天。

- 7 天內只要連上網路一次，期限就會重新往後算 7 天。
- 超過 7 天都沒連網，App 會顯示「需要連網驗證授權」，並說明「授權至少每 7 天需要連網驗證一次」。連上網路後按「重試」就會恢復。
- 手機把系統時間往回調是沒用的，App 偵測到時間不合理時，也會要求連網確認。

:::tip
平常有開網路的話，你完全不會感覺到這個限制。出國或長時間沒網路前，記得先開一次 App 讓它確認授權。
:::

## 授權失效時會看到什麼

- **到期**：開啟 App 會出現「需要授權金鑰」，並寫著「你的授權已於 yyyy-MM-dd 到期，請輸入新的金鑰。」輸入新金鑰即可。
- **使用中被管理員停用或到期**：App 開著時也會在一段時間內重新確認，確認後同樣會切到授權頁。
- **要換帳號**：在授權頁按「登出並切換帳號」。登出後換帳號會清掉這支手機上原本的資料，見[安裝與登入](../preface/install-login.md)。

## 輸入金鑰時的錯誤訊息

| 看到的訊息 | 怎麼辦 |
|---|---|
| 請輸入授權金鑰 | 輸入框是空的 |
| 金鑰格式不正確 | 檢查有沒有少打、多打，或把 0 和 O 弄混 |
| 找不到這把金鑰，請確認是否輸入正確 | 重新核對，或向管理員確認金鑰 |
| 這把金鑰已經被使用過了 | 金鑰只能用一次，請向管理員要新的 |
| 這把金鑰已被停用 | 管理員已撤銷，請洽管理員 |
| 嘗試次數過多，請稍後再試 | 短時間輸入錯太多次，等一會兒再試 |
| 無法連線到伺服器，請檢查網路後再試 | 確認手機有網路 |

## 注意事項／小提醒

:::warning 不要把金鑰貼到公開的地方
金鑰一旦被別人先啟用，你就不能再用了。傳給家人或朋友時，請用私訊。
:::

- 金鑰是管理員發的，App 裡沒有購買或申請的入口。
- 如果你的 App 版本太舊，會先看到「請更新 App」，更新後才會進到授權流程。
