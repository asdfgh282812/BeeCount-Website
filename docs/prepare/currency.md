出國刷日圓、網購付美金、帳戶裡放著一筆外幣定存，這些都不用另外開一個 App。**帳好嗎**預設以新台幣（TWD）為主，遇到外幣時會依匯率折算回新台幣，讓淨資產、統計報表都用同一把尺。

只用新台幣的人可以直接略過這一頁，什麼都不用設定。

> 📱 App　💻 Web

## 為什麼這樣設計

外幣的金額不能直接跟新台幣相加，所以每筆外幣交易和帳戶，都要有一個折算成本位幣的數字。匯率預設自動取得，但實際換匯、刷卡的金額常常跟牌價有落差，所以所有需要匯率的地方，都讓你能手動修正成真實的金額。

## 「顯示幣種」與「帳本幣種」

4.0 起，原本都叫「主幣種」的兩個設定正式分開命名：

| 名稱 | 設定位置 | 用在哪裡 |
|---|---|---|
| 帳本幣種（帳本的本位幣） | 新建帳本，或「帳本設定」→「帳本幣種」，見 [帳本](./ledger.md) | 這個帳本的統計與外幣交易折算的目標 |
| 顯示幣種（整個 App 共用） | App「我的」→「一般」→「顯示幣種」；Web「個人資料」→「顯示幣種」 | 資產頁淨資產、資產構成的折算目標，以及匯率管理的基準 |

兩個預設都是 TWD，絕大多數人不用改。

## 怎麼操作

### 📱 在 App 上

**建立外幣帳戶**

![App 記帳頁的「選擇幣種」清單，每個幣別下方顯示目前的匯率](/img/prepare/currency-1.png)
*圖中：記帳頁的「選擇幣種」清單，可搜尋幣別（中文或代碼），每個幣別下方顯示目前的匯率*

1. 資產頁點右上角「＋」，進入「新建帳戶」。
2. 點「幣種」，在選擇清單裡挑外幣，例如日圓。清單上方會優先列出帳本幣種與你已經在用的幣別，並附國旗與匯率。
3. 填名稱與「初始資金」（以該幣別計）後儲存。

帳戶一旦有交易，幣種就不能再改。

**記外幣消費**

1. 新增支出或收入，在「帳戶」選外幣帳戶（清單會列出所有幣別的帳戶，外幣帳戶副標題會標幣別代碼）。
2. 輸入外幣金額，金額下方會顯示折算成帳本幣種的預覽，例如「≈ NT$1,830」。
3. 想核對或修正，點那一列開啟「幣別換算」：有「換算金額」與「匯率」兩欄，改任何一欄另一欄會跟著算。預設開著「採用線上匯率」，兩欄唯讀；關掉後就能手動輸入，以你填的為準。
4. 完成後送出。

你也可以不換帳戶、只改幣別：選好台幣帳戶後，點金額列的幣別，改選日圓，輸入日圓金額。交易會以日圓記錄，並折算回帳本幣種。

**跨幣別轉帳**

轉出與轉入帳戶幣別不同時（例如台幣戶轉到日圓戶），轉帳頁會多出「轉入金額」與匯率列。預設用線上匯率自動算；銀行實際入帳的金額不同時，關掉「採用線上匯率」，手填真正入帳的金額。步驟見 [轉帳](../record/transfer.md)。

**查看與修正匯率**

1. 到「我的」→「一般」→「匯率管理」（4.0 起這是正式入口，同一頁的「顯示幣種」也在這裡）。也可以在資產頁點齒輪「設定」進入，不過這個入口只有在你使用了兩種以上幣別時才會出現。
2. 最上方是「顯示幣種」，點它可更換。
3. 下方列出你正在使用的每個外幣，顯示目前匯率（1 外幣等於多少顯示幣種）、來源「自動」或「手動」與更新日期。還沒取得時顯示「未取得」。
4. 點某個幣別開啟「編輯匯率」，輸入你想用的匯率，儲存後來源會變成「手動」。要回到系統匯率，點「恢復自動」。
5. 右上角的重新整理圖示可以立刻重抓匯率，成功會提示「匯率已更新」。

頁面底部說明：匯率來源是開源匯率資料、每日更新，折算僅供參考，可能與銀行實際牌價有差異。

![App「我的 → 一般」頁：顯示幣種與匯率管理在最上方](/img/prepare/currency-4.png)
*圖中：「一般」頁第一組有「顯示幣種」與「匯率管理」（另有每月起始日捷徑與農場設定），第二組是語言、每週起始日、行事曆預設顯示、餘額顯示格式、收支顏色方案與股票漲跌顏色*

![App 匯率管理頁：顯示幣種與各外幣的目前匯率、來源與更新日期](/img/prepare/currency-2.png)
*圖中：「匯率管理」頁列出正在使用的外幣匯率，右上角可重新整理，點某個幣別可編輯匯率*

**外幣帳戶在資產頁：顯示幣別、一鍵換算顯示幣種**

帳戶的幣別和顯示幣種不同時（例如顯示幣種是 TWD 時的「日圓現金」），資產頁每一列的金額前面會標出幣別代碼，右邊多一個 ⇌ 按鈕。點一下，這一列就切換成換算後的顯示幣種金額，再點一下切回原幣別。所有類型的帳戶都一樣，不限於投資理財帳戶。

![App 資產頁的外幣帳戶：金額前標示 JPY，右邊的 ⇌ 可切換成換算後的顯示幣種金額](/img/prepare/account-foreign.png)
*圖中：外幣帳戶的金額前面標示幣別（JPY），右邊的 ⇌ 按鈕可切換成換算後的顯示幣種金額；群組合計在這張圖開了簡潔顯示，所以是「萬」*

:::note
如果還沒有那個幣別的匯率、算不出換算金額，⇌ 按鈕就不會出現。App 不會拿 1.0 去假裝換算。到「匯率管理」補上匯率即可。
:::

**換算金額取整**

外幣換算成帳本幣別之後，小數怎麼處理，可以依帳本自己決定：

1. 在資產頁點右上角的齒輪「設定」。
2. 在「設定」視窗找到「換算金額取整」，選「無條件捨去」「四捨五入」或「保留小數」。

![App 資產頁設定視窗的「換算金額取整」：三個選項](/img/prepare/currency-rounding.png)
*圖中：資產頁齒輪的「設定」視窗，「換算金額取整」可選無條件捨去、四捨五入或保留小數*

- 這一項只有帳本裡用到兩種以上幣別時才會出現。
- 預設值看帳本幣種：台幣、日圓、韓元的帳本預設「無條件捨去」到整數；其他幣別（例如美元帳本）預設「保留小數」，免得 $3.09 被悄悄顯示成 $3。
- 每個帳本各自設定，並且跟著你的雲端帳號同步，換手機會一致。
- 取整是「每個帳戶、每種幣別各自取整再加總」，所以畫面上的小計加起來一定對得上。

設計理由：台幣沒有零錢，把換算後的金額顯示到小數點以下只是干擾；但每個人對「捨去還是四捨五入」的習慣不同，所以讓你自己選。

:::warning
取整只影響「顯示用」的換算金額：帳戶列的 ⇌ 換算值、分類小計、折算明細、淨資產卡與資產構成圖。原幣別的金額、統計報表、以及交易本身記下的金額都不受影響；資產頁的淨值趨勢圖和桌面小工具則維持不取整的算法，所以兩邊的零頭可能差幾元。
:::

**更換顯示幣種**

到「我的」→「一般」或「匯率管理」頁點「顯示幣種」，選新的幣別。如果新的顯示幣種已經有你手動設過的匯率，會提示並立即套用，然後重新取得自動匯率。

### 💻 在 Web 上

1. 點右上角頭像，在「設定」群組選「個人資料」。
2. 「顯示幣種」下拉選單可更換顯示幣種（提示說明為「資產折算的目標幣種，與 App 端同步」）。
3. 同一頁往下的「匯率管理」卡片，列出各外幣匯率，可「編輯匯率」或「恢復自動」，也可按「重新整理匯率」。
4. 帳本幣種在「帳本」頁的「帳本設定」裡設定。
5. 帳戶頁在涉及兩種以上幣別、且已設定顯示幣種時，會顯示折算後淨資產；沒設定會提示「前往設定主幣種」，點下去就是設定顯示幣種。

![Web 個人資料頁的顯示幣種與匯率管理](/img/prepare/currency-3.png)
*圖中：Web 個人資料頁的「顯示幣種」（會跟 App 同步）與「匯率管理」，可按「重新整理匯率」*

## 外幣帳戶的買入均價 {#fx-cost}

換匯存了一筆日圓、美元之後，很自然會想問：「我當初平均用多少匯率買的？現在賺還是賠？」4.3.4 起，外幣帳戶多了「買入均價」卡片，替你從交易紀錄算出來，不用另外做試算表。

> 📱 App　💻 Web

### 為什麼這樣設計

買入均價預設由帳戶裡**已經有的交易**即時算出來：只採用成本確實知道的紀錄，不知道的就不猜，寧可少算也不亂算。如果外幣帳戶在開始記帳前原本就有一筆餘額（沒有換匯買進紀錄），4.3.5 起也可以手動補填「期初均價」當作起算基準，讓後續買賣接著算移動平均。

### 哪些帳戶有、怎麼看

只有「帳戶幣別和帳本幣種不同」，而且類型是現金、銀行帳戶、行動支付或其他的帳戶才有這張卡片。信用卡、帳戶群組、貸款與股票帳戶沒有「買入」的概念，不會顯示。

- 📱 **App**：資產 → 點開外幣帳戶 →「資訊」分頁，在「帳戶資訊」卡片下方。
- 💻 **Web**：帳戶 → 點開外幣帳戶，帳戶詳情視窗的同一個位置。

![App 外幣帳戶「資訊」分頁的「買入均價」卡片：目前持有的買入均價、目前匯率、持有成本與匯兌損益](/img/prepare/currency-fx-cost-1.png)
*圖中：「持有」視圖顯示目前持有的買入均價、目前匯率、持有成本，以及未實現與已實現的匯兌損益*

卡片上方可以切換視圖：

| 視圖 | 看到什麼 |
|---|---|
| 持有 | 目前持有的買入均價、目前匯率、持有成本、未實現匯兌損益與已實現匯兌損益 |
| 7 天、1 個月、3 個月、1 年 | 只看這段期間內買進的平均匯率，方便對照銀行 App 的「近一年平均買進匯率」 |

![App 買入均價卡片切到 1 個月：顯示這段期間的平均買進匯率](/img/prepare/currency-fx-cost-2.png)
*圖中：切到「1 個月」，只計算這段期間內買進的加權平均匯率*

![Web 帳戶詳情視窗裡外幣帳戶的買入均價卡片](/img/prepare/currency-fx-cost-web-1.png)
*圖中：Web 帳戶詳情視窗的「買入均價」卡片，視圖與資訊和 App 一致*

### 怎麼算

- 採**移動平均成本法**：每次買進，把新買的外幣與成本併進去重新算均價；賣出不會改變均價，只會減少持有量與成本，並結出已實現的匯兌損益。
- **手續費計入成本**，所以均價是含手續費的實際匯率。
- 未實現匯兌損益 ＝ 持有的外幣依「目前匯率」換算的價值，減去持有成本。
- 金額都以帳本幣種表示。

### 哪些交易會被算進去

| 會納入 | 說明 |
|---|---|
| 帳本幣種帳戶轉入這個外幣帳戶（換匯轉帳） | 視為買進，用實際轉入的外幣金額與付出的本位幣金額（含手續費） |
| 這個外幣帳戶轉到帳本幣種帳戶 | 視為賣出 |
| 外幣收入與外幣支出 | 例如領美元薪水視為買進、用美元消費視為賣出；需要已有折算成帳本幣種的金額 |

期初餘額、調整總額、從別的外幣轉進來（例如日圓轉韓元）沒有可靠的本位幣成本，預設不會納入均價；轉出到第三種外幣會減少持有量，但賣得的金額不明，所以不計入損益。

### 手動設定期初均價 {#fx-opening}

4.3.5 起，如果外幣帳戶一開始就有餘額、還沒在**帳好嗎**裡記過當初的換匯買進，可以手動輸入期初基準，讓後續的買進與賣出從這個基準接著算移動平均：

- **入口**：
  - 📱 **App**：資產 → 點開外幣帳戶 →「資訊」分頁 →「買入均價」卡片（切到「持有」視圖）→ 點底部「設定期初均價」（即使尚未有任何換匯紀錄，空狀態下方也會提供這個按鈕）。
  - 💻 **Web**：帳戶 → 點開外幣帳戶 →「買入均價」卡片（持有視圖）→「設定期初均價」。
- **怎麼填**：在「期初均價基準」視窗輸入「期初持有」與「均價」（兩者皆須大於 0）。第一次設定時，「期初持有」會自動預填「目前帳戶餘額 − 已有成本紀錄的持有量」，通常只要補上你當時的平均買進匯率即可。
- **計算規則**：期初基準一律視為**所有交易紀錄之前**的最早持倉，之後的換匯買進與賣出都會接著做移動平均與已實現損益計算。如果帳戶只有期初基準、尚無任何換匯紀錄，卡片會直接顯示均價（不顯示區間切換列）。
- **區間視圖不計入**：切到「7 天」「1 個月」「3 個月」「1 年」時，卡片不會顯示期初基準，因為期初持倉不是該區間內的新買進。
- **修改、清除與同步**：設定完成後，卡片會顯示「期初基準 5,000 JPY @ 0.2000 TWD」一列，點它即可修改，或在視窗中點「清除基準」（會二次確認）。期初基準會隨帳戶同步到 App 與 Web，並包含在設定檔匯出／匯入中。

![App「期初均價基準」輸入視窗：自動預填尚未有成本紀錄的 5,000 JPY，再輸入均價 0.2000 TWD](/img/prepare/currency-fx-opening-1.png)
*圖中：點「設定期初均價」後開啟的輸入視窗，預填未涵蓋餘額 5,000 JPY 並輸入當時均價 0.2000（示範資料）*

![App「買入均價」卡片設定期初基準後：顯示「期初基準 5,000 JPY @ 0.2000 TWD」並重新計算均價與持有成本](/img/prepare/currency-fx-opening-2.png)
*圖中：儲存後「買入均價」卡片納入期初基準計算移動平均，並提供鉛筆圖示隨時修改或清除（示範資料）*

:::note 卡片說「成本紀錄涵蓋 N% 的餘額」是什麼意思
帳戶餘額裡有一部分沒有買進匯率（例如開帳時就有的期初餘額），這部分預設不會算進均價。卡片會顯示成本紀錄涵蓋餘額的百分比，不到 100% 時，均價只代表「有紀錄的那部分」。你可以點下方的「設定期初均價」補上開帳前的持有量與均價，涵蓋率補滿後提示就會消失。
:::

## 更換帳本幣種

在「帳本設定」（我的 → 資料管理 → 帳本管理 → 長按帳本 → 設定）點「帳本幣種」，改成別的幣別時，系統會先確認：「修改本位幣將按目前匯率重算全部歷史交易的折算值」，並顯示將重算並同步幾筆交易。確認後會立即抓取最新匯率並重算。

如果某些外幣交易因為缺匯率而沒有折算，統計報表上會出現「偵測到該帳本有未折算的外幣交易」，點「按目前匯率重算折算」即可補上。

## 注意事項／小提醒

:::tip 登入後匯率更一致
登入**帳好嗎 Cloud** 後，App 優先使用伺服器上的匯率，和 Web 看到的數字一致，所以 App 與 Web 算出的總資產不會差在匯率上。
:::

:::note 匯率更新頻率
自動匯率每 24 小時最多更新一次。要馬上用新匯率，到「匯率管理」按重新整理。
:::

:::warning 缺匯率的外幣不會算進淨資產
資產頁會標示「未折算」，並提示「某幣別未折算，點選設定匯率」。補上匯率之後才會納入合計。
:::

:::note 週期性轉帳不支援跨幣別
定期自動轉帳的規則目前只能在同幣別帳戶之間設定。
:::
