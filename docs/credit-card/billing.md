「這個月到底刷了多少？上個月的帳單繳了沒？」這一頁說明**帳好嗎**怎麼把信用卡消費切成一期一期的帳單、每個數字代表什麼、什麼時候會提醒你繳款。

> 📱 App　💻 Web

## 為什麼這樣設計

- 一期帳單是「上次結帳日隔天到本次結帳日」，跟銀行一致，你拿銀行帳單來對才對得上。
- 欠款用「先進先出」算：你繳的錢先沖最舊的欠款，所以哪一期還沒繳清一目了然。
- 提醒有全域預設，卡很多的人設一次就好；個別卡片有不同需求時，再單獨覆寫。

## 怎麼操作

### 帳單彙總

**📱 在 App 上**：「資產」點進信用卡或合併帳單主帳戶，切到「交易明細」分頁，最上面就是帳單彙總。

![App 合併帳單主帳戶的交易明細：帳單彙總顯示期間、新增花費、上期欠款、應繳與剩餘帳款](/img/credit-card/billing-1.png)
*圖中：合併帳單主帳戶的交易明細，由上而下是期間切換、帳單彙總、轉為分期與對帳模式入口，以及繳款記錄的「＋」*

**💻 在 Web 上**：頂部導覽列點「帳戶」，點開信用卡，彈出視窗上方是目前這一期的數字，標題旁有切換週期的箭頭。

彙總裡每一列的意思：

| 項目 | 意思 |
|---|---|
| 新增花費 | 這一期的消費，扣掉退款、回饋金和手動轉入的錢 |
| 上期欠款 | 上一期結帳時還沒繳清的金額 |
| 應繳金額 | 新增花費加上期欠款 |
| 回饋折抵 | 這一期入帳的紅利回饋金（有回饋時才出現） |
| 已繳金額 | 到目前為止，這一期被你繳掉的部分 |
| 帳單分期 | 這張卡有轉成分期時顯示進度，沒有則顯示「---」 |
| 剩餘帳款 | 還欠多少；繳清時顯示「已繳清」 |

幾個容易搞混的地方：

- 目前還沒結束的這一期，「新增花費」只算到今天，日期排在未來的交易（例如下個月才扣款的訂閱）不會提早算進來。
- 合併帳單群組的數字是各子卡加總，換算成帳本的本位幣顯示。有卡溢繳時，會先和其他卡的欠款互相抵掉，最後才判斷剩餘帳款。整組加起來是溢繳的話，剩餘帳款顯示 0，不顯示負數。
- 外幣消費（例如在台幣卡刷日圓）會用記帳當下的折算金額計入帳單。

### 切換帳期

- 📱 App：用左右箭頭切換，或點中間的期間文字，在「選擇區間」清單直接挑。
- 💻 Web：用標題旁的左右箭頭，或點日期範圍展開清單。

下方的對帳、紅利回饋、繳款記錄與一般記錄，都會跟著你選的這一期一起換。

📱 App 的交易列表分成兩塊：「繳款記錄 (N)」是這一期真正沖掉欠款的繳款，「一般記錄 (N)」是這一期的消費。兩塊標題右邊各有一個「＋」：繳款記錄的＋是新增繳款，一般記錄的＋是補記一筆遺漏的消費。合併帳單群組的列表，每筆交易金額下方會有色塊標出是哪張子卡、哪個專案。

:::note 繳款記錄放在哪一期
「繳款記錄」會放在它實際沖掉的那一期。例如 8/12 繳的錢是用來結清 7/11 – 8/11 那期的帳單，就會出現在那一期，而不是 8/12 所在的下一期。目前還沒結帳的這一期，通常看不到繳款記錄。
:::

### 「可繳款」徽章

資產頁（App）和帳戶頁（Web）的信用卡名稱旁，如果最近一次已結帳的那一期還有欠款，會出現紅色的「可繳款 截止日 MM/DD」。繳清之後就消失。

![App 資產頁的負債帳戶區：信用卡名稱旁出現紅色「可繳款」徽章與截止日](/img/credit-card/billing-2.png)
*圖中：信用卡名稱旁的紅色「可繳款」徽章與截止日*

- 沒有「快到期才出現」的時間限制，帳單一出來、只要還有欠款就會顯示。
- 只出現在獨立信用卡和合併帳單主帳戶上，子卡不會重複顯示。
- 📱 App 是結帳日的隔天起才顯示；💻 Web 結帳日當天就可能出現，所以兩邊在結帳日當天可能差一天。

### 看額度和繳款日倒數

📱 App 的「帳戶資訊」分頁最上方有一張概覽卡：

- 有設額度時，顯示額度、已用額度、可用額度和使用率進度條。低於 50% 是綠色，到 80% 變橘色，超過是紅色。
- 顯示每月幾號出帳、幾號還款，以及距離還款日還有幾天。7 天內變橘色，3 天內變紅色。
- 合併帳單的子卡沒有自己的額度時，會用主帳戶的額度，「已用」是整組加總。
- 沒設額度也沒設還款日時，這張卡片不會出現。

要看欠多少，請看帳單彙總的「剩餘帳款」，概覽卡不再重複列「待還款」。

💻 Web 的帳單區塊點開後，會顯示目前應繳、繳款截止日、本期帳單金額、本期已消費（未結帳）和可用額度，也會提示「某日之後消費，最晚可延到某日才繳款（最長 N 天免息期）」，幫你挑刷卡日。

### 提醒

信用卡的繳費提醒是 4.0 重新整理過的：每張卡可以沿用「全域預設」，也可以只替這一張卡個別設定。提醒的設定頁就只有一個，從下面兩個入口進去都是同一頁。

**📱 在 App 上**

- 全域預設：點「我的」→「提醒」，在「通知」區點「信用卡繳費提醒」。
- 單張卡：「資產」點進信用卡（或合併帳單主帳戶），切到「帳戶資訊」分頁，點「信用卡繳費提醒」那一列（右邊寫著「結帳日、繳款日提醒」）。掛在主帳戶底下的子卡，會自動開成主帳戶的設定，同一張帳單不會被提醒兩次。

![App 信用卡繳費提醒總覽：全域預設的提醒時間與三種提醒開關，下方「各卡提醒」列出每張卡沿用預設或個別覆寫](/img/credit-card/billing-3.png)
*圖中：上半部是全域預設的提醒時間與三種提醒，下半部「各卡提醒」逐卡標示「沿用全域預設」或「個別覆寫」*

1. 點「提醒時間」，選每天幾點提醒，三種提醒共用這個時間。
2. 打開你要的提醒：
   - 「還款提醒」：在還款日前提醒，可選提前 1、3、5、7 天。
   - 「帳單結算提醒」：實際結帳日的隔天提醒，帶出這一期的應繳金額。
   - 「到期連續提醒」：從還款日起每天提醒，直到繳清為止，最長可選 1 到 10 天。
3. 每次改動立即生效，不用儲存。

新安裝時三種提醒預設都是關閉的；設定頁最下面的「各卡提醒」會列出每張獨立信用卡與合併帳單主帳戶，點進去就是那一張卡的設定。

![App 單張信用卡的提醒設定：「沿用全域預設」開關關閉後，可個別設定提醒時間與三種提醒](/img/credit-card/billing-4.png)
*圖中：單張卡的設定頁，最上面是「沿用全域預設」開關，關掉之後下方的選項才能修改*

單張卡的設定頁最上面有「沿用全域預設」開關：

- 開著：這張卡跟著全域預設走，之後全域怎麼改，這張卡就怎麼變。
- 關掉：這張卡改成「個別覆寫」，一開始會把目前有效的值複製過來，之後全域再改也不影響這張卡。
- 再開回來：覆寫會被清掉，立刻改回讀最新的全域預設。

要排得出提醒，這張卡必須先設好結帳日與繳款期限，沒設的話頁面會提示「請先在帳戶設定填寫結帳日與繳款期限，才能排程提醒」。

**💻 在 Web 上**

點右上角頭像選單，在「設定」群組點「信用卡繳費提醒」；也可以在帳戶詳情裡點進去，會直接開那張卡的設定。頁面選項和 App 相同：提醒時間、「提前繳款提醒」、「帳單結算提醒」、「到期連續提醒」，以及「各卡提醒」與「沿用全域預設」。

![Web 信用卡繳費提醒頁：全域預設與各卡提醒](/img/credit-card/billing-5.png)
*圖中：Web 的「信用卡繳費提醒」頁，上方是全域預設，下方「各卡提醒」可點進單張卡*

**提醒怎麼送到你手上**

使用**帳好嗎 Cloud** 並登入時，提醒設定會跟著帳號同步，App 與 Web 共用同一份，雲端會把這些提醒寫進「待處理中心」的通知（App 首頁右上角的鈴鐺，Web 在右上角的通知鈴鐺），App 也會在手機上預先排好同樣時間的系統通知，所以沒開 App 也收得到。沒有使用 Cloud 時，只由手機本機排提醒。通知權限要在每台手機上各自允許；手機通知裡的應繳金額是上次更新排程時的快照。已經繳清或沒欠款的帳單不會提醒。

:::note 用 Cloud、但沒動過新設定時
如果你使用**帳好嗎 Cloud**，而且從來沒有操作過新版的提醒設定，設定頁會先顯示「目前保留舊版 Cloud 提醒」的說明，維持原本的提醒時間點：結帳日隔天、繳款截止日前 7 天、截止日當天，以及逾期還沒繳的時候。只要你改過任何一個選項，就改依這一頁的設定。
:::

## 注意事項／小提醒

:::note 交易標題怎麼顯示
對帳模式和信用卡的「一般記錄」，每筆交易的標題會跟著「我的」→「記帳偏好」→「備註顯示方式」切換：「分類優先」顯示分類名稱、備註以括號附在後面；「備註優先」有備註就顯示備註。轉帳一律顯示「轉帳」。
:::

- 帳單日、繳款日不在同一個月也沒關係，繳款截止日是結帳日之後第一個還款日。
- 子卡的帳單日沿用主帳戶，順序是：子卡自己的結帳日、主帳戶的結帳日、帳本月起算日。
- 帳單日還沒設定時，信用卡的明細頁不會有帳單彙總，請先到[設定信用卡](./setup.md)補上。
- 分期付款要轉成分期，請到[分期付款](../record/installment.md)。
