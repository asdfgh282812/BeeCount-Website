信用卡繳款日、朋友欠你的錢、除息後該確認的股利，這些日子很容易忘。蜜蜂記帳會在對的時候提醒你，提醒集中在「通知中心」，你也可以另外設定每天固定時間的記帳提醒。

> 📱 App　💻 Web（通知中心需要登入 BeeCount Cloud，兩邊看到的是同一份通知）

## 為什麼這樣設計

通知是由伺服器依你的資料（帳單週期、欠款到期日、持股除息日…）統一產生的，App 和 Web 只負責顯示與標示已讀。這樣你在手機上看過的通知，在 Web 上也已經是已讀，不會重複提醒。

### 通知中心與鈴鐺

**📱 在 App 上**

![App 通知中心：欠款未結清、股利待確認、信用卡回饋入帳等通知，紅點代表還沒讀](/img/more/notifications-3.png)
*圖中：① 一則通知（點開可看完整內容）　② 紅點代表還沒讀　③ 股利待確認　④ 信用卡回饋入帳*

1. 首頁頂部有一個鈴鐺圖示，有未讀通知時右上角會出現紅色數字（超過 99 顯示 99+）。
2. 點鈴鐺進入「通知」頁。沒有通知時會顯示「目前沒有通知」。
3. 點一則通知，會標為已讀，並從下方彈出「詳情面板」，顯示完整標題、確切時間（本地時間）與完整內文，內文可以長按複製。過長時面板內可以捲動。
4. 如果這則通知有對應的項目（信用卡、欠款、週期性收支、股利），面板上會有「前往查看」按鈕，按下才會跳到相關頁面：信用卡通知到帳戶詳情、週期性收支通知到週期帳單清單、欠款到期通知到還款頁、股利通知到待確認股利頁。沒有對應項目的通知（例如系統公告）只有「關閉」。

![App 通知詳情面板：完整標題、時間與內文，下方是「關閉」與「前往查看」](/img/more/notifications-detail.png)
*圖中：① 完整標題與確切時間　② 完整內文，可以長按複製　③ 關閉　④ 「前往查看」：直接跳到對應的信用卡、欠款等項目（有對應項目的通知才有）*

設計理由：通知列表為了排版整齊，每則最多只顯示 3 行，太長的公告以前根本看不到全文；而且跳轉之前系統要先查本機資料，有時還要切換帳本，只是想讀全文的人不該被直接帶走。所以改成先看詳情，要跳再按「前往查看」。
5. 右上角「全部標為已讀」可一次清掉未讀。
6. 通知頁可以下拉重新整理；載入失敗時按「重試」。

**通知分類分頁（3.9.0）**

通知中心頂部有一排可左右滑動的分類分頁：

![App 通知中心頂部的分類分頁：全部、待完成、欠還款、信用卡、週期，各有未讀數](/img/more/notif-tabs-1.png)
*圖中：頂端一排分頁，每個分頁右上角的紅色數字是該類的未讀數*

| 分頁 | 內容 |
|---|---|
| 全部 | 所有通知（不含待完成交易） |
| 待完成 | 還沒補上的訂金尾款，直接列在這裡，見[訂金尾款追蹤](../record/deposit.md) |
| 欠還款 | 欠款到期、未結清款項 |
| 信用卡 | 帳單、繳款提醒與紅利回饋入帳 |
| 週期 | 週期性收支續期、轉帳被跳過 |
| 系統 | 預算警示、股利待確認、系統公告與其他 |

- 「待完成」分頁的數字是待補的尾款筆數，其他分頁是該類的未讀數，「全部」是全部未讀。
- 「待完成」分頁裡每一筆都有「補尾款」，也能直接編輯或刪除，不用再進到另一個畫面；它讀的是本機資料，沒有登入 BeeCount Cloud 也看得到。

![App 通知中心的「待完成」分頁：尾款金額與「補尾款」按鈕](/img/more/notif-tabs-2.png)
*圖中：待完成分頁列出訂金尾款，右下角是「補尾款」，旁邊有編輯與刪除*

- 「全部標為已讀」是全域的，不分分頁；分頁選擇不會記住，每次進來都從「全部」開始。

**💻 在 Web 上**

點右上角的鈴鐺，會展開通知清單，可以「全部已讀」；點選一則通知後，按「查看詳情」會跳到對應的帳戶、欠款或週期性收支。

**通知清單裡會出現的通知**

| 通知 | 什麼時候出現 |
|---|---|
| 信用卡帳單 | 結帳日隔天（帳單已結算）、繳款日前 7 天、繳款日當天、繳款日已過仍未繳清。已繳清的帳單不會提醒。 |
| 欠款到期 | 借還款的到期日快到或已逾期，且還沒還清。 |
| 未結清款項 | 某個對象還有未結清的借還款時，會有一則摘要（例如「小明有未結清款項」），結清前一直維持未讀。 |
| 週期性收支 | 週期規則自動續期，或轉帳因餘額不足被跳過。 |
| 紅利回饋 | 信用卡紅利回饋派發。 |
| 訂金尾款 | 登記的尾款快到期（前 3 天）或已逾期，由 BeeCount Cloud 寫進通知；另外 App 在尾款到期當天還會有本機推播，見[訂金尾款追蹤](../record/deposit.md#提醒)。 |
| 股利待確認 | 持有的股票除息後，有股利等你確認入帳。 |

欠款通知會固定排在最上面，其次是信用卡帳單。

:::note 通知什麼時候會跳出來
- App 開著、或剛回到前景時，新的通知會跳出手機的系統通知橫幅，通知清單約每分鐘更新一次。
- **App 沒開時也會跳（3.8.3 起）：** 登入 BeeCount Cloud 之後，App 會請手機系統定期在背景喚醒它，去拉最新的通知，有新的未讀就跳出系統通知。不需要任何設定。
- 但喚醒的時機由系統決定，可能延遲幾分鐘到幾小時：iOS 通常一天幾次，要看你的使用習慣；Android 最短約 15 分鐘，還會受省電模式影響。所以它適合「不急的通知」（股利待確認、回饋入帳、公告），不是即時推播。
- **從多工畫面把 App 往上滑掉之後，iOS 就不會再喚醒它**（這是 Apple 的規則）。低電量模式、或關閉了「背景 App 重新整理」時也一樣。想收到通知，請讓 App 留在背景。
:::

### 每日記帳提醒

1. 「我的」→「自動化」→「記帳提醒」。
2. 打開「每日記帳提醒」。
3. 點「提醒時間」設定幾點提醒，預設是晚上 9:00。預設是關閉的。
4. 想確認通知能不能正常跳出，按「發送測試通知」。

![App 記帳提醒頁：每日提醒開關、提醒時間與發送測試通知按鈕](/img/more/notifications-2.png)
*圖中：① 每日記帳提醒開關　② 提醒時間　③ 發送測試通知　④ iOS 通知權限與使用提醒*

Android 如果收不到通知，頁面下方有「檢查電池最佳化狀態」與「檢查通知頻道設定」可以排查，建議關閉電池最佳化並允許通知。iOS 的本機通知要靠 App 留在背景，請不要在多工畫面把 App 往上滑掉。

### 信用卡繳費提醒

1. 「我的」→「自動化」→「信用卡繳費提醒」。
2. 頁面最上方會寫「套用於 N 張信用卡帳戶」，下面的設定是全部信用卡共用的：
   - 「提醒時間」：三種提醒共用的時間；
   - 「還款提醒」：在繳款日前提前 1、3、5 或 7 天提醒；
   - 「帳單結算提醒」：結帳當天提醒並顯示應繳金額；
   - 「到期連續提醒」：從繳款日起每天提醒到繳清為止，最長 3、5、7 或 10 天。

![App 信用卡繳費提醒頁：還款、帳單結算與到期連續三種提醒](/img/credit-card/billing-3.png)
*圖中：① 提醒時間　② 還款提醒（可選提前幾天）　③ 帳單結算提醒　④ 到期連續提醒（最長提醒幾天）*

信用卡要先設好結帳日與繳款日才會有提醒，設定方式見[設定信用卡](../credit-card/setup.md)。

:::note 登入 BeeCount Cloud 時：信用卡通知不開 App 也會準時跳（3.8.3 起）
信用卡的帳單日與還款日，App 本機本來就有，時間是可以預測的，不需要等伺服器通知你。所以登入 BeeCount Cloud 後，App 會把下面四種提醒直接排進手機系統，到時間手機自己跳出來，不用開著 App：

| 提醒 | 什麼時候跳 |
|---|---|
| 帳單已結算 | 結帳日隔天 |
| 還款快到了 | 繳款日前 7 天 |
| 今天到期 | 繳款日當天 |
| 已逾期 | 繳款日隔天（同一期只提醒一次） |

- 跳出的時間沿用「信用卡繳費提醒」裡設定的「提醒時間」（預設 10:00），內容與通知中心的信用卡通知一致。
- 這四種信用卡通知在通知中心裡仍然看得到，但背景拉取不會再重複跳出系統通知，所以不會收到兩次。
- **金額是上一次使用 App 時的快照：** 每次開啟或離開 App 時會重新計算排程。如果你在別的裝置繳了款，又一直沒開這台的 App，通知可能還是跳舊金額。
- 已經繳清的那一期不會排；沒有欠款的卡不會預排本期的提醒。「帳單已結算」的文案不帶金額（結算當下的金額到那天才算得出來）。
- 自動扣繳的結果（扣款成功、餘額不足略過）要等 Cloud 排程跑完才知道，本機算不出來，仍由通知中心與背景拉取負責。
:::

### App 更新提醒

- **Android**：有新版本時，開啟 App 會跳出「發現新版本」，按「立即更新」會下載並安裝；按「稍後」則 24 小時內不再提醒。想主動檢查，到「我的」→「關於」→「檢查更新」。
- **iOS**：有新版本時會跳出「有新版本可用」，告訴你目前版本與新版本，請到你原本取得安裝檔的管道更新。可以按「知道了」，或「不再提示此版本」（下一個版本發布後會再提醒）。

如果 App 版本過舊、低於伺服器要求的最低可同步版本，會直接停在更新頁，必須先更新才能繼續同步。

## 注意事項／小提醒

:::tip 提醒設定跟著帳號走
記帳提醒與信用卡提醒的設定存在你的帳號裡，換新手機或重新安裝後會自動套用。但系統的「通知權限」要在每台裝置上各自允許。
:::

- 沒登入 BeeCount Cloud 時看不到鈴鐺與通知中心；本版本需要登入才能使用，通常不會遇到。
- 想少收一點通知：到手機的系統設定裡針對「蜜蜂記帳」調整，或關掉個別提醒開關。
