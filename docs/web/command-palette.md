# 指令面板與快速鍵

Web 端右上角搜尋框可以用 **⌘K（macOS）/ Ctrl+K（Windows / Linux）**隨時呼出，是桌面端最高效的操作入口－不用點滑鼠翻頁，打字或按方向鍵就能完成大部分操作。

![指令面板](/img/web/command-palette.jpg)

## 呼出方式

- 快速鍵 `⌘K` / `Ctrl+K`（任何頁面都可以按）
- 點選右上角搜尋框

按 `Esc` 關閉，方向鍵 `↑↓` 切換選項，`Enter` 執行。

## 快速操作

面板頂部「快速操作」區，隨時可以執行：

| 操作 | 說明 |
|---|---|
| 新交易 | 快速鍵 `N`，直接呼出記帳視窗 |
| 年度報告 | 開啟年度記帳回顧（12 螢幕沉浸式） |
| 匯出本月 / 本年 CSV | 直接下載目前帳本的交易資料 |
| 匯入帳本資料 | 開啟[匯入資料](../app/record/import-export.md#web-端匯入)對話方塊 |
| 切換到淺色 / 深色主題 | 跟頭像選單的主題切換等價 |
| 加入共享帳本 | 輸入邀請碼加入他人的[共享帳本](../app/shared-ledger.md) |
| 登出 | 登出目前帳號 |

## 頁面導覽

直接跳到任何主要頁面：首頁、交易、日曆、帳戶、分類、標籤等，不用點頂部導航。

## 搜尋交易

在搜尋框直接輸入關鍵字（備註、分類名稱、金額），指令面板會即時列出符合的交易，回車可直接開啟該筆交易詳情－比進交易清單頁再篩選更快。

## 使用技巧

- 記帳時按 `N` 比點滑鼠去頂部導航更快，尤其是鍵盤操作熟練的用戶
- 月底匯出對賬，直接 `⌘K` → 輸入「匯出」→ 回車，不用進設定頁找入口
- ⌘K 面板裡也能直接問 AI 記帳問題，詳見 [AI 對話](../app/ai/chat.md#web-端-k-也能問-ai-文件)
