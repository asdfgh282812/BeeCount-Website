收銀台前不想一格一格填欄位？拿手機對著發票拍一張、對著手機說一句「午餐 120」，或是把轉帳截圖丟進來，AI 會幫你辨識金額、分類、帳戶和時間，直接建立帳單。

> 📱 App　💻 Web（⌘K 命令面板可貼文字或圖片記帳，Web 也有浮動 AI 助手與智慧記帳設定頁）

AI 記帳有五種入口：

| 入口 | 怎麼用 |
|---|---|
| 文字 | 在 AI 小助手對話裡打「買了杯咖啡 35 元」，詳見 [AI 聊天與查帳](./ai-chat.md) |
| 語音 | 長按底部中間鍵（在任何分頁都可以）→「語音」；或「我的 → 智慧記帳」→「語音記帳」 |
| 拍照 | 長按底部中間鍵 →「拍照」；或「我的 → 智慧記帳」→「拍照記帳」 |
| 相簿／剪貼簿圖片 | 長按底部中間鍵 →「相簿」；或「我的 → 智慧記帳」→「相簿記帳」 |
| iOS 分享選單 | 截圖後分享給「**帳好嗎**」，詳見 [自動記帳](./auto.md) |

## 為什麼這樣設計

支援的手機可以用**裝置內建 AI**完成基本辨識，不需要 API Key；想使用拆帳、借還款、週期等較完整的能力，也可以自行設定雲端 AI 服務商。文字、語音、圖片共用同一套「執行策略」，讓你決定哪些辨識留在手機、哪些情況可以交給雲端。App 不內建預設的雲端服務商。

## 開始前：開啟並設定 AI

4.0 起，原本分開的「智慧記帳」與「AI 小助手」兩頁合併成「我的 → 智慧記帳」一頁：常用偏好、立即記帳、語音設定與自動化都在這裡，服務商與模型則放在下一層的「AI 服務管理」。

![App「我的 → 智慧記帳」頁：常用記帳偏好、AI 服務管理、立即記帳、語音記帳與自動化記帳](/img/record/ai-hub-1.png)
*圖中：由上到下是「常用記帳偏好」、「AI 服務管理」、「立即記帳」（拍照、相簿、語音）、「語音記帳」設定，以及「自動化記帳」（自動記帳、捷徑）*

### 1. 先選執行策略 {#on-device}

入口：「我的 → 智慧記帳 → AI 服務管理 → 執行策略」。支援裝置內建 AI 的手機會看到三種選項：

| 策略 | 怎麼處理 | 要準備什麼 |
|---|---|---|
| 僅雲端 | 只用能力綁定所選的雲端服務商 | 自行新增服務商、填 API Key，並綁定需要的能力 |
| 本機優先 | 手機支援的能力先在本機處理；失敗時改用已設定的雲端，以完整提示詞重跑。不支援的能力直接用雲端 | 本機模型準備完成；需要雲端接手時，仍須有可用的服務商與金鑰 |
| 僅本機 | 只用手機內建能力，不會自動改用雲端 | 不需要 API Key；手機未支援或尚未準備好的能力不能用 |

![App 執行策略選單，列出僅雲端、本機優先與僅本機](/img/record/ai-ondevice-strategies.png)
*圖中：支援裝置內建 AI 的手機可選三種策略；舊版的「雲端優先」已整併為「僅雲端」*

選好後回到上一層「智慧記帳」，再開啟「啟用 AI 小助手」。選「僅本機」可略過下方的新增雲端服務商與能力綁定步驟。

**確認這台手機能做什麼**

選本機策略後，「執行策略」的副標題會列出「手機可處理：文字、圖片、語音」中的可用項目；上方能力列則顯示「裝置內建（離線）」。各項支援度可能不同，以這台手機實際顯示為準。

![App 僅本機策略，文字、圖片與語音顯示裝置內建（離線）](/img/record/ai-ondevice-only.png)
*圖中：示範三項能力都可用的狀態，未設定雲端服務商；下方也列出內建模型的限制*

本機優先且已綁定可用的雲端時，能力列會顯示「裝置內建（離線） → My AI」這類文字，表示本機失敗時可由該服務商接手。

![App 本機優先策略，能力列顯示裝置內建（離線）到 My AI](/img/record/ai-ondevice-first.png)
*圖中：My AI 是自行設定的示範雲端服務商，不是 App 內建服務*

**手機支援條件與模型準備**

- iPhone 的文字擷取使用系統內建模型，需要支援 Apple Intelligence 的機型、iOS 26 以上，以及可用的繁體中文模型。若畫面提示「請先到系統『設定』開啟 Apple Intelligence」，請先到系統完成設定。
- Android 的文字擷取依賴手機提供的 Gemini Nano／AICore；並非所有 Android 手機都支援。若提示需要下載模型，選擇本機策略後會開始準備，顯示「模型下載中」時請等待完成。
- 圖片會先在手機辨識文字，再由文字模型擷取帳單；語音也需要可用的離線轉文字能力與文字模型。語音支援還會受系統語言、離線語音包與系統版本影響。
- 不支援裝置內建 AI 的手機，選單通常只列「僅雲端」。若從另一台裝置同步來「僅本機」或「本機優先」，仍會顯示目前策略，並註明「這台手機不支援裝置內建 AI」。

![App 收到僅本機策略，但這台手機不支援裝置內建 AI](/img/record/ai-ondevice-unsupported.png)
*圖中：策略已同步過來，但不代表這台手機也能執行；可改回「僅雲端」並設定服務商*

:::note 策略會同步，手機能力不會跟著變
執行策略跟著帳號同步，Web 也能修改。若 A 手機支援本機 AI、B 手機不支援，選「僅本機」後 B 的 AI 就不能用；B 改回「僅雲端」也會同步回 A。選「本機優先」時，未支援的能力仍需有效的雲端設定。
:::

:::tip 本機辨識與離線的範圍
「僅本機」讓 AI 辨識在手機內執行，不把辨識內容送到第三方 AI 服務商；**一般帳務、附件與對話仍會依原本設定同步到帳好嗎 Cloud**。下載模型、讀取線上手冊、更新匯率及雲端同步仍需要網路，並非整個 App 都不連網。
:::

### 2. 開啟 AI 小助手 {#1-開啟-ai-小助手}

1. 在「我的」點「智慧記帳」。
2. 在「常用記帳偏好」打開「啟用 AI 小助手」。

![App「智慧記帳」頁的常用記帳偏好：啟用 AI 小助手、顯示浮動氣泡、自動新增附件、記帳來源標籤、AI 專案指定與 AI 標籤指定](/img/record/ai-1.png)
*圖中：「常用記帳偏好」區的開關與選項，下面一列是進入「AI 服務管理」的入口*

使用「僅雲端」或「本機優先」，從關閉切到開啟時，會跳出「開啟 AI 功能前，請知悉」的提示，說明資料可能傳給哪個服務商、傳哪些內容、用在哪裡。按「同意並開啟」才會真的開啟；按取消，開關會維持關閉。「僅本機」不需要這個第三方資料分享同意。

![App 開啟 AI 功能前的提示：說明資料傳給誰、傳什麼、用在哪，下方「取消」「同意並開啟」](/img/record/ai-consent-1.png)
*圖中：提示列出「傳送給誰」「傳送什麼」「用途」三點，最下方可點「隱私政策」*

:::note
雲端策略在開關從「關」切到「開」時會顯示提示。如果先以「僅本機」開啟 AI，之後切到「本機優先」或「僅雲端」，而這台裝置尚未同意過雲端資料分享，也會先詢問；取消就維持原本策略。已在別台裝置開啟、同步下來的 AI 開關不會單獨再觸發啟用提示。
:::

### 3. 設定雲端服務商與金鑰（需要雲端時） {#2-新增服務商並填入金鑰}

雲端 AI 服務商就是替你做辨識的那家公司。App 不內建雲端服務商（4.0 起移除了預設的智譜 GLM），使用「僅雲端」或希望「本機優先」失敗後能接手時，要自己新增，並填入該服務商給你的 API Key。裝置內建 AI 不必新增成一個服務商。

![App 服務商管理頁：已新增的 My AI 與文字、視覺、語音能力](/img/record/ai-2.png)
*圖中：已新增的服務商與支援能力；右上角的「＋」可新增，點選服務商可編輯設定*

![App 新增服務商頁：選 OpenAI 體系或 Gemini 原生體系，填網址、金鑰與各項模型](/img/record/ai-3.png)
*圖中：新增服務商頁，由上到下是服務商名稱、API 體系、Base URL、API Key 與各用途的模型（文字、視覺、語音），可以按「一鍵測試全部」*

1. 在「智慧記帳」頁點「AI 服務管理」，再點「服務商管理」。
2. 點右上角的「＋」（或「新增服務商」）。
3. 在「服務商名稱」輸入你看得懂的名字，例如「我的 Gemini」。
4. 選擇 API 體系：
   - 「Gemini 原生體系」：直接使用 Google 的 Gemini。選了之後「Base URL」會自動帶入 Google 的預設位址，不用自己填。
   - 「OpenAI 體系」：任何相容 OpenAI 標準聊天補全介面的服務（包含自架或第三方代理）。「Base URL」要填服務商給你的位址，例如 `https://api.example.com/v1`。
5. 在「API Key」貼上你的金鑰（右側眼睛圖示可切換顯示）。
6. 在「模型設定」填寫三種模型：「文字模型」「視覺模型」「語音模型」。留空代表這個服務商不提供該能力。
7. 按「一鍵測試全部」，確認三項都顯示測試通過，再按「儲存」。測試不是必要步驟，但能先抓出金鑰或模型名稱打錯的問題。

![App 新增服務商：一鍵測試全部後，API Key 與文字、視覺、語音三個模型都顯示「測試通過」](/img/record/ai-test-1.png)
*圖中：每個模型旁的「測試通過」，最下方的按鈕也會變成「測試通過」；任何一項失敗會在該欄旁顯示原因*

**Gemini 原生體系**一把金鑰就能同時處理文字、圖片和語音，最省事。欄位裡的提示範例是 `gemini-3.5-flash`，實際能用哪個模型，取決於你的 Google 帳戶與配額。Google 的 API Key 可以到 Google AI Studio 建立。

**OpenAI 體系**的提示範例是文字 `gpt-4o-mini`、視覺 `gpt-4o`、語音 `whisper-1`，換成你的服務商實際提供的模型名稱即可。

### 4. 綁定雲端能力（需要雲端時） {#3-綁定能力}

新增完雲端服務商還要告訴 App：文字、圖片、語音各交給誰處理。這裡綁定的是雲端選擇；本機策略會依手機能力優先顯示裝置內建狀態，不需要把內建模型加進清單。

![App「AI 服務管理」頁：服務商管理、能力綁定、執行策略與提示詞編輯](/img/record/ai-4.png)
*圖中：「AI 服務管理」頁，依序是服務商管理、能力綁定（文字對話、圖片理解、語音轉文字）、執行策略與提示詞編輯*

1. 回到「智慧記帳」頁，點「AI 服務管理」，找到「能力綁定」。
2. 分別點「文字對話」「圖片理解」「語音轉文字」。每一項下面會顯示目前綁定的服務商，還沒綁就顯示「尚未設定」。
3. 在清單中選擇剛剛新增的服務商。沒填對應模型的服務商不會出現在清單裡，沒填金鑰的會標示「未設定 API Key」。

![App 點「文字對話」跳出服務商清單：沒填金鑰的服務商標示未設定 API Key](/img/record/ai-bind-1.png)
*圖中：選擇文字對話要用哪個服務商；已選的是勾選的那一個*

![App 能力綁定：文字對話、圖片理解、語音轉文字都綁到「My AI」](/img/record/ai-bind-2.png)
*圖中：三項能力各自綁定的服務商顯示在每一列，可以分別選不同家*

:::tip
「提示詞編輯」一般用預設就好。自訂提示詞只在雲端擷取時使用，本機模型使用精簡提示詞。雲端自訂提示詞若沒有要求輸出商家，信用卡回饋就可能無法自動比對；要使用商家比對，請保留商家欄位。既有雲端自訂提示詞不用重寫，執行時會自動補上拆帳、費用、借還款與週期的欄位說明。
:::

### 5. 或用共享 AI 點數（支持者方案） {#共享-ai-點數}

如果你的授權是[支持者方案](/pricing#共享-ai-點數)，而且營運者有開放共享 AI，就**不必自己新增服務商與 API Key**：只要沒有自己的服務商，AI 小助手、文字、圖片與語音記帳會自動改用營運者分享的 AI，並從「共享 AI 點數」扣點。

- **點數怎麼算**：每月 50 點，從你**第一次使用 AI** 才開始算一個月（不是每月 1 號）；這個月結束後，下一次使用會重新開始一個月並重新發放。
- **怎麼扣**：依每次用掉的 token 數（你送出的內容加上 AI 的回覆）。一句簡短的話大約 1～2 點，一輪一般的對話大約 3～5 點，對話越長、附的圖片或內容越多，扣得越多；語音轉文字每段錄音固定 3 點。失敗的請求不扣點。
- **哪裡看餘額**：📱 我的 → 智慧記帳 → 最上方的「共享 AI 點數」，點一下看說明；💻 Web 右上角頭像選單 → 智慧記帳。
- **自己有服務商就用自己的**：你設定了服務商的能力，會優先用你自己的、不扣點；只有沒設定或沒綁定模型的能力才用共享 AI。
- **用完之後**：會提示「本週期的共享 AI 點數已用完」，並顯示何時重新發放。其它記帳功能不受影響，也可以隨時改用自己的 AI 服務商。
- 一般方案不含共享 AI 點數；營運者沒有開放時，「共享 AI 點數」區塊不會出現。
- 資料會經由營運者的伺服器轉送到營運者的 AI 服務商；伺服器只記錄用量，不儲存你的內容。開啟 AI 前會顯示資料分享同意。

## 拆帳、費用、借還款與週期

4.1 起，AI 能把下面這些內容記成有關聯的交易、欠款或週期規則。App 的文字、語音、圖片與背景辨識共用這套能力；Web 會先整理成可修改的草稿，確認後才儲存。是否能正確辨識，仍取決於你使用的模型與說明是否完整。

:::note 進階記帳請使用雲端
手機內建模型主要擷取金額、時間、備註、商家、分類、類型、帳戶與幣別，**不支援下列拆帳、費用、借還款、週期，以及由 AI 判斷專案、內容標籤與自訂提示詞**。需要這些內容時，請先切到「僅雲端」並設定服務商。「本機優先」只在本機處理失敗時改用雲端，不保證辨認出進階需求後就自動切換；請核對記帳結果。
:::

| 想記的內容 | 可以這樣說 | 記好後的結果 |
|---|---|---|
| 多分類拆帳 | 「賣場結帳 1,500，食材 900、日用品 600，用現金」 | 一筆付款分到兩個分類，不會變成兩筆完整付款 |
| 拆帳含代墊 | 「晚餐付了 900，我自己 300，小明欠我 600，用現金」 | 帳戶扣 900，自己的支出算 300，另追蹤小明的應收款 600 |
| 原價、手續費與折扣 | 「原價 1,000，折扣 100，運費 60，用現金」 | 保存各項金額，實付為 960 |
| 轉帳手續費 | 「從銀行轉 1,000 到現金，手續費 15」 | 轉帳本金為 1,000，轉出帳戶另扣手續費 15 |
| 借出／借入 | 「用現金借給小明 2,000」或「向小華借 1,000，收到現金」 | 建立欠款與對應的帳戶金額變動，不計入收支與預算 |
| 收款／還款 | 「小明還我 500，收到現金」或「用現金還小華 250」 | 連到既有未結清欠款，可記部分收還款 |
| 週期排程 | 「設定從 2026 年 11 月 5 日開始，每月用現金付房租 12,000」 | 建立第一筆與週期規則，後續依既有週期機制處理 |

範例中的帳戶名稱要換成你實際建立的名稱。手續費、運費與服務費可作為費用，折扣請說金額；若說的是「折扣後實付 960，含運費 60」，請明確指出 960 已是實付，避免辨識時混淆原價與總額。收入、支出與轉帳的費用算法見[手續費與折扣](./fields.md#手續費與折扣)與[轉帳](./transfer.md)。

### 哪些情況要先確認

- **拆帳**：至少兩筆明細、至少一筆一般收支分類，明細合計必須等於實付／實收。代墊份額請說清楚對象；後續由[借還款](./debt.md)追蹤，不必另外再記一筆借出。
- **收款／還款**：只會配對目前帳本中，對象、方向都相符的唯一一筆未結清欠款。找不到、同名有多筆或金額超過未結清餘額時不會儲存，請到[借還款](./debt.md)指定款項。AI 尚未提供既有欠款登記、分期借貸或一次分配到多筆欠款的操作。
- **幣別與帳戶**：借還款、含欠款的拆帳要使用帳本主要幣別的帳戶。週期也必須有完整帳戶資料；背景辨識無法配對必要帳戶時，會回報失敗，請改用前景入口補選。
- **週期**：支援每幾天、週、月或年，以及選填結束日。只有明確要求建立持續排程才會建立規則；「今天付了月費 199」只記這次付款，不會自動設成週期。後續期數的產生方式見[週期性收支](./recurring.md)。
- **目前不能合併**：週期搭配拆帳、週期搭配借還款，以及借還款搭配手續費／折扣。這些組合會拒絕儲存，不會只留下其中一部分。

### 記好後怎麼核對

📱 App：AI 對話的記帳卡片會顯示實際幣別，並依內容列出原價、手續費、折扣、拆帳份額、借還款對象與週期。按「修改」可開啟既有編輯頁；一般交易的「撤銷」刪除該筆，**新建週期的「撤銷」會先確認，再刪掉整條規則與所有已產生期數**。若只想處理某一期，請從交易列表編輯或刪除並選擇範圍。有關聯欠款且已收還款的起點交易，仍受欠款刪除保護。借還款或週期卡片不提供單筆換帳本捷徑。

💻 Web：在文字／圖片記帳或浮動助手的草稿中核對進階欄位，可修改費用、拆帳分類／份額／對象、借還款方向與對象，以及週期間隔與結束日，再確認儲存。拆帳合計不符或使用不支援的組合時，必須先修正。

#### AI 記完之後

- **自動附上原圖**：圖片或拍照記帳時，原圖預設會存成這筆帳的附件。要關閉，到「我的 → 智慧記帳」的「常用記帳偏好」把「自動新增附件」關掉。附件的用法見 [附件](./attachment.md)。
- **自動加來源標籤**：預設會替帳單加上「圖片記帳」「拍照記帳」「語音記帳」「AI記帳」之類的標籤，方便日後篩選。要關閉，到同一頁把「記帳來源標籤」關掉。

![App 首頁列表：AI 記的帳單帶「AI記帳」標籤](/img/record/ai-tags-1.png)
*圖中：列表裡每筆 AI 記的帳都有「AI記帳」標籤，圖片記帳另外有「圖片記帳」*
- **信用卡回饋自動套用**：如果這筆帳記在信用卡帳戶，AI 辨識出商家，而且剛好只有一條你設定好的回饋規則符合，就會直接套用，不必事後再勾。有兩條以上符合、或一條都沒有時不會猜，帳單照常建立。詳見 [紅利回饋](../credit-card/rewards.md)。
- **外幣帳單**：拍到日圓收據時，AI 會辨識出幣別。如果你有日圓帳戶，會直接記進去；如果沒有，選了新台幣帳戶，金額會依匯率換算後再記，不會把「10,230 日圓」誤記成「10,230 元」。一般沒有進階欄位的交易找不到匯率時，會先以 1:1 暫記並提示你到統計頁補折算；進階交易需要換幣別卻沒有有效匯率時，會拒絕建立，請先補好匯率再重試。幣別的設定見 [多幣種與匯率](../prepare/currency.md)。
- **民國年**：發票或收據上的「115/09/20」這種民國年日期，AI 會自動換成 2026/09/20。

- 在 App 內用語音、拍照、相簿、對話記帳：會跳出「選擇帳戶」，你選一個就繼續；按取消，這筆就略過不記，記完會提示「已略過幾筆」。

*圖中：選一個帳戶才會繼續記帳*
- 背景處理（截圖監聽、分享圖片）沒有畫面可以問：一般交易照常建立，但標示為「待確認帳戶」。到「資產」頁，會出現「待確認帳戶」的卡片，點進去會到待處理中心的「待處理」分頁，逐筆補選。借還款、含欠款的拆帳與週期交易若缺少必要帳戶，會回報失敗，請改用 App 內的入口補選帳戶後重試。

另外，信用卡「合併帳單的主帳戶」只是管理用的容器，AI 不會把帳單記到它身上，也不會出現在給 AI 挑選的帳戶清單裡。主帳戶的概念見 [帳戶](../prepare/account.md)。

## 注意事項

:::warning
AI 辨識不是 100% 準確。金額、分類和帳戶建議在記完後掃一眼；記錯了可以在 AI 小助手的記帳卡片按「撤銷」，或到首頁、「全部交易」找到那一筆修改。
:::

:::note
**AI 設定會同步。** 服務商設定（包含你填的 API Key）、能力綁定、執行策略、專案與標籤指定、語音設定，會隨**帳好嗎 Cloud** 帳號同步到你的其他裝置，換手機不用重填；模型是否可用仍由各裝置決定。同步機制見 [雲同步與離線](../sync/overview.md)。
:::

- 看到「請先在智慧記帳開啟 AI，再開始記帳」，代表 AI 小助手沒開；看到「請先到 AI 服務管理設定所需模型與 API Key」，請先確認執行策略。雲端策略要檢查能力綁定與金鑰；本機策略要檢查手機支援度與模型準備狀態。雲端圖片記帳需要圖片理解模型，本機圖片則先辨識文字再擷取帳單；語音需要轉文字及文字擷取能力。
- 本機模型較小，輸入太長、欄位太複雜或日期只說「午餐」「晚上」時，結果可能不完整；請縮短內容、明確寫日期時間，或改用雲端。較複雜的查帳與分析限制見[本機聊天](./ai-chat.md#on-device-chat)。
- Android 的內建文字模型需要 App 在前景。背景自動辨識在「僅本機」可能失敗，「本機優先」則需要可用的雲端接手；詳見[自動記帳](./auto.md)。
- 辨識進度只是示意動畫，不是實際進度，卡住太久請稍等或重試。
- 辨識到不是帳單的圖片時，會提示「未識別到帳單資訊，請確認圖片是帳單後重試」。
- 免費的 API 額度通常有限，用量大時可能被限流而失敗。
- 使用共享 AI 點數時，點數用完前每次請求都會扣點；想看餘額與重新發放日，到「智慧記帳」頁最上方查看，說明見[共享 AI 點數](#共享-ai-點數)。
