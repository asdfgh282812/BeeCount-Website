# 信用卡紅利回饋規則

> ⚠️ **僅 Cloud 版可用**：本頁功能是 BeeCount Cloud（自建服務端）獨有的進階功能，純 App 本機記帳沒有這個入口。

幫信用卡設定回饋規則後，系統會自動算你這期刷了多少回饋、並且能自動幫你入帳一筆收入。

## 建立回饋規則

在信用卡帳戶詳情頁點「紅利回饋」，新增規則：

| 欄位 | 說明 |
|---|---|
| 名稱 | 方便辨識用，例如「一般消費 2% 回饋」 |
| 限定分類 | 選填，不填代表所有分類都算 |
| 回饋類型 | 百分比 / 固定金額 |
| 回饋率 | 例如 2 代表 2% |
| 取整方式 | 無條件捨去 / 四捨五入 / 無條件進位 / 不取整 |
| 計算基準 | 依交易日還是依入帳日計算所屬週期 |
| 統計週期 | 按帳單週期還是按日曆月 |
| 最低消費門檻 / 單筆最低金額 | 選填 |
| 回饋上限 | 選填，可跨多張卡共用同一個上限額度 |
| 結算方式 | 見下方說明 |
| 入帳目的帳戶 | 回饋金要記到哪個帳戶（可以是同一張卡，直接抵扣應繳；也可以是別的錢包帳戶） |

![信用卡回饋規則](https://photo.pnsgzomf.synology.me/i/2026/08/11/6a79f9045434f.png)

> 有交易或已入帳紀錄之後，回饋率、計算方式這些核心計算欄位就會鎖定不能再改，只能改名稱、備註跟啟用狀態——避免規則中途變動導致歷史回饋算法對不上。

## 結算方式怎麼選

| 結算方式 | 什麼時候入帳 |
|---|---|
| 消費後立即結算 | 每一筆符合條件的消費，記帳當下馬上算好回饋 |
| 入帳日後結算 | 消費入帳後幾天才算回饋 |
| 週期結束後結算 | 整個統計週期（例如整期帳單）結束才一次算總回饋 |
| 手動 | 完全不自動算，靠你自己按「手動入帳」 |

自動結算一樣是背景排程（跟自動扣款共用同一套 15 分鐘排程）觸發，週期結束結算的話還會額外發一則通知提醒你。

## 手動入帳

不想等自動結算，可以直接按「手動入帳」，當場指定金額跟入帳帳戶記一筆回饋收入，金額不必跟規則設定完全一致（例如客服補償的額外回饋）。

## 常見問題

**回饋規則能不能只套用某些消費？**
可以，「限定分類」跟「單筆最低金額」都可以縮小適用範圍，不填就是全部消費都算。

**多張卡想共用一個年度回饋上限怎麼設？**
把這幾張卡的規則都填同一個「共用上限分組」代號，系統就會把這幾條規則的回饋金額加總去扣同一個上限，而不是各自獨立算。
