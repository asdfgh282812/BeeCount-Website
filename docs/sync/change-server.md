管理員通知你「伺服器換網址了」，或是你要從一台**帳好嗎 Cloud** 改連到另一台，不用解除安裝 App。到「雲服務」把伺服器位址改掉、重新登入一次就好，大約一分鐘。

> 📱 App

## 換之前先確認

- **先讓資料同步完。** 到「我的 → 雲端帳號與同步 → 雲同步」，確認「未推送變更」是 0。還沒傳上舊伺服器的記錄，換過去之後不會自動跟過去。
- **確認新位址和登入帳號。** 向管理員確認新的伺服器位址（像 `https://example.com` 這樣的網址），以及你在新伺服器上要用哪個帳號登入。
- **連上網路。** 改位址和登入都要連線。

:::warning 登入不同的帳號，手機上的資料會先清空
如果你在新伺服器登入的帳號，和舊伺服器上的不是同一個帳號，App 會先清掉這支手機上屬於前一個帳號的資料，再從新伺服器把資料拉下來。清掉的資料不會傳到新帳號，所以沒同步完的變更會遺失。管理員只是把伺服器搬到新網址、帳號與資料都沒變時，就不會被清掉。拿不準的話，先問管理員。
:::

## 怎麼改伺服器位址

1. 點底部「我的」→「雲端帳號與同步」。最上面一格顯示目前連到的伺服器。
2. 點「雲服務」（說明是「切換或設定雲端服務」）。這一頁只有「**帳好嗎 Cloud**」一張卡片，卡片上寫著目前的伺服器位址，打勾代表正在使用。

   ![App「我的 → 雲端帳號與同步 → 雲服務」頁：帳好嗎 Cloud 卡片顯示目前的伺服器位址，右下角有「設定」，右上角有「測試連線」](/img/sync/change-server-1.png)
   *圖中：雲服務頁，卡片右下角的「設定」就是改位址的入口*

3. 點卡片右下角的「設定」，跳出「設定帳好嗎 Cloud」視窗。把「伺服器位址」改成新的網址，按「儲存」。視窗下方的提示會提醒你：儲存後要點「登入」，登入在瀏覽器完成，不用在這裡輸入帳號密碼。

   ![App「設定帳好嗎 Cloud」視窗：伺服器位址欄填入新的網址，下方有取消與儲存按鈕](/img/sync/change-server-2.png)
   *圖中：設定視窗，把「伺服器位址」改成新網址後按「儲存」*

4. 儲存後 App 會直接帶你到「登入」頁。按「使用 SSO 登入」，App 會開啟手機瀏覽器，請在瀏覽器裡用新伺服器的帳號完成登入，成功後會自動跳回 App。

   ![App 登入頁：「登入」標題與「使用 SSO 登入」按鈕](/img/sync/change-server-3.png)
   *圖中：儲存後出現的登入頁，按「使用 SSO 登入」到瀏覽器完成登入*

5. 如果新伺服器要求授權金鑰，會多出「需要授權金鑰」頁，輸入管理員給的金鑰即可，見[授權金鑰](./license.md)。
6. 登入完成後，回到「我的 → 雲端帳號與同步」，確認最上面顯示的是新伺服器，同步狀態是「已同步」。

:::tip 改完可以測一下
回到「雲服務」頁，點右上角的「測試連線」。顯示「連線正常」就代表位址對了。
:::

## 常見問題

- **按「使用 SSO 登入」沒有反應，或登入失敗。** 先檢查位址有沒有打錯（要包含 `https://`，前後不要有空格）、手機有沒有連上網路。位址對了還是不行，請管理員確認新伺服器是不是正常運作。
- **改完位址發現打錯了。** 回到「雲服務」再按一次「設定」，改成正確的位址儲存即可。
- **不小心登入到錯的帳號。** 到「我的 → 雲端帳號與同步」按「登出」，再重新設定位址並登入。注意登出會清掉這支手機上的本機資料，見[雲同步與離線](./overview.md#被登出時會怎麼樣)。
- **Web 版要怎麼換？** Web 是直接開伺服器的網址，沒有設定位址的地方。伺服器換了網址，在瀏覽器開啟新網址登入就好，見 [Web 版](./web.md)。

## 注意事項／小提醒

- 改位址和重新登入，都不會刪掉舊伺服器上的資料；舊伺服器上的帳本仍然留在原處，只是這支手機不再連到那裡。
- 第一次連到新伺服器、而且帳號在新伺服器上已經有帳本時，資料多的話整份拉下來要一些時間，請用 Wi-Fi 並等它跑完，見[雲同步與離線](./overview.md)。
- 其他裝置（另一支手機、平板）也要各自照這一頁改一次位址並重新登入。
