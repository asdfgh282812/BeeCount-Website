每月 5 號繳房租、每月 15 號領薪水、每年續訂影音平台、每週一固定轉 500 元去存款……這些款項一直重複，每次手動記很累，漏記又對不上帳。把它設成週期性收支，系統會依你設定的頻率自動產生每一期的交易。

> 📱 App　💻 Web　需登入 BeeCount Cloud。規則與已產生的交易會在 App 與 Web 之間同步，轉帳類規則的自動執行由雲端進行。

## 為什麼這樣設計

週期性收支的做法是「一次排好一整段」：建立規則時，系統會先把接下來約一年的每一期交易建好（有結束時間就排到結束），之後快用完時自動補。這樣你在月曆上就能提前看到下個月哪天要扣款、預算也有預留。App 離線也能先算出日期，連上網路後再與 Web 同步。

另外，「只改這一期」與「連同以後都改」是兩種完全不同的需求（例如這個月房租特別調漲，還是之後都漲），所以每次編輯或刪除都會讓你選範圍。

## 怎麼建立

### 📱 在 App 上

1. 在新增交易頁選「支出」或「收入」，填好分類、金額、帳戶。第一期的日期就是你選的日期。
2. 往下找到日期下方的「單次」列，點它開啟「進階設定」。這一列只有新增時才有，編輯舊交易時沒有。
3. 上方有三個頁籤：「單次」「週期」「分期」，選「週期」。
4. 設定重複頻率：
   - 「每」＋ 數字 ＋ 單位（天／週／月／年）。數字用加減鍵調整。例如每 1 個月、每 2 週。
   - 選「週」時，下方出現「重複於」，點選星期一到日，可複選，至少留一天（選週時間隔固定為 1 週）。
   - 選「月」時，下方出現「每月幾號」，橫向捲動選 1 到 31 號。選了 31 號而該月沒有 31 日，會落在當月最後一天。
5. 「結束方式」三選一：
   - 無限期：一直重複
   - 指定次數：點數字可直接輸入次數，不用一直按加減
   - 截止日期：到哪一天為止
6. 「入帳方式」目前只有「立即入帳」。
7. 點「確定」，回到表單。「單次」那一列會變成週期摘要，例如「每月 5 號」。
8. 照常送出。第一期與之後的各期都會建好。

![進階設定視窗的「週期」頁籤，標出每 N 單位、重複於、結束方式](/img/record/recurring-1.png)

### 💻 在 Web 上

1. 到「交易」頁點「建立交易」，在視窗中段找到「設為週期性收支」開關（只有新增時才有），打開。
2. 設定「頻率」（每天／每週／每月／每年）、「間隔（每 N 個週期）」、「結束時間（可選）」。
3. 想指定每週星期幾或每月第幾天，用「進階規則」：「每週指定星期幾」或「每月指定日期」。
4. 按「建立交易」。

也可以到規則頁新增：右上角頭像（滑鼠移上去）→「工具」→「週期性收支」，右上角「新增規則」。規則視窗還能選「一般交易」或「股票定期定額」，後者見[定期定額](../invest/dca.md)。

![Web 的週期性收支頁，規則卡片與「新增規則」按鈕](/img/record/recurring-web-1.png)

:::note 每月幾號怎麼定
沒有使用「進階規則」時，每月幾號就是「下次執行時間」那一天，間隔填 1 就是每個月一次。
:::

## 規則管理頁

### 📱 在 App 上

入口：「我的」→「自動化」→ 進入「自動化功能」頁 →「週期記帳」（副標「管理定期收支與轉帳規則」）。

1. 頁面最上方有兩排篩選。第一排是「全部」「一般交易」「股票定期定額」，第二排是「近期」「進行中」「已結束」「全部」。預設「近期」：進行中的全部顯示，已到期的只顯示最近 7 天內到期的，手動停用且未到期的暫時隱藏。
2. 規則分成「進行中」與「已結束」兩組。每張卡片顯示備註或商家（沒有就顯示類型名稱）與金額，下方是分類與頻率摘要，右邊有開關可隨時啟用或停用。
3. 卡片下方有四個按鈕：
   - 「展開」／「收起」：看這條規則已產生的每一期，每一期顯示日期、金額，被單獨改過的有「已單獨編輯」標籤。每一期有「連同以後」「編輯」「刪除」。
   - 「終止未來週期」：刪掉這條規則已排好、還沒發生的所有期數，並停止再產生。已發生的紀錄保留。
   - 「編輯」：進入「編輯週期規則」頁。
   - 「刪除」：刪除規則與所有未來週期，已發生的記錄保留。

「編輯週期規則」頁可以改：金額、分類、帳戶（轉帳規則則是轉出與轉入帳戶）、商家、標籤、紅利回饋、頻率、間隔、下次執行時間、結束時間（可選）。「類型」只能看，不能改。儲存時會問「套用到未來交易？」，意思是這次的改動會同時套到規則本身，以及所有尚未發生、而且沒被你單獨改過的未來各期。已經發生的與被單獨改過的不受影響。

頻率、間隔、結束時間的改動不會搬動已排好各期的日期，只影響規則之後新長出來的期數。唯一例外是把結束時間改得更早：已排好、超出新結束時間且尚未發生的期數會被刪除。

### 💻 在 Web 上

入口：頭像選單 →「工具」→「週期性收支」。頂部有類型與狀態篩選（近期／進行中／已結束／全部）。每張規則卡有「查看已生成交易」、「終止未來週期」、「編輯」、「刪除」。展開後每一期有「連同以後」。

## 編輯或刪除其中一期

在明細月曆點週期產生的交易，按「編輯」或「刪除」前，會先跳出「這是一筆週期性交易」：

| 選項 | 效果 |
|---|---|
| 修改此記錄 | 只改這一筆，並標為「已單獨編輯」，之後的批次修改會略過它 |
| 修改連同未來週期 | 從這一期起，把你的改動套用到之後所有沒被單獨改過的期數與規則本身 |
| 刪除此記錄 | 只刪這一筆 |
| 刪除連同未來週期 | 刪掉這一筆與之後所有未發生的期數，規則同時停用 |

選「修改連同未來週期」時，標籤、專案、紅利回饋項目、手續費與折扣、備註、商家都會一起轉送，連「清空」也算一種修改（例如清掉備註，之後各期的備註也會被清掉）。附件、匯率與幣別、帳單標記、拆帳、延後入帳日是逐筆的資料，不會轉送。

Web 在交易列表或詳情點編輯時也有同樣的選擇視窗（「修改此記錄」「修改連同未來週期」），刪除規則時則問：「只刪除規則」（已產生的交易全部保留）或「同時刪除未來的收支記錄」。

## App 與 Web 的差異

| 項目 | App | Web |
|---|---|---|
| 在規則頁編輯規則本身 | 儲存時套用到所有未來、沒被單獨改過的各期 | 只更新規則本身與之後新產生的期數；要改已排好的各期，請用「連同以後」 |
| 星期幾、每月幾號 | 建立時在「進階設定」選 | 建立時用「進階規則」選；編輯既有規則時不能再改 |
| 規則編輯可改的欄位 | 沒有專案與手續費欄位 | 可設手續費與折扣 |
| 建立入口 | 新增交易頁的「單次」列 | 建立交易視窗的開關，或規則頁「新增規則」 |

## 轉帳類週期（自動扣款）

轉帳規則不會提前排好。它是「到期當天才產生」，產生前會檢查轉出帳戶的餘額，不夠就跳過那一期（不推進進度），並發通知告訴你。通知由雲端產生，點通知會跳到「週期記帳」。

## 注意事項／小提醒

:::warning 不能同時使用的功能
拆帳、分期與週期是互斥的：打開週期時按拆帳會提示「拆帳不能跟週期性收支同時使用，請先關閉週期性收支」。在「進階設定」裡「單次」「週期」「分期」也只能選一個。
:::

:::note 週期交易不支援的設定
由週期規則產生的交易，不支援「不計入收支」「不計入預算」、退款關聯與共享帳本覆寫。需要時，到單筆交易再編輯。
:::

:::tip 想關掉卻不想刪規則
把規則的開關關掉，它會變成「已結束」，之後不再產生，已發生的紀錄都保留，之後想用再打開。
:::
