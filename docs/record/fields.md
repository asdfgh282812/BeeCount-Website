記帳畫面欄位不少，但多數可以不填。這一頁把每個欄位的用途、預設值與小技巧整理在一起，需要時再回來查。

> 📱 App　💻 Web（兩邊欄位大致相同，差異會標出來）

## 為什麼這樣設計

App 的新增交易頁是單頁式表單：分類在最上面，金額與送出鍵在中間，其他欄位往下排。常用的（分類、金額、帳戶）一眼就看到，少用的（手續費、專案、標籤、附件）才往下找，目標是兩三下就記完一筆。

## 欄位總覽

### 📱 在 App 上

由上到下依序是：

| 欄位 | 說明 |
|---|---|
| 分類 | 必填。一次顯示兩行，有子分類的會整個換成子分類格 |
| 金額列 | 必填。幣別、手續費／折扣的「+」、金額、送出勾勾 |
| 名稱… | 備註，選填 |
| 商家… | 商家名稱，選填 |
| 帳戶 | 必填 |
| 專案 | 選填，預設「不指定專案」 |
| 標籤列 | 標籤、紅利回饋（信用卡才有）、附件、帳單標記四個小圖示 |
| 日期（與時間） | 預設現在 |
| 單次／週期／分期 | 只有新增時才有，見[週期性收支](./recurring.md)與[分期付款](./installment.md) |
| 常用金額 | 這個分類最近用過的金額，點一下代入 |

![新增支出分頁完整畫面，標出分類、金額列、名稱、商家、帳戶、專案、標籤列、日期](/img/record/fields-1.png)

### 💻 在 Web 上

Web 的「建立交易」是一個視窗，欄位依序為：帳本、類型（支出／收入／轉帳）、分類、金額、帳戶、關聯專案、商店（選填）、紅利回饋規則（信用卡才有）、時間、備註、設為週期性收支／設為分期付款（新增時）、不計入收支／不計入預算、關聯欠款、實際入帳日（選填）、標籤。

## 金額列與鍵盤算式

### 📱 在 App 上

1. 點金額那一格，下方出現計算機鍵盤：數字、`.`、`00`，以及 `÷` `×` `-` `+`。
2. 連續運算是由左到右逐步算：輸入 `100`，按 `+`，輸入 `50`，按 `×`，輸入 `2`，再按 Enter 形狀的算出鍵，結果是 300（先算 100+50，再乘 2），不是先乘後加。金額格裡會顯示算到一半的數字與運算符號，下面顯示目前結果。
3. `C` 清空全部，退格鍵刪一個字。小數最多兩位。
4. 還在運算時，按勾勾鍵會先算出結果；結果出來後再按一次才是送出。鍵盤上的勾勾在分類或金額沒填好時是灰色，不能按。
5. 點名稱或商家欄位時，系統鍵盤會暫時取代計算機；點回金額格，計算機又回來。

金額列最右邊的勾勾也是送出鍵。這一顆不管必填欄位有沒有填完都能按，沒填完會提示缺什麼，不會沒反應。

### 💻 在 Web 上

Web 的金額欄是一般輸入框，可直接打算式，例如 `1200+350`，支援 `+` `-` `*` `/` 與括號。按 `=` 或 Enter（離開欄位也會）就會把算式換成結果；算式打錯則維持原樣讓你修改。

## 幣別與外幣

金額左邊的幣別小標籤預設是帳本的主要幣別（預設 TWD）。想記一筆日圓消費：

### 📱 在 App 上

1. 先選好帳戶（例如台幣的「玉山銀行活存」）。
2. 點金額列的幣別標籤，選「JPY」。帳戶不會被清掉。
3. 輸入日圓金額，金額下方出現「≈ 台幣金額」的換算預覽。
4. 想改匯率或實際扣款金額，點開這一列的「幣別換算」視窗：「換算金額」與「匯率」互相連動，「採用線上匯率」關閉後才能手動改。
5. 查不到匯率時，送出會提示「請手動填寫本筆匯率後儲存」。

幣別與帳戶幣別是各自獨立的：台幣帳戶可以記日圓，外幣帳戶也可以記台幣。沒有手動改幣別時，選到外幣帳戶會自動帶入該帳戶的幣別。更多見[多幣種與匯率](../prepare/currency.md)。

### 💻 在 Web 上

金額下方有幣別選擇，與帳戶幣別不同時會出現換算列，可手動填換算金額或匯率。缺匯率時提示「缺少匯率，請手動輸入換算匯率」。

## 分類

分類是必填，沒選就送出會提示「請選擇分類」。

- 📱 分類格一次顯示兩行，格子內可上下捲動。點有子分類的分類，格子會換成它的子分類，第一格「返回」回到上一層。選好後分類變成一行，點它可重新展開。
- 一筆交易想分到多個分類，點分類旁的分岔圖示，見[拆帳與退款](./split-refund.md)。
- 💻 Web 在「分類」欄點開選擇。轉帳沒有分類。

## 帳戶

帳戶必填，沒選會提示「請選擇帳戶」。選擇器裡沒有「不選擇帳戶」，也不會列出純管理用的合併帳單主帳戶（只列真正能記帳的帳戶）。

- 📱 App 會自動幫你帶帳戶，依序是：你在這個分類最常用的帳戶、否則是資產頁設定的預設帳戶。你自己手動選過之後就不再自動換。
- 預設帳戶設定：「資產」頁右上角的設定圖示 →「設定」→「預設支出帳戶」「預設收入帳戶」，詳見[帳戶](../prepare/account.md)。
- 再次開啟選擇器時，已選的帳戶會排在最上面並標出勾勾。
- 選到信用卡時，標籤列會多一個禮物圖示，可選這筆適用的紅利回饋規則，見[紅利回饋](../credit-card/rewards.md)。
- 其他來源（背景自動記帳、舊資料匯入）找不到帳戶時，交易仍會建立並標為「待確認帳戶」。這時「資產」頁的「其他」分組會多一張「待確認帳戶」卡片，逐筆補選帳戶，補完之前這些交易不計入任何帳戶餘額。

## 日期與時間

- 📱 日期欄預設是現在，點開是月曆格選擇器：左上角的鍵盤圖示可以直接用四位數輸入月日（例如 `1009`），右上角「今天」，底下「取消」「確定」。可選未來日期。
- 時間欄預設不顯示。到「我的」→「個性化設定」開啟「顯示交易時間」，日期旁才會多一個時間欄，點開是時、分兩欄滾輪。
- 💻 Web 的「時間」欄同時選日期與時、分。

## 備註與商家

- 備註在 App 的欄位叫「名稱…」，Web 叫「備註」。商家是獨立欄位（App「商家…」、Web「商店」），日後可依商家搜尋。
- 📱 點名稱或商家欄位時，鍵盤上方會出現建議列，列出這個分類以前用過的備註或商家，點一下就填入，鍵盤保持開啟可繼續改。系統自動產生的備註（例如信用卡回饋入帳）不會出現在建議裡。歷史備註的顯示範圍、排序與數量可在「個性化設定」的「歷史備註」調整。

## 專案

「專案」列預設「不指定專案」。點開會列出帳本內的專案，有預算的專案旁邊顯示剩餘預算（超支為紅字），純記錄的專案顯示「純記錄」。專案的建立與管理見[專案](../prepare/project.md)。Web 欄位名稱為「關聯專案」，預設「不掛專案」。

## 標籤

點標籤列左邊的文字區（還沒選時寫「選擇標籤」）開啟選擇器，可複選。標籤管理見[標籤](../prepare/tag.md)。Web 在表單最下方的「標籤」欄選。

## 附件

標籤列的圖片圖示：沒有附件時點它選「拍照」或「從相簿選擇」，已有附件時點它進預覽頁，可繼續新增或刪除。詳見[附件](./attachment.md)。

## 手續費與折扣

刷卡手續費、折價券會讓實際付出的錢跟標價不一樣。用「+」把兩者分開記，既能看到原價，帳戶餘額也準。

### 📱 在 App 上

1. 點金額列左邊的「+」（提示「新增手續費/折扣」）。
2. 展開的面板有「手續費」與「折扣」兩列，各有名稱與金額，下方即時顯示「總額」。
3. 點手續費或折扣的金額數字，會叫出同一個計算機鍵盤（只有點到數字才會叫出）。此時鍵盤上的勾勾只是收起鍵盤，不會送出整筆交易。
4. 主金額輸入的是「原始金額」。送出後以「總額」入帳。
5. 不想用就點面板右下的「移除」。

總額算法：

- 支出：總額 = 原始金額 + 手續費 − 折扣
- 收入：總額 = 原始金額 − 手續費 + 折扣

例如標價 NT$1,000 的商品，手續費 30、折價券 100，支出的總額是 930。三個數字都不能是負數。名稱留空時分別用「手續費」「折扣」。編輯舊交易時金額顯示的是原始金額，面板會自動展開。

### 💻 在 Web 上

金額欄旁點「+」展開手續費與折扣，算法相同。

:::note 不能同時使用的情況
拆帳、週期性收支、分期付款、欠款都不支援手續費／折扣。
:::

## 紅利回饋預估與上限提示

選了信用卡帳戶並勾選回饋規則後，📱 App 會顯示「預計可獲得回饋：NT$xx」。如果這條規則在同一個帳單週期內，額度已被其他交易用掉一部分，下面會用警示色列出「〈規則名稱〉 已達上限，本筆僅能獲得 NT$xx」。這是在手機上估算的，實際入帳金額以雲端排程為準。回饋規則的設定見[紅利回饋](../credit-card/rewards.md)。

## 送出鍵與漏填提示

| 提示 | 原因 |
|---|---|
| 請選擇分類 | 沒選分類 |
| 請輸入金額 | 金額是 0 |
| 請選擇帳戶 | 沒選帳戶 |
| 請完成拆帳明細（至少 2 筆，且金額需大於 0） | 拆帳明細不足 |
| 請手動填寫本筆匯率後儲存 | 外幣查不到匯率 |
| 金額不可為負數 | 手續費或折扣是負數 |

送出成功時會有輕微震動與點擊聲，畫面關閉。Web 的對應提示為「請選擇分類。」「金額必須大於 0。」「請先選擇帳戶。」。

## 交易資訊卡：退款、刪除、複製、編輯

在明細月曆、搜尋、分類明細、帳戶「交易明細」等任何清單點一筆交易，不會直接進編輯，而是從下方彈出唯讀的「交易資訊卡」，避免手指誤觸改到資料。

### 📱 在 App 上

卡片右上角由左到右的圖示：

| 圖示 | 做什麼 |
|---|---|
| 還款／收款 | 只有欠款相關交易才有，直接進記錄還款頁，見[借還款](./debt.md) |
| 退款 | 開新增交易頁，類型自動對調（支出變收入），帶入金額、備註、帳戶與幣別，分類要自己選。金額改小就是部分退款，見[拆帳與退款](./split-refund.md) |
| 刪除 | 二次確認後刪除。週期或分期產生的交易會先問範圍 |
| 複製 | 開新增交易頁，帶入除了日期、附件以外的欄位，日期重設為現在 |
| 編輯 | 進入完整編輯頁 |

左上角是關閉。中間有附圖就顯示圖片（點圖可放大），沒有就顯示大分類圖示。下方依序是備註與金額、帳戶、標籤、商家、專案、單次或週期、日期時間；如果有手續費／折扣會顯示原始金額，拆帳交易有「拆帳」徽章與「分類明細」，被退款過的會列出「已退款」清單。

退款圖示在這幾種情況會變灰，長按或懸停可看原因：

- 已經退過款：「這筆交易已經退過款，不能重複退款」
- 這筆本身就是退款單：「退款交易不能再退款」
- 轉帳或餘額調整：「轉帳和估值調整不能退款」

餘額調整交易的「編輯」也會變灰，提示「調整交易不能編輯，刪除後重新調整即可」。

### 💻 在 Web 上

點交易列開啟「交易詳情」視窗，底部有「退款」「複製」「編輯」「刪除」。詳情會多顯示建立人與最後編輯人（共享帳本）、關聯欠款、延後入帳日等。

## 注意事項／小提醒

:::tip 先選分類再輸入金額
App 的順序是先選分類，再按金額輸入。選分類後，備註建議、常用帳戶、常用金額都會依這個分類更新，所以先選分類能省下最多步驟。
:::

:::warning 週期或分期產生的交易
編輯或刪除這類交易時，會先跳出視窗問你要改「這一筆」還是「連同未來」。詳見[週期性收支](./recurring.md)與[分期付款](./installment.md)。
:::
