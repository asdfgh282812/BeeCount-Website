從薪轉戶提 5,000 元放進錢包、把台幣換成日圓放進外幣帳戶、從活存轉錢去繳信用卡……這些錢只是換了個地方，總資產沒有變，就用「轉帳」記，不要記成支出再記成收入。這樣報表上的收入與支出才不會被灌水。

> 📱 App　💻 Web

## 為什麼這樣設計

轉帳會同時動到兩個帳戶：轉出帳戶減少、轉入帳戶增加。實際生活中銀行常收手續費，換匯時也常有匯差，所以轉帳另外提供「手續費」與「折損」兩個欄位，兩邊的帳戶餘額才能和銀行帳單一致。

## 怎麼操作

### 📱 在 App 上

1. 底部導覽列中間點「記帳」，新增交易頁上方切到「轉帳」分頁。
2. 畫面上方有兩張帳戶卡片並排：左邊「轉出帳戶」，右邊「轉入帳戶」，中間是左右箭頭的交換鍵。點卡片選帳戶，同一個帳戶不能同時出現在兩邊。選反了就點交換鍵。
3. 輸入金額（用法同[記帳欄位](./fields.md)的計算機鍵盤）。
4. 需要的話填名稱、商家、標籤、附件，並確認日期。
5. 點金額列右邊的勾勾，或鍵盤上的「✓」送出，會提示「轉帳記錄建立成功」。

![轉帳分頁：左邊轉出帳戶、右邊轉入帳戶、中間交換鍵，下方是金額列](/img/record/transfer-1.png)

兩張帳戶卡片上會顯示帳戶目前的餘額。餘額不是 0 時，餘額旁有一個向下的小箭頭（提示「代入目前餘額」）：點轉出側會把整個餘額填進金額，適合「把這個戶頭的錢全部轉走」。

開啟轉帳分頁時，App 會自動帶入你上一筆一般轉帳的兩個帳戶，因為轉帳的來源與去處通常很固定。

### 💻 在 Web 上

1. 到「交易」頁點「建立交易」，上方類型選「轉帳」。分類欄會變成不可選。
2. 選「轉出帳戶」與「轉入帳戶」（兩者不可相同，否則提示「轉出與轉入帳戶不可相同。」）。
3. 輸入金額，必要時展開手續費或折損，按「建立交易」。

兩個帳戶欄位旁各有「代入目前餘額」的按鈕。

## 跨幣別轉帳

轉出與轉入帳戶幣別不同時（例如台幣轉到日圓帳戶），畫面會多出「轉入金額」區塊：

1. 區塊右上角預設開著「採用線上匯率」，轉入金額由系統依匯率算出，欄位唯讀，下面一行小字顯示「1 TWD = 4.7 JPY」這樣的匯率。
2. 想記下銀行實際換到的金額（含匯差），關閉「採用線上匯率」，自己輸入轉入金額。
3. 跨幣別時一定要有轉入金額，沒填會提示「請輸入轉入金額」。
4. 換帳戶或按交換鍵後，轉入金額會重置，避免留下上一組帳戶的數字。
5. 編輯舊的跨幣別轉帳時，轉入金額會原樣回填，視為手動值，不會被線上匯率蓋掉。

轉出帳戶扣「金額」，轉入帳戶加「轉入金額」。線上匯率是以帳本主要幣別為基準換算的；如果轉出與轉入都不是主要幣別，會經由主要幣別中轉，預覽可能略有誤差，這時關掉開關手動填最準。匯率的來源與管理見[多幣種與匯率](../prepare/currency.md)。

Web 的跨幣別轉帳也是同樣的邏輯：選了不同幣別的帳戶後，出現「轉入金額」欄與換算匯率。

## 手續費與折損

### 📱 在 App 上

- **手續費**：金額列左邊有個「+」（提示「新增手續費」）。展開後填手續費名稱（預設「手續費」）與金額，幣別是轉出帳戶的幣別。轉出帳戶實際扣款 = 金額 + 手續費。
- **折損**：轉入金額區塊右上角的「+」（提示「新增折損」）。適合對方收到的比轉出的少的情況，例如跨行匯款對方銀行扣費。轉入帳戶實際入帳 = 轉入金額 − 折損。

兩個開關互相獨立，各有「移除」。金額不能是負數，折損也不能大於轉入金額（提示「折損金額不能超過轉入金額」）。同幣別轉帳預設不顯示轉入金額區塊，打開折損後才會出現。

### 💻 在 Web 上

金額標題旁的「+」是手續費；轉入金額旁另有折損的「+」，各有「移除」按鈕。

:::note 手續費怎麼算進統計
轉帳的手續費記在轉出側，會計入支出統計。轉帳本身不算收入也不算支出。
:::

## 轉出 → 轉入的顯示

轉帳在明細月曆、搜尋結果、分類或專案或標籤的明細清單、交易資訊卡上，都會寫成「轉出戶名 → 轉入戶名」，一眼看出錢去哪裡。跨幣別轉帳列表上的「≈」金額，是你實際轉入的金額換算成帳本主要幣別後的數字，不是用即時匯率重算。

## 信用卡繳費的帳戶記憶

從信用卡的詳情頁進入轉帳繳款時，轉出帳戶會自動帶入「上次繳這張卡所用的帳戶」。如果你在轉帳分頁手動把轉入帳戶選成某張信用卡，且轉出帳戶還沒選，也會自動帶入該卡上次的繳款來源帳戶。繳 A 卡的帳戶不會被帶到繳 B 卡，從首頁新增的一般轉帳帶入的也是上一筆一般轉帳，不會被繳款記錄影響。

:::warning 手動轉入信用卡不等於繳款
自己用轉帳分頁記一筆轉入信用卡，系統視為收入（例如退款），不會算進「已繳金額」，也不會出現在繳款記錄裡。要繳款請走信用卡的繳款功能，詳見[信用卡繳款](../credit-card/payment.md)。繳款是靠交易備註前綴「信用卡繳款（帳單…」判斷的，請不要手動改掉。
:::

## 注意事項／小提醒

:::note 轉帳沒有的功能
轉帳沒有分類、不能拆帳、不能退款、沒有「不計入收支」標記（轉帳本來就不進收支）。週期性轉帳規則目前不支援手續費與折損。
:::

:::tip 週期自動轉帳
每月固定轉帳（例如固定存款）可設成週期性規則，見[週期性收支](./recurring.md)。
:::
