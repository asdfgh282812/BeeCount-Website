一年過去，你記了幾筆帳？錢最多花在哪？哪個月最瘋狂？年度回顧把這一年做成像限時動態一樣的故事，點一下翻一頁，最後揭曉專屬於你的年度稱號。

> 📱 App（入口叫「年度帳單」，在報表頁頂部）　💻 Web（入口叫「年度報告」）

## 為什麼這樣設計

- **一章一個主角數字。** 財務數字需要時間看，所以不會自動播放翻頁，由你自己點。
- **每年都不一樣。** 配色、冷知識、猜謎題目都會隨年份改變，但同一年每次打開看到的是一樣的內容。
- **只算已經結束的年度才提醒。** 新年 1 月 1 日起，首頁會提醒你看去年的完整一年，不會在年底拿不完整的數字來提醒。

## 怎麼操作

### 📱 在 App 上

#### 進入年度回顧

- 底部點「報表」，報表清單最上面固定有一張「年度帳單」卡，點進去就是年度回顧（4.0 起從「我的」搬到這裡）。每年 12 月到隔年 1 月，這張卡會換成主色底、寫著「年度回顧準備好了」。
- 新的一年開始後，首頁（日曆上方）會出現「〈年份〉 年度回顧出爐了」卡片，點卡片任何地方或「查看」就開啟那一年。

![App 年度回顧封面：生肖標籤、年份與主題標語](/img/analysis/annual-1.png)
*圖中：封面上方是章節進度、年份切換、分享與關閉，輕點右側進下一章，輕點左側回上一章*

提醒卡的規則：

| 項目 | 規則 |
|---|---|
| 何時出現 | 每年 1 月 1 日起，提醒「去年」，沒有截止日 |
| 何時消失 | 看過那一年的回顧（從首頁的提醒卡或「報表 → 年度帳單」皆可），或按 ✕ |
| 不出現 | 去年沒有任何收支（例如新使用者） |
| 年中偷看今年 | 不算看過，隔年 1 月照樣提醒完整版 |

「看過」只記在這台裝置，不跟帳號同步；在另一支手機上看過，那一支仍會再提醒一次。只會提醒去年，不會補提醒更早的年份。

#### 翻頁方式

1. 點畫面**右側**進入下一章，點**左側**回上一章，也可以左右滑。
2. 頂部有分段進度條、年份標籤（點開可從最近 5 年選一年）、分享、關閉。
3. 最後一章按「再看一次」從頭看，或按「生成分享海報」。
4. 第一次進入會有操作導覽，之後想重看：「我的 → 功能說明 → 年度回顧」。

所有金額會跟著你的「隱藏金額」設定，收支和股票漲跌色也依你的顏色設定。

#### 章節內容

章節依序是：封面 → 記了幾筆 → 第一筆 → 收支總結 → 錢去哪了 → 每月起伏 → 花錢的節奏 → 平均下來 → 冷知識 → 年度高光 → 跟去年比 → 股票總覽 → 股票亮點 → 成就 → 壓軸（年度稱號）。**沒有資料的章節不會出現**，例如沒有股票交易就沒有股票章，去年沒有收支就沒有「跟去年比」。

#### 每年都不一樣

- **生肖主題：** 封面有生肖標籤（例如「🐴 馬年 · 奔騰」）和大圖騰，整份回顧與分享長圖的配色隨年份轉換，12 年一輪。生肖以西曆年份為準，不處理農曆新年前的 1 月。
- **冷知識：** 從你的帳裡找出有趣的事實，例如最晚的一筆記帳時間、單日記最多筆的那天、最常光顧的商家、重複最多次的金額、最小一筆、最常記帳的星期幾、全年支出換算成幾杯珍奶。門檻設得高，寧缺勿濫，每年抽 3 則。
- **先猜再揭曉：** 「錢去哪了」「每月起伏」兩章會先出題（「你覺得錢最多花在哪個分類？」「你覺得今年哪個月花最多？」），選完才翻答案，猜錯會告訴你正確答案。翻回去不會再問；點空白處等於略過。

![App 年度回顧的壓軸章：年度稱號、稀有度標籤與三項依據](/img/analysis/annual-4.png)
*圖中：壓軸章揭曉年度稱號與稀有度、三項判斷依據，下方有「生成分享海報」與「再看一次」*

- **稀有稱號：** 壓軸會揭曉年度稱號，有「普通」「稀有」「傳說」三種稀有度，稀有以上會灑彩帶。

| 稀有度 | 稱號 | 條件 |
|---|---|---|
| 傳說 | 全勤記帳王 | 年度到目前每天都有記帳（至少 60 天） |
| 傳說 | 鋼鐵意志 | 連續記帳超過 100 天 |
| 傳說 | 超級存錢筒 | 儲蓄率 50% 以上 |
| 稀有 | 盤面操盤手／領息達人 | 股票風格為積極交易／領息獵人 |
| 稀有 | 儲蓄達人 | 儲蓄率 30% 以上 |
| 稀有 | 記帳模範生 | 連續記帳 30 天以上 |
| 普通 | 週末享樂派、專一消費派、自由冒險家、穩健平衡派 | 週末日均花費是平日 1.5 倍以上、單一分類占支出 40% 以上、花得比賺得多、其他 |

  依上表由上而下判斷，符合第一個就是你的稱號。年度記帳不到 10 筆時只顯示結語，沒有稱號。

- **成就與隱藏成就：** 成就章列出「持之以恆」（連續記帳 7 天）、「精打細算」（年度結餘為正）、「明察秋毫」（記帳 100 筆），有股票時還有 5 個股票成就。另外有「從頭記到尾」（年度第一天和最後一天都有記）、「夜貓子」（凌晨 0 到 5 點記了 10 筆以上支出）兩個**隱藏成就，解鎖了才會出現在清單**。App 沒有跨使用者的統計，所以不會告訴你「有多少 % 的人拿到這個稱號」。

#### 股票章

該年度有股票買進、賣出或股利時，會多兩章：

![App 年度回顧的「股票年度總覽」章：年度已實現損益、買賣金額與股利收入](/img/analysis/annual-3.png)
*圖中：股票年度總覽章列出年度已實現損益、交易筆數、買進與賣出金額、股利收入與手續費證交稅，以及交易了幾檔標的*

- **股票總覽：** 年度已實現損益、交易筆數（買幾筆賣幾筆）、買進與賣出金額、股利收入、手續費與證交稅、交易標的數。有多種幣別時用上方標籤切換，各幣別分開、不相加。
- **股票亮點：** 你的投資風格（積極交易者、領息獵人、長期持有者、波段操作者、新手上路）、最賺與最賠的一筆、勝率、領息王、最常交易、每月已實現損益。

股票買賣是轉帳，不計入收支，所以「收支總結」章若有股票買賣，會補一行說明投資淨投入，解釋為什麼「儲蓄」不等於剩下的現金。已實現損益依年度內的賣出計算，成本沿用全部歷史，去年買、今年賣也算得對。股票的賺賠顏色用「股票漲跌顏色」設定。細節見[股票持股](../invest/overview.md)與[股利與已實現損益](../invest/dividend.md)。

#### 節日標籤

如果「我的 → 外觀 → 節日」是開啟的，那一年的「第一筆」「年度高光」（最大支出、最大收入）若剛好落在節日，日期旁會多一個節日標籤，例如「🥮 中秋節」。「平均下來」章也會多一個「節日花最多」：哪個節日、哪一天、花了多少，沒有節日支出就不顯示。若你另外勾選了其他國家的節日，非主要國家的節日名稱後面會加國旗。

#### 台灣在地化

年度回顧的金額只顯示數字，不帶其他貨幣符號，數字用台灣格式，文案是繁體中文。年度範圍依帳本的設定計算，見[帳本](../prepare/ledger.md)。

#### 分享長圖

在壓軸章按「生成分享海報」，會產生一張同風格的長圖：封面卡（含年度稱號）、各章重點、股票區塊。預覽畫面可以先打開「隱藏收入」，總收入、儲蓄率、最大收入與股票金額都會遮罩，再存到相簿或分享。

### 💻 在 Web 上

1. 首頁（總覽）最上方會出現同樣的「〈年份〉 年度回顧出爐了」提醒卡，點整張卡直接開啟去年的回顧；也可以點頭像，在「帳本與回顧」群組點「年度報告」，或用 ⌘K 搜尋，先選年份。
2. 翻頁：點畫面右側 70% 下一章、左側 30% 上一章，也支援觸控左右滑、鍵盤 ← → 與空白鍵、滾輪、點進度條直接跳章。
3. 章節順序：封面 → 記了幾筆 → 跟去年比 → 錢去哪了 → 每月起伏 → 帳戶 → 時段 → 平日／週末 → 難忘時刻 → 記帳畫像 → 冷知識 → 標籤 → 股票 → 成就 → 年度稱號。
4. 生肖主題、冷知識、先猜再揭曉、稀有稱號與隱藏成就的規則與 App 一致；傳說稱號是「全勤記帳王」「超級存錢筒」「自律記帳王」（連續記帳 100 天以上），隱藏成就中的「夜貓子」在 Web 叫「午夜場常客」。
5. 提醒卡規則跟 App 相同，另外有一個條件：目前帳本去年記帳筆數不到 30 筆就不顯示。看過的年份記在這個瀏覽器，不跟帳號同步，所以 App 看過、Web 仍會提醒一次。
6. 「生成海報」會產生一張同風格的長圖（含年度稱號、QR 碼），可下載。
7. Web 以瀏覽器的本地時間切年度，台灣 1 月 1 日凌晨的帳會算在新的一年。

## 注意事項／小提醒

:::note
- 年度還沒過完時從「報表 → 年度帳單」看今年，「跟去年比」是拿「今年到今天」對「去年全年」。
- 年度收支都是 0（整年只有股票轉帳）時，會顯示「暫無資料」，不會出現股票章。
:::
