帳務資料很私密。手機被朋友借去滑一下、舊手機換掉後帳號還登在上面，都讓人有點不安。這一頁整理幾個保護資料的方法：看有哪些裝置登入過、幫 App 加上 PIN 碼或生物辨識鎖、在 Web 啟用二次驗證。

## 為什麼這樣設計

資料雖然放在雲端，但「誰拿到你的手機」也是風險。所以 App 有自己的鎖，不用登出就能擋住旁人；Web 則提供裝置列表讓你看得到帳號被用在哪裡。

## 線上裝置

> 💻 Web

「裝置」頁會列出登入過你帳號的裝置，方便你確認有沒有不認識的。

1. 把滑鼠移到右上角頭像，在「設定」分組點「裝置」。
2. 每台裝置是一張卡片，標題是裝置名稱，右上角有「在線」或「離線」標籤。卡片上會顯示平台、App 版本、裝置型號、系統版本，以及「最近活躍」「首次登入」的時間；如果有記錄，還會顯示最近的 IP。
3. 上方可以搜尋，並選擇看「最近 30 天」或「全部歷史」。
4. 「去重裝置」會把同一台裝置合併成一張卡，並標示有幾個「連線數」（工作階段）；改選「全部工作階段」則一筆一筆列出。

![Web 的「裝置」頁](/img/sync/devices-1.png)

:::note
目前這一頁只能查看，沒有「踢掉某台裝置」的按鈕。如果你懷疑帳號被別人使用，請聯絡管理員處理。App 裡沒有這個頁面。
:::

## 健康檢查

> 💻 Web

「健康」頁讓你確認伺服器本身有沒有在正常運作，同步不動時可以先看這裡。

1. 在頭像選單的「設定」分組點「健康」。
2. 看到「運行中」就代表伺服器正常。下方還會顯示「資料庫」、「在線使用者」數量與「伺服器時間」。
3. 按「重新整理」重新取得狀態。

![Web 的「健康」頁](/img/sync/devices-2.png)

一般使用者只會看到這些基本資訊。全站的使用統計是管理員才看得到的。

手機上的同步狀態檢查在 App 的「我的 → 同步」，見[雲同步與離線](./overview.md)。

## App 鎖（PIN 碼與生物辨識）

> 📱 App

App 鎖會在你開啟 App 或從背景切回來時，要求輸入 4 位數 PIN 碼，或用 Face ID、指紋解鎖。就算別人拿到你解鎖後的手機，也打不開蜜蜂記帳。

### 開啟 App 鎖

1. 點底部的「我的」，進入「個性化設定」。
2. 找到「應用鎖」（說明是「PIN碼與生物辨識保護隱私」），點進去。
3. 開啟「啟用應用鎖」。
4. 依畫面輸入兩次 4 位數密碼：先「請設定新密碼」，再「請再次輸入密碼」。成功會顯示「密碼設定成功」。

### 調整設定

開啟之後，同一頁還可以：

- 「修改密碼」：先輸入目前的密碼，再設定新密碼。
- 「生物辨識解鎖」：用 Face ID 或指紋快速解鎖。這個選項只有手機支援且已設定生物辨識時才會出現，開啟時會先請你驗證一次身分。
- 「自動鎖定時間」：切到背景多久之後要重新解鎖，可選「立即」「1分鐘後」「5分鐘後」「15分鐘後」。

### 關閉 App 鎖

在「應用鎖」頁把「啟用應用鎖」關掉，需要先輸入目前的密碼，成功會顯示「應用鎖已關閉」。

:::tip 多工畫面也會模糊
開啟 App 鎖後，你在手機上切換 App、查看多工畫面時，蜜蜂記帳的內容會被模糊處理，旁人看不到金額。這個保護只在 App 鎖開啟時才有。
:::

:::warning 忘記 PIN 碼怎麼辦
App 沒有「忘記密碼」的重設流程。如果忘記，需要解除安裝再重新安裝 App，並重新登入。因為資料都在雲端，登入後會自動回來，但還沒同步到雲端的修改會遺失，所以請把密碼記好。
:::

## 二次驗證（2FA）

> 💻 Web

二次驗證會在「用帳號密碼登入」時，多要一組 authenticator App（例如 Google Authenticator、1Password）產生的 6 位數動態碼。

:::note 這個設定可能用不到
這個版本的登入主要是用 SSO（在瀏覽器完成登入）。二次驗證只會在帳號密碼登入時被要求，通常 SSO 的登入安全由身分服務負責。是否需要啟用，請依管理員的說明為準。App 的「雲同步」頁會顯示你的二次驗證狀態（「已啟用 ✓」或「未啟用」），但設定要到 Web 進行。
:::

### 啟用

1. 頭像選單 → 「個人資料」，找到「二次驗證」，點開視窗後按「啟用」。
2. 用 authenticator App 掃描畫面上的 QR code，或手動輸入畫面上的 secret，按「下一步」。
3. 輸入 App 上顯示的「6 位動態碼」，按「驗證並啟用」。
4. 畫面會顯示一組恢復碼。這些碼只會出現這一次，請按「複製全部」或「下載 .txt」存好，勾選「我已經妥善保存這些恢復碼」再按「完成」。

恢復碼是在你的 authenticator App 不見時救急用的，每個碼只能用一次。

### 重新產生恢復碼或停用

- 在同一個視窗按「重新生成恢復碼」，輸入目前的動態碼，會產生 10 個新碼，舊的全部失效。
- 按「禁用」，需要輸入「帳號密碼」與目前的 6 位動態碼確認。停用後所有恢復碼都會失效。

## 注意事項／小提醒

- App 鎖只保護這一支手機的 App，換新手機要重新設定。
- 不要把授權金鑰、恢復碼、邀請碼截圖傳到公開的地方。
