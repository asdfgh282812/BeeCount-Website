這個月錢花到哪去了？哪家店吃最多？信用卡回饋大概領了多少？統計報表把同一份帳目換不同角度看：每月、每週、每年各有一份預設報表，你也可以建一份「只看某個專案」「排除某個帳戶」的專屬報表。

> 📱 App　（Web 沒有清單式報表，請看「在 Web 上」）

## 為什麼這樣設計

- **報表是「期間 + 篩選條件」的組合。** 同一份報表可以一直往前、往後翻期，不用每次重選日期。
- **十個分頁看同一份資料。** 切換分頁不會重新計算，所以很快。
- **只能點上方分頁切換，不能左右滑。** 這是為了讓趨勢圖的左右滑（翻上一期、下一期）不會跟分頁切換打架。

## 怎麼操作

### 📱 在 App 上

#### 報表清單

底部導覽第 4 個分頁「報表」，進去是報表清單，預設有「每週報表」「每月報表」「每年報表」，卡片上顯示該期的收入、支出、結餘。

![App 報表分頁：每月、每週、每年三份報表，各顯示支出、收入與結餘](/img/analysis/statistics-1.png)

- 右上「+」新增報表；右上「恢復」圖示可以把刪掉的預設報表加回來（全部刪光後不會自動補回，要按「恢復預設報表」）。
- 卡片右側「⋯」可以「編輯」「複製」「刪除」。
- 長按卡片拖曳可以調整順序。

#### 看一份報表

點開一份報表，頂部可以：

![App 每月報表的總覽分頁：支出收入結餘、主要支出類別與前三大支出](/img/analysis/statistics-2.png)

- 點左右箭頭翻到上一期、下一期，點中間的期間文字可以選到更早的期間。選單只列到你帳本第一筆交易那一期，到頭就不能再往前翻。
- 右上「篩選」（有條件時顯示數字徽章）、「編輯」；只有「每 1 月」或「每 1 年」且沒有篩選的報表，才有「分享」海報按鈕。

十個分頁，點上方分頁列切換：

| 分頁 | 看什麼 |
|---|---|
| 總覽 | 支出、收入、結餘、筆數；主要支出類別前 5 名；TOP 3 支出；商家統計 |
| 明細 | 趨勢圖加交易列表，可切換「支出／收入／結餘」，列表可選「新到舊／舊到新」，點圖上的點會捲到那一天 |
| 類別 | 圓餅圖、分類排行、趨勢，可切「支出／收入／結餘」，一級分類可展開子分類 |
| 排行 | 單筆金額排行 |
| 帳戶、專案、帳戶分組、名稱、商家、標籤和對象 | 依該維度分組的金額與佔比 |

「明細」分頁的「結餘」會列出全部記錄，包含轉帳，這是轉帳在報表裡唯一會列出的地方。

#### 支出、收入、轉帳、回饋金切換

「帳戶」「專案」「帳戶分組」「名稱」「商家」「標籤和對象」「排行」這幾個分頁，上方可以四選一：「支出／收入／轉帳／回饋金」。

![App 報表的帳戶分頁，上方可切換支出、收入、轉帳、回饋金](/img/analysis/statistics-3.png)

- **轉帳：** 只算轉帳（不含餘額調整）。帳戶和帳戶分組的轉帳金額是「轉入 + 轉出」，同一筆轉帳會同時出現在兩個帳戶，所以這兩個維度的佔比是用各列合計算的，頁面下方有註腳。
- **回饋金：** 依信用卡回饋規則**估算**的金額，算法跟回饋明細頁相同，實際入帳金額以發卡行為準。回饋規則怎麼設，見[紅利回饋](../credit-card/rewards.md)。
- 一筆記錄有多個標籤時，每個標籤都會算一次，各列加總可能大於總額。

#### 點進去看明細（下鑽）

點任一列，會開啟只列「同一類」的交易列表，標題下方標出目前是哪一類，例如「2026-09 · 支出」。在「支出」點某個專案，不會混進該專案的收入和轉帳。支出的下鑽列表也會列出扣在這些支出上的退款單，退款單雖然顯示為收入，金額已從合計扣掉，所以表頭合計和每一列加起來是對的。

#### 收支上色

金額顏色照你的「收支顏色方案」顯示（在「我的 → 個性化設定 → 收支顏色方案」，「紅色收入 · 綠色支出」或「紅色支出 · 綠色收入」）。收入和回饋金用收入色、支出用支出色、轉帳用中性色；結餘大於等於 0 用收入色，小於 0 用支出色。分享海報和年度回顧也一起跟隨。

#### 新增或編輯報表

1. 清單右上點「+」，或在報表頁點「編輯」。
2. 填「名稱」。
3. 選「期間」類型：
   - 「重複循環」：每 N 日／週／月／年，會一期一期往前後翻。月和年依帳本的「每月起始日」切，每 N 月會對齊，例如每 3 月就是從 1、4、7、10 月起。
   - 「截至今天」：「最近 N 個單位」或「從指定日期起」，也可以選「全部時間」。
   - 「單一區間」：自己選開始與結束日期。
4. 回到報表頁點「篩選」，可以對記錄類型、分類、帳戶、專案、名稱、商家、標籤、對象設「包含」或「排除」，也可以限定金額範圍；頁首會顯示「已套用 N 個篩選條件」，「清除全部篩選」可以一次還原。
5. 儲存。

![App 新增報表頁：名稱、期間類型、單位與篩選條件](/img/analysis/statistics-5.png)

#### 登入雲端後，報表跟著帳號走

登入 BeeCount Cloud 後，你的報表清單、名稱、篩選、順序和刪除都會同步到帳號，換手機或重裝後會還原。兩台裝置同時離線各改一份報表時，以最後修改的那一份整份為準，不會逐筆合併。每份報表目前翻到第幾期不會同步。

### 💻 在 Web 上

Web 沒有清單式的統計報表，對應的是：

- 首頁（總覽）的各種圖表卡片，可以用「自訂首頁」排列。
- 並排比較月份的「比較報表」，見[比較報表](./comparison.md)。

## 統計口徑

- 只算收入和支出。**轉帳和餘額調整不計入收支**，只出現在「明細」列表與「帳戶／帳戶分組」的轉入、轉出。
- 設為「不計入統計」的帳單不算，見[帳單標記](../record/flags.md)。
- 退款會扣回原本那筆的分類，詳見[拆帳與退款](../record/split-refund.md)。拆帳交易依明細金額分別歸到各分類。
- 外幣交易用折算後的本位幣金額。
- 統計時間看交易發生日，不看延後入帳日。
- 每月起始日不是 1 的帳本，期間依帳本設定切，見[帳本](../prepare/ledger.md)。

### 買股票為什麼報表上看不到

股票買賣是轉帳，不是支出，所以「支出」不會因為你買了 0050 而變多；股利是收入，會算進收入。為了讓你查得到錢去哪了，沒有套用篩選的報表「總覽」會多一行：

- 「投資淨投入 +X」，附「買進 · 賣出」與「未計入收入與支出」。
- 「手續費與證交稅 X（投資成本，不計入支出）」。
- 「股利收入 X（已計入收入）」。

期間內沒有任何股票買賣或股利時，這一塊不會出現；套了篩選的報表也不顯示（篩選範圍和股票明細對不上）。

## 注意事項／小提醒

:::tip
翻報表的期間不會動到首頁的月份，兩邊各自獨立。
:::

:::note
目前不支援報表匯出 CSV，也不能自訂每份報表顯示哪些分頁。「類別」分頁只有「支出／收入／結餘」，沒有轉帳和回饋金。
:::
