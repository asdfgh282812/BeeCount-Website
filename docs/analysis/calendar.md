想看「哪幾天花得多」、「上禮拜五到底買了什麼」，月曆最直覺。蜜蜂記帳的「明細」分頁就是月曆：每一天顯示當天的收支淨額，點一天就能看到那天的交易。

> 📱 App　💻 Web

## 為什麼這樣設計

- **月曆放在最常用的位置。** 記帳大多是「今天」或「補記某一天」，所以月曆直接放在「明細」分頁，原本按日期分組的長列表移到「明細」按鈕後面，並加上時間篩選。
- **選中的日期會被記住。** 翻到下個月仍停在同一天、記帳時日期自動帶入，少按幾次。

## 怎麼操作

### 📱 在 App 上

#### 月曆上看什麼

底部導覽中間的按鈕是「明細」，點進去就是月曆（在「明細」分頁時，這顆按鈕會變成「記帳」）。

- 每一格是日期加當天的**淨額**（收入 − 支出）：正數帶 +，負數帶 −，超過千或萬會簡寫成 k、w（例如 +1.2k、−3.4w）。顏色照你的收支顏色方案。
- 轉帳不算進淨額。如果某天只有股票買賣（轉帳），格子會顯示一個小圖示，表示那天有紀錄。
- 開啟「節日」後（「我的 → 個性化設定 → 節日」），節日那格右上角會有節日 emoji，補假顯示「休」；點選節日那天，左上會出現「節日名 · 台詞」。

點一天，下方就列出當天的交易；沒有交易時顯示「當天無交易」。點交易可以看詳情、編輯、複製。

![明細分頁的月曆，選中一天並列出當天交易](/img/analysis/calendar-1.png)

#### 翻月、跳月、回今天

- 左右滑動或點標題兩側的箭頭翻月。**翻月時會保留選中的「日」**：目前選 9/7，翻到下個月就停在 10/7；目標月份沒有那一天（例如從 1/31 翻到 2 月）就停在該月最後一天。
- 點標題「2026年10月 ▾」，可以用年月選擇器直接跳到某個月。
- 點月曆上方右側的「今天」，回到今天。

#### 週視圖

在月曆上**向上滑**，月曆收成只剩一週；**向下滑**，再展開回整個月。收成週視圖後，會定位在你選中那天所在的那一週，點「今天」也會跳到今天所在的那一週。

![App 月曆往上滑收成一週的週視圖，選中日的交易列在下方](/img/analysis/calendar-2.png)

#### 從選中的日期快速記帳

1. 在月曆上點選要記帳的那一天。
2. 點底部中間的「記帳」按鈕。
3. 新增交易頁會直接帶入那一天的日期，時間沿用現在的時間。

沒有選日期時，記帳預設是今天。日期欄可以改選未來的日期，例如預先登記下週的訂閱扣款。

#### 「明細」按鈕：交易列表

首頁頂部右側有一顆「明細」圖示（收據圖案），點開是依日期分組的交易列表，上方有時間篩選：

![App 明細頁：上方可選今日、七天內、一個月內、全部，下方依日期列出交易](/img/analysis/calendar-3.png)

- 「今日」（預設）
- 「七天內」：含今天在內最近 7 個自然日。
- 「一個月內」：從今天往前推一個月。
- 「全部」

這幾個篩選沒有設上限，所以未來日期的交易（除了「全部」）也會看到，避免手滑設錯日期的交易憑空消失。列表右上有搜尋圖示，怎麼搜尋與批次處理見[搜尋與批次處理](../record/search-batch.md)。

:::tip
每週要從週一還是週日開始排，可以到「我的 → 個性化設定」的「每週起始日」調整。
:::

### 💻 在 Web 上

1. 點頂部右上角的日曆圖示（提示文字「日曆」），或用 ⌘K 命令面板搜尋「日曆」。
2. 月曆的每一格是**色塊**：顏色越深，代表當天金額越大（色塊越深 · 當天金額越大），顏色跟隨你的收支顏色，網頁左下有圖例。
3. 點一天，右側列出當天的交易；沒有交易時顯示「當日無交易」。
4. 點「新增」可以直接記到選中的那一天，時間預設是中午 12:00。
5. 左右「上月／下月」翻月，「今天」回到今天。網址帶有目前的月份和日期，重新整理或分享連結都會回到同一天。
6. 鍵盤：方向鍵移動日期（跨月自動換月）、N 新增、T 回今天、⌘[ 與 ⌘] 翻月（Windows 用 Ctrl）。
7. 週一為每週第一天（中文介面）。

![Web 日曆，色塊代表當天金額大小](/img/analysis/calendar-4.png)

## 注意事項／小提醒

:::note
- 月曆格子的淨額只算收入和支出；轉帳（含股票買賣）、餘額調整不在裡面。
- 「明細」分頁的月曆以每月 1 日起算；帳本若設定了「每月起始日」，統計報表的月份才會依它切。
:::
