# 第一次记账（Web 版）

这一篇假设你是**第一次使用蜜蜂记账**——不管你有没有用过手机 App，只要打开了 Web 版就能照着这篇把第一笔账记下来。还没登录的话先看[总览](./overview.md#登录)。

## 打开记账窗口

Web 端目前没有单独的「+」记账按钮，统一通过右上角的**命令面板**打开：

1. 按快捷键 **`⌘K`（macOS）/ `Ctrl+K`（Windows / Linux）**，或直接点右上角的搜索框
2. 面板顶部「快捷操作」第一项就是 **新建交易**，直接按 **Enter**（或用鼠标点它）即可打开记账窗口——熟悉之后，面板打开时直接按字母 **`N`** 也能触发同一个操作

![记账窗口](/img/web/record-form.jpg)

## 记账窗口字段说明

窗口打开后是一张空白表单，逐项说明：

| 字段 | 说明 |
|---|---|
| 帐本 | 这笔交易记到哪个帐本，默认是当前帐本；如果你有多本帐（比如个人 + 家庭共享帐本），在这里切换 |
| 类型 | **支出**（花掉的钱）/ **收入**（赚到的钱）/ **转账**（钱从一个账户移到另一个账户，不影响总资产，比如把现金存进银行卡） |
| 金额 | 数字键盘直接输入 |
| 时间 | 默认是现在，改成过去的日期时间就能补记之前忘记记的账 |
| 分类 | 这笔钱花在什么类型上（餐饮、交通、购物……），用于后续的统计分析；类型选「转账」时不需要分类 |
| 帐户 | 钱实际在哪里（现金、储蓄卡、信用卡……）；分类回答「花在哪种事情上」，帐户回答「钱在哪个地方」，两者不是同一件事 |
| 标签 | 可选，给交易打一个或多个自定义标签，方便之后筛选（比如「报销」「旅行」） |
| 备注 | 可选，写清楚这笔钱具体是什么，比如商家名称 |
| 不计入收支 | 打开后这笔交易不会算进本月收入/支出统计，适合借出去之后收回来这种不算真实花费的流水 |
| 不计入预算 | 打开后这笔交易不会扣减对应分类的预算额度 |

如果分类或帐户列表是空的（刚注册的新帐号常见），先去[分类管理](../app/category/manage.md)、[帐户管理](../app/account/manage.md)建几个——这两页 App 和 Web 共用同一份设置，不用重复设置两次。

## 填一个例子

比如中午买了一份 120 元的午餐：类型选「支出」，金额填 `120`，备注写「午餐」，分类选「餐饮」，帐户选付款用的那张卡或现金。

![填好的记账窗口范例](/img/web/record-form-filled.jpg)

确认无误后点右下角**「建立交易」**保存，窗口关闭，这笔交易马上出现在[交易列表](../app/features/record.md)里。

## 记账技巧

- **月底批量导出对账**：命令面板 → 输入「匯出」→ 选「匯出本月 CSV」，比逐笔核对快很多
- **忘记记的账别放弃，直接补记**：打开记账窗口后把「时间」改成实际发生的日期，跟当天记的效果一样
- **常态性的收支不用每次手动记**：房租、订阅费这类每月固定发生的，用 [Cloud 進階功能 → 週期性收支](./cloud-advanced/recurring.md) 设一次规则，之后系统自动生成
- **桌面端可以直接拖图/贴图记账**：截个消费凭证的图，`⌘V` 贴到页面里交给 AI 识别，见 [AI 图片识别](../app/ai/image.md#web-端图片记账)
