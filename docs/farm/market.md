菜收成了，總得有地方放、有人買。這一頁說明收成之後的故事：放在哪裡、什麼時候會壞、怎麼賣，以及一個像投資教室的大頭菜小生意。

> 📱 App

## 為什麼這樣設計

- **作物有保存期限。** 放太久的作物會壞掉，這是為了避免無限囤貨、等價格漲了再賣，逼你自己判斷什麼時候出手。
- **賣出要等買家。** 在攤位上架後，買家會過一小段時間才來，不是按下去就立刻拿錢，讓「賣菜」有點像真的在擺攤。
- **行情會起伏。** 作物價格不是固定的，讓你有時會想「再等等」，有時會想「現在賣」。
- **大頭菜是投資教室。** 它有風險、有賺有賠、你只看得到現在的價格，看不到未來，就像真正的投資一樣。農場借它來提醒你：投資有賺有賠，大頭菜也是。

## 怎麼操作

### 📱 倉庫與板條箱

進入「農場 → 倉庫」（或點農場上設成倉庫用途的建築），可以看到所有庫存。

- **收成會先放進倉庫**；倉庫滿了，剩下的才會放進板條箱。兩邊都放不下時，這次收成會失敗，作物留在田裡。
- **倉庫和板條箱是各自獨立的空間。** 只有放在**倉庫**裡的作物才能上架賣出；板條箱裡的作物要先搬回倉庫。每批作物右邊有箭頭，點一下就能在兩邊之間搬移，數量比較多的時候會讓你選要搬多少。
- **種子與道具不占空間**，永遠放在倉庫，也不能搬進板條箱。
- 每批作物會標出**到期時間**，過了就會壞掉消失，快過期的先賣。

倉庫不夠用時可以這樣做：

1. 在倉庫頁按「擴充倉庫」（或到「商店 → 擴充」），花好幣**永久**增加倉庫的格數。
2. 到「佈置農場 → 擺設」買**板條箱**放進農場，每個板條箱提供額外的收納空間，不過它佔位子。點農場上的板條箱也會直接開倉庫頁。

![倉庫頁：倉庫與板條箱的使用量，下方依批次列出作物與到期時間](/img/farm/market-1.png)
*圖中：倉庫頁上方顯示倉庫與板條箱各自的使用量，下面每批作物標有到期時間，右邊的箭頭可以搬到另一邊*

### 📱 市場：在攤位上架賣出

進入「農場 → 市場」，畫面上有幾個攤位。

1. 點空攤位，在清單裡選要賣的作物（旁邊會標出目前的行情）。
2. 選數量，確認。數量選單有「減少」「增加」，也能直接輸入數字，或按「全部」一次選到最大數量，最後按「確定」才會送出。
3. 上架後作物會離開倉庫，攤位顯示「等待買家」和一條等待進度條。**價格以上架那一刻為準**，之後行情怎麼變都不影響這一筆。
4. 買家會在一小段時間內到來，你不用守著，離開 App 也一樣會成交。
5. 成交後，攤位顯示「已成交，點選領取」。**貨款先留在攤位上**，點一下攤位才會領進錢包，這時會有好幣飛向錢包的小動畫。

:::note
- 如果作物在買家到來**之前**就先壞掉，這批就賣不出去了；但已經成交的貨款，不會因為之後才過期就消失。
- 離開很久再回來，成交的攤位仍然在等你領取。
- 市場上沒有「一鍵全部領取」，各個攤位各點各的。
:::

#### 行情怎麼變

一般作物的行情每天會更新好幾次，在合理範圍內小幅起伏。雲端農場裡，如果大家都在賣同一種作物，那種作物的價格會被壓低一點，所以不一定每次都賣最熱門的最划算。每種作物的實際價格，以你上架當下看到的為準。

### 📱 大頭菜

大頭菜**不能種**，只能向菜販買進，是個用來「投機」的商品。

- **週日**：整天都能買進，價格每週不同。每週有購買量的上限。
- **週一到週六**：每天依時段會有不同的收購價，你可以挑覺得高的時候賣。
- **沒賣完的**，到下一個週日凌晨就會爛掉，所以不能無限放著。
- 每個人每週的行情走勢都是自己抽的，彼此不一樣；你看不到未來的價格，只能從現在已經出現的價格去猜接下來會漲還是跌。有時候大賺，有時候血本無歸。

入口有兩個：「農場 → 市場」右上角的大頭菜圖示，或在倉庫裡直接點大頭菜。頁面上會**分開顯示**幾種數量，避免弄混：

- 本週累計購買了多少（賣出不會讓購買額度恢復）
- 目前持有多少（含放在板條箱裡的）
- 倉庫裡現在能賣多少（板條箱裡的要先搬回倉庫）

也會列出持有批次的腐壞時間。買不到時，頁面會直接告訴你原因：倉庫放不下、本週購買量已到上限，或好幣不夠。

![大頭菜頁：本週累計購買、目前持有、倉庫可賣，與買進、賣出按鈕](/img/farm/market-7.png)
*圖中：大頭菜頁分開顯示本週購買量、目前持有量與倉庫可賣量，下面是買進與賣出*

雲端農場還有一種玩法：**去農友的農場賣大頭菜**，用對方農場當下的收購價賣。這是從動物森友會得到的靈感，見[社交](./social.md)。

## 注意事項／小提醒

:::tip
- 收成前先看一下倉庫還有多少空位，收成失敗的話作物會繼續留在田裡。
- 快過期的作物先賣；作物擺越久，越容易白白壞掉。
- 大頭菜的錢是遊戲幣，賠了不會影響你真實的錢，但也別把所有好幣都押進去，好幣還要拿來買種子、擴地。
:::

:::note
- 攤位數量有限，賣得快的話不用一次把所有作物都上架。
- 板條箱裡的作物不能直接賣；移除板條箱時，裡面的作物會退回倉庫，倉庫放不下就不能移除。
:::
