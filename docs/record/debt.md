朋友週轉跟你借了 10,000 元說下個月還；或是你跟家人借了一筆錢買機車。這些錢確實進出了你的帳戶，但它不是一般的收入或支出，而且要記得「還剩多少沒還」。借還款功能把這種往來獨立出來追蹤，剩餘金額由收款、還款紀錄即時算出。

在 App 裡這個功能叫「應收應付款項」，本頁沿用「借還款」稱呼。

> 📱 App　💻 Web　需登入帳好嗎 Cloud（款項資料與 App、Web 同步；到期提醒與未結清通知由雲端產生）。

## 為什麼這樣設計

借出去的錢是你的資產（應收款項），借進來的錢是負債（應付款項）。所以款項會計入「資產」頁的淨資產，不會混進當月的收入與支出。

為了不灌水收支，借出、借入、每一次收款與還款都**不計入收支、也不計入預算**，但帳戶餘額照常變動，錢的流向在帳戶上看得清楚。只有你選「轉為支出／轉為收入」（呆帳處理）時，才會產生一筆計入收支的交易。

## 兩個方向

| 方向 | 意思 | 建立「新款項」時帳戶餘額 | 收款／還款時 |
|---|---|---|---|
| 應付款項 | 我向別人借錢（借入） | 選的帳戶增加 | 「還款」，帳戶減少 |
| 應收款項 | 我借給別人（借出、代付） | 選的帳戶減少 | 「收款」，帳戶增加 |

記帳頁分別叫「應付」與「應收」。Web 的方向名稱是「我欠款」與「別人欠我」。

## 怎麼建立款項

### 📱 在 App 上

方式一，從記帳頁：

1. 新增交易頁切到最右邊的「借貸」分頁。4.0 之前「應收」「應付」是兩個分頁，現在合併成「借貸」，頂部用切換鍵選「應收」或「應付」。
2. 選一個「分類」。預設的應收分類有「借出」「代付」「報帳」，應付分類有「借入」「信貸」「車貸」「房貸」，可以自己新增或編輯，管理在「我的 → 資料管理 → 分類管理」的「應收」「應付」分頁。分類必選，沒選會提示「請選擇分類」。
3. 用計算機鍵盤輸入金額，填「對象」。點對象欄位時，鍵盤上方會列出近期用過的對象（依使用次數排序，最多 20 個），點一下就帶入，不用重打。需要時寫備註。
4. 選「帳戶」（新款項必填，沒選會提示「請選擇帳戶」）。
5. 需要時選「日期」「到期日」（可「清除到期日」）。應收款項且用信用卡帳戶時，還會出現「紅利回饋」。
6. 單次、分期、款項類型、不納入總餘額這些選項在最下面的設定列（例如「單次 · 新借出」），下一節說明。
7. 送出。

![記帳頁的「借貸」分頁（應收）：頂部切換應收／應付，下方是分類、金額、對象、帳戶、日期與進階設定](/img/record/debt-1.png)
*圖中：頂部的應收／應付切換、分類格、金額與對象、帳戶、到期日，最下面的設定列顯示目前的單次／分期與款項類型*

方式二，從應收應付款項頁：底部「規劃」分頁 →「未來的錢」→「應收應付款項」，點右上角「＋」，會開啟同一個借貸分頁，欄位相同。4.0 之前這個入口在「資產」頁最下方的「其他」分組，現在已搬到規劃分頁。

送出新款項後，系統會同時建立款項與一筆「起點交易」，立刻改動所選帳戶的餘額（見上表）。起點交易不算收款或還款，所以新款項的剩餘金額不會一建好就被沖成 0。

款項本金一律以帳本主要幣別計。

### 進階設定

點最下面顯示「單次 · 新借出」等摘要的設定列，開啟「進階設定」視窗，裡面可以選：

| 項目 | 說明 |
|---|---|
| 單次／分期 | 分期會依期數建好未來每個月的收款或還款排程，並顯示「每期 …，共 … 期」 |
| 款項類型 | 應付：「新借入」（現在才借到，錢會實際存進帳戶）或「既有欠款」（開始記帳前就借了，只登記目前還欠多少，不動帳戶）。應收：「新借出」或「既有應收」；分期時還多一個「代刷分期」 |
| 期數與日期 | 分期時填「分期期數」（既有款項則是「剩餘期數」）與首次或下期的收款日、還款日；代刷分期是「首期刷卡日」 |
| 還款帳戶／收款帳戶（選填） | 既有款項分期時，指定到期時要入帳或扣款的帳戶 |
| 不納入總餘額 | 只影響淨資產總額統計，清單與通知仍會照常顯示 |

「既有」款項不會建立起點交易、不動帳戶，本金就是登記時的剩餘金額。分期的各期金額由總額與期數平均分配，除不盡的尾差放在最後一期，沒有利息。

「代刷分期」只有應收款項才有：幫別人代刷信用卡分期時，每一期各自成為一筆應收款項，從你的卡刷出，各期分別追蹤。

![借貸分頁的「進階設定」視窗：單次或分期、款項類型、期數與不納入總餘額](/img/record/debt-4.png)
*圖中：進階設定視窗，由上到下是單次／分期、款項類型、分期期數與日期，最下面是「不納入總餘額」*

### 💻 在 Web 上

1. 到「交易」頁點「建立交易」（右上角全域的「＋」也是同一個視窗），上方類型選「應收」或「應付」（只有帳本擁有者看得到這兩個選項）。
2. 版面跟 App 一樣：分類（欠款分類）、金額、對象與備註、帳戶與時間、到期日，以及「進階設定」（單次或分期、款項類型、期數、首期日、不納入總餘額）。
3. 按「建立交易」。

也可以到應收應付款項頁新增：右上角頭像（滑鼠移上去）→「記帳工具」→「應收應付款項」，右上角「新增款項」，同樣可選應收或應付。

Web 新增款項目前還不能勾選信用卡紅利回饋，要用回饋請在 App 建立。

在「建立交易」視窗的支出或收入，也可以在拆帳時掛欠款，見[拆帳與退款](./split-refund.md)。

## 記錄收款或還款

### 📱 在 App 上

1. 到「應收應付款項」頁，點要處理的那一筆，在跳出的選項點「新增收款」（應收）或「新增還款」（應付）。也可以在相關交易的[交易詳情](./fields.md#交易詳情退款刪除複製編輯)上點「收款」或「還款」圖示，或點到期提醒通知直接進入。
2. 進入「記錄收款」或「記錄還款」頁：「金額」預設是剩餘金額（可改小做部分收款或還款）、選「帳戶」、「日期」，也可選「分類」「備註」。
3. 儲存，會產生一筆對應的交易（不計收支，只動帳戶餘額）。

![App 記錄收款頁：金額、帳戶、日期、分類與備註](/img/record/debt-3.png)
*圖中：記錄收款頁，金額預設帶入剩餘金額，下方是帳戶、日期與備註*

同一位對象有好幾筆未結清款項時，可以一次收還：在款項清單勾選多筆（見下一節），按底部的「新增收款」或「新增還款」。這時畫面標題是「新增多筆收款」或「新增多筆還款」，上方每一筆款項各顯示自己分到的金額，依借出日由舊到新先收滿；「＋」可以再加入其他同方向的款項，頁底顯示「剩餘款項：…」，超過剩餘金額會被擋下。多筆收不滿時，會問你要「繼續追蹤」剩餘款項，還是「視為結清」。

![App 新增多筆收款頁：上方各款項分到的金額，頁底顯示剩餘款項與不足金額](/img/record/debt-6.png)
*圖中：多筆收款頁，每一筆款項顯示各自分配到的金額，頁底是剩餘款項與不足的金額*

### 💻 在 Web 上

款項列點開選單選「新增收款」或「新增還款」，填金額、帳戶、日期與備註後記錄。勾選多筆時，底部出現「新增收款」或「新增還款」，規則與 App 相同：依借出日由舊到新分配，超過剩餘金額會擋下，收不滿時問「繼續追蹤」或「視為結清」。

## 應收應付款項頁

入口：底部「規劃」分頁 →「未來的錢」→「應收應付款項」。入口卡片顯示的是跨所有帳本的淨應收或淨應付；點進去的款項頁只顯示目前帳本的款項，兩者範圍不同。

![App 應收應付款項頁：進行中、未開始、已完成三個分頁，下方依對象分組列出款項](/img/record/debt-2.png)
*圖中：上方是進行中、未開始、已完成三個分頁與對象篩選，下方依對象分組，每筆款項顯示金額、狀態與標籤*

- **三個分頁**：「進行中」「未開始」「已完成」，各帶筆數。借出日在未來的款項（例如代刷分期還沒到的那幾期）在「未開始」。已結清或已停止追蹤的在「已完成」。
- **對象篩選**：分頁下方一排「全部」與每位對象的名字，點一位只看他的款項。
- **依對象分組**：每組的標題列有收合鈕、對象名稱與筆數、「借還款歷史」圖示、合計，以及整組勾選。
- **每一列**：顯示日期時間、備註（沒有就顯示款項類型）、對象與分期、到期或逾期、狀態（尚未收款、尚未還款、部分收款、待出帳、未開始、已結清、已停止追蹤）、金額，以及類型、帳戶、「不納入總餘額」等標籤。
- **右上角**：左邊是「對象設定」，右邊是「＋」新增。

狀態是即時算的：還有剩餘是「尚未收款」或「尚未還款」，收了一部分是「部分收款」或「部分還款」，剩餘為 0 是「已結清」。「已停止追蹤」是你手動標的，優先於金額判斷。分期的排程在到期前不算已收或已還，會顯示「待出帳 …」，帳戶餘額也要到期日才變動。

### 點一筆款項

點款項列會跳出選項：

| 選項 | 說明 |
|---|---|
| 查看詳情 | 進入「編輯欠款」頁，見下方「編輯款項」 |
| 新增收款／新增還款 | 款項還沒完成時才有，進入記錄收款或還款頁 |
| 收款歷史／還款歷史 | 列出起點與每一筆收還款，點一列開啟該筆交易 |
| 停止追蹤／重新追蹤 | 見下方「停止追蹤」 |
| 不納入總餘額／納入總餘額 | 切換這筆是否計入淨資產總額統計 |

![App 點一筆款項跳出的選項：查看詳情、新增收款、收款歷史、停止追蹤、不納入總餘額](/img/record/debt-5.png)
*圖中：點款項列後的選項視窗，列出查看詳情、新增收款、收款歷史、停止追蹤與不納入總餘額*

### 勾選多筆

在「進行中」或「未開始」分頁，每一列右邊有勾選框，組頭可以整組勾選。勾選後底部出現「新增收款」或「新增還款」（帶合計金額）與「…」選項（停止追蹤、不納入總餘額）。應收與應付不能混選，混選會提示「應收和應付要分開收還款」。

### 借還款歷史與對象設定

- 組頭的「借還款歷史」圖示，或交易詳情上的「查看借還款歷史」：上方彙總該對象的應付款項、還款金額、剩餘款項（或應收款項、收款金額、剩餘款項），下方時間軸由新到舊，列出每一筆起點與收還款。
- 右上角「對象設定」：可以搜尋對象、修改對象名稱，點對象名字看歷史。改成已存在的名字時會提示「已有同名對象，改名後會合併成同一個對象」。

![App 借還款歷史：上方彙總，下方依時間列出每一筆借出與收款](/img/record/debt-7.png)
*圖中：對象的借還款歷史，上方是應收款項、收款金額與剩餘款項的彙總，下方是由新到舊的時間軸*

### 💻 在 Web 上

入口：頭像選單 →「記帳工具」→「應收應付款項」。版面與 App 相同：進行中、未開始、已完成三個分頁，對象篩選，依對象分組，點一列出現選單（查看詳情、新增收款、收款歷史、停止追蹤或重新追蹤、不納入或納入總餘額），勾選多筆後底部出現「新增收款」或「新增還款」。組頭有借還款歷史。

## 停止追蹤、重新追蹤與刪除

- **停止追蹤**：對方不會還了、或不想再追蹤時，在選項點「停止追蹤」。會先問「需要把未收款項轉為額外支出嗎？」（應付則是「轉為額外收入」），可選：
  - 「轉為支出」（應付是「轉為收入」）：進入轉換頁，選一個支出（或收入）分類，帳戶預設是起點交易的帳戶，備註預設「呆帳」。帳戶餘額不變：剩餘款項視為已收回（或已還清），另外記一筆同額、計入收支的支出（或收入），代表這筆錢由你自己吸收。
  - 「停止追蹤」：只標記結束，不產生交易。
  - 沒有收完就停止追蹤不代表已全額還清，只是不再追蹤。停止追蹤後不計入淨資產。還沒到期的分期款項會一併刪除，之後重新追蹤不會長回來。
- **重新追蹤**：已停止追蹤的款項，在選項點「重新追蹤」。
- **刪除**：在「編輯欠款」頁右上角的垃圾桶。只有還沒有任何已發生的收款或還款記錄時才能刪（有記錄時提示「這筆欠款已有還款記錄，無法刪除」）。只有未來排程的款項可以刪，排程會一起刪。刪除前會二次確認。
- 刪掉款項的起點交易時，若還沒有收還款記錄，款項也會一併刪除；已有記錄的話只刪交易、款項保留。

## 編輯款項

在款項選項點「查看詳情」進入「編輯欠款」頁。頁面上方是唯讀資訊（款項類型、日期、分期、剩餘與待出帳）。方向與本金建立後不能改。可以改到期日、分類、備註、「排除計入總額」與對象名稱。改對象名稱時，欄位下方會提示「修改對象名稱會套用到此對象名下所有記錄」，儲存後這位對象的所有款項一次改名。

「排除計入總額」只影響淨資產總額統計，款項清單與通知仍照常顯示。

## 通知

需登入帳好嗎 Cloud，通知在首頁鈴鐺的待處理中心，歸在「欠還款」分頁：

- **到期提醒**：有到期日的款項，到期前會出現並固定釘在列表最上方。點通知直接進還款頁（已帶入剩餘金額）。每筆款項只提醒一次。
- **未結清對象**：不看到期日，只要某位對象還有沒結清的款項就會有，會彙總金額與筆數，結清後自動變已讀，點它會跳到「應收應付款項」頁。

通知總覽見[通知與提醒](../more/notifications.md)。

## 注意事項／小提醒

:::note 一般交易欄位限制
款項不支援手續費／折扣，也不能拆帳（拆帳中掛欠款另見拆帳與退款）或設成週期。款項本金一律以帳本主要幣別計。
:::

:::tip 想改款項的起點交易
點起點交易或收還款交易的「編輯」，開啟的是款項專用的編輯畫面，而不是一般記帳頁，才改得到本金、收還款金額等款項專屬的欄位。
:::

:::note 網頁建立的款項在 App 沒出現
更新 App 到最新版並同步一次，會自動補回。
:::

:::note 收支統計不含借還款
借出、借入、收款、還款不算收入或支出，所以月報表的數字不會因為借還款而變動，只有「轉為支出／轉為收入」那一筆會計入。舊版本（4.0 之前）記下的借還款也已經一併改成不計收支。
:::
