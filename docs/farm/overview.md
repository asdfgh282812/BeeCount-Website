記帳這件事，做久了難免冒出「今天先不記，明天一起補」的念頭。所以**帳好嗎**在首頁放了一座小農場：你有記帳，水壺就比較充裕，每週還有好幣可以領；沒記也不會被罰，只是種起來比較辛苦一點。

農場是 4.0 起新增的輕量小遊戲，**不會修改你的帳目或帳戶餘額**，不想玩的話可以整個關掉（見[設定、通知與小技巧](./settings.md)）。

> 📱 App（玩農場）　💻 Web（只有每週排行榜，不能種田）

## 為什麼這樣設計

- **獎勵好的記帳習慣，不是獎勵有錢。** 農場看的是你有沒有常記、花得穩不穩、有沒有存下來，不看金額多寡。收入高不會比較吃香，沒有收入的學生或家管也一樣能拿高分。
- **輕輕玩就好。** 照顧農場不需要整天盯著，記完帳順手進去看一眼、澆澆水、收個菜就夠了。作物就算你關掉 App 也會照常生長。
- **跟真實世界連動。** 季節、天氣、日夜都是真的，下雨天你的菜也在淋雨，換季時田裡沒收的菜會枯掉。
- **好幣只是遊戲幣。** 好幣和真實金錢完全獨立：不能用真錢買，不能換回真錢，也不會出現在任何帳戶或報表裡。農場裡的任何事都不會動到你的帳戶餘額。

## 怎麼操作

### 📱 在 App 上

#### 怎麼進入農場

首頁頂部下方有一條細長的「農場」小卡。還沒開過農場時，它會寫著「種當季的菜；每日記帳補充水壺，每週依記帳表現領好幣。」；開過之後，會改成顯示你現在的好幣和水壺還剩幾次。點它就進去了。

![首頁頂部下方的農場小卡，顯示好幣與水壺次數](/img/farm/overview-1.png)
*圖中：首頁帳本標題列下方的「農場」小卡，點一下進入農場*

第一次進入時：

- **沒有登入帳好嗎 Cloud（單機）**：畫面中央會有「開啟農場」按鈕，按下去就會建立這支手機上的農場。
- **已登入帳好嗎 Cloud**：會自動載入你帳號的雲端農場，換手機登入也一樣。如果你的帳號還沒有農場，會看到「建立雲端農場」，可以選「新建農場」，或把這支手機上的單機農場「搬遷」過去，接著取一個**農場暱稱**（拜訪、互動紀錄與排行榜都會用這個名字）。

![第一次進入農場，畫面中央有「開啟農場」按鈕](/img/farm/overview-2.png)
*圖中：還沒開啟農場時的畫面，按「開啟農場」建立農場*

![登入後建立雲端農場：選擇新建農場或搬遷單機農場](/img/farm/overview-3.png)
*圖中：帳號還沒有雲端農場時，可以選「新建農場」或「搬遷單機農場」*

#### 農場畫面長什麼樣子

農場是一整個全螢幕的像素畫面，不需要翻頁：

- **左上角**是返回，旁邊依序是這幾個膠囊：**好幣**（點下去進「週結算」）、**水壺**（今天還能澆幾次水）、**等級**（點下去看升級進度）。
- **右上角**是設定；登入雲端的農場還多一個「農場社交」（人像圖示）。
- **下面一列**是天氣、季節，雲端農場還有「誰來過」。點天氣可以看到目前的氣溫與降雨，點季節可以看到下次換季的日期。
- **畫面中間**就是你的田。點空田可以播種，點作物會在旁邊彈出氣泡，上面有澆水、除草、除蟲、收成等動作。
- **最下面一排**是「商店」「市場」「倉庫」「佈置農場」。

![農場主畫面：左上好幣、水壺、等級，下方天氣與季節，田地與底部的功能鈕](/img/farm/overview-4.png)
*圖中：農場主畫面，上方是好幣、水壺、等級與天氣季節，中間是田地，底部是商店、市場、倉庫與佈置農場*

第一次進到農場，以及第一次進到商店、市場、倉庫、佈置、設定、社交等各個頁面時，App 會用「聚光燈」一步一步指給你看，每個頁面只會自動介紹一次。錯過或想重看，到「我的 → 功能說明」，最下面的「農場」分組都可以重播，詳見[功能說明與新功能](../preface/tour.md)。

### 單機與雲端有什麼差別

農場有兩種存檔方式，取決於你有沒有登入**帳好嗎 Cloud**：

| | 單機（沒登入） | 雲端（登入**帳好嗎 Cloud**） |
|---|---|---|
| 種田、商店、市場、倉庫、佈置、大頭菜、週結算 | ✅ 都能玩 | ✅ 都能玩 |
| 存檔放哪 | 這支手機，會包含在快照備份裡 | 你帳號的雲端農場，換手機登入就回來 |
| 拜訪、幫忙、偷菜、看門狗、誰來過 | 沒有（畫面上不會出現社交相關按鈕） | ✅ |
| 每週排行榜 | 沒有 | ✅（App 和 Web 都看得到） |
| 農場通知 | 沒有 | ✅（集中在待處理中心的「農場」分頁） |
| 沒網路時 | 照常玩 | 只能看最後同步的畫面，不能操作 |

幾件事要知道：

- 一旦登入**帳好嗎 Cloud**，農場就**一律以帳號的雲端農場為準**，原本的單機農場不再顯示。第一次建立雲端農場時，可以選「搬遷」把單機農場的田地與庫存複製過去（好幣有帶入上限，歷史結算不會帶過去）。
- 雲端農場的週結算由伺服器用你已同步的交易計算，所以記帳資料同步得越及時越好，見[記帳怎麼影響農場](./bookkeeping.md)。
- 社交只有雲端農場才有，玩法見[社交](./social.md)。

### 💻 在 Web 上

Web **沒有種田的畫面**，只有一頁「農場排行榜」，用來看每週的名次。入口與說明見[社交：每週排行榜](./social.md)。

## 農場的整個流程

1. **記帳**：每天記帳，水壺比較充裕；每週依記帳表現結算，領好幣。
2. **種田**：用好幣買當季的種子，播種、照顧、收成。
3. **賣出**：收成放進倉庫，拿到市場賣，或趁行情好時處理；大頭菜是個有風險的投機小生意。
4. **花掉**：好幣拿來擴充田地與倉庫、買保護作物的道具、佈置農場。
5. **升級**：收成累積經驗，升級解鎖更多作物、能買更多田，還會送道具寶箱。
6. **（雲端）社交**：拜訪農友、幫忙、留下表情，也有人會來偷菜，每週還有排行榜。

## 注意事項／小提醒

:::note
- 好幣不能換成真錢，農場裡的動作也不會改變任何一筆交易或帳戶餘額。
- 季節與每週的界線都以**台北時間**計算。
- 單機農場如果發現手機時間被往回調，會暫停操作，等時間恢復正常再玩，避免時間錯亂把作物狀態弄壞。
:::
