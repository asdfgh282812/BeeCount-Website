想看「哪幾天花得多」、「上禮拜五到底買了什麼」，月曆最直覺。帳好嗎的「首頁」就是日曆（4.0 之前叫「明細」分頁）：每一天顯示當天的收支淨額，點一天就能看到那天的交易。

> 📱 App　💻 Web

## 為什麼這樣設計

- **日曆放在最常用的位置。** 記帳大多是「今天」或「補記某一天」，所以日曆直接放在「首頁」，未設定時先顯示一週，今天的交易一進來就看得到，也可以在「我的 → 一般」改成預設顯示一個月；原本按日期分組的長列表移到「全部交易」按鈕後面，並加上時間篩選。
- **選中的日期會被記住。** 翻到下個月仍停在同一天、記帳時日期自動帶入，少按幾次。

## 怎麼操作

### 📱 在 App 上

#### 日曆上看什麼

底部導覽中間的按鈕是「首頁」，點進去就是日曆（已經在首頁時，這顆按鈕會變成「記帳」）。

- 每一格是日期加當天的**淨額**（收入 − 支出）：正數帶 +，負數帶 −，超過千或萬會簡寫成 k、w（例如 +1.2k、−3.4w）。顏色照你的收支顏色方案。
- 轉帳不算進淨額。如果某天只有股票買賣（轉帳），格子會顯示一個小圖示，表示那天有紀錄。
- 開啟「節日」後（「我的 → 外觀 → 節日」），節日那格右上角會有節日 emoji，補假顯示「休」；點選節日那天，左上會出現「節日名 · 台詞」。

點一天，下方就列出當天的交易；沒有交易時顯示「當天無交易」。點交易可以看詳情、編輯、複製。

![首頁的日曆預設只顯示一週，選中一天並列出當天交易](/img/analysis/calendar-1.png)
*圖中：首頁日曆預設顯示一週，標題列有年月與「今天」，每格標示當天收支，下方列出選中那天的交易*

#### 翻週、翻月、跳月、回今天

- 左右滑動或點標題兩側的箭頭翻週（展開整月時是翻月）。**翻月時會保留選中的「日」**：目前選 9/7，翻到下個月就停在 10/7；目標月份沒有那一天（例如從 1/31 翻到 2 月）就停在該月最後一天。
- 點標題「2026年10月 ▾」，可以用年月選擇器直接跳到某個月。
- 點標題列的「今天」，回到今天。

#### 一週與整個月

**設定預設顯示方式**：到「我的 → 一般 → 行事曆預設顯示」，選「一週」或「一個月」。未設定時是「一週」；修改後會立即套用到首頁，也會保存為之後開啟日曆的預設。全新帳號也能在[首次登入個人化引導](../preface/install-login.md#首次登入個人化引導)的「習慣怎麼看帳」這一步選擇。

**臨時切換**：點標題列最右邊的「展開整個月」（⌄）看整月，或點「收合成一週」（⌃）收回一週。在日曆上**向下滑**展開、**向上滑**收合也一樣有效。這些操作不會改掉你在設定中選的預設顯示方式。

切換時會保留選中的日期；收成一週後，會定位在那天所在的一週。點「今天」會回到今天，並維持目前的一週或整月檢視。

:::note 僅於 App 生效
「行事曆預設顯示」可以在 App 或 Web 設定並同步，但只影響 App。Web 日曆仍從月檢視開始，頁面上的週／月切換獨立運作。
:::

![App 展開整個月的日曆，選中日的交易列在下方](/img/analysis/calendar-2.png)
*圖中：點標題列最右邊的「展開整個月」後，日曆展開成整個月，選中日的交易列在下方*

#### 從選中的日期快速記帳

1. 在月曆上點選要記帳的那一天。
2. 點底部中間的「記帳」按鈕（在首頁時，中間鍵就是「記帳」）。
3. 新增交易頁會直接帶入那一天的日期，時間沿用現在的時間。

沒有選日期時，記帳預設是今天。日期欄可以改選未來的日期，例如預先登記下週的訂閱扣款。

#### 「全部交易」按鈕：交易列表

首頁頂部右側有一顆「全部交易」圖示（清單圖案，4.0 之前叫「明細」），點開是依日期分組的交易列表，上方有時間篩選：

![App 全部交易頁：上方可選今日、七天內、一個月內、全部，下方依日期列出交易](/img/analysis/calendar-3.png)
*圖中：上方有搜尋與今日、七天內、一個月內、全部的篩選，下方依日期分組，標示每天的收入與支出合計與當天的交易*

- 「今日」（預設）
- 「七天內」：含今天在內最近 7 個自然日。
- 「一個月內」：從今天往前推一個月。
- 「全部」

這幾個篩選沒有設上限，所以未來日期的交易（除了「全部」）也會看到，避免手滑設錯日期的交易憑空消失。列表右上有搜尋圖示，怎麼搜尋與批次處理見[搜尋與批次處理](../record/search-batch.md)。

:::tip
每週要從週一還是週日開始排，可以到「我的 → 一般」的「每週起始日」調整。
:::

### 💻 在 Web 上

1. 點頂部右上角的日曆圖示（提示文字「日曆」），或用 ⌘K 命令面板搜尋「日曆」。
2. 月曆的每一格是**色塊**：顏色越深，代表當天金額越大（色塊越深 · 當天金額越大），顏色跟隨你的收支顏色，網頁左下有圖例。
3. 點一天，右側列出當天的交易；沒有交易時顯示「當日無交易」。
4. 點「新增」可以直接記到選中的那一天，時間預設是中午 12:00。
5. Web 預設顯示整月，可點右上角的箭頭在一週與一個月之間切換；選中的日期會保留。這個切換不會改寫 App 的「行事曆預設顯示」。
6. 左右箭頭在月檢視翻月、週檢視翻週，「今天」回到今天。網址帶有目前的月份和日期，重新整理或分享連結都會回到同一天。
7. 鍵盤：方向鍵移動日期（跨月自動換月）、N 新增、T 回今天、⌘[ 與 ⌘] 翻月或翻週（依目前檢視，Windows 用 Ctrl）。
8. 每週從星期一或星期日開始，依「每週起始日」設定排列；這個設定會與 App 同步。

![Web 日曆，色塊代表當天金額大小](/img/analysis/calendar-4.png)
*圖中：Web 日曆的月曆格是色塊，紅色是進帳多的日子、綠色是花得多的日子，左下有圖例說明顏色越深代表當天金額越大，右側顯示選中那天的明細與合計，並可在這天新增一筆*

## 注意事項／小提醒

:::note
- 月曆格子的淨額只算收入和支出；轉帳（含股票買賣）、餘額調整不在裡面。
- 首頁的日曆以每月 1 日起算；帳本若設定了「每月起始日」，統計報表的月份才會依它切。
:::
