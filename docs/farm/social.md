農場裡不是只有你一個人。登入帳好嗎 Cloud 之後，同一台伺服器上的農友都能互相拜訪：幫忙澆個水、留個表情，或是……趁主人不在偷一點菜。每週還有排行榜，看誰記帳記得最勤。

> 📱 App（拜訪、幫忙、偷菜、排行榜）　💻 Web（只有每週排行榜，不能玩）
>
> 社交**只有登入帳好嗎 Cloud 的雲端農場**才有。沒登入的單機農場，畫面上不會出現社交的按鈕。

## 為什麼這樣設計

- **全服互通，不做好友系統。** 同一台帳好嗎 Cloud 上、有開農場的帳號彼此都看得到，不需要一個個加好友。
- **友善為主，偷菜是點綴。** 幫忙是雙贏；偷菜有風險、有限制，而且被偷的人會拿到補償，所以偷菜不會變成主要收入，也不會讓人懷恨在心。
- **保護新手，也保護在玩的人。** 新手有保護期；主人正在農場裡的時候不能偷；同一個人對同一座農場有冷卻、每天有次數上限。
- **記帳表現決定排名，不是金額。** 排行榜只出現分數、名次、暱稱和頭像，**絕不出現真實金額或電子郵件**。

## 怎麼操作

### 📱 誰會出現

- 只有**有開啟農場**的雲端帳號會出現。在設定裡關閉農場的人，不會出現在任何列表，也不會被偷。
- 顯示的名字是你的**農場暱稱**（第一次建立雲端農場時取的，之後可以改）。還沒取暱稱的人顯示「尚未取暱稱的農友」，不會顯示帳號或信箱。
- 不想在榜上露臉的話，可以開啟「排行榜匿名」，見[設定、通知與小技巧](./settings.md)。

### 📱 進入社交頁

點農場右上角的「農場社交」（人像圖示），或到「農場 → 設定 → 農場社交」。頁面裡有：

- **每週排行榜**入口。
- **活躍農友 / 可收成農友**分段：前者是最近有上線的人，後者是田裡有作物成熟的人（也就是可能可以偷的目標）。
- **最近互動**：最近發生在你和別人之間的事，被偷之後可以在這裡「回禮」。
- 右上角的名牌圖示：修改你的農場暱稱。

列表裡的 🦝 是「小偷標記」，後面會說明。

![農場社交頁：排行榜入口、活躍與可收成農友分段、最近互動](/img/farm/social-1.png)
*圖中：農場社交頁，上面是每週排行榜入口與農友分段，中間是最近互動，下面是農友清單*

### 📱 拜訪農友

點農友，會進到對方的農場，是和你自己農場一樣的全螢幕畫面：

- 上方顯示對方的名字、你的好幣、「拜訪規則」（ⓘ）、對方現在是**在家還是外出**，有的話還會顯示小偷標記與看門狗。
- 點有作物的田，旁邊會跳出氣泡，**只列出此刻真的做得到的動作**：需要水才有澆水、有雜草才有除草、有蟲才有除蟲、成熟的作物才有偷菜。
- 底部有「留下表情」和「在這裡賣大頭菜」。

進到農友的農場時，會自動留下一個**足跡**（同一個人在一段時間內對同一座農場只會記一次）。對方在自己的農場畫面上方點「**誰來過**」，可以看到最近的訪客與他們做了什麼；有人留下表情時，表情會從農舍飄出來。這些是事後讀取，不是即時推播。

![拜訪農友的畫面：上方顯示農友名稱、在家狀態，底部有留下表情與賣大頭菜](/img/farm/social-2.png)
*圖中：拜訪農友的全螢幕畫面，上方顯示對方狀態，底部是留下表情與賣大頭菜*

### 📱 幫忙

幫農友澆水、除草、除蟲，**雙方都會拿到一點好幣**，是偷菜之外最友善的互動，還會讓你的良心值回升。每天幫忙的次數有上限。

![拜訪時點作物的氣泡：只列出此刻可以做的幫忙動作](/img/farm/social-3.png)
*圖中：點對方有作物的田，氣泡只列出當下做得到的動作，例如幫忙澆水*

### 📱 留下表情

在拜訪畫面底部選「留下表情」，可以送出愛心、讚、向日葵、小芽、慶祝或揮手；表情會從對方的農舍飄起來，對方也能在「誰來過」看到。短時間內不能連續送。文字留言則沒有，省得被亂寫。

![留下表情的選單：愛心、讚、向日葵、小芽、慶祝、揮手](/img/farm/social-4.png)
*圖中：選一個表情送給農友*

### 📱 偷菜

成熟了還沒收成的作物，在別人不在的時候是有機會被偷走的。先看規則：

- **只能偷成熟還沒收成的作物。**
- **主人還在農場遊戲裡就偷不了**（農場、商店、社交等任何農場畫面都算；你自己在拜訪別人時，也算在農場裡）。偷菜按鈕這時會變灰，並告訴你「主人還在農場裡，晚點再來吧」。
- **有新手保護期。** 保護期內，你不能偷別人，別人也不能偷你。
- **同一座農場有冷卻，每天總共能偷的次數有上限，每週對同一座農場也有上限。**
- **得放得下才偷得了。** 你的倉庫和板條箱要有空位，裝不下就不能偷。

偷成功的話：

- 你會拿走那塊田**當期成熟的作物**，並從寶箱抽到隨機的道具（會有開箱畫面）。
- 被偷的那塊田會**休耕一陣子**：不能播種；如果是多次採收的作物，植株保留，但暫停生長。
- 主人會收到通知（短時間內被偷好幾次會合併成一則），通常也會拿到**一部分補償**；如果主人的實力遠高於偷菜的人，就不發補償。

![偷菜成功的開箱畫面：偷到的作物與抽到的道具](/img/farm/social-5.png)
*圖中：偷菜成功後，開箱揭曉偷到的作物與抽到的道具*

### 📱 看門狗、小偷標記與良心值

這幾樣是偷菜的「後果機制」，讓偷菜有風險：

**看門狗**（主人買的道具）
- 在「農場 → 設定 → 看門狗」花好幣購買，保護**一段時間**，到期失效，不能補糧也不能疊加時間，要等到期才能重買。
- 有看門狗時，偷菜有機率被抓到。**被抓的風險會依雙方狀態調整**。拜訪時你能看到對方有沒有狗，也會看到這次被抓的大概機率。
- 被抓到：**偷不到東西**，還要付**罰金**，直接給主人。如果你的好幣不夠付可能的罰金，就不能偷有狗的農場。

**小偷標記** 🦝
- 被看門狗抓到的人，頭上會掛著小偷標記**一段時間**，全服的農友列表、拜訪畫面、排行榜上都看得到。

**良心值**
- 幫忙會讓良心值回升，偷菜會降低，被抓到降得更多；時間久了會慢慢回復。
- 良心值太低時，會**不能偷菜**，賣東西的收購價也會被打折。設定頁裡可以看到自己的良心值。

**回禮**
- 作物被偷後的**一段時間內**，你可以去對方農場，選一塊成熟的田「回禮」偷回去。回禮的限制比一般偷菜寬鬆。
- 入口在「誰來過」或社交頁的「最近互動」，有機會時會出現「回禮」按鈕。

### 📱 在農友的農場賣大頭菜

拜訪時，底部有「在這裡賣大頭菜」。它會用**對方農場當下的收購價**賣，不是你自己的行情，所以你可以去找價格比較高的朋友。你的良心值太低時，收購價會被打折。大頭菜怎麼玩見[賣出、倉庫與大頭菜](./market.md)。

### 📱 每週排行榜

在社交頁點「每週排行榜」。榜單分成好幾種，每種看不同的東西：

| 榜 | 看什麼 |
|---|---|
| 記帳榜 | 你當週的記帳表現分數（和[週結算](./bookkeeping.md)是同一個分數）|
| 收成榜 | 你當週收成作物的整體價值，收成越豐盛排名越前 |
| 偷菜榜 | 你當週成功偷菜的次數，被看門狗抓到的不算 |
| 護農榜 | 你家的看門狗當週成功抓到小偷的次數，幫忙澆水除草不算 |

- 每週結算一次，只顯示**已經結束並完成結算的週次**，可以切換看以前的週。
- 數值越高排名越前，同分的時候由系統依其他條件決定先後。
- 記帳榜上方還會顯示全服的平均分，和你與平均的差距。
- 結算後會發獎勵：名次靠前的人拿到比較好的獎勵，達到基本水準的人也有保底；榜首還會得到稱號（例如「本週帳王」「本週神偷」「本週守護者」），顯示在名字下面；記帳榜的榜首還會得到排行榜裝飾的免費額度，可以在佈置農場時擺上特別的樹木。
- **參與的人太少時**，名次的加碼獎勵會暫停，只發保底獎勵。
- 榜單只會出現分數、名次、暱稱和頭像。想隱藏的人可以開「排行榜匿名」，會顯示成匿名農友。

App 在選榜的清單、Web 在榜的旁邊，都有問號可以點開看「計算方式」，用較白話的方式說明這個榜看什麼。

*圖中：每週排行榜，上方可選榜與週次，中間是你的分數，下面列出名次、暱稱與稱號*

### 💻 在 Web 上

Web 沒有種田的畫面，只提供**農場排行榜**，用來看每週的名次。

1. 登入 Web，點右上角頭像，在選單裡選「農場排行榜」（也可以用 ⌘K 命令面板搜尋「農場排行榜」）。
2. 上方選榜：記帳榜、豐收榜、神偷榜、守護榜（和 App 裡的記帳榜、收成榜、偷菜榜、護農榜是同樣的榜）。
3. 右邊的週次選單可以切換已結算的週次；旁邊的問號可以看「計算方式」。
4. 頁面上會顯示參與人數、記帳榜的平均分與你和平均的差距，下面是名次表，包含農友、分數與獎勵。你的那一列會用主色標示，被看門狗抓到的人旁邊會有 🦝 小偷標記。
5. 想改自己顯示的名字，要到 App 的「農場 → 設定 → 農場暱稱」。

## 注意事項／小提醒

:::tip
- 想在不被偷的情況下安心睡覺？買看門狗，作物成熟了就盡快收。
- 先幫忙再去偷，良心值比較不會見底；常被抓到的話，小偷標記會讓大家都看到。
:::

:::note
- 社交都需要網路；離線時雲端農場只能看最後同步的畫面，不能拜訪或操作。
- 偷菜是遊戲裡的互動，好幣也只是遊戲幣，和真實帳務無關。
- 通知的種類與開關見[設定、通知與小技巧](./settings.md)。
:::
