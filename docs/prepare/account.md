每一筆收支都有一個出處或去處：錢包裡的現金、玉山銀行活存、信用卡、悠遊卡。把這些「放錢的地方」先建成帳戶，之後每次記帳選對帳戶，餘額才會跟真實情況對得上。

這一頁教你建立帳戶清單，並說明常用的進階設定。信用卡的結帳日、繳款日等細節放在 [設定信用卡](../credit-card/setup.md)。

> 📱 App　💻 Web

## 為什麼這樣設計

記帳時**一定要選帳戶**（沒選帳戶按送出會提示「請選擇帳戶」），因為帳戶餘額是用「初始資金＋收入－支出±轉帳」算出來的。先把初始資金設對，之後不用手動維護餘額。

帳戶是所有帳本共用的，換帳本不用重建一次。

## 帳戶類型

新增帳戶時要先選類型，類型決定它在資產頁出現在哪一組、算資產還是負債：

| 類型 | 說明 |
|---|---|
| 現金 | 錢包、零錢 |
| 銀行卡 | 活存、定存、數位帳戶 |
| 信用卡 | 算負債；可設額度、帳單日、還款日 |
| 支付寶、微信、其他 | 其他電子錢包或自訂用途 |
| 不動產、車輛、投資理財、保險、公積金/社保 | 在第二個分頁，算資產 |
| 貸款 | 在第二個分頁，算負債 |
| 主帳戶（群組） | 把多個帳戶收在同一組（見下方） |

新增畫面上方有兩個分頁，第二個分頁名稱含「估值」。它現在只是類型分組，所有類型都一樣會把你記的收支算進餘額，記帳與轉帳時也都選得到。

## 怎麼操作

### 📱 在 App 上

**新增帳戶**

1. 點底部的「資產」，進入「資產管理」頁。
2. 點右上角的「＋」，進入「新建帳戶」頁。
3. 在上方選帳戶類型。
4. 輸入「帳戶名稱」，例如「玉山銀行活存」。名稱不能與現有帳戶重複。
5. 確認「幣種」（新安裝預設 TWD）。
6. 在「初始資金」填入現在帳戶裡的金額，可以先留空。
7. 需要時填「開戶行」「卡號後四位」「備註」，或點「帳戶頭像」選圖。
8. 點「儲存」。

**編輯與刪除**

1. 在資產頁長按帳戶，或進入帳戶明細後點右上角的鉛筆圖示，開啟「編輯帳戶」。
2. 修改後點「儲存」。

要刪除帳戶，在編輯頁最下方點紅色的「刪除」（旁邊是「隱藏帳戶」）。如果帳戶已有交易，系統會提醒有幾筆關聯交易，刪除後那些交易的帳戶欄位會被清空。

### 💻 在 Web 上

1. 點上方導覽的「帳戶」。
2. 點「建立帳戶」，在視窗中選「帳戶類型」，填「帳戶名稱」「幣別」「初始餘額」。
3. 點「建立帳戶」儲存。要改的話點帳戶卡片上的「編輯」，按「更新帳戶」。

Web 上的欄位叫「初始餘額」，App 叫「初始資金」，兩者是同一個意思。

Web 刪除帳戶時，如果帳戶還有交易，會出現兩段式確認，並說明**這些交易會一起被刪除**，無法復原。這和 App 只清空交易上的帳戶欄位不同，要刪之前請先想清楚。

## 初始資金

「初始資金」是你開始用蜜蜂記帳那一刻，帳戶裡已經有的金額。例如銀行帳戶現在有 NT$52,300，就填 52300。

- 信用卡的欄位提示是「目前欠款（填負數）」：目前已經刷了 NT$8,000 還沒繳，就填 -8000。
- 之後如果發現餘額和實際不符，不要去改初始資金，用下面的「調整餘額」補一筆差額比較安全。
- 「主帳戶（群組）」沒有自己的初始資金，它的餘額是底下子帳戶加總。

## 進階設定

### 隱藏帳戶

不再使用的帳戶（例如已結清的舊卡）可以隱藏，而不用刪除。

1. 在帳戶的編輯頁點「隱藏帳戶」，確認「隱藏此帳戶？」。
2. 隱藏後記帳時不會再看到它，歷史交易與餘額都保留。
3. 資產頁最下方會出現「已隱藏」區塊，要用回來時點「恢復」。

Web 上在編輯視窗打開「隱藏帳戶」開關，也能在「已隱藏」區塊按「恢復」。

隱藏時如果它是預設收支帳戶，預設會一併取消；如果有週期性收支還在用它，系統會提醒這些週期帳單隱藏後會跳過產生，建議先改到別的帳戶。

### 隱藏金額 📱

資產頁每一列帳戶右側有一個眼睛圖示，點一下就只遮住這個帳戶的金額，再點一次恢復。適合只想遮住投資或存款帳戶，但不影響其他畫面。要一次遮住全部金額，用「我的」頁右上角的眼睛開關。

這只是畫面上遮起來，不影響淨資產與各項合計。

### 納入總餘額

某些帳戶你想留著記帳，但不想算進淨資產，例如小孩的存錢筒、暫借給朋友的款項帳戶。

1. 資產頁點該帳戶，進入帳戶明細。
2. 切到「帳戶資訊」分頁。
3. 關閉「納入總餘額」。

關閉後帳戶仍然會顯示、也能正常記帳，只是不計入「淨資產」「資產構成」「淨值趨勢」；收支統計不受影響。新建的「投資理財」帳戶預設就是不納入，因為股票市值另外顯示在「投資市值（預估）」卡上。

Web 上這個開關在帳戶編輯視窗裡。

### 主帳戶（群組） 🔖

主帳戶是把幾個帳戶收在一起的容器，有兩種用法：

- **一般群組**：同一家銀行底下的台幣戶與日圓戶，放在「永豐銀行」這個群組下，資產頁會顯示合計，明細頁合併列出所有子帳戶的交易。
- **信用卡合併帳單**：同銀行的多張信用卡共用額度與帳單日。打開群組的「信用卡合併帳單」開關後，才會出現額度、帳單日、還款日欄位。做法見 [設定信用卡](../credit-card/setup.md)。

操作方式：

1. 新增帳戶，類型選最後一個「主帳戶（群組）」，取名後儲存。
2. 編輯要放進群組的帳戶，在「主帳戶（群組）」欄位選這個群組；也可以在下拉選單選「＋新增主帳戶」直接建立。
3. 子帳戶要移出時，選「無（獨立帳戶）」。

群組本身不能直接記帳，記帳時只能選底下的子帳戶。群組內有信用卡時，「信用卡合併帳單」固定為開，不能關。

進入子帳戶的明細頁後，標題旁如果有「▼」，點開可以直接切換到同一群組的其他子帳戶，不用返回再點。

### 排序與滑動快捷 📱

**調整順序**

1. 資產頁右上角點齒輪「設定」。
2. 選「編輯排序」，右上角會變成「完成」。
3. 按住帳戶右側的拖曳把手上下移動；有子帳戶的群組，群組之間和子帳戶之間各自排序。
4. 點「完成」。

排序只能在同一類型內調整，也不能把子帳戶拖進別的群組。排序會同步到其他裝置。Web 的帳戶頁也有「編輯排序」。

**滑動快捷**

在資產頁把帳戶卡片向右滑，會露出「調整餘額」；向左滑會露出「新增交易」（自動帶入這個帳戶）。再點一下露出的色塊才會執行。投資理財帳戶預設右滑買進、左滑賣出。

想改成別的動作，到「我的」→「個性化設定」的「滑動快捷操作」，可選「無」「調整餘額」「新增交易」「編輯」，兩邊都選「無」就是關閉。

**預設收支帳戶**

資產頁齒輪裡可以設定「預設支出帳戶」「預設收入帳戶」，之後新增交易會自動帶入，不想要就選「不設定」。

### 調整餘額

帳上的數字跟實際不一樣時（例如忘了記幾筆小額花費），用「調整餘額」一次補平：

1. 資產頁點帳戶，進入帳戶明細。
2. 點標題列的「調整餘額」圖示（或用上面的滑動快捷）。
3. 在「調整總額」視窗輸入「調整後的餘額」，可加備註。
4. 點確定。系統會用「調整後餘額－目前餘額」建立一筆「餘額調整」交易。

Web 上在帳戶詳情視窗找「調整餘額」，輸入「目標餘額」後按「確認調整」。

詳細說明見 [餘額調整](../reconciliation/adjust.md)。

## 注意事項／小提醒

:::tip 先建幾個就好
一開始建現金、常用的銀行帳戶、常刷的信用卡就夠了。之後記帳時發現漏了再補，隨時都能新增。
:::

:::note 帳戶已有交易就不能改幣種
帳戶一旦有交易記錄，「幣種」就會鎖住，系統會提示無法變更。要用別的幣別，請另外建一個帳戶。
:::

:::note 調整餘額的限制
調整出來的交易不能編輯，要改只能刪除後重新調整；「主帳戶（群組）」與投資理財帳戶沒有「調整餘額」。投資理財帳戶的餘額是持股成本，請改用買進、賣出記錄，見 [股票持股](../invest/overview.md)。
:::

:::warning 記帳沒選到帳戶
自動記帳等背景流程找不到帳戶時，交易會先記下並標為「待確認帳戶」。資產頁會出現「待確認帳戶」入口，逐筆補選帳戶後才會計入餘額。
:::
